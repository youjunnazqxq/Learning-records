这份讲义的核心思想是解决**动态连通性（Dynamic Connectivity）**问题。简单来说，就是在一堆元素中，高效地处理两个核心操作：

1. `connect(x, y)`：将两个元素 `x` 和 `y` 连接起来。
    
2. `isConnected(x, y)`：检查两个元素 `x` 和 `y` 是否已经连通（可以是间接连通）。
    

下面是讲义中提到的几种实现方法，从最笨的到最高效的演进过程：

---

### 1. 最初的尝试：`ListOfSets` (用集合列表实现)

这是最直观的想法。我们用一个列表来存放所有互相连通的组件，每个组件本身是一个集合

`Set`。

- **想法**：`List<Set<Integer>>`。例如 `[{0, 1, 4}, {2, 3}, {5}]` 表示 0,1,4 在一个组，2,3 在一个组，5 自己一个组。
    
- **缺点**：非常慢！无论是
    
    `connect` 还是 `isConnected` 操作，都可能需要遍历整个列表来找到元素所在的集合，时间复杂度最差是 O(N)。
    

---

### 2. 第一次优化：`QuickFind` (快速查找)

为了提高查找效率，我们换一种数据结构：一个整数数组

`id[]`。

- **想法**：`id[i]` 存储元素 `i` 所属集合的唯一标识（ID）。如果 `id[p] == id[q]`，那么 `p` 和 `q` 就是连通的。
    
- **优点**：`isConnected(p, q)` 操作非常快，只需要一次数组访问，时间复杂度是 Θ(1)。
    
- **缺点**：`connect(p, q)` 操作很慢。为了合并两个集合，需要遍历整个数组，把所有属于一个集合的元素的 ID 修改为另一个集合的 ID，时间复杂度是
    
    Θ(N)。
    

---

### 3. 思路转变：`QuickUnion` (快速合并)

既然 `connect` 操作太慢，我们尝试优化它。这次 `id[]` 数组的含义变了。

- **想法**：数组 `parent[i]` 存储元素 `i` 的**父节点**。 这样，每个集合就构成了一棵树。一个集合的代表就是这棵树的
    
    **根节点**。
    
- **如何工作**：
    
    - `connect(p, q)`：先分别找到 `p` 和 `q` 的根节点，然后将一个根节点连接到另一个根节点上，只需要修改一次数组，非常快。
        
    - `isConnected(p, q)`：检查它们是否拥有相同的根节点。
        
- **新问题**：树可能会变得又高又瘦，像一根链条。在最坏的情况下，查找根节点需要一直往上爬，
    
    `connect` 和 `isConnected` 的时间复杂度都会退化到 O(N)。
    

---

### 4. 关键优化：`WeightedQuickUnion` (加权快速合并)

为了解决 `QuickUnion` 中树可能过高的问题，我们引入一个简单的优化策略。

- **想法**：在合并两棵树时，不再随意连接，而是**总是将小树连接到大树的根上**。树的大小（权重）通常指树中节点的数量。
    
- **优点**：这个简单的改动能有效地保持树的平衡，防止它变得过高。树的高度被限制在 log(N) 级别。
    
- **结果**：`connect` 和 `isConnected` 的时间复杂度都优化到了 O(logN)。这对于绝大多数应用来说已经足够快了。
    

---

### 5. 终极优化：`Path Compression` (路径压缩)

这是在 `WeightedQuickUnion` 基础上的一个锦上添花的技巧。

- **想法**：当我们在一次查询中从某个节点出发去寻找根节点时，把这条路径上经过的所有节点**直接连接到根节点上**。
    
- **优点**：这会让树变得极其扁平。经过多次操作后，几乎所有节点的父节点就是根节点。
    
- **结果**：加上路径压缩后，操作的平均时间复杂度接近**常数时间**，其上界由一个增长极其缓慢的函数 α(N) (反阿克曼函数) 决定。对于任何实际大小的输入，
    
    α(N) 的值都不会超过 5，所以可以认为它几乎是 O(1) 的、、

```
public class ex06_union {  
    private int [] parent;  
    public ex06_union(int N){  
        parent = new int [N];  
        for(int i = 0; i < N; i++){  
            parent[i] = -1;  
        }  
    }  
    public int find(int x){  
     int current =x;  
     while(parent[current]>=0){  
         current=parent[current];  
     }  
     int path_find_root=current;  
     int find_path=x;  
     while(find_path!=current){  
         int next_node=parent[find_path];  
         parent[find_path]=current;  
         find_path=next_node;  
     }  
     return current;  
    }  
    public int find_re(int x){  
        if(parent[x]<0){  
                return x;  
        }  
        int root=find_re(parent[x]);  
        parent[x]=root;  
        return root;  
    }  
  
    public boolean isconnected(int a,int b){  
        return find(a)==find(b);  
    }  
    public void connect(int a,int b){  
        int root_A=find(a);  
        int root_B=find(b);  
        if(root_B==root_A){  
            return;  
        }  
        /*a的权重大*/  
        if(parent[root_B]>parent[root_A]){  
            parent[root_A]+=parent[root_B];  
            parent[root_B]=root_A;  
        }else{  
            parent[root_B]+=parent[root_A];  
            parent[root_A]=root_B;  
        }  
    }  
}
```
