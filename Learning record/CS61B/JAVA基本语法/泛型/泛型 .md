# 知识点：泛型 (Generics / 泛式) - 基本语法

## 1. 概念回顾（简洁版）

泛型允许你编写**类型不固定**的代码。你可以用一个**类型占位符**（如 `T`, `E`），在实际使用时再指定这个占位符代表的具体类型。核心目的是提供**编译时的类型安全**和**代码复用**。

## 2. 泛型语法的核心结构

泛型语法主要体现在声明类、接口和方法时。

### 2.1 泛型类 (Generic Class) 的基本语法

- **目的**：创建一个可以操作任何指定类型的类。
    
- **语法**：在类名后面，用尖括号 `<>` 声明一个或多个类型参数。
    
- **示例**：
    
    Java
    
    ```
    // 泛型类定义：Box 可以存放任意类型的物品 T
    public class Box<T> { // <T> 声明类型参数 T
        private T item; // 成员变量的类型是 T
    
        public Box(T item) { // 构造器的参数类型是 T
            this.item = item;
        }
    
        public T getItem() { // 方法返回类型是 T
            return item;
        }
    
        public void setItem(T item) { // 方法参数类型是 T
            this.item = item;
        }
    }
    
    // 如何使用 (实例化) 泛型类：
    // 创建一个存放 String 的 Box
    Box<String> stringBox = new Box<>("Hello");
    String s = stringBox.getItem(); // 直接获取 String 类型
    
    // 创建一个存放 Integer 的 Box
    Box<Integer> intBox = new Box<>(123);
    int i = intBox.getItem(); // 直接获取 Integer 类型
    ```
    

### 2.2 泛型接口 (Generic Interface) 的基本语法

- **目的**：定义一个可以操作任何指定类型的方法集合（规范）。
    
- **语法**：在接口名后面，用尖括号 `<>` 声明一个或多个类型参数。
    
- **示例**：
    
    Java
    
    ```
    // 泛型接口定义：MyComparator 用于比较任意类型 T 的对象
    public interface MyComparator<T> { // <T> 声明类型参数 T
        int compare(T o1, T o2); // 方法参数类型是 T
    }
    
    // 如何使用 (实现) 泛型接口：
    class IntegerComparator implements MyComparator<Integer> { // 实现时指定具体类型 Integer
        @Override
        public int compare(Integer o1, Integer o2) {
            return o1.compareTo(o2);
        }
    }
    
    // 使用示例：
    MyComparator<Integer> comparator = new IntegerComparator();
    int result = comparator.compare(5, 10); // 结果 -5
    ```
    

### 2.3 泛型方法 (Generic Method) 的基本语法

- **目的**：定义一个可以处理任何指定类型的方法，而不管它所在的类是否是泛型类。
    
- **语法**：在方法的**返回类型之前**，用尖括号 `<>` 声明一个或多个类型参数。
    
- **示例**：
    
    Java
    
    ```
    public class ArrayUtils {
        // 泛型方法定义：可以打印任意类型的数组
        // <T> 在 public static 后面，返回值 void 前
        public static <T> void printArray(T[] array) { // 方法参数类型是 T[]
            for (T element : array) { // 循环变量类型是 T
                System.out.print(element + " ");
            }
            System.out.println();
        }
    
        // 另一个泛型方法：查找数组中的最大值 (T 必须是可比较的)
        // <T extends Comparable<T>> 表示 T 必须实现 Comparable 接口
        public static <T extends Comparable<T>> T findMax(T[] array) {
            if (array == null || array.length == 0) {
                return null;
            }
            T max = array[0];
            for (int i = 1; i < array.length; i++) {
                if (array[i].compareTo(max) > 0) { // 可以调用 compareTo 方法，因为 T 实现了 Comparable
                    max = array[i];
                }
            }
            return max;
        }
    }
    
    // 如何使用 (调用) 泛型方法：
    Integer[] intArray = {1, 5, 2, 8, 3};
    ArrayUtils.<Integer>printArray(intArray); // 显式指定类型参数 (通常可以省略，编译器能推断)
    // 实际调用时，通常省略 <Integer>：
    ArrayUtils.printArray(intArray); // 编译器会自动推断 T 为 Integer
    
    String[] stringArray = {"apple", "banana", "cherry"};
    ArrayUtils.printArray(stringArray); // 编译器会自动推断 T 为 String
    
    System.out.println("Max int: " + ArrayUtils.findMax(intArray)); // 输出 Max int: 8
    System.out.println("Max string: " + ArrayUtils.findMax(stringArray)); // 输出 Max string: cherry
    ```
    

### 2.4 泛型通配符 (Wildcards) 的基本语法

- **目的**：增加泛型使用的灵活性，处理未知或受限制的泛型类型集合。
    
- **语法**：使用问号 `?` 结合 `extends` 或 `super` 关键字。
    
- **示例**：
    
    Java
    
    ```
    public class ListProcessor {
        // 无界通配符：可以接受任意类型的 List，但只能读取 Object 类型，不能添加
        public static void printList(List<?> list) {
            for (Object o : list) {
                System.out.print(o + " ");
            }
            System.out.println();
            // list.add("test"); // 编译错误！不能添加元素
        }
    
        // 上界通配符：接受 Number 或其子类的 List，可以读取 Number 类型
        public static double sumOfNumbers(List<? extends Number> list) {
            double sum = 0;
            for (Number num : list) { // 可以读取 Number 类型
                sum += num.doubleValue();
            }
            // list.add(new Integer(10)); // 编译错误！不能添加元素
            return sum;
        }
    
        // 下界通配符：接受 Integer 或其父类的 List，可以添加 Integer 或其子类
        public static void addIntegers(List<? super Integer> list) {
            list.add(1); // 可以添加 Integer
            list.add(new Integer(2)); // 可以添加 Integer
            // Integer i = list.get(0); // 编译错误！只能获取 Object 类型
            Object o = list.get(0); // 只能获取 Object
        }
    }
    
    // 使用示例：
    List<Integer> ints = Arrays.asList(1, 2, 3);
    List<Double> doubles = Arrays.asList(1.1, 2.2, 3.3);
    List<String> strings = Arrays.asList("A", "B");
    
    ListProcessor.printList(ints); // 输出: 1 2 3
    ListProcessor.printList(strings); // 输出: A B
    
    System.out.println("Sum of ints: " + ListProcessor.sumOfNumbers(ints)); // 输出: 6.0
    System.out.println("Sum of doubles: " + ListProcessor.sumOfNumbers(doubles)); // 输出: 6.6
    
    List<Number> numbers = new ArrayList<>();
    ListProcessor.addIntegers(numbers); // 可以向 List<Number> 中添加 Integer
    System.out.println("Numbers list after adding: " + numbers); // 输出: [1, 2]
    ```
    

## 3. 作用（简单总结）

- **类型安全**：编译时检查，避免运行时 `ClassCastException`。
    
- **减少强制类型转换**：代码更简洁。
    
- **代码复用**：一次编写，多类型适用。
    
- **更好的 API 设计**：例如 Java 集合框架。




## 泛式数组

基本语法 ...[] a= (... []) new Object [?]

Java

```
Glorp[] a = (Glorp []) new Object[cap];
```

你问到后面的 `Object` 又是什么。这里的 `Object` 是 Java 中所有类的**根类 (Root Class)**。

### `new Object[cap]` 是什么意思？

- **`new` 关键字**：用于创建一个新的对象或数组。
    
- **`Object`**：这是 Java 语言中所有类的基类。这意味着任何 Java 对象（包括你自定义的类、`String`、`Integer` 等）都可以向上转型为 `Object` 类型。
    
- **`[cap]`**：表示你正在创建一个数组，并且数组的长度由变量 `cap`（capacity 的缩写，表示容量）决定。
    

所以，`new Object[cap]` 的完整含义是：

**创建一个新的、长度为 `cap` 的 `Object` 类型的数组。**

### 为什么这里要创建 `Object` 数组？

这再次回到我们之前讨论的**类型擦除**和**不能直接创建泛型数组**的问题：

1. **不能直接 `new Glorp[cap]`**：
    
    - 在 Java 中，由于泛型的**类型擦除**，编译器在运行时并不知道 `Glorp` 究竟是 `String`、`Integer` 还是你自定义的 `MyClass`。
        
    - 数组在创建时必须知道其确切的**组件类型**（Component Type）。例如，`new String[10]` 在运行时会创建一个专门存放 `String` 对象的数组，`new Integer[10]` 则创建一个存放 `Integer` 对象的数组。
        
    - 因为运行时 `Glorp` 的具体类型已经丢失，所以 `JVM` 无法知道要创建一个什么“特定类型”的数组。直接写 `new Glorp[cap]` 会导致编译错误。
        
2. **`Object[]` 是通用的解决方案**：
    
    - 由于 `Object` 是所有类的父类，一个 `Object[]` 数组可以存放任何类型的对象（因为任何对象都可以被向上转型为 `Object`）。
        
    - 所以，当你需要一个泛型数组（例如 `Glorp[]`）来作为内部存储（比如链表的 `items` 数组或 `ArrayList` 的内部数组）时，常见的做法就是先创建一个**最通用的 `Object[]` 数组**。
        

### 总结 `(Glorp []) new Object[cap]` 这整行：

- `new Object[cap]`：在内存中创建了一个可以存放 `cap` 个 `Object` 类型元素的数组。
    
- `(Glorp [])`：这是一个**强制类型转换**。它告诉编译器：“我知道 `new Object[cap]` 创建的是一个 `Object[]`，但我现在要把它当作 `Glorp[]` 来使用，我保证我只会往里面放 `Glorp` 类型（或其子类型）的对象。”
    
- `Glorp[] a = ...`：将这个经过类型转换后的 `Object[]` 引用赋值给 `Glorp[]` 类型的变量 `a`。
