## 1. 编译时 (Compile Time) 与 运行时 (Run Time) 的差异

|特性|编译时 (Compile Time)|运行时 (Run Time)|
|---|---|---|
|**阶段**|代码被 Java 编译器 (javac) 翻译成字节码 (.class 文件)。|字节码被 Java 虚拟机 (JVM) 加载、解释或即时编译并执行。|
|**关注点**|**语法检查、类型检查、签名绑定**。|**程序执行、内存管理、动态行为**。|
|**关键概念**|**静态类型 (Static Type)**：变量声明的类型。|**动态类型 (Dynamic Type)**：对象实际的类型。|
|**方法调用**|**确定方法签名**：根据变量的静态类型查找方法。|**动态方法选择 (Dynamic Method Dispatch)**：根据对象的动态类型查找并执行具体的方法实现。|
|**错误类型**|**编译错误 (Compile-time Error)**：语法错误、类型不匹配、方法不存在等。|**运行时错误 (Runtime Error)**：如 `NullPointerException` (空指针), `ArrayIndexOutOfBoundsException` (数组越界), `ClassCastException` (类转换异常), `StackOverflowError` (栈溢出) 等。|
|**主要目标**|确保代码语法正确、类型安全，生成可执行的字节码。|实际运行程序，执行业务逻辑，处理数据。|

## 2. 兼容性 (Compatibility) - 子类型多态 (Subtype Polymorphism)

- **核心理念**：子类对象可以被当做父类对象来使用，因为子类“is-a”（是一种）父类。
    
- **体现**：一个**父类类型**的变量可以引用一个**子类对象**。
    
    - **语法**：`父类类型 变量名 = new 子类构造器();`
        
    - **示例**：`Animal animal = new Dog();`
        
- **编译时**：
    
    - 编译器会根据变量的**静态类型**（`Animal`）来检查其是否拥有被调用的方法。
        
    - 编译器认为这种赋值是安全的，因为它总是将一个更具体的类型转换为一个更通用的类型。
        
- **运行时**：
    
    - JVM 会根据变量实际引用的对象（即其**动态类型**，`Dog`）来执行方法。如果子类重写了该方法，就会调用子类的实现。
        
- **优点**：
    
    - **多态性**：使得代码更灵活、更通用。你可以编写处理父类类型的方法，而这些方法能够无缝地处理所有子类的对象。
        
    - **代码复用**：父类定义的通用行为可以在所有子类中复用，或者被子类特化。
        
    - **降低耦合**：代码可以面向接口或抽象编程，无需关心具体实现。
        

## 3. 类型转型 (Type Casting)

类型转型是指在 Java 中将一个对象的类型从一种类型转换为另一种类型。它分为两种：

### 3.1 向上转型 (Upcasting)

- **概念**：将**子类类型**的引用转换为**父类类型**的引用。
    
- **语法**：**自动进行**，无需显式强制转换。
    
- **示例**：
    
    Java
    
    ```
    Dog myDog = new Dog();
    Animal animalRef = myDog; // 自动向上转型，将 Dog 引用赋给 Animal 类型变量
    ```
    
- **安全性**：**总是安全的**，因为子类总是包含父类的所有成员。不会在运行时抛出 `ClassCastException`。
    
- **目的**：实现多态，用更通用的类型来处理对象。
    

### 3.2 向下转型 (Downcasting)

- **概念**：将**父类类型**的引用转换为**子类类型**的引用。
    
- **语法**：**必须显式强制转换**，使用括号 `()`。
    
- **示例**：
    
    Java
    
    ```
    Animal animalRef = new Dog(); // 首先向上转型
    Dog myDogRef = (Dog) animalRef; // 显式向下转型
    ```
    
- **安全性**：**不总是安全的**。如果在运行时，被转换的父类引用实际指向的不是目标子类类型或其子类型，就会抛出 `ClassCastException`。
    
    Java
    
    ```
    Animal anotherAnimal = new Cat(); // Cat 也是 Animal 的子类
    // Dog anotherDog = (Dog) anotherAnimal; // 编译通过，但运行时会抛 ClassCastException
    ```
    
- **运行时检查**：JVM 会在运行时对向下转型进行检查，以确保类型转换的合法性。
    
- **目的**：
    
    - 当需要调用子类特有的方法时（这些方法在父类中不存在）。
        
    - 通常在使用 `instanceof` 运算符进行类型检查后再进行，以避免 `ClassCastException`。
        
    
    Java
    
    ```
    if (animalRef instanceof Dog) { // 在向下转型前进行检查
        Dog dog = (Dog) animalRef;
        dog.bark(); // 调用 Dog 特有的方法
    }
    ```
    

### 总结：

理解编译时和运行时的行为是掌握 Java 类型系统和面向对象编程的关键。

- **编译时**：负责代码的**静态检查**和方法签名的**绑定**，依赖于变量的**静态类型**。
    
- **运行时**：负责代码的**实际执行**和方法的**动态选择**，依赖于对象的**动态类型**。
    
- **兼容性（向上转型）**：子类对象可以安全地被视为父类对象，是多态的基础。
    
- **类型转型（向下转型）**：将父类引用转换为子类引用，需要显式操作，且存在运行时风险。
