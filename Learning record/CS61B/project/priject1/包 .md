

### 1. 为什么需要包？（组织与隔离）

- **组织代码**：当一个项目变得越来越大时，会有很多个 `.java` 文件。将功能相关的类放在同一个包里，可以让项目结构更清晰，更容易维护 1。
    
    - **项目示例**：在您的项目中，所有与“双端队列 (Deque)”数据结构相关的代码（如 `LinkedListDeque` 和 `ArrayDeque`）都应该放在 `deque` 包里。而所有与“吉他英雄”功能相关的代码（如 `GuitarString`）都放在 `gh2` 包里 2。这样逻辑就非常清楚。
        
- **避免命名冲突 (Name Conflicts)**：想象一下，如果你在项目中写了一个叫 `List` 的类，但同时又想使用 Java 自带的 `java.util.List` 类，程序怎么知道你指的是哪一个呢？包解决了这个问题。
    
    - **类比**：就像你的手机通讯录里有两个都叫“张伟”的朋友。为了区分他们，你可能会备注成“同事张伟”和“同学张伟”。这里的“同事”和“同学”就扮演了包的角色。
        
    - **实际例子**：一个大型软件可能会同时使用两个不同公司开发的数据库工具，而这两个工具可能都提供了一个名为 `Connection` 的类。如果它们分别在 `com.companyA.db` 和 `com.companyB.db` 这两个不同的包里，我们就可以清楚地区分和使用它们。
        

### 2. 如何使用包？

#### **a. 如何将类放入包中？**

正如图片中所示，你需要在

`.java` 文件的 **第一行** 使用 `package` 关键字来声明这个文件属于哪个包 3。

Java

```
package deque; // 这句话必须是文件的第一句代码

public class ArrayDeque<T> {
    // ... 你的代码 ...
}
```

**重要提示**：文件的物理位置必须与包名匹配。也就是说，`ArrayDeque.java` 这个文件必须存放在一个名为 `deque` 的文件夹里。

#### **b. 如何使用其他包中的类？**

你有两种方法来使用另一个包中的类，比如在 `main` 方法中使用你写的 `ArrayDeque`：

- 方法一：使用完全限定的规范名称 (Canonical Name)
    
    你每次使用时都写出它的“全名”，即“包名.类名” 4。
    
    Java
    
    ```
    public class Main {
        public static void main(String[] args) {
            // 这里写全名 deque.ArrayDeque
            deque.ArrayDeque<String> myDeque = new deque.ArrayDeque<>();
            myDeque.addFirst("hello");
        }
    }
    ```
    
    这种方法的好处是绝对不会弄错，但缺点是写起来很繁琐。
    
- 方法二：使用 import 语句 (推荐)
    
    在文件的开头（
    
    `package` 语句之后）使用 `import` 关键字，相当于告诉编译器：“我接下来要用到 `ArrayDeque` 这个类，你从 `deque` 这个包里帮我找就行了” 5。之后你就可以直接使用它的“简单名称”
    
    `ArrayDeque` 了。
    
    Java
    
    ```
    package some_other_package;
    
    // 使用 import 导入
    import deque.ArrayDeque;
    
    public class Main {
        public static void main(String[] args) {
            // 现在可以直接使用简单名称 ArrayDeque
            ArrayDeque<String> myDeque = new ArrayDeque<>();
            myDeque.addFirst("hello");
        }
    }
    ```
    
    这就是
    
    `import` 语句的作用：让你能用更简洁的方式（简单名称）来使用其他包里的类
