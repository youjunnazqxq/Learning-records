
### 基本语法

最核心的语法是：

cd [目录路径]

这里的 `[目录路径]` 可以是绝对路径，也可以是相对路径。

---

### 常用命令示例

1. 切换到子目录
    
    切换到当前目录下的一个子目录。
    
    Bash
    
    ```
    # 切换到名为 documents 的子目录
    cd documents
    ```
    
2. 切换到父目录
    
    使用 .. (两个点) 代表上一级目录。
    
    Bash
    
    ```
    # 返回到上一级目录
    cd ..
    ```
    
    你也可以连续使用它来跳到更上层的目录：
    
    Bash
    
    ```
    # 返回到上两级目录
    cd ../..
    ```
    
3. 切换到用户主目录 (Home Directory)
    
    这是你登录后通常所在的目录。
    
    - 方法一：使用 ~ (波浪号)
        
        ~ 是主目录的快捷方式。
        
        Bash
        
        ```
        cd ~
        ```
        
    - 方法二：直接输入 cd
        
        不带任何参数的 cd 命令默认就是切换到主目录。
        
        Bash
        
        ```
        cd
        ```
        
4. 切换到根目录 (Root Directory)
    
    根目录是整个文件系统的最顶层。
    
    Bash
    
    ```
    # 切换到根目录
    cd /
    ```
    
5. 使用绝对路径切换
    
    从文件系统的根目录开始的完整路径。无论你当前在哪里，它都会将你带到指定位置。
    
    Bash
    
    ```
    # 切换到 /var/log 目录 (macOS/Linux)
    cd /var/log
    
    # 切换到 C:\Users\YourUser\Desktop 目录 (Windows Git Bash)
    cd /c/Users/YourUser/Desktop
    ```
    
6. 切换到上一个工作目录
    
    使用 - (一个连字符) 可以让你在前两个目录之间快速来回切换，非常方便。
    
    Bash
    
    ```
    cd -
    ```
    

### 辅助命令

在使用 `cd` 时，有两个命令几乎总是一起使用，能帮你确定位置：

- **`pwd` (Print Working Directory)**：显示你**当前**所在的目录路径。
    
    Bash
    
    ```
    pwd
    ```
    
- **`ls` (List)**：列出当前目录下的文件和子目录，这样你就知道接下来可以 `cd` 到哪里。
    
    Bash
    
    ```
    ls
    ```
