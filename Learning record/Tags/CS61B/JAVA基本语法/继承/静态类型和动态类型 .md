
### 1. 静态类型 (Static Type)

- **定义**：静态类型（也称为**编译时类型**）是指**变量在声明时所使用的类型**。这个类型是在编译阶段就确定的，不能改变。
    
- **特点**：
    
    - 在编译时，编译器会根据变量的静态类型来检查它是否能够调用某个方法或访问某个属性。如果静态类型中没有定义该方法或属性，即使实际对象有，编译器也会报错。
        
    - 它限制了变量可以引用的对象的类型范围。一个变量的静态类型决定了它能引用什么类型的对象（只能引用自身类型或其子类型的对象）。
        
- **示例**：
    
    Java
    
    ```
    List list = new ArrayList(); // 变量 list 的静态类型是 List
    Animal animal = new Dog();   // 变量 animal 的静态类型是 Animal
    ```
    
    在这个例子中，`list` 的静态类型是 `List` 接口，`animal` 的静态类型是 `Animal` 类。
    

### 2. 动态类型 (Dynamic Type)

- **定义**：动态类型（也称为**运行时类型**或**实际类型**）是指**变量实际引用（指向）的对象的类型**。这个类型是在程序运行阶段才确定的，因为变量在运行时可能指向不同类型的对象（只要这些对象是其静态类型的子类型）。
    
- **特点**：
    
    - 动态类型决定了实际调用哪个方法实现。当通过一个变量调用方法时，Java 虚拟机 (JVM) 会根据该变量所引用的对象的动态类型来查找并执行对应的方法。
        
    - 它是在运行时才能确定的。
        
- **示例**：
    
    Java
    
    ```
    List list = new ArrayList(); // 变量 list 引用的对象的动态类型是 ArrayList
    Animal animal = new Dog();   // 变量 animal 引用的对象的动态类型是 Dog
    ```
    
    在这个例子中，`list` 变量实际引用的是一个 `ArrayList` 对象，所以它的动态类型是 `ArrayList`。`animal` 变量实际引用的是一个 `Dog` 对象，所以它的动态类型是 `Dog`。
    

### 静态类型与动态类型的关系：

1. **静态类型是动态类型的父类型或自身类型**：一个变量的动态类型永远是其静态类型本身，或者是其静态类型的子类型。例如，如果变量的静态类型是 `Animal`，那么它引用的对象可以是 `Animal` 类型，也可以是 `Dog`、`Cat` 等 `Animal` 的子类型。
    
2. **编译时看静态，运行时看动态**：
    
    - **编译时**：编译器根据变量的**静态类型**来检查代码的合法性（例如，能否调用某个方法）。
        
    - **运行时**：JVM 根据对象的**动态类型**来决定实际执行哪个方法（这就是动态方法选择或后期绑定）。
        

### 示例演示：

Java

```
class Animal {
    public void makeSound() {
        System.out.println("Animal makes a sound");
    }
    public void eat() {
        System.out.println("Animal eats food");
    }
}

class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Dog barks");
    }
    public void fetch() {
        System.out.println("Dog fetches a ball");
    }
}

public class TypeExample {
    public static void main(String[] args) {
        // 静态类型是 Animal，动态类型是 Dog
        Animal myAnimal = new Dog();

        // 编译时：编译器看到 myAnimal 的静态类型是 Animal。
        // Animal 类有 makeSound() 方法，所以编译通过。
        // 运行时：myAnimal 实际指向 Dog 对象，JVM 调用 Dog 类的 makeSound()。
        myAnimal.makeSound(); // 输出: Dog barks

        // 编译时：编译器看到 myAnimal 的静态类型是 Animal。
        // Animal 类有 eat() 方法，所以编译通过。
        // 运行时：myAnimal 实际指向 Dog 对象，Dog 没有重写 eat()，所以调用 Animal 类的 eat()。
        myAnimal.eat();       // 输出: Animal eats food

        // 编译时：编译器看到 myAnimal 的静态类型是 Animal。
        // Animal 类没有 fetch() 方法，所以编译报错！
        // myAnimal.fetch(); // 这行代码会引发编译错误

        // 如果想调用 fetch()，必须将变量转换为 Dog 类型 (需要运行时类型检查)
        if (myAnimal instanceof Dog) {
            Dog myDog = (Dog) myAnimal; // 静态类型和动态类型都是 Dog
            myDog.fetch();              // 输出: Dog fetches a ball
        }
    }
}
```

在这个例子中：

- `myAnimal` 变量的**静态类型**是 `Animal`。
    
- `myAnimal` 变量引用的对象的**动态类型**是 `Dog`。
    

理解这两个概念对于掌握 Java 的多态性（Polymorphism）和方法重写（Method Overriding）至关重要。
