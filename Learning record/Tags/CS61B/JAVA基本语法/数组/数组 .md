# Java 中数组的基本语法

在 Java 中，数组是一种用于存储多个同类型数据的固定大小的结构。以下是 Java 中数组的基本语法和相关规则。

## 1. 数组的声明

数组需要显式声明其类型和名称。声明时使用 `[]` 表示数组。

```java
数据类型[] 数组名; // 推荐方式
// 或者
数据类型 数组名[]; // 也有效，但不常用
```

- **示例**：

```java
int[] numbers; // 声明一个整数数组
String[] names; // 声明一个字符串数组
```

## 2. 数组的初始化

声明数组后，需要分配内存并初始化。可以使用以下方式：

- **显式指定大小**：

```java
数据类型[] 数组名 = new 数据类型[大小];
```

- **直接初始化元素**：

```java
数据类型[] 数组名 = {元素1, 元素2, ...};
```

- **示例**：

```java
int[] numbers = new int[5]; // 分配5个整数的数组，默认值0
String[] names = {"Alice", "Bob", "Charlie"}; // 直接初始化
```

## 3. 访问和修改数组元素

数组元素通过索引访问，索引从 `0` 开始，到 `长度-1` 结束。

```java
数组名[索引] = 值; // 修改元素
值 = 数组名[索引]; // 访问元素
```

- **示例**：

```java
int[] numbers = new int[3];
numbers[0] = 10; // 第一个元素
numbers[1] = 20;
numbers[2] = 30;
System.out.println(numbers[1]); // 输出 20
```

## 4. 数组长度

数组长度是固定的，可以通过 `length` 属性获取。

```java
int 长度 = 数组名.length;
```

- **示例**：

```java
int[] numbers = {1, 2, 3, 4, 5};
System.out.println(numbers.length); // 输出 5
```

## 5. 数组的遍历

可以使用 `for` 循环遍历数组元素。

```java
for (int i = 0; i < 数组名.length; i++) {
    System.out.println(数组名[i]);
}
```

- **示例**：

```java
int[] numbers = {10, 20, 30};
for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]); // 输出 10, 20, 30
}
```

## 6. 多维数组

Java 支持多维数组，最常见的是二维数组，类似于表格。

- **声明和初始化**：

```java
数据类型[][] 数组名 = new 数据类型[行数][列数];
数据类型[][] 数组名 = {{元素1, 元素2}, {元素3, 元素4}};
```

- **示例**：

```java
int[][] matrix = new int[2][3]; // 2行3列
matrix[0][0] = 1;
matrix[0][1] = 2;
matrix[1][0] = 3;

int[][] matrix2 = {{1, 2, 3}, {4, 5, 6}};
System.out.println(matrix2[1][2]); // 输出 6
```

## 7. 数组的默认值

- 数值类型（`int`, `double` 等）：`0`
    
- 布尔类型（`boolean`）：`false`
    
- 对象类型（`String`, 自定义类等）：`null`
    
- **示例**：
    

```java
int[] numbers = new int[3];
System.out.println(numbers[0]); // 输出 0
```

## 8. 注意事项

- 数组大小在初始化后不可更改（固定长度）。
- 访问超出索引范围（例如 `numbers[5]` 当 `length` 为 3 时）会抛出 `ArrayIndexOutOfBoundsException`。
- 数组是对象类型，存储在堆内存中，引用传递。

## 9. 综合示例

```java
public class ArrayExample {
    public static void main(String[] args) {
        int[] numbers = new int[4];
        numbers[0] = 5;
        numbers[1] = 10;
        numbers[2] = 15;
        numbers[3] = 20;

        for (int i = 0; i < numbers.length; i++) {
            System.out.println("Element at index " + i + ": " + numbers[i]);
        }

        int[][] matrix = {{1, 2}, {3, 4}};
        System.out.println("Matrix[1][0]: " + matrix[1][0]); // 输出 3
    }
}
```
