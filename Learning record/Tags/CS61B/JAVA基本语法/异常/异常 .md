
1. **`try` - 尝试执行**
    
    - **语法**: `try { ... }`
        
    - **作用**: 你把**可能会**抛出异常的“风险代码”放在 `try` 的大括号 `{}` 里。这是你的“A计划”。
        
2. **`catch` - 捕获问题**
    
    - **语法**: `catch (ExceptionType e) { ... }`
        
    - **作用**: `catch` 紧跟在 `try` 后面，就像是“B计划”。如果 `try` 块里的代码真的抛出了一个特定类型（比如 `NoSuchElementException`）的异常，程序会立刻跳到对应的 `catch` 块里来执行代码，而不会崩溃。`e` 是一个变量名，它会引用那个被抛出的异常对象，你可以用它来获取更多信息（比如错误消息）。
        
3. **`finally` - 无论如何都要做** (可选)
    
    - **语法**: `finally { ... }`
        
    - **作用**: `finally` 块里的代码**总是**会被执行。无论 `try` 块是成功运行了，还是被 `catch` 捕获了，`finally` 里的代码最后都会执行。它通常用来做一些“清理”工作，比如关闭文件或者网络连接，确保资源被释放。
        

**把它们组合起来看一个例子：**

假设我们在 `main` 方法里使用我们刚写好的 `OHIterator`，我们可以这样安全地调用它：

Java

```
// 假设 iterator 是我们创建的 OHIterator 实例
try {
    // A计划：尝试获取下一个元素
    System.out.println("尝试获取下一个请求...");
    OHRequest req = iterator.next(); 
    System.out.println("成功获取到: " + req.name);

} catch (NoSuchElementException e) {
    // B计划：如果上面的代码抛出了NoSuchElementException
    System.out.println("捕获到异常：已经没有更多请求了！");
    // 我们可以打印出异常里的消息
    // System.out.println(e.getMessage()); 

} finally {
    // C计划：无论成功还是失败，都执行这里
    System.out.println("...尝试结束。");
}
```

- 如果迭代器有下一个元素，你会看到：`尝试获取下一个请求...` -> `成功获取到...` -> `...尝试结束。`
    
- 如果迭代器已经没有元素了，你会看到：`尝试获取下一个请求...` -> `捕获到异常...` -> `...尝试结束。`
