# Java 中函数的基本语法

在 Java 中，函数通常被称为**方法**（method），是类的一部分，用于封装特定的功能或行为。以下是 Java 中方法的基本语法和相关规则。

## 1. 基本语法

方法的基本结构如下：

```java
访问修饰符 返回类型 方法名(参数列表) {
    // 方法体
    return 返回值; // 如果有返回值
}
```

### 各部分说明：

- **访问修饰符**（可选）：定义方法的访问权限，如 `public`、`private`、`protected` 或默认（包访问权限）。例如：
    - `public`：任何地方可见。
    - `private`：仅在类内部可见。
- **返回类型**：方法返回的值类型，可以是基本类型（`int`、`double` 等）、引用类型（`String`、`ArrayList` 等）或 `void`（表示无返回值）。
- **方法名**：方法的名字，遵循驼峰命名法（首字母小写，后续单词首字母大写），如 `calculateSum`。
- **参数列表**：方法接受的输入参数，格式为 `类型 参数名`（可有多个，用逗号分隔），也可以没有参数（空括号 `()`）。
- **方法体**：包含方法执行的代码逻辑，用 `{}` 括起来。
- **return 语句**：如果方法有返回值，必须使用 `return` 关键字返回与返回类型匹配的值；`void` 方法可以省略 `return` 或使用 `return;` 结束。

## 2. 示例

### 无参数、无返回值

```java
public class Example {
    public void sayHello() {
        System.out.println("Hello, World!");
    }
}
```

### 有参数、有返回值

```java
public class Example {
    public int add(int a, int b) {
        return a + b;
    }
}
```

### 主入口方法

Java 程序的入口方法，特殊但符合基本语法：

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Program starts here");
    }
}
```

- `static` 表示静态方法，可由类直接调用，无需实例化。
- `String[] args` 是命令行参数数组。

## 3. 参数与返回值

- **参数**：可以有零个或多个参数，多个参数用逗号分隔。
    - 示例：
        
        ```java
        public double multiply(double x, double y) {
            return x * y;
        }
        ```
        
- **返回值**：必须与声明的返回类型匹配。如果是 `void`，不能有 `return` 值。
    - 示例（错误用法）：
        
        ```java
        public int wrongMethod() { // 编译错误
            return; // 缺少 int 类型返回值
        }
        ```
        

## 4. 访问修饰符

- `public`：任何地方可见。
- `private`：仅类内部可见。
- `protected`：同一包内或子类可见。
- 默认（无修饰符）：同一包内可见。

## 5. 静态方法与实例方法

- **静态方法**：用 `static` 修饰，属于类本身，可直接通过类名调用（如 `ClassName.methodName()`）。
    - 示例：
        
        ```java
        public static int getValue() {
            return 10;
        }
        ```
        
- **实例方法**：需要创建对象实例才能调用（如 `object.methodName()`）。

## 6. 注意事项

- 方法名应有意义，遵循命名规范。
- 参数类型和返回值类型必须明确。
- 方法体中的代码必须以 `{}` 包裹，单行代码也可省略 `{}`（不推荐）。
- 如果方法有返回值，`return` 语句必须确保返回与类型一致。
- 方法可以调用其他方法（包括自身，称为递归）。

## 7. 综合示例

```java
public class Calculator {
    // 实例方法
    public int subtract(int a, int b) {
        return a - b;
    }

    // 静态方法
    public static double divide(double a, double b) {
        if (b == 0) {
            return 0.0; // 避免除以零
        }
        return a / b;
    }

    public static void main(String[] args) {
        Calculator calc = new Calculator();
        int result1 = calc.subtract(10, 4);
        double result2 = divide(10.0, 2.0);
        System.out.println("Subtract: " + result1); // 输出 6
        System.out.println("Divide: " + result2);   // 输出 5.0
    }
}
```
