
### 1. 核心语法与两个关键接口

Java的迭代器机制主要围绕两个接口工作：

- **`Iterable<T>` (可迭代的)**
    
    - **作用**: 一个类实现这个接口，就等于向外界声明：“我是可以被 `for-each` 循环遍历的”。
        
    - **必须实现的方法**: `public Iterator<T> iterator();` 这个方法必须返回一个迭代器对象。
        
- **`Iterator<T>` (迭代器)**
    
    - **作用**: 这是真正负责遍历逻辑的“向导”对象。
        
    - **必须实现的方法**:
        
        - `public boolean hasNext();` // 检查是否还有下一个元素。
            
        - `public T next();` // 返回下一个元素，并将指针后移。
            
    - **可选实现的方法**: `public void remove();` // 移除 `next()` 上一次返回的元素。

### 2. 何时需要自己创建迭代器 (以及示例)

当你的类 **没有** 使用标准的Java集合来存储数据时，或者你需要特殊的遍历逻辑时，就需要自己动手写。最常见的例子就是使用 **普通数组**。

**示例：为一个管理字符串数组的类创建迭代器**

Java

```
import java.util.Iterator;

public class MyStringArray implements Iterable<String> {

    private String[] elements;

    public MyStringArray(String[] elements) {
        this.elements = elements;
    }

    // 实现 Iterable 接口，返回我们自定义的迭代器
    @Override
    public Iterator<String> iterator() {
        return new MyIterator();
    }

    // 内部类，实现 Iterator 接口，负责真正的遍历
    private class MyIterator implements Iterator<String> {
        private int index = 0;

        @Override
        public boolean hasNext() {
            // 当索引小于数组长度时，说明还有元素
            return index < elements.length;
        }

        @Override
        public String next() {
            // 返回当前元素，然后索引+1
            return elements[index++];
        }
    }

    public static void main(String[] args) {
        MyStringArray myArray = new MyStringArray(new String[]{"苹果", "香蕉", "橙子"});
        for (String fruit : myArray) {
            System.out.println(fruit);
        }
    }
}
```

### 3. 何时使用Java自带的迭代器 (以及示例)

当你的类内部使用了任何一个标准的Java集合（如 `ArrayList`, `LinkedList`, `HashSet` 等）来管理数据时，你应该 **直接返回该集合自带的迭代器**。这是最简单、最推荐的做法。

**示例：为一个包装了 `ArrayList` 的类提供迭代器**

Java

```
import java.util.ArrayList;
import java.util.Iterator;
import java.util.List;

public class MyShoppingList implements Iterable<String> {

    private List<String> items = new ArrayList<>();

    public void addItem(String item) {
        this.items.add(item);
    }

    // 实现 Iterable 接口，直接返回 ArrayList 自带的迭代器
    @Override
    public Iterator<String> iterator() {
        return this.items.iterator();
    }


    public static void main(String[] args) {
        MyShoppingList list = new MyShoppingList();
        list.addItem("牛奶");
        list.addItem("面包");

        for(String item : list) {
            System.out.println(item);
        }
    }
}
```
