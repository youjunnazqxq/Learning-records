## 定义

**提取的文字：**

命题联结词有5种，分别是否定、合取、析取、蕴涵、等价联结词。

**对应的符号：**

- 否定 (Negation): ¬ 
- 合取 (Conjunction): ∧
- 析取 (Disjunction): ∨
- 蕴涵 (Implication): →
- 等价 (Equivalence / Biconditional): ↔

Of course. Here are the truth tables for the five logical connectives.

In these tables, "T" or "1" represents True (真), and "F" or "0" represents False (假).

---

### 1. 否定 (Negation, ¬p)

Negation reverses the truth value of a proposition.

|   |   |
|---|---|
|**p**|**¬p**|
|T|F|
|F|T|

---

### 2. 合取 (Conjunction, p∧q)

Conjunction is true **only if both** propositions are true.

|   |   |   |
|---|---|---|
|**p**|**q**|**p∧q**|
|T|T|T|
|T|F|F|
|F|T|F|
|F|F|F|

---

### 3. 析取 (Disjunction, p∨q)

Disjunction is true if **at least one** of the propositions is true.

|   |   |   |
|---|---|---|
|**p**|**q**|**p∨q**|
|T|T|T|
|T|F|T|
|F|T|T|
|F|F|F|

---

### 4. 蕴涵 (Implication, p→q)

Implication is false **only when** the first proposition (p) is true and the second (q) is false. It can be read as "if p, then q".

|   |   |   |
|---|---|---|
|**p**|**q**|**p→q**|
|T|T|T|
|T|F|F|
|F|T|T|
|F|F|T|

---

### 5. 等价 (Equivalence, p↔q)

Equivalence is true **only when** both propositions have the **same** truth value. It can be read as "p if and only if q".

|   |   |   |
|---|---|---|
|**p**|**q**|**p↔q**|
|T|T|T|
|T|F|F|
|F|T|F|
|F|F|T|



## 优先级
好的，这些命题联结词在逻辑运算中的优先级顺序如下，从高到低排列：

1. **否定 (¬)**
2. **合取 (∧)**
3. **析取 (∨)**
4. **蕴涵 (→)**
5. **等价 (↔)**

**详细解释：**

- **否定 (¬)** 拥有最高的优先级。在一个复杂的表达式中，会最先计算否定。例如，`¬p ∧ q` 等同于 `(¬p) ∧ q`。
- 接下来是 **合取 (∧)** 和 **析取 (∨)**。通常约定合取的优先级高于析取，这与算术中的乘法高于加法类似。
- **蕴涵 (→)** 和 **等价 (↔)** 的优先级最低。

**用括号改变优先级：**

和数学中的四则运算一样，你可以使用 **括号 ( )** 来改变默认的运算顺序。括号内的表达式永远最先计算。

**总结一下最常用的优先级规则：**

**括号 > 否定 > 合取 > 析取 > 蕴涵 > 等价**

为了避免歧义，尤其是在书写复杂的逻辑表达式时，强烈建议使用括号来明确你想要的运算顺序。
