**题2.** 含3个命题变元的命题公式的主合取范式为 M0​∧M3​∧M4​∧M6​∧M7​，则它的主析取范式为 m1​∨m2​∨m5​ (表示成 m∨n 的形式)。

**中间文字:**

3个命题变项

0 1 2 3 4 5 6 7

**底部文字:**

设 mi​ 与 Mi​ 是极小项和极大项，则 ¬mi​⟺Mi​,¬Mi​⟺mi​


当然可以。使用真值表是求主析取范式（PDNF）和主合取范式（PCNF）最直观的方法。

核心思想非常简单：

- **主析取范式 (PDNF)**：关心公式结果为 **真 (1)** 的情况。它是所有对应“真”情况的 **极小项 (minterm)** 的 **析取 (OR, ∨)**。
- **主合取范式 (PCNF)**：关心公式结果为 **假 (0)** 的情况。它是所有对应“假”情况的 **极大项 (maxterm)** 的 **合取 (AND, ∧)**。

---

### 分步指南 (以公式 PtoQ 为例)

#### **第1步：画出完整的真值表**

首先，列出所有变量的取值组合，并计算出公式最终的结果。

| 行号 | P | Q | PtoQ |

| :--- | :-: | :-: | :-------: |

| 0 | 0 | 0 | 1 |

| 1 | 0 | 1 | 1 |

| 2 | 1 | 0 | 0 |

| 3 | 1 | 1 | 1 |

---

### **第2步：求主析取范式 (PDNF) 找“1”** ✅

1. 找出结果为 1 的所有行。
    
    在我们的例子中，是第 0、1、3 行。
    
2. 为每一行写出其对应的极小项 (minterm)。
    
    规则是：变量值为 1，则保留原变量；值为 0，则使用否定 (¬)。
    
    - **第0行 (P=0, Q=0)**: 结果为 1 ➡️ 极小项是 m_0=(negPlandnegQ)
    - **第1行 (P=0, Q=1)**: 结果为 1 ➡️ 极小项是 m_1=(negPlandQ)
    - **第3行 (P=1, Q=1)**: 结果为 1 ➡️ 极小项是 m_3=(PlandQ)
3. 将所有极小项用“或”(∨)连接起来。
    
    这就是最终的 PDNF。
    
    主析取范式 (PDNF): (negPlandnegQ)lor(negPlandQ)lor(PlandQ)
    
    或者记为：m_0lorm_1lorm_3
    

---

### **第3步：求主合取范式 (PCNF) 找“0”** ❌

1. 找出结果为 0 的所有行。
    
    在我们的例子中，只有第 2 行。
    
2. 为每一行写出其对应的极大项 (maxterm)。
    
    规则与极小项相反：变量值为 0，则保留原变量；值为 1，则使用否定 (¬)。
    
    - **第2行 (P=1, Q=0)**: 结果为 0 ➡️ 极大项是 M_2=(negPlorQ)
3. 将所有极大项用“与”(∧)连接起来。
    
    因为这里只有一项，所以它本身就是 PCNF。
    
    主合取范式 (PCNF): (negPlorQ)
    
    或者记为：M_2
    

---

### 总结

|   |   |   |
|---|---|---|
||**主析取范式 (PDNF)**|**主合取范式 (PCNF)**|
|**关注**|真值表中结果为 **真 (1)** 的行|真值表中结果为 **假 (0)** 的行|
|**构件**|**极小项 (Minterm)**|**极大项 (Maxterm)**|
|**规则**|变量 1 ➡️ P &lt;br> 变量 0 ➡️ negP|变量 1 ➡️ negP &lt;br> 变量 0 ➡️ P|
|**连接**|使用 **析取 (OR, ∨)**|使用 **合取 (AND, ∧)**|
|**别称**|“积之和” (Sum of Products)|“和之积” (Product of Sums)|
