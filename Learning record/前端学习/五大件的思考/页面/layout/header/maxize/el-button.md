`el-button` 是基于 Vue 的主流 UI 组件库（如 Element UI / Element Plus）中最核心、最常用的基础组件，主要用于在页面中承载点击事件、提交表单或触发特定操作。

它的设计非常灵活，可以通过配置不同的**属性（Props）**来改变外观、尺寸和状态。以下是它最常用的核心属性分类总结：

### 1. 外观与主题属性

这些属性决定了按钮的“长相”和色彩语义：

- **`type`**：按钮的类型（决定颜色基调）。
    
    - 可选值：`primary`（主要，通常为主题色蓝色）、`success`（成功，绿色）、`warning`（警告，橙色）、`danger`（危险，红色）、`info`（信息，灰色）、`text`（纯文本按钮）。
        
- **`plain`**：布尔值。是否为“朴素按钮”。开启后，按钮背景变透明，边框和文字带颜色，视觉权重比普通按钮低。
    
- **`round`**：布尔值。是否为圆角按钮（左右两端变成完整的半圆）。
    
- **`circle`**：布尔值。是否为正圆形按钮。通常不加文字，只配合 `icon` 图标使用（例如页面右下角的悬浮加号）。
    
- **`link`**（Element Plus Vue3 特有）：布尔值。是否为链接样式按钮（替代了 Vue2 中的 `type="text"`）。
    

### 2. 状态控制属性

用于控制按钮的交互可用性：

- **`disabled`**：布尔值。是否禁用该按钮。设为 `true` 后，按钮会变灰，鼠标悬浮显示禁用光标，且无法触发点击事件。
    
- **`loading`**：布尔值。是否处于加载中状态。设为 `true` 时，按钮左侧会自动出现一个旋转的 Loading 动画图标，并且**按钮会自动被禁用**。这在向后端发送请求、防止用户连续重复点击时非常有用。
    

### 3. 尺寸控制属性

- **`size`**：控制按钮的整体大小。
    
    - Element Plus (Vue3) 可选值：`large`（大）、`default`（默认）、`small`（小）。
        
    - Element UI (Vue2) 可选值：`medium`（中）、`small`（小）、`mini`（迷你）。
        

### 4. 图标与原生机制属性

- **`icon`**：给按钮添加图标。在 Vue2 中传入图标对应的字符串类名（如 `el-icon-search`），在 Vue3 中直接传入对应的图标组件。
    
- **`native-type`**：设置 HTML 按钮元素原生的 `type` 属性。在配合原生 `<form>` 表单使用时非常关键。
    
    - 可选值：`button`（默认）、`submit`（点击自动触发提交表单）、`reset`（点击自动重置表单）。
        
- **`color`**（Element Plus Vue3 特有）：字符串。允许你直接传入十六进制颜色值（如 `#626aef`）来自定义按钮颜色，组件库会自动帮你计算和生成对应的 hover（悬浮）和 active（按下）颜色。
