
### 第一步：安装官方图标库依赖

Element Plus 的图标是被单独提取出来的一个包，你需要先在项目的根目录下打开终端，运行以下命令安装它：

Bash

```
# 如果你使用的是 npm
npm install @element-plus/icons-vue

# 如果你使用的是 yarn
yarn add @element-plus/icons-vue

# 如果你使用的是 pnpm
pnpm install @element-plus/icons-vue
```

### 第二步：在代码中引入并使用

在 Vue 3 的 `<script setup>` 语法中，**按需引入**是最推荐的方式，这样打包出来的文件体积最小。

你需要做的就是：

1. 从 `@element-plus/icons-vue` 中 `import` 你需要的图标组件（比如全屏图标叫 `FullScreen`）。
    
2. 在 `<template>` 中，配合 `<el-icon>` 标签将它渲染出来。
    

这是为你修改好的完整代码：

代码段

```
<template>
  <div class="header-tools">
    <el-tooltip effect="dark" content="内容最大化" placement="bottom">
      <div class="icon-btn" @click="handleMaximize">
        <el-icon><FullScreen /></el-icon>
      </div>
    </el-tooltip>
  </div>
</template>

<script setup lang="ts">
// 引入你自己的全局仓库
import { useGlobalStore } from "@/stores/modules/useGlobal";
// 引入 Element Plus 的全屏图标组件
import { FullScreen } from '@element-plus/icons-vue';

const globalStore = useGlobalStore();

// 触发最大化
const handleMaximize = () => {
  globalStore.setGlobalState("maximize", true);
};
</script>

<style scoped>
.icon-btn {
  cursor: pointer;
  padding: 0 10px;
  /* 你可以直接调整外层容器或 el-icon 的字体大小来改变图标大小 */
  font-size: 18px; 
}
</style>
```

### 💡 如何查找其他图标？

Element Plus 官方提供了一个非常直观的图标集合页面。你需要其他图标时，只需要：

1. 访问官方图标库网址：[Element Plus Icon 集合](https://www.google.com/search?q=https://element-plus.org/zh-CN/component/icon.html%23icon-collection)
    
2. 在页面上寻找你想要的图标（比如搜索 "user", "setting", "close" 等）。
    
3. 点击你看中的图标，它会自动复制对应的组件名。
    
4. 像上面的 `FullScreen` 一样，把它 `import` 进来并在代码里使用就可以了。
    

这种方式非常干净利落，直接替换掉原本的 `<i class="iconfont..."></i>` 即可完美运行。
