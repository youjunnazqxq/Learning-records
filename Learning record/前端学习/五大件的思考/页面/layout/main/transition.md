
把 CSS 中的 `transition` 想象成是一个“电影导演”。它的核心作用就是**把网页元素原本“瞬间突变”的动作，变成一段“平滑的过渡动画”**。

如果没有 `transition`，当你把一个盒子的宽度从 100px 改为 200px 时，它是瞬间“啪”地一下闪过去的。加上了 `transition` 后，它会在你规定的时间内，一点一点地把宽度撑开。

### `transition` 需要传入什么？

`transition` 其实是一个**简写属性**，它就像一个打包盒，里面按顺序装了 4 个具体的值。它的基础语法公式如下：

CSS

```
transition: <属性名> <持续时间> <速度曲线> <延迟时间>;
```

下面为你拆解这 4 个参数分别代表什么：

**1. 属性名 (Property) —— “你要让谁动？”**

- 你想让哪个具体的 CSS 属性发生动画？比如 `width` (宽度)、`opacity` (透明度)、`background-color` (背景色)。
    
- 如果你想偷懒，或者想让所有发生改变的属性都有动画效果，可以直接写 **`all`**。
    

**2. 持续时间 (Duration) —— “动多久？”（必填项）**

- 这个动画从开始到结束要花多少时间？通常用秒 (`s`) 或毫秒 (`ms`) 表示。
    
- 例如写 `0.3s` 或者 `300ms`（在后台系统中，0.2s 到 0.3s 是最让人觉得干脆利落的舒适时长）。
    

**3. 速度曲线/缓动函数 (Timing-function) —— “怎么个动法？”（可选项）**

- 动画是匀速的，还是先快后慢的？这决定了动画的“物理手感”。常见的值有：
    
    - `linear`: 像机械齿轮一样，全程匀速。
        
    - `ease`: 默认值。像汽车起步，缓慢开始，中间加速，最后慢慢刹车停下。
        
    - `ease-in`: 慢慢开始，然后一直加速（适合离开页面的动画）。
        
    - `ease-out`: 全速开始，然后慢慢减速刹车（适合进入页面的动画，符合真实物理世界的阻尼感）。
        
    - `cubic-bezier(...)`: 自定义的高级贝塞尔曲线，就是你之前图片里看到的那些数字。
        

**4. 延迟时间 (Delay) —— “等多久再动？”（可选项）**

- 触发变化后，要等多久才开始播放动画？比如 `0.1s` 就是等待 0.1 秒后再开始动。如果不写，默认就是 `0s`（立刻开始）。

### 实际代码演示

我们把参数组合起来看两个最常见的例子：

CSS

```
/* 例子 1：最无脑、最通用的写法 */
.box {
  /* 解释：不管 .box 的什么属性发生了改变，都用 0.3秒 的时间，以平滑减速 (ease-out) 的方式过渡 */
  transition: all 0.3s ease-out;
}

/* 例子 2：精确控制（性能更好） */
.menu-item {
  /* 解释：只有改变透明度时，花 0.5秒过渡；改变背景色时，花 0.2秒过渡 */
  transition: opacity 0.5s, background-color 0.2s;
}
```

理解了这个公式后，再回头看我们之前写的 Vue 路由动画类名 `.fade-enter-active { transition: opacity 0.3s ease-in-out; }`，是不是就完全能看懂它在做什么了？

在后台项目中，最常遇到需要这种平滑过渡的场景就是鼠标悬停（Hover）或者侧边栏的展开收起。你要不要试着自己写几行代码，实现一个“鼠标悬停在按钮上时，背景色平滑改变”的例子练练手？
