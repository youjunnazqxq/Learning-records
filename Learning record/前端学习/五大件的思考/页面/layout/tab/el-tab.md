这两个标签是 Element Plus 中用于构建标签页导航的核心组件。它们是典型的**“父子关系”**，必须配合使用才能生效。

我们可以把它们想象成一个**文件柜**和里面的**文件夹**。

### 1. `<el-tabs>` (文件柜 —— 外层容器与总控)

**作用：** 它是整个标签页系统的“大管家”，负责管理外层的整体样式、监听用户的点击/删除动作，以及记录当前到底哪一个标签处于激活状态。

**常用属性 (Props) 与事件 (Events)：**

| **属性/事件**         | **类型**            | **作用与用法**                                                                      |
| ----------------- | ----------------- | ------------------------------------------------------------------------------ |
| **`v-model`**     | `String / Number` | **(核心)** 绑定当前被激活的标签的 `name` 值。它的值变了，高亮的标签就会跟着变。                                |
| **`type`**        | `String`          | 控制标签页的整体视觉风格。常用值：`card` (卡片风格，最适合后台)、`border-card` (带有边框的卡片)。如果不传，就是最普通的下划线风格。 |
| **`@tab-click`**  | `Function`        | **(事件)** 当用户用鼠标点击某个标签时触发。通常用来执行 `router.push` 跳转路由。                            |
| **`@tab-remove`** | `Function`        | **(事件)** 当用户点击标签上的 "X" 关闭按钮时触发。通常用来执行仓库里的删除逻辑。                                 |

---

### 2. `<el-tab-pane>` (文件夹 —— 单个标签与内容区)

**作用：**

它是内部的具体的标签项。它定义了标签顶部显示什么文字（或图标），以及这个标签拥有哪些独立的特权（比如能不能被单独关闭）。

**常用属性 (Props)：**

|**属性**|**类型**|**作用与用法**|
|---|---|---|
|**`name`**|`String / Number`|**(核心)** 该标签的唯一标识符。它必须与 `<el-tabs>` 的 `v-model` 配合使用。（在我们的路由逻辑中，通常传入 `item.path`）。|
|**`label`**|`String`|标签卡片上显示的纯文本标题（比如 `"首页"`、`"用户列表"`）。|
|**`closable`**|`Boolean`|控制**这一个**标签是否显示 "X" 关闭按钮。传入 `true` 显示，`false` 隐藏（常用于固定首页）。|
|**`disabled`**|`Boolean`|设为 `true` 时，该标签将被置灰且无法被点击。|

---

### 💡 核心联动机制：`v-model` 与 `name` 的相爱相杀

这是新手最容易迷惑的地方，理解了这一点就彻底掌握了这个组件：

`<el-tabs>` 就像一个只认 ID 号的安检员。

1. 你给每一个 `<el-tab-pane>` 发了一个唯一的身份证号，也就是 **`name`** 属性（例如：`name="/home"`，`name="/user"`）。
    
2. 你把当前的 URL 路径交给了 `<el-tabs>` 的 **`v-model`**（例如：`v-model="/user"`）。
    
3. `<el-tabs>` 会自动去下面的一堆 pane 里寻找：**谁的 `name` 等于我的 `v-model`？** 找到了，就把那个标签高亮显示。
    

这也是为什么在代码中，`v-model="activeTab"` 和 `:name="item.path"` 是这套 UI 能够和 Vue Router 完美同步运转的最底层秘密。
