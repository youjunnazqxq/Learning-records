

### 1. 混合单位计算（最强大的特性）

这是 `calc()` 的“杀手锏”。在普通的 CSS 或是预编译语言（如 SCSS）的自身数学运算中，你无法直接将不同的单位混合加减。但 `calc()` 可以将**相对单位**（如 `%`、`vw`、`vh`、`em`）和**绝对单位**（如 `px`）放在一起计算。

- **图中的例子：** `calc(100vh - 60px)` 的意思是，将元素的高度设置为**当前浏览器视口总高度（100vh）**，然后精确地减去 **60像素**。这通常用于做页面布局，减去的 60px 一般是顶部固定导航栏（Header）的高度，这样剩下的内容区域就能不多不少、完美地铺满整个屏幕，不会产生多余的纵向滚动条。
    

### 2. 浏览器实时动态计算

与 SCSS 中在编译打包阶段就计算成固定值的运算不同，`calc()` 是由浏览器在**运行渲染时**实时计算的。这意味着当用户调整浏览器窗口大小时（`100vh` 代表的实际物理像素发生了变化），浏览器会自动重新执行 `calc()` 里的公式，并立刻更新元素的高度。

### 3. 支持基础四则运算

它支持加（`+`）、减（`-`）、乘（`*`）、除（`/`）运算，并且可以像普通数学公式一样，使用小括号 `()` 来改变运算优先级，例如：`calc((100% - 20px) / 2)`。

### 4. 极其严格的空格语法（新手易错点）

这是 `calc()` 最特别的语法机制：在使用加号（`+`）和减号（`-`）时，**运算符的左右两侧必须有空格！**

- ✅ **生效：** `calc(100vh - 60px)`
    
- ❌ **失效：** `calc(100vh-60px)` （如果没有空格，浏览器会解析错误，这行样式会直接作废）
    

_(注：乘号和除号虽然没有强制要求空格，但为了统一代码风格和可读性，强烈建议所有运算符前后都加上空格。)_
