`gap` 属性在 CSS Flexbox（弹性盒子）和 Grid（网格）布局中，是一个非常现代且优雅的**“容器级”间距控制属性**。

它的核心操作性质可以概括为：**“只管中间，不管两头”**。

具体来说，它与传统的间距操作有以下几个本质区别：

- **作用于全局容器，而非个体**：传统的做法是给每个子组件单独设置 `margin-left` 或 `margin-right`。而 `gap` 是写在父容器（比如你的 `.header-right`）上的。它就像一个规则制定者，宣告：“在我这个容器里的所有相邻元素，中间必须保持 16px 的距离。”
    
- **消除冗余边距（最爽的一点）**：以前用 `margin` 时，最后一个元素通常会多出一个不需要的外边距，导致整体布局与容器边缘对齐时出现偏差（还需要写 `:last-child { margin-right: 0; }` 去消除它）。`gap` 极其智能，它**只在元素之间**生成空白，绝对不会在第一个元素之前或最后一个元素之后添加多余的距离。
    
- **天然契合数据驱动（如 Vue 的 `v-if`）**：在后台系统中，很多按钮（比如“全屏”、“消息”）是动态渲染的。如果某个用户没有权限，对应的图标用 `v-if` 隐藏了，`gap` 依然能保证剩下的元素之间维持完美的 `16px` 间距。如果是用 `margin`，中间元素消失可能会导致相邻元素的 `margin` 发生错乱。
