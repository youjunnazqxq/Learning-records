`var()` 是 CSS3 原生提供的一个内置函数，它的全称是 variable（变量）。它的核心作用是**读取并应用事先定义好的 CSS 自定义属性（即 CSS 变量）的值**。

具体到你截图中的这行代码 `color: var(--el-color-primary);`，我们可以这样拆解：

### 1. 变量声明前缀 (`--`)

在标准的 CSS 中，所有的自定义变量名**必须**以两个连字符（`--`）开头。

- 这里的 `--el-color-primary` 就是一个变量名。
    
- 从命名特征（`el-` 前缀）可以非常明显地看出，这是 **Element Plus** (或 Element UI) 组件库在全局定义的一个核心主题颜色变量（通常默认是代表“主要”的蓝色 `#409EFF`）。
    

### 2. 取值函数 (`var()`)

既然前面用 `--` 定义了变量，在使用它的时候，就必须用 `var()` 函数把它包裹起来提取出来。

- 浏览器在解析到这行代码时，会去该元素的祖先节点（通常是挂载在 `<html>` 或 `:root` 根节点上）寻找 `--el-color-primary` 到底代表什么颜色代码，然后把那个真实的颜色值“填”到这里。
    

---

### 为什么推荐这样写（它的优势）？

在现代前端开发中，使用 `var()` 来管理颜色、尺寸等属性已成为绝对的主流，主要有以下两大作用：

- **统一管理，一处修改全局生效**
    
    过去我们在写 CSS 时，如果一个蓝色 `#409EFF` 在项目中用到了 100 次，我们就得写 100 遍。如果产品经理要求把主题色换成紫色，就得全局搜索替换。而有了 `var()`，你只需要在根节点改一次变量的赋值，全站 100 个用到该变量的地方都会瞬间同步改变。
    
- **无缝实现“深色模式 / 动态主题”**
    
    这是预编译语言（如 SCSS / LESS 的 `$color` 变量）做不到的。SCSS 变量在打包打包后就变成了写死的静态值。而原生 CSS 的 `var()` 是由浏览器**实时计算**的，你可以直接通过 JavaScript 在网页运行时动态改变这个变量的值，从而极其方便地实现一键切换“暗黑模式”或让用户自定义主题色。
