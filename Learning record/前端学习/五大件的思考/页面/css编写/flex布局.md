
### 1. 开启 Flex 布局

一切的起点在于父容器。只要给父容器加上 `display: flex;`，它里面的直接子元素就会自动变成 Flex 项目。

CSS

```
.container {
  display: flex; /* 开启 flex 布局 */
}
```

### 2. 父容器的常用核心属性

这四个属性决定了子元素在容器里的排列和对齐方式：

|**属性**|**作用**|**最常用的值**|
|---|---|---|
|**`flex-direction`**|决定主轴方向（元素是横排还是竖排）|`row` (默认，从左到右横排)<br><br>  <br><br>`column` (从上到下竖排)|
|**`justify-content`**|主轴（通常是水平方向）上的对齐方式|`center` (居中)<br><br>  <br><br>`space-between` (两端对齐，中间留白)<br><br>  <br><br>`flex-start` (起点对齐)|
|**`align-items`**|交叉轴（通常是垂直方向）上的对齐方式|`center` (垂直居中)<br><br>  <br><br>`stretch` (默认，拉伸填满容器高度)|
|**`flex-wrap`**|元素超出容器宽度时，是否换行|`nowrap` (默认，不换行，会压缩子元素)<br><br>  <br><br>`wrap` (自动换行)|

### 3. 子元素的常用属性

通常情况下，你只需要控制父容器就能完成大部分布局，但有时也需要单独控制某个特定的子元素：

- **`flex: 1;`**：这是一个缩写属性，表示该子元素会**自动占据父容器中剩余的所有空间**。非常适合用来做“左边固定宽度，右边自动撑满”的布局。
    
- **`align-self`**：允许某个具体的子元素拥有和 `align-items` 不同的交叉轴对齐方式（例如让某个元素单独沉底对齐）。
    

---

### 4. 编写时的重要注意点

- **主轴与交叉轴会随时互换**：这是新手最容易迷糊的地方。如果你设置了 `flex-direction: column;`（竖排），那么 `justify-content` 控制的就是**垂直方向**的对齐，而 `align-items` 控制的变成了**水平方向**的对齐。
    
- **只对“直接子元素”有效**：Flex 布局的属性不会继承给孙子元素。如果孙子元素也需要弹性布局，你需要给子元素也加上 `display: flex;`。
    
- **传统的排版属性会失效**：在 Flex 项目（子元素）中，传统的 `float`、`clear` 和 `vertical-align` 属性都会失效。不要把它们和 Flex 混用。
    
- **默认不换行**：即使子元素的宽度总和超过了父容器，默认情况下它们也会被强行压缩在同一行里，除非你显式声明了 `flex-wrap: wrap;`。
