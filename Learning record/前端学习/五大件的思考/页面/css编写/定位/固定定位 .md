

### 1. 绝对脱离文档流 (Out of Normal Flow)

当你给一个元素设置 `position: fixed;` 时，它会**完全脱离原本的 HTML 排版队伍**。

- 它原本在页面上占据的空间会瞬间消失。
    
- 紧跟在它后面的普通元素会自动顶上来填补空缺，就当它不存在一样。
    
- 此时，该元素就像是悬浮在整个页面上方的一个独立图层（它的 `z-index` 堆叠层级也会发生变化）。
    

### 2. 参照物永远是“浏览器视口” (Viewport)

这是固定定位与绝对定位（`position: absolute`）最大的区别。绝对定位会去寻找最近的带定位的父辈元素作为参照，而**固定定位极其专一，它只认“当前浏览器的可视窗口”作为参照物**。

### 3. 如何精准控制位置？

一旦设置了 `position: fixed;`，你必须配合四个方位属性 `top`、`bottom`、`left`、`right` 来告诉浏览器它应该钉在哪里。

- **示例代码**：如果你想在屏幕右下角放一个“退出最大化”或“回到顶部”的按钮：
    
    CSS
    
    ```
    .exit-button {
      position: fixed;
      bottom: 40px; /* 距离浏览器窗口底部 40 像素 */
      right: 40px;  /* 距离浏览器窗口右侧 40 像素 */
    }
    ```
    

### 4. 经典的真实应用场景

- **吸顶导航栏 (Fixed Header)**：很多网站的顶部菜单栏，随着你往下看文章，菜单栏始终固定在最顶端。
    
- **悬浮工具/客服图标**：页面右下角常驻的聊天气泡或快捷按钮。
    
- **全屏弹窗遮罩层 (Dialog/Modal)**：配合 `top: 0; left: 0; right: 0; bottom: 0;` 或使用 `100vw` / `100vh`，可以铺满整个屏幕。因为它是固定的，即便底层页面很长且能滚动，遮罩层也会稳稳盖住当前视野。
    

---

### ⚠️ 新手极易踩坑的“特例”

虽然前面说固定定位的参照物“永远”是视口，但在现代 CSS 中有一个著名的陷阱：

如果一个 `position: fixed` 元素的**任何一个祖先级容器**身上，被设置了 `transform`、`perspective` 或 `filter` 属性（且值不为 `none`），那么**这个祖先元素就会瞬间取代浏览器视口，成为固定定位的新参照物**。

这时候你会发现：页面一滚动，你的固定定位元素居然跟着跑了，或者位置完全错乱。如果你以后在开发 Vue 组件时发现 `fixed` 莫名其妙失效，第一反应就要去排查外层是不是加了诸如 `transform: translate(...)` 之类的动画或样式。
