在 Vue 中，当你封装一个稍微复杂一点的组件时，往往需要预留多个“坑位”。比如一个标准的“卡片（Card）”组件，通常会分为**头部（标题/操作按钮）**、**主体（核心内容）**和**底部（分页/确认按钮）**。

这时候就需要用**具名插槽（Named Slots）**来精准投递内容。

### 1. 子组件挖坑：定义具名插槽 (`MyCard.vue`)

在封装子组件时，使用 `<slot>` 标签，并给它加上 `name` 属性，这就是在“挖具名坑位”。如果不写 `name`，它就是一个默认插槽（名字隐式为 `default`）。

代码段

```
<template>
  <div class="my-card">
    <div class="card-header">
      <slot name="header">
        <span>默认标题</span>
      </slot>
    </div>

    <div class="card-body">
      <slot></slot>
    </div>

    <div class="card-footer">
      <slot name="footer"></slot>
    </div>
  </div>
</template>

<style scoped>
.my-card { border: 1px solid #ebeef5; border-radius: 4px; }
.card-header, .card-footer { padding: 10px; background-color: #f5f7fa; }
.card-body { padding: 20px; }
</style>
```

### 2. 父组件填坑：使用具名插槽 (`App.vue`)

在父组件中使用这个卡片时，借助 `<template>` 标签和 `#名字` 的语法糖，将内容精确地分发到对应的坑位里。

代码段

```
<template>
  <MyCard>
    <template #header>
      <div style="display: flex; justify-content: space-between;">
        <span>用户信息</span>
        <el-button type="primary" size="small">编辑</el-button>
      </div>
    </template>

    <p>姓名：张三</p>
    <p>年龄：21</p>
    <p>专业：计算机科学与技术</p>

    <template #footer>
      <el-button>取消</el-button>
      <el-button type="success">保存提交</el-button>
    </template>
  </MyCard>
</template>

<script setup lang="ts">
import MyCard from './MyCard.vue'
</script>
```

### 核心语法总结

1. **子组件定义：** `<slot name="自定义名字"></slot>`
    
2. **父组件使用：** `<template v-slot:自定义名字>`，在实际开发中，几乎 100% 会使用它的简写形态：`<template #自定义名字>`。
    
3. **默认插槽的真身：** 你平时直接写在组件标签中间的内容，其实是被放进了一个叫 `default` 的隐藏具名插槽里。也就是说，直接写内容等价于把它包在 `<template #default> ... </template>` 中。
    
4. **顺序无关紧要：** 在父组件写 `<template #xxx>` 时，顺序是可以随便打乱的。Vue 在渲染时，会自动根据 `name` 找对位置去拼装，这也是具名插槽最大的优势所在。
