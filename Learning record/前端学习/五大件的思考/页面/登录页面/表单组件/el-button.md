。

### 一、 登录场景下的必备属性：`loading`（防抖神器）

这是你在写登录按钮时**最需要关注**的属性。

- **作用**：当它的值为 `true` 时，按钮左侧会出现一个旋转的加载图标，并且按钮会自动变成**不可点击**的状态。
    
- **为什么登录必须要用它**：当用户点击登录后，前端需要向后端发送网络请求，这通常需要几百毫秒到几秒钟。如果没有 `loading` 状态，急性子的用户可能会在这几秒内疯狂点击按钮，导致前端向后端发送了十几条重复的登录请求，甚至可能引发服务器报错。
    
- **用法**：你需要定义一个响应式变量（比如 `const isLoading = ref(false)`），绑定为 `:loading="isLoading"`。点击登录时设为 `true`，请求结束（成功或失败）后改回 `false`。
    

### 二、 控制外观的常用属性

- **`type`（按钮类型/颜色）**：控制按钮的视觉重要级。登录按钮是页面的核心操作，必须使用 `type="primary"`（主按钮，默认是醒目的蓝色），引导用户去点击。
    
- **`size`（尺寸）**：接受 `large`、`default`、`small`。为了和尺寸较大的输入框保持视觉统一，登录按钮通常也会设置为 `size="large"`。
    
- **`round` / `plain`（形状与样式）**：`round` 可以让按钮两边变成半圆形，`plain` 可以让按钮变成幽灵按钮（背景透明，只有边框）。这主要取决于你的 UI 设计图。
    

### 三、 核心事件监听

- **`@click`（点击事件）**：这是最基础的触发机制。用户点击按钮时执行你的登录逻辑代码，直接写 `@click="handleLogin"` 即可。
    

---

### 完整的登录按钮代码示例

结合上述重点，一个成熟的后台登录按钮通常是这样写的：

HTML

```
<el-form-item>
  <el-button 
    type="primary" 
    size="large" 
    style="width: 100%" 
    :loading="isLoading" 
    @click="handleLogin"
  >
    {{ isLoading ? '登 录 中...' : '登 录' }}
  </el-button>
</el-form-item>
```
