`ColumnProps` 是 Geeker-Admin 中 `ProTable` 组件最核心的配置接口之一。它主要用于定义表格每一列的展示行为、搜索表单绑定、字典映射以及自定义渲染逻辑。

为了让你更直观地理解，我们可以将其组成部分拆解为 **基础继承层** 和 **自定义拓展层** 两个维度来看。

### 1. 基础继承层 (Element Plus 属性透传)

TypeScript

```
extends Partial<Omit<TableColumnCtx<T>, "type" | "children" | "renderCell" | "renderHeader">>
```

- **设计理念：** 站在巨人的肩膀上。它继承了 Element Plus 原生的 `TableColumnCtx`（即 `<el-table-column>` 的属性）。
    
- **作用：** 这意味着你在配置 `ProTable` 列时，可以直接使用 Element Plus 官方支持的所有基础属性，例如 `prop`, `label`, `width`, `min-width`, `fixed`, `align` 等。
    
- **拦截重写：** 使用 `Omit` 故意剔除了原生的 `type`, `children`, `renderCell`, `renderHeader`，因为 Geeker-Admin 需要对这些属性进行更高级的二次封装或替换。
    

---

### 2. 自定义拓展层 (Geeker-Admin 专属配置)

在这个接口内部定义的属性，是框架为了实现“表格+搜索表单+分页”一体化而添加的业务属性。可以按功能划分为以下几类：

#### 核心状态与显示控制

- **`type?: TypeProps;`**
    
    - **作用：** 重新定义了列的类型。支持 `"index"` (序号列)、`"selection"` (多选框)、`"radio"` (单选框)、`"expand"` (展开行) 和 `"sort"` (拖拽排序行)。
        
- **`isShow?: boolean | Ref<boolean>;`**
    
    - **作用：** 控制该列是否在表格中渲染出来。支持传入 Vue 的 `Ref` 响应式数据，可以动态控制列的显隐。
        
- **`isSetting?: boolean | Ref<boolean>;`**
    
    - **作用：** 控制该列是否出现在表格右上角的“列设置”面板中。如果设为 `false`，用户将无法在工具栏中勾选/取消勾选该列。
        

#### 搜索表单配置 (Search)

- **`search?: SearchProps | undefined;`**
    
    - **作用：** `ProTable` 的灵魂功能。只要在这里配置了 `search`，框架就会自动把这个字段提取到表格顶部的搜索区域，并渲染成对应的表单组件（如 Input、Select、DatePicker 等）。大大减少了重复写搜索表单的工作量。
        

#### 字典映射与格式化 (Enum)

- **`enum?: EnumProps[] | Ref<EnumProps[]> | ((params?: any) => Promise<any>);`**
    
    - **作用：** 字典配置。既可以是静态的数组，也可以是一个返回 Promise 的 API 接口函数。它会自动发起请求获取字典数据，常用于 Select 搜索项的下拉数据，或者表格内数据的翻译回显（例如将状态 `1` 翻译为 `启用`）。
        
- **`isFilterEnum?: boolean | Ref<boolean>;`**
    
    - **作用：** 决定表格单元格里的当前值是否需要根据 `enum` 字典进行格式化。有时候你可能只想让字典作为搜索项的下拉框，而不在表格里进行文本替换，就可以将其设为 `false`。
        
- **`fieldNames?: FieldNamesProps;`**
    
    - **作用：** 如果后端的字典接口返回的字段名不是约定的 `label` 和 `value`（比如返回的是 `dictName` 和 `dictId`），可以通过这个属性进行字段映射替换。
        
- **`tag?: boolean | Ref<boolean>;`**
    
    - **作用：** 开启后，配合字典 `enum` 中的 `tagType`，可以把普通文本自动渲染成 Element Plus 的 `<el-tag>` 标签，让界面更美观（比如：成功状态显绿色标签，失败显红色标签）。
        

#### 自定义渲染 (TSX)

- **`headerRender?: (scope: HeaderRenderScope<T>) => VNode;`**
    
    - **作用：** 使用 TSX/JSX 语法自定义表头内容。
        
- **`render?: (scope: RenderScope<T>) => VNode | string;`**
    
    - **作用：** 使用 TSX/JSX 语法自定义单元格里的内容。完美替代了传统 Vue 模板里繁琐的 `<template #default="scope">` 具名插槽写法。
        

#### 嵌套属性

- **`_children?: ColumnProps<T>[];`**
    
    - **作用：** 用于配置多级表头。由于原生 `children` 被 `Omit` 移除了，框架使用 `_children` 来递归渲染复杂的多级表头结构。
