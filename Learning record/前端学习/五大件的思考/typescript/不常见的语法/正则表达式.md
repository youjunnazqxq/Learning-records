

### 1. 基础占位符（代表“什么类型的字符”）

这些是最常用的快捷符号，通常都是反斜杠 `\` 加上一个字母。**大写字母通常是小写字母的相反意思。**

|**符号**|**大白话解释**|**例子说明**|
|---|---|---|
|`\d`|**任何数字** (digit)|`/\d/` 可以匹配 "3"、"9"|
|`\D`|**非数字**|`/\D/` 可以匹配 "A"、"@"、空格，但不能是数字|
|`\w`|**字母、数字或下划线** (word)|`/\w/` 可以匹配 "a"、"Z"、"6"、"_"|
|`\W`|**非字母数字下划线**|`/\W/` 可以匹配 "@"、"!"、空格|
|`\s`|**空格**、换行符、Tab (space)|`/\s/` 可以匹配文本里的空白处|
|`.`|**万能匹配**（除了换行符）|`/./` 匹配任何单个字符，比如 "a"、"1"、"#"|

### 2. 量词（代表“出现多少次”）

占位符默认只匹配**一个**字符。如果你想匹配多个，就需要加上量词。量词永远放在它要修饰的字符**后面**。

|**符号**|**大白话解释**|**例子说明**|
|---|---|---|
|`*`|**0 次或多次**（可有可无，多多益善）|`/a*/` 匹配 ""、"a"、"aaa"|
|`+`|**1 次或多次**（至少得有 1 个）|`/a+/` 匹配 "a"、"aaa"，但不匹配 ""|
|`?`|**0 次或 1 次**（要么没有，要么只有 1 个）|`/a?/` 匹配 "" 或 "a"，常用于可选字符|
|`{n}`|**正好 n 次**|`/\d{4}/` 匹配正好 4 位数字，如 "2026"|
|`{n,}`|**至少 n 次**|`/\d{3,}/` 匹配 3 位及以上的数字|
|`{n,m}`|**n 到 m 次之间**|`/\d{3,6}/` 匹配 3 到 6 位数字|

### 3. 边界符（代表“必须在这个位置”）

边界符不匹配具体的字符，它匹配的是**位置**。

|**符号**|**大白话解释**|**例子说明**|
|---|---|---|
|`^`|**必须以此开头**|`/^A/` 匹配 "Apple"，但不匹配 "bA"|
|`$`|**必须以此结尾**|`/ing$/` 匹配 "playing"，但不匹配 "ingu"|

_(注：如果你同时写了 `^` 和 `$`，比如 `/^\d{6}$/`，意思就是“从头到尾只能是 6 位数字”，不能多也不能少，这就叫**严格匹配**，你之前看过的 `hexToRgb` 源码里就用了这个组合！)_

### 4. 集合与逻辑（代表“多选一”或“分组”）

当你需要更灵活的规则时（比如“只能是 a、b、c 中的一个”），就需要用到括号。

|**符号**|**大白话解释**|**例子说明**|
|---|---|---|
|`[ ]`|**选一个**（字符集合）|`/[abc]/` 匹配 "a" 或 "b" 或 "c"。<br><br>  <br><br>`/[0-9]/` 等同于 `\d`。<br><br>  <br><br>`/[a-zA-Z]/` 匹配任何英文字母。|
|`[^ ]`|**排除这些**（注意 `^` 在中括号里是“非”的意思）|`/[^0-9]/` 匹配任何**不是**数字的字符。|
|`|`|**或者**（逻辑或）|
|`( )`|**编成一组**|`/(abc){2}/` 匹配 "abcabc"。如果不加括号 `/abc{2}/` 则只匹配 "abcc"。|

### 5. 修饰符（全局设定）

写在两个斜杠的外面，像开关一样改变正则的整体行为。

|**符号**|**大白话解释**|**例子说明**|
|---|---|---|
|`g`|**全局匹配** (Global)|找到所有匹配项，而不是找到第一个就收工。|
|`i`|**忽略大小写** (Ignore case)|`/a/i` 可以同时匹配 "a" 和 "A"。|

### 实战演练：用“积木”拼出一个手机号验证

让我们把上面的零件组合起来，写一个验证中国大陆手机号的正则表达式：

**规则要求**：

1. 必须是 11 位数字。
    
2. 必须以 `1` 开头。
    
3. 第二位数字目前通常是 `3-9` 之间的数字。
    

**拼装过程**：

1. 开头必须是 1：`^1`
    
2. 第二位是 3 到 9：`[3-9]`
    
3. 后面跟着 9 个数字：`\d{9}`
    
4. 到此必须结束：`$`
    

**最终成品**：`/^1[3-9]\d{9}$/`

JavaScript

```
const phoneReg = /^1[3-9]\d{9}$/;

phoneReg.test("13812345678"); // true (完全符合)
phoneReg.test("23812345678"); // false (开头不是1)
phoneReg.test("138123456789"); // false (超过11位了，因为尾部有 $ 限制)
```

### 1. `test()` —— 铁面无私的“门卫”

- **它是谁的**：它是**正则表达式对象**（RegExp）自带的方法。
    
- **语法格式**：`正则.test(字符串)`
    
- **它的作用**：只做真假判断。它会拿着你定好的规则，去检查字符串里**是否包含了**符合规则的内容。
    
- **返回值**：永远只返回 `true`（匹配成功）或 `false`（匹配失败）。
    

**大白话比喻**：就像夜店门口的门卫拿着一个规则（“必须穿正装”），你（字符串）想进去，他扫你一眼，只告诉你“能进（true）”或“不能进（false）”，绝不跟你多废话。

**代码示例**：

JavaScript

```
const reg = /hello/; // 规则：必须包含 hello 这个词
const str1 = "hello world";
const str2 = "hi there";

console.log(reg.test(str1)); // 输出: true (找到了)
console.log(reg.test(str2)); // 输出: false (没找到)
```

在你之前的 `color.ts` 代码里，`!reg.test(str)` 就是在用“门卫”检查你传入的颜色代码是不是合法的十六进制。不合法直接拦截报错。

### 2. `match()` —— 精准提取的“荧光笔”

- **它是谁的**：它是**字符串对象**（String）自带的方法。
    
- **语法格式**：`字符串.match(正则)`
    
- **它的作用**：不仅要找，还要**把找到的东西全掏出来**。它会像荧光笔一样，在字符串里把所有符合规则的片段全画出来，并收集在一起。
    
- **返回值**：
    
    - 如果找到了：返回一个**数组**，里面装着所有匹配到的文本。
        
    - 如果没找到：返回 `null`。
        

**大白话比喻**：就像你在一份长文档（字符串）里找所有的邮箱地址。`test` 只会告诉你“这里面有邮箱”，而 `match` 会直接给你列出一张清单：“这里面有 3 个邮箱，分别是 a@qq.com、b@163.com 和 c@gmail.com”。

**代码示例**：

JavaScript

```
// 规则：连续的两个任意字符 (就是你代码里的 /../g)
// 注意末尾的 g 代表 global(全局)，意思是找到一个别停，继续往后找
const reg = /../g; 
const str = "409eff";

console.log(str.match(reg)); 
// 输出: ["40", "9e", "ff"] (成功提取并装进数组)
```

### 总结对比

|**特性**|**test()**|**match()**|
|---|---|---|
|**调用者**|正则对象 (`reg.test(str)`)|字符串对象 (`str.match(reg)`)|
|**主要功能**|**验证**格式是否正确|**提取**我们需要的数据|
|**返回值**|布尔值 (`true` / `false`)|数组 (`[...]`) 或 `null`|
|**常用场景**|表单校验（查手机号、查邮箱格式）|数据清洗（从一堆长文本里抓取链接、提取标签）|
