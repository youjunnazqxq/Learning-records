

### 1. 制造遥控器和接收器

首先，你需要实例化一个 `AbortController` 对象。

JavaScript

```
const controller = new AbortController();
```

这个 `controller` 对象身上有两个核心部位：

- **`controller.signal`**：这是信号接收器（我们要把它绑在请求上）。
    
- **`controller.abort()`**：这是遥控器上的红色引爆按钮（留在我们手里）。
    

### 2. 把接收器绑在 Axios 请求上

在发请求的时候，把这个 `signal` 放进 Axios 的配置项（config）里。

JavaScript

```
axios.get('/api/user/list', {
  signal: controller.signal  // <--- 绑上了！
}).then(res => {
  console.log(res);
}).catch(err => {
  // 如果请求被取消，这里会捕获到一个特殊的取消错误
});
```

### 3. 按下引爆按钮（取消请求）

如果你发现用户疯狂连点按钮，或者用户切换了页面，上一个 `/api/user/list` 的请求还在路上，你只需要在你代码的任何地方执行：

JavaScript

```
controller.abort(); 
```

只要这行代码一运行，还在路上的那个网络请求就会立刻被浏览器和 Axios 强制中断！
