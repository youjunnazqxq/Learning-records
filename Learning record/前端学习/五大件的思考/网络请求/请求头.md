为了让你更直观地理解“请求头（Request Headers）”，我们继续用刚才“寄快递”的例子。

如果你寄的是一份机密文件（请求体 Data），你肯定不能把它直接暴露在外面，而是要装进信封或快递盒里。那么，贴在快递盒外面的那张**快递面单**，就是**请求头**。

快递面单上写着：

- 这是加急件还是普通件？
    
- 寄件人是谁？
    
- 里面装的是易碎品还是普通文件？
    

**请求头（Headers）就是浏览器和服务器之间沟通的“元数据（Metadata）”**。它是一组键值对，用来告诉服务器关于这次请求的一些额外说明，而不是具体的业务数据本身。

前端开发中最常打交道的两个核心请求头是：

1. **`Content-Type`（内容类型）:** 告诉服务器“我发给你的数据（Data）是什么格式的”。比如 `application/json`（JSON 格式，Axios 默认）、`multipart/form-data`（上传文件用的表单格式）、`application/x-www-form-urlencoded`（传统表单格式）。
    
2. **`Authorization`（授权凭证）:** 告诉服务器“我是谁”。通常我们会把用户登录后拿到的 Token 放在这里，比如 `Bearer eyJhbGciOiJIUzI1Ni...`。
    

---

### 在 Axios 中配置请求头的三种级别

在实际项目中，我们有三种方式来配置请求头，它们的“作用范围”和“优先级”各不相同。优先级是：**单次请求配置 > 拦截器/实例配置**。

#### 1. 全局/实例默认配置（作用于所有请求）

如果你希望某个项目里的所有请求都带上特定的头（比如规定所有请求体都是 JSON），你可以在创建 Axios 实例时统一配置：

JavaScript

```
import axios from 'axios';

const request = axios.create({
  baseURL: 'https://api.example.com',
  timeout: 5000,
  // 统一配置基础请求头
  headers: {
    'Content-Type': 'application/json;charset=utf-8',
    'X-Client-Type': 'Web' // 自定义头，告诉后端这是网页端发来的请求
  }
});
```

#### 2. 请求拦截器中动态配置（最常用，处理 Token 的绝佳位置）

有些请求头是动态的，比如用户的 Token，只有在用户登录后才会有。如果写在上面的默认配置里，代码一运行就写死了。所以我们通常在**请求拦截器**里动态读取并塞进请求头里：

JavaScript

```
// 添加请求拦截器
request.interceptors.request.use(
  (config) => {
    // 每次发请求前，都去 localStorage 里拿一下最新的 token
    const token = localStorage.getItem('user_token');
    
    // 如果有 token，就把它加到请求头的 Authorization 字段里
    if (token) {
      config.headers['Authorization'] = `Bearer ${token}`;
    }
    
    return config;
  },
  (error) => {
    return Promise.reject(error);
  }
);
```

_这种写法的收益极大：你只需要在这里写一次，整个项目里成百上千个接口就自动带上 Token 了，不需要每次发请求都手动传。_

#### 3. 单次请求的独立配置（覆盖全局配置）

有时候你需要搞点“特殊化”。比如全局配置了所有的请求都是 JSON 格式，但唯独有一个“上传头像”的接口，必须使用 `multipart/form-data` 格式。

这时候，你就可以利用我们上一个问题讲到的**配置对象参数**（GET 的第二个参数，POST 的第三个参数）来单独覆盖它：

JavaScript

```
// 导入上面配置好的带有拦截器的 request 实例
import request from '@/utils/request';

// 普通接口，走拦截器里的默认头 (application/json)
export const getUserInfo = () => request.get('/user/info');

// 上传文件的特殊接口，单独覆盖请求头
export const uploadAvatar = (fileData) => {
  return request.post(
    '/user/avatar', 
    fileData, 
    {
      // 这里的 headers 会和拦截器里的 headers 合并
      // 如果有同名的键，这里的优先级最高，会覆盖掉前面的
      headers: {
        'Content-Type': 'multipart/form-data'
      }
    }
  );
};
```
