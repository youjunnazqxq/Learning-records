# Pinia 基础配置与核心语法指南

## 1. 安装与全局注入

在 Vue 3 项目中，Pinia 作为全局状态管理的标准库，需要先进行安装并在应用入口进行挂载。

**安装依赖：**
```bash
pnpm add pinia
# Geeker-Admin 中通常还会配合持久化插件
pnpm add pinia-plugin-persistedstate 
````

**入口配置 (`src/main.ts`)：**

TypeScript

```
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import piniaPluginPersistedstate from 'pinia-plugin-persistedstate'
import App from './App.vue'

const app = createApp(App)
const pinia = createPinia()

// 注册持久化插件
pinia.use(piniaPluginPersistedstate)

app.use(pinia)
app.mount('#app')
```

## 2. Store 的定义与模块化

Pinia 支持两种语法：**Option Store** 和 **Setup Store**。在配合 TypeScript 时，高度推荐使用 **Setup Store**，它与 Vue 3 的 Composition API 完全一致。

**目录结构规范：**通常存放在 `src/stores/modules/` 下，按业务模块划分（如 `user.ts`, `auth.ts` 等）。

**基础示例 (`src/stores/modules/counter.ts`)：**

TypeScript

```
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

// 1. 定义 State 的接口类型
interface CounterState {
  count: number;
  name: string;
}

// 2. 定义 Store
// 第一个参数 'counter' 是全局唯一的 id
export const useCounterStore = defineStore('counter', () => {
  
  // ================= State (状态) =================
  // 使用 ref 或 reactive 定义响应式数据
  const count = ref<number>(0)
  const name = ref<string>('Geeker')

  // ================= Getters (计算属性) =================
  // 使用 computed 定义派生状态
  const doubleCount = computed(() => count.value * 2)
  const greeting = computed(() => `Hello, ${name.value}!`)

  // ================= Actions (动作/方法) =================
  // 使用普通函数定义业务逻辑，支持同步和异步 (async/await)
  const increment = (num: number = 1) => {
    count.value += num
  }

  const fetchInitialData = async () => {
    // 模拟异步请求
    // const res = await api.getCounterData()
    // count.value = res.data
  }

  // 3. 必须将所有需要暴露的属性和方法 return 出去
  return {
    count,
    name,
    doubleCount,
    greeting,
    increment,
    fetchInitialData
  }
}, {
  // 4. 第三参数：配置项 (如持久化)
  persist: true 
})
```

## 3. 在 Vue 组件中的使用语法

在组件中使用 Store 时，最核心的原则是：**直接解构会失去响应式**，必须借助 `storeToRefs` 来解构 State 和 Getters。

**组件示例 (`CounterComponent.vue`)：**

代码段

```
<template>
  <div class="counter-box">
    <h3>{{ greeting }}</h3>
    <p>当前计数: {{ count }}</p>
    <p>双倍计数: {{ doubleCount }}</p>
    
    <el-button @click="increment(1)">增加 1</el-button>
    <el-button @click="handleAsyncUpdate">异步更新</el-button>
    
    <el-button @click="counterStore.count = 0">重置</el-button>
  </div>
</template>

<script setup lang="ts">
import { storeToRefs } from 'pinia'
import { useCounterStore } from '@/stores/modules/counter'

// 1. 实例化 Store
const counterStore = useCounterStore()

// 2. 解构 State 和 Getters (必须使用 storeToRefs 保持响应式)
const { count, name, doubleCount, greeting } = storeToRefs(counterStore)

// 3. 解构 Actions (普通函数，直接解构即可，不需要 storeToRefs)
const { increment, fetchInitialData } = counterStore

// 4. 业务逻辑封装
const handleAsyncUpdate = async () => {
  await fetchInitialData()
}
</script>
```

## 4. 核心语法速记 (对比 Vuex / Options API)

|**概念**|**Pinia (Setup 语法)**|**作用说明**|
|---|---|---|
|**State**|`ref()` 或 `reactive()`|存储全局状态数据|
|**Getters**|`computed()`|相当于组件的计算属性，有缓存特性|
|**Actions**|`function()`|处理业务逻辑，支持同步和异步操作，**废弃了 Mutations**|
|**解构辅助**|`storeToRefs()`|提取 state/getter 并保持视图响应式同步|
