在 Vue 3 的开发中，`mittBus` 是一个非常经典且轻量的**全局事件总线（Event Bus）**库。

简单来说，它的作用是让**两个完全没有血缘关系（非父子、非祖孙）的组件能够直接通信**。

---

### 1. 为什么在这里要用 mittBus？

在 **YJ-Admin**（或 Geeker-Admin）的结构中：

- **触发按钮**：通常在 `Header` 组件的工具栏里。
    
- **设置抽屉**：就是你现在写的 `ThemeDrawer` 组件，它可能被挂载在 `App.vue` 或者 `Layout` 的最外层。
    

如果没有 `mittBus`，你可能需要把“打开抽屉”的状态写在 Pinia 里，或者通过极其复杂的层层组件传值。

而使用 `mitt` 之后，逻辑变得非常直白：

1. **Header 按钮说**：“我发个信号叫 `openThemeDrawer`，谁爱听谁听。”
    
2. **ThemeDrawer 监听说**：“我一直在听这个信号，一旦有人发，我就把 `drawerVisible` 设为 `true`。”
    

---

### 2. 如何实现它？

要让这套逻辑跑起来，你通常需要三个步骤：

#### 第一步：安装并创建工具类

Bash

```
# 安装 mitt
npm install mitt
```

然后在 `@/utils/mittBus.ts` 中实例化它：

TypeScript

```
import mitt from "mitt";

// 定义事件类型，方便 TypeScript 类型提示
type Events = {
  openThemeDrawer: void; // 不需要传参
  // 你以后可以在这里加别的事件，比如 greet: string;
};

const mittBus = mitt<Events>();
export default mittBus;
```

#### 第二步：在 Header 中发出指令（发送端）

当用户点击 Header 上的设置图标时：

TypeScript

```
import mittBus from "@/utils/mittBus";

const openDrawer = () => {
  mittBus.emit("openThemeDrawer"); // 发出信号
};
```

#### 第三步：在 ThemeDrawer 中接收（接收端）

也就是你截图中看到的代码：

TypeScript

```
import mittBus from "@/utils/mittBus";

// 持续监听，只要信号一响，就执行回调函数
mittBus.on("openThemeDrawer", () => {
  drawerVisible.value = true;
});
```

---

### 3. 注意点（避坑指南）

作为一个 CS 专业且在写 Vue 项目的同学，你需要注意 **内存泄漏** 的问题。

当组件被销毁时，如果还在监听，可能会导致意外报错。建议在 `onBeforeUnmount` 中关闭监听：

TypeScript

```
import { onBeforeUnmount } from "vue";

// 销毁时移除监听
onBeforeUnmount(() => {
  mittBus.off("openThemeDrawer");
});
```

**总结：**

`mittBus` 就是一个跨组件的“对讲机”。在你的 **YJ-Admin** 中，它完美解决了 Header 按钮远程控制 Layout 侧边抽屉开启的需求。
