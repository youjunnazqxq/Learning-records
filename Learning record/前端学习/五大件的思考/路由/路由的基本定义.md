# 📝 Vue Router 路由配置核心笔记

在 Vue 3 (Vue Router 4) 中，我们通过定义 `RouteRecordRaw` 数组来配置路由。每一个路由对象都是一张“地图”，指引程序如何找到对应的页面。

## 一、 核心基础属性

|**属性名**|**说明**|**示例**|
|---|---|---|
|**`path`**|**必填**。匹配的 URL 路径。|`path: '/home'`|
|**`name`**|路由的唯一标识（绰号），跳转时推荐使用 name。|`name: 'home_page'`|
|**`component`**|路由对应的组件。推荐使用**懒加载**函数。|`component: () => import('@/views/home.vue')`|
|**`children`**|**嵌套路由**。在一个布局组件中展示子页面。|`children: [ { path: 'list', ... } ]`|

---

## 二、 关键点：`path` 的斜杠（`/`）秘籍 ⚠️

这是新手最容易踩坑的地方，请务必记住以下规则：

### 1. 绝对路径 vs 相对路径

- **带斜杠 (`/`)**：代表**绝对路径**。无论嵌套在哪个层级，它都从根部开始计算。
    
    - 父路由是 `/admin`，子路由写 `path: '/user'` $\rightarrow$ 访问地址是 `/user`。
        
- **不带斜杠**：代表**相对路径**。它会继承父路由的路径。
    
    - 父路由是 `/admin`，子路由写 `path: 'user'` $\rightarrow$ 访问地址是 `/admin/user`。
        

### 2. 根路径 `/`

- 通常整个应用的首页路径就是 `/`。
    

### 3. 动态路径参数

- 使用冒号 `:` 标记。例如 `path: '/user/:id'`。
    
- 此时 `path` 可以匹配 `/user/123` 或 `/user/abc`。
    

---

## 三、 进阶功能属性

### 1. `redirect` (重定向)

当访问当前路径时，强制跳到另一个地址。

- `path: '/', redirect: '/login'`（访问首页直接进登录页）。
    

### 2. `props` (解耦)

将路由参数（params）直接传给组件的 `props`。

- `props: true`：组件里可以直接写 `defineProps(['id'])` 拿值，不用再写 `route.params.id`。
    

---

## 四、 `meta` 路由元数据 (Geeker-Admin 的灵魂)

`meta` 是一个自定义对象，用来存放额外信息。在后台管理系统中，它决定了菜单的外观。

TypeScript

```
meta: {
  title: "用户管理",      // 侧边栏显示的文字
  icon: "User",          // 图标名称
  isHide: false,         // 是否在菜单中隐藏
  isKeepAlive: true,     // 页面是否缓存（切换后不销毁）
  isAffix: true,         // 是否固定在标签页导航栏
  roles: ['admin']       // 哪些角色有权访问
}
```

## 五、 结构示例 (结合 Geeker-Admin 逻辑)

TypeScript

```
const routes: RouteRecordRaw[] = [
  {
    path: "/layout",
    name: "layout",
    component: () => import("@/layouts/index.vue"),
    redirect: "/layout/home",
    children: [
      {
        path: "home", // 注意：不带斜杠，完整路径是 /layout/home
        name: "home",
        component: () => import("@/views/home/index.vue"),
        meta: { title: "首页", icon: "HomeFilled" }
      },
      {
        path: "user/:id", // 动态路径参数
        name: "userDetail",
        component: () => import("@/views/user/detail.vue"),
        meta: { isHide: true, title: "用户详情" }
      }
    ]
  }
];
```

**💡 学习建议：**

在 **Geeker-Admin** 中，你会看到很多路由是动态加载的，但无论多复杂，它们最终都会转换成上面这种 `RouteRecordRaw` 的格式。**重点关注 `meta` 属性**，因为那是控制整个框架 UI 显示（面包屑、标题、标签页）的关键。
