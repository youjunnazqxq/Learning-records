对于路由（`createRouter`）的配置来说，配置对象一般包含以下几个关键属性（结合你截图中的代码以及常见扩展来分析）：

### 1. 截图中涉及的核心配置属性

- **`history`（必填项）**：
    
    决定路由的工作模式。最常见的是 HTML5 模式（URL 看起来很正常，如 `/home`，对应 `createWebHistory()`）和 Hash 模式（URL 带 `#`，如 `/#/home`，对应 `createWebHashHistory()`）。
    
    _截图里通过 `routerMode[mode]()` 动态调用工厂函数，这是一种很灵活的封装方式，可以根据环境变量来决定使用哪种模式。_
    
- **`routes`（必填项）**：
    
    路由表，定义了 URL 路径与 Vue 组件之间的映射关系。它是一个数组。
    
    _截图里使用了 ES6 的扩展运算符 `...` 将 `staticRouter`（通常是登录页、404等不需要权限的静态路由）和 `errorRouter`（错误拦截路由）合并成了一个数组传入。_
    
- **`strict`**：
    
    严格模式配置。决定路由匹配时是否严格区分 URL 尾部的斜杠。
    
    _截图里设为 `false`（这也是默认值），意味着访问 `/users` 和 `/users/` 会匹配到同一个组件。_
    
- **`scrollBehavior`**：
    
    控制路由跳转后的滚动条行为。
    
    _截图中的箭头函数 `() => ({ left: 0, top: 0 })` 表示每次切换路由进入新页面时，都会自动滚动到页面的最顶端。_

### 2. 路由表 (`routes`) 内部单个路由对象的常见属性

虽然截图中没有展开写 `routes` 数组里具体的一条条路由是什么样的，但在实际配置时，数组里的每一个路由对象（Route Record）一般会包含以下属性：

- **`path`**: 匹配的 URL 路径（例如 `/login` 或 `/user/:id`）。
    
- **`component`**: 匹配成功后要渲染的组件。通常为了性能会使用路由懒加载（例如 `() => import('@/views/Login/index.vue')`）。
    
- **`name`**: 路由的名称。有了名字后，在代码里进行跳转（如 `router.push({ name: 'Home' })`）会比直接拼写路径更方便且不易出错。
    
- **`redirect`**: 重定向。访问当前路径时，自动跳转到另一个路径（例如访问 `/` 重定向到 `/dashboard`）。
    
- **`children`**: 嵌套路由。用于定义该组件内部的子路由（配合 `<router-view>` 实现页面局部刷新）。
    
- **`meta`**: **路由元信息**。这是一个极其灵活和常用的属性，可以存放任何与该路由相关的自定义数据。比如：
    
    - `title`: 配合导航守卫用来动态修改网页标题。
        
    - `icon`: 侧边栏菜单对应的图标。
        
    - `isKeepAlive`: 标记该页面组件是否需要被缓存。
        
    - `requiresAuth`: 标记进入该页面是否需要先登录鉴权。
        

### 3. 其他全局配置属性

除了图中的几个，有时还会配置：
