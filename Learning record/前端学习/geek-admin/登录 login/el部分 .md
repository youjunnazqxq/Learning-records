既然你已经对 `v-bind` (:) 和对象语法有了感觉，我们现在就把 **`el-form`** 的这两大核心支柱——**`model`** 和 **`rules`** 彻底讲透。

在 Element Plus 中，这两者是**相辅相成**的：`model` 提供数据，`rules` 提供标准，而 `prop` 则是连接它们的桥梁。

---

### 1. `model`：数据的“账本”

正如我们之前讨论的，`:model="loginForm"` 是给整个表单指定一个**数据源**。

- **它的角色**：它是一个容器（通常是一个 `reactive` 对象），里面装满了用户输入的所有字段。
    
- **在 Geeker-Admin 中**：
    
    TypeScript
    
    ```
    const loginForm = reactive({
      username: "",
      password: ""
    });
    ```
    
    当你在 `<el-form :model="loginForm">` 绑定它后，表单组件内部就拿到了这个对象的引用。
    

---

### 2. `rules`：规则的“说明书”

`:rules="loginRules"` 定义了每一个字段必须满足什么条件。

- **它的角色**：它告诉表单，数据在什么情况下是“合法”的，什么情况下该“报错”。
    
- **常用配置项**：
    
    - **`required: true`**：必填项。
        
    - **`min` / `max`**：限制字符串长度。
        
    - **`message`**：校验失败时弹出的文字。
        
    - **`trigger`**：触发时机（`blur` 是失去焦点时检查，`change` 是内容变动时检查）。
        

---

### 3. 核心机制：它们是怎么关联的？

这是最关键的一环。你可能会问：“表单怎么知道 `loginRules` 里的 `username` 对应的是 `loginForm` 里的哪一个值？”

答案就在 **`prop`** 属性上。请看这个“连连看”逻辑：

|**步骤**|**位置**|**代码**|**作用**|
|---|---|---|---|
|**1. 找仓库**|`el-form`|`:model="loginForm"`|确定数据去哪找。|
|**2. 找说明书**|`el-form`|`:rules="loginRules"`|确定规则是什么。|
|**3. 建立连接**|`el-form-item`|**`prop="username"`**|**核心！** 它告诉表单：这个格子请去 `model` 里取 `username` 的值，并对比 `rules` 里的 `username` 规则。|

---

### 4. 为什么要这样设计？

如果你不用 `el-form` 的这套体系，你可能需要手动写很多 `if...else`：

JavaScript

```
// 伪代码：不使用 el-form 的痛苦写法
if (loginForm.username === "") {
  alert("请输入用户名");
}
```

**有了 `model` 和 `rules` 配合后：**

1. **自动提示**：用户只要鼠标点开再离开，输入框下面自动变红并出提示。
    
2. **一键检查**：在 `login` 函数里，你只需要执行 `formEl.validate()`。它会**自动遍历** `rules` 里的所有规则，检查 `model` 里的所有数据。
    

---

### 💡 一个直观的例子

想象你在办入职手续：

- **`model`**：是你的**入职申请表**（你填写的姓名、电话）。
    
- **`rules`**：是**公司的招聘标准**（姓名不能为空，电话必须是11位）。
    
- **`prop`**：是申请表上的**每一个格子标题**（通过标题，HR 才能知道哪一行对应哪个标准）。
