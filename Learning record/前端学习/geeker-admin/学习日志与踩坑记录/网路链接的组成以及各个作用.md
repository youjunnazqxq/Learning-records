

### URL 组成示意图

`https://` `www.geeker.com` `:8848` `/src/index.html` `?id=123&name=admin` `#section1`

---

### 1. 协议 (Protocol) —— **“沟通的语言”**

- **示例**：`http://` 或 `https://`
    
- **作用**：规定浏览器和服务器之间交换数据的规则。
    
    - **HTTP**：基础的传输协议。
        
    - **HTTPS**：在 HTTP 基础上加了“S”（Secure），代表加密传输，现在绝大多数企业级项目（如 Geeker-Admin）在生产环境都必须使用它。
        

### 2. 域名/主机 (Domain/Host) —— **“房子的地址”**

- **示例**：`www.google.com` 或 `localhost`
    
- **作用**：指明资源所在的服务器。
    
    - 在互联网上，它通过 DNS 系统指向具体的 IP 地址。
        
    - 在本地开发时，你常用的 `localhost` 指的就是你自己的电脑。
        

### 3. 端口 (Port) —— **“进屋的门”**

- **示例**：`:8848`（你在 `.env` 文件里看到的那个）
    
- **作用**：区分同一台服务器上的不同服务。
    
    - 浏览器默认 HTTP 端口是 `80`，HTTPS 是 `443`（通常隐藏不显示）。
        
    - **Geeker-Admin** 设置为 `8848`，是为了避免和其他项目冲突。
        

### 4. 路径 (Path) —— **“具体的房间”**

- **示例**：`/src/views/login/index.vue`
    
- **作用**：描述资源在服务器上的物理位置或逻辑位置。就像电脑文件夹的路径一样，告诉服务器你要看的是哪一个具体的页面或文件。
    

### 5. 查询参数 (Query Parameters) —— **“随身的纸条”**

- **示例**：`?id=123&type=edit`
    
- **作用**：以 `?` 开始，用 `&` 连接多个参数。
    
    - 用于向页面传递额外信息。比如在 Geeker-Admin 中，点击跳转到用户详情页时，URL 可能会带上 `?id=1`，这样页面就知道该去请求哪个用户的数据了。
        

### 6. 锚点/片段 (Fragment/Hash) —— **“书签”**

- **示例**：`#section1`
    
- **作用**：以 `#` 开始。
    
    - **页面内导航**：告诉浏览器直接跳转到页面的某个特定位置（通常是某个 ID 对应的元素）。
        
    - **路由模式**：在 Vue 等单页面应用（SPA）中，由于 Geeker-Admin 默认可能使用 **Hash 模式**，`#` 后面的内容用来控制前端页面的路由跳转，而不会引起页面刷新。
        

---

### 📝 建议笔记：URL 结构速记

> **核心公式：协议 + 域名 + 端口 + 路径 + 参数 + 锚点**
> 
> - **端口**：对应 `.env` 中的 `VITE_PORT`。
>     
> - **参数**：前端开发中用来页面传参（如 `useRoute().query`）。
>     
> - **锚点**：Vue Router 区分页面路径的重要标志。
>
