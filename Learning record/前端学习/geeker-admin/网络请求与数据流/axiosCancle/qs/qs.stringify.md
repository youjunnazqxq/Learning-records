

## 🛠️ `qs.stringify` 常用配置项（Options）

这些配置项决定了你的 JS 对象最终会变成什么样的 URL 字符串。

### 1. `arrayFormat`：数组变形记

这是最常用的配置。后端不同的语言（Java, PHP, Python）对数组的接收方式可能不同。

- **`indices` (默认)**: `{ a: ['b', 'c'] }` -> `a[0]=b&a[1]=c`
    
- **`brackets`**: `{ a: ['b', 'c'] }` -> `a[]=b&a[]=c`
    
- **`repeat` (Geeker 使用的)**: `{ a: ['b', 'c'] }` -> `a=b&a=c`
    
- **`comma`**: `{ a: ['b', 'c'] }` -> `a=b,c`
    

### 2. `allowDots`：处理嵌套对象

如果你有一个深层对象，比如 `{ user: { name: 'Geeker' } }`：

- **`false` (默认)**: `user[name]=Geeker`
    
- **`true`**: `user.name=Geeker` (很多后端框架更喜欢这种点号写法)
    

### 3. `encode`：安全字符转义

- **`true` (默认)**: 会把特殊字符（如空格、中文字符）转成 `%XX` 这种形式，防止网址解析出错。
    
- **`false`**: 原样输出。通常为了安全，我们保持默认开启。
    

### 4. `skipNulls`：过滤空值

- **作用**: 如果你的对象里有 `null`，设置 `true` 后，它就不会出现在最终的字符串里。
    
- **例子**: `{ a: 1, b: null }` -> `a=1` (如果不设置，会变成 `a=1&b=`)。
    

### 5. `sort`：排序（Geeker 的核心点）

- **作用**: 接收一个排序函数。
    
- **意义**: 保证无论你对象里的属性顺序如何，生成的字符串永远一致。这对 **“请求拦截”** 和 **“缓存判定”** 至关重要。
    

---

## 💡 为什么这种配置化方法这么流行？

这种模式被广泛应用（如 Axios, ECharts, Vue Router），是因为它符合 **“开闭原则”**：

- **对扩展开放**：库的作者可以不断增加新功能，只需要在配置对象里加新属性。
    
- **对修改关闭**：不需要改动函数的主体代码，也不需要用户记住长长的参数列表。
