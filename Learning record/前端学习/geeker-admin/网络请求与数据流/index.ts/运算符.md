这个 `??` 符号也是 TypeScript/JavaScript 中一个非常重要的语法，它的学名叫 **空值合并运算符 (Nullish Coalescing Operator)**。

你可以把它看作是 `??=` 的“地基”。刚才讲的 `config.cancel ??= true` 其实就是 `config.cancel = config.cancel ?? true` 的缩写。

为了让你彻底明白，我们只要搞懂它和 `||` (或者) 的区别就行了：

### 1. `||` (逻辑或) —— “只要是假的我就换”

它非常霸道。只要左边的值是“假”的（比如 `false`、`0`、`""` 空字符串），它都会用右边的值去替换。

- **场景**：设置默认名字。
    
    JavaScript
    
    ```
    const name = inputName || "匿名用户";
    // 如果 inputName 是空字符串 ""，也会变成 "匿名用户"。这通常是我们想要的。
    ```
    

### 2. `??` (空值合并) —— “只有是空的才换”

它比较讲理。它**只认准** `null` 和 `undefined`。如果左边是 `0` 或者 `false`，它觉得这是**有效的值**，会保留下来。

- **场景**：设置默认分数。
    
    JavaScript
    
    ```
    const score = inputScore ?? 60;
    
    // 情况 A：没传分数 (undefined) -> 结果是 60 (及格了)
    // 情况 B：传了 0 分 -> 结果是 0 (虽然考了0分，但也是有效成绩，不能改成60)
    ```
    

### 总结图表

|**符号**|**左边是 0**|**左边是 false**|**左边是 null**|**左边是 undefined**|
|---|---|---|---|---|
|**`||`**|换右边 ❌|换右边 ❌|
|**`??`**|**保留左边** ✅|**保留左边** ✅|**换右边**|**换右边**|

**在你的项目中：**

因为 `config.loading` 和 `config.cancel` 是开关（boolean），可能需要被设置为 `false`（关闭）。

如果用 `||`，一旦你传了 `false`，它会觉得“false 是假的”，强行给你改成默认值 `true`，那就关不掉 loading 了。

所以这里**必须**用 `??`。
