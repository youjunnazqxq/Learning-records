要想“完全掌握”Axios，并能像在 `geeker-admin` 这种企业级项目中游刃有余地使用，你需要把学习内容分为 **五个层级**。

绝大多数前端开发只停留在第一、二层，但如果你能掌握到第四层，你就是团队里的技术骨干了。

下面是系统学习的路线图：

---

### 第一层级：基础 API 与传参（必会）

这是最基本的“会用”，你需要搞清楚如何正确地把数据发出去。

1. **常用请求方法**：
    
    - `get` vs `post` 的核心区别（语义和传参方式）。
        
    - `put` (更新)、`delete` (删除) 的用法。
        
2. **参数传递的“两大坑”**：
    
    - **`params`**：用于 GET 请求，数据拼接在 URL 后面（`?id=1`）。
        
    - **`data`**：用于 POST/PUT 请求，数据在 Request Body 里。
        
    - _重点_：要搞清什么时候用哪个，混淆是新手最常见的错误。
        
3. **配置对象 Config**：
    
    - `headers`：如何手动设置请求头（如 `Content-Type`）。
        
    - `timeout`：超时设置。
        

### 第二层级：工程化封装（Geeker-Admin 的核心）

这是**从“写代码”到“架构代码”的跨越**。在真实项目中，没人会直接用 `axios.get`，都是用封装过的实例。

1. **Axios 实例 (`axios.create`)**：
    
    - 为什么要创建实例？（为了不同环境有不同的基础配置）。
        
    - 如何配置 `baseURL`（开发环境和生产环境的切换）。
        
2. **拦截器 (`Interceptors`) —— 重中之重**：
    
    - **请求拦截**：如何统一注入 Token？如何防止重复点击导致重复请求？
        
    - **响应拦截**：
        
        - 如何统一处理 HTTP 状态码（401, 403, 500）？
            
        - 如何统一处理业务错误码（比如后端返回 200，但 body 里 code 是 -1）？
            
        - 如何“脱壳”（只返回 `data` 里的核心数据，丢掉外层的 `msg`, `code`）。
            

### 第三层级：进阶场景处理（解决复杂问题）

掌握这些，你就能解决“页面卡顿”、“文件上传”等棘手问题。

1. **取消请求 (`AbortController` / `CancelToken`)**：
    
    - 场景：用户快速切换 Tab，上一个 Tab 的请求还没回来，如何取消它以节省资源并防止数据错乱？
        
2. **文件处理**：
    
    - 如何上传文件？（`FormData` 的使用）。
        
    - 如何监听上传/下载进度？（`onUploadProgress`，做进度条用）。
        
    - 如何下载二进制流文件（Blob）并转成 Excel 导出？
        
3. **数据转换 (`transformRequest` / `transformResponse`)**：
    
    - 在拦截器介入之前，如何修改发送的数据格式？
        

### 第四层级：TypeScript 深度整合（Geeker-Admin 必修）

`geeker-admin` 是全 TS 的，不懂这个你就看不懂它的类型定义。

1. **泛型定义**：
    
    - 如何给 Axios 的返回值定义类型？
        
    - `axios.get<Result<User>>(...)` 到底是什么意思？
        
2. **接口封装**：
    
    - 如何定义一个全局的 `Result` 接口（包含 code, msg, data），让所有 API 复用。
        

### 第五层级：源码与原理（面试/造轮子）

这是通往架构师的路，理解它是怎么实现的。

1. **适配器模式 (`Adapter`)**：
    
    - Axios 为什么既能在浏览器用，又能在 Node.js 用？（浏览器用 XHR/Fetch，Node 用 http 模块）。
        
2. **拦截器链的设计**：
    
    - 它是如何通过 Promise 链把请求拦截器、发送请求、响应拦截器串起来的？
        

---

### 建议的学习路径

既然你在看 `geeker-admin`，我建议你的学习顺序是：

1. **先看第二层级**：搞懂 `axios.create` 和拦截器，这样你就能看懂 `geeker-admin` 里 `utils/http` 文件夹的代码了。
    
2. **再看第四层级**：搞懂 TS 类型定义，这样你就能看懂 `api` 文件夹里那些 `<Result>` 是什么东西。
    
3. **最后补全第一、三层级**：在实际写业务的时候查漏补缺。
