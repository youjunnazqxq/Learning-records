**防抖（Debounce）** 和 **节流（Throttle）** 是前端开发中应对“高频事件触发”的两大法宝。

我们在开发中经常会遇到一些会被频繁触发的事件，比如：

- 窗口的 `resize`（改变大小）
    
- 页面的 `scroll`（滚动）
    
- 输入框的 `keyup` / `input`（实时搜索）
    
- 鼠标的 `mousemove`
    

如果这些事件绑定的回调函数非常复杂（比如包含大量的 DOM 操作或频繁的网络请求），哪怕只是轻轻滑动一下鼠标，函数可能会在一秒内执行几十上百次，导致浏览器卡顿甚至崩溃。

防抖和节流就是用来**限制函数执行频率**的，但它们的策略完全不同。

---

### 1. 防抖 (Debounce)

**💡 核心概念：**

把“防抖”想象成**等电梯**。你走进电梯，电梯准备在 5 秒后关门。但在第 4 秒的时候，又进来了个人，电梯为了安全，不得不**重新计时** 5 秒。只有在整整 5 秒内都没人再进来时，电梯才会真正关门运行。

**在代码里就是**：无论你触发了多少次事件，我只认**最后一次**。在动作停止后等待 `N` 毫秒才执行函数；如果在这 `N` 毫秒内又触发了，就重新计时。

**✅ 应用场景：**

- **搜索框输入联想**：用户不断打字时不发请求，等用户停下键盘 0.5 秒后再发送请求。
    
- **窗口大小调整 (resize)**：等用户拖拽完窗口边框，松开鼠标后再重新计算布局。
    

**💻 手写代码实现：**

JavaScript

```
/**
 * 防抖函数 (Debounce)
 * @param {Function} fn - 需要防抖的原始函数
 * @param {number} delay - 延迟时间 (毫秒)
 */
function debounce(fn, delay) {
  let timer = null; // 闭包保存定时器引用
  
  return function(...args) {
    // 每次进来先把之前的定时器清掉 (重新计时)
    if (timer) {
      clearTimeout(timer);
    }
    
    // 设置新的定时器
    timer = setTimeout(() => {
      // 保证 this 指向和参数的正确传递
      fn.apply(this, args);
      timer = null;
    }, delay);
  };
}

// 使用示例：
const searchInput = document.getElementById('search');
searchInput.addEventListener('input', debounce(function(e) {
  console.log('向后端发送搜索请求：', e.target.value);
}, 500));
```

### 2. 节流 (Throttle)

**💡 核心概念：**

把“节流”想象成游戏里英雄的**大招冷却时间 (CD)**。不管你按键盘有多快，只要大招放过一次，接下来 5 秒内你怎么按都没用，必须等 5 秒的冷却时间结束，才能放出下一个大招。

**在代码里就是**：规定在一个单位时间内，只能触发一次函数。如果这个单位时间内触发多次函数，只有一次生效。**它稀释了函数的执行频率，让其以固定的节奏执行。**

**✅ 应用场景：**

- **滚动加载 (无限滚动)**：判断是否滑到底部，不需要哪怕移动 1 像素都计算一次，每隔 300ms 检查一次即可。
    
- **疯狂点击按钮**：防止用户手抖连续点击提交表单按钮。
    
- **拖拽元素 (mousemove)**：按照固定的频率去更新元素的位置，保证动画流畅度即可，没必要一秒更新 60 次。
    

**💻 手写代码实现（时间戳版 - 最常用）：**

JavaScript

```
/**
 * 节流函数 (Throttle) - 时间戳版本
 * @param {Function} fn - 需要节流的原始函数
 * @param {number} delay - 冷却时间 (毫秒)
 */
function throttle(fn, delay) {
  let lastTime = 0; // 记录上一次执行的时间戳
  
  return function(...args) {
    const now = Date.now(); // 获取当前时间戳
    
    // 只有距离上次执行的时间超过了规定的冷却时间，才再次执行
    if (now - lastTime >= delay) {
      fn.apply(this, args);
      lastTime = now; // 更新最后执行时间
    }
  };
}

// 使用示例：
window.addEventListener('scroll', throttle(function() {
  console.log('检查是否滚动到底部了...');
}, 300));
```

### 💡 互动演示：防抖 vs 节流 直观对比

为了让你一眼看穿这两者的本质区别，我为你制作了一个对比模拟器。

**请在下方的“互动区域”里疯狂移动你的鼠标**，然后观察下方三个计数器的反应：

- **原生事件**：你的鼠标只要动一下，它就加一。
    
- **防抖**：只要你的鼠标一直在动，它就一直死等。只有当你**彻底停下**超过 0.5 秒，它才会加一。
    
- **节流**：无论你的鼠标晃得多快，它都会像钟表一样，**极其规律地**每 0.5 秒加一。
    

**面试一句话总结：**

- **防抖**：多次触发，只执行**最后一次**。（等彻底消停了再干活）
    
- **节流**：多次触发，变成**规律触发**。（无论多急，按照规定的节奏干活）
