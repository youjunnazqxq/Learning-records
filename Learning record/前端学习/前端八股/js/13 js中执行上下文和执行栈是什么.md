**面试标准答句（执行上下文与执行栈 极简版）**

在面试中，这部分知识主要用来考察你对 JavaScript 引擎底层运行机制的理解。建议按照“基本概念 -> 生命周期的底层细节 -> 执行栈的运转机制”来回答：

**1. 什么是执行上下文？（基本概念）** “执行上下文就是 JavaScript 代码运行环境的一种抽象概念。主要分为两类：全局执行上下文（浏览器中也就是 window 对象）和函数执行上下文（每次调用函数时都会创建一个全新的上下文）。”

**2. 生命周期的底层细节（核心加分项：解释变量提升）** “执行上下文的生命周期分为创建、执行和回收三个阶段。 最核心的是**创建阶段**，它会做三件事：确定 `this` 的指向、创建词法环境、创建变量环境。 这里也是**变量提升的底层原理所在**：在创建阶段，引擎会扫描代码中的声明。其中 `var` 声明的变量会被存入变量环境并初始化为 `undefined`，而 `let` 和 `const` 声明的变量会被存入词法环境且保持‘未初始化’（uninitialized）状态。”

**3. 什么是执行栈？（运转机制）** “执行栈（也叫调用栈）是一个后进先出（LIFO）的数据结构，专门用来管理这些执行上下文。 当代码开始执行时，引擎会先创建一个全局上下文压入栈底。之后每遇到一个函数调用，就会为它创建一个新的函数上下文并压入栈顶。引擎永远只会执行栈顶的上下文，当函数执行完毕后，它的上下文就会被弹出栈销毁，把控制权交还给下层的上下文，直到整个程序执行结束。”
