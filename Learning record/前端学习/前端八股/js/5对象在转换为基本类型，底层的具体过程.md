

### 一、 核心转换方法

当对象需要被转换为原始值时，引擎会按照一定的优先级调用以下三个方法：

- **`Symbol.toPrimitive`**：这是 ES6 引入的一个内置 Symbol。如果对象上部署了这个方法，引擎会优先调用它，并直接使用它的返回值（无论预期是什么类型）。
    
- **`valueOf()`**：该方法的目的是返回对象的“原始值”表示。对于大多数普通对象，默认的 `valueOf()` 只是返回对象本身（依然不是原始值）；但对于像 `Date` 包装对象，它会返回一个时间戳（数字）。
    
- **`toString()`**：该方法的目的是返回对象的“字符串”表示。对于普通对象，默认返回 `"[object Object]"`；对于数组，返回拼接的字符串。
    

---

### 二、 引擎的调用顺序（面试高频考点）

引擎究竟先调用 `valueOf` 还是 `toString`，取决于**当前的运算场景（Hint）**是期望得到一个数字，还是期望得到一个字符串：

**1. 期望转换为字符串（String Hint）**

比如你在进行字符串拼接，或者使用模板字符串。

- **调用顺序**：优先调用 `toString()`。如果 `toString()` 返回的不是原始值，则继续调用 `valueOf()`。如果都得不到原始值，就会报错（`TypeError`）。
    

**2. 期望转换为数值（Number/Default Hint）**

比如你在进行数学计算（减、乘、除），或者使用 `==` 比较。

- **调用顺序**：优先调用 `valueOf()`。如果 `valueOf()` 返回的不是原始值，则继续调用 `toString()`。如果都得不到原始值，就会报错。

### 三、 经典代码示例演示

为了让你更直观地理解，我们可以手动重写一个对象的这几个方法，看看引擎是如何调用的：

JavaScript

```
const myObj = {
  // 重写 valueOf
  valueOf() {
    console.log("调用了 valueOf");
    return 10; 
  },
  // 重写 toString
  toString() {
    console.log("调用了 toString");
    return "hello";
  }
};

// 场景 1：数学运算（期望得到数值）
console.log(myObj * 2); 
// 打印输出: 
// "调用了 valueOf"
// 20

// 场景 2：期望得到字符串（强制类型转换）
console.log(String(myObj)); 
// 打印输出:
// "调用了 toString"
// "hello"

// 场景 3：加号运算 (+)
// 加号运算既可以是数字相加，也可以是字符串拼接，因此它的默认偏好是 Number（除了 Date 对象）。
console.log(myObj + " world"); 
// 打印输出:
// "调用了 valueOf"
// "10 world" （注意：这里先通过 valueOf 拿到了数字 10，然后因为遇到了字符串 " world"，触发了隐式转换的拼接规则）
```

### 四、 面试标准答句（建议掌握）

如果在面试中，面试官追问：**“对象在转换为基本类型时，底层的具体过程是怎样的？”** 你可以这样回答：

“在 JavaScript 底层，对象转基本类型的过程是通过 `ToPrimitive` 机制完成的。这个过程主要依赖对象内部的三个方法：`Symbol.toPrimitive`、`valueOf()` 和 `toString()`。

当发生类型转换时，引擎会优先检查对象是否部署了 `Symbol.toPrimitive` 方法，如果有则直接调用。如果没有，引擎会根据当前的运算场景来决定调用顺序。

如果是处于需要字符串的场景（比如显式调用 `String()`），引擎会优先调用 `toString()` 方法，如果返回的不是原始值，再调用 `valueOf()` 方法。如果是处于需要数值的场景（比如数学运算），引擎则会优先调用 `valueOf()` 方法，如果得不到原始值，再去调用 `toString()` 方法。这就是对象进行隐式转换时的核心底层逻辑。”
