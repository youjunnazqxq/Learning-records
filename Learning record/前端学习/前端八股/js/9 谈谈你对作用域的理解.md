**面试标准答句（作用域与作用域链 极简版）**

在面试中，建议按照“作用域分类 -> 词法作用域特征 -> 作用域链查找机制”的逻辑来回答，这能与你上一题的“闭包”知识完美串联起来。

你可以这样回答面试官：

**1. 什么是作用域及其分类**

“作用域就是变量和函数生效、能被访问的区域，它决定了代码中变量的可见性。在 JavaScript 中主要分为三种：

- **全局作用域：** 任何不在函数或大括号中声明的变量，在程序的任意位置都能访问。
    
- **函数（局部）作用域：** 在函数内部声明的变量，只能在函数内部访问。
    
- **块级作用域：** ES6 引入的 `let` 和 `const` 关键字生成的，仅在当前大括号（如 if/for 语句）内部生效。”
    

**2. JavaScript 的核心特征：词法作用域（加分项）**

“这里需要强调的是，JavaScript 遵循的是**词法作用域（又叫静态作用域）**。这意味着变量的作用域在代码写好（变量被创建）时就已经确定了，而不是在代码执行阶段确定的。”

**3. 什么是作用域链？（核心答句）**

“当我们在代码中使用一个变量时，JavaScript 引擎会尝试在当前作用域下寻找该变量。

如果没找到，它就会顺着代码的物理层级，向它的上一层（外层）作用域去寻找，以此类推，就像在大楼里一层一层往上爬，直到找遍顶层的全局作用域。

这种一层一层嵌套的查找关系，就构成了**作用域链**。如果在全局作用域依然找不到，严格模式下就会直接报错。”
