**面试标准答句（极简版）**

你可以这样回答面试官，条理清晰且直击核心：

**1. 核心区别（一句话概括）**

“它们最根本的区别在于**是否真正开辟了新的堆内存空间**。浅拷贝只复制对象的第一层，对于里面的引用类型，拷贝的只是内存地址，修改会相互影响；深拷贝则是递归复制所有层级，新旧对象完全独立，互不干扰。”

**2. 浅拷贝的常见方式**

“日常开发中，浅拷贝常表现为：`Object.assign`、ES6 的展开运算符 `...`，以及数组的 `slice()` 和 `concat()` 方法。”

**3. 深拷贝的实现与避坑（加分项）**

“实现深拷贝最快的方法是 `JSON.parse(JSON.stringify(obj))`，但它有忽略 `undefined`、`Symbol` 和函数的弊端。因此在实际项目中，一般推荐直接使用 lodash 的 `_.cloneDeep()`。如果需要手写，核心思路是利用**递归**来遍历，并且一定要借助 `WeakMap` 来缓存已经拷贝过的对象，以此解决循环引用导致的死循环问题。”

```

function deepClone(obj, hash = new WeakMap()) {
  if (obj === null) return obj; // 如果是null或者undefined我就不进行拷贝操作
  if (obj instanceof Date) return new Date(obj);
  if (obj instanceof RegExp) return new RegExp(obj);
  // 可能是对象或者普通的值  如果是函数的话是不需要深拷贝
  if (typeof obj !== "object") return obj;
  // 是对象的话就要进行深拷贝
  if (hash.get(obj)) return hash.get(obj);
  let cloneObj = new obj.constructor();
  // 找到的是所属类原型上的constructor,而原型上的 constructor指向的是当前类本身
  hash.set(obj, cloneObj);
  for (let key in obj) {
    if (obj.hasOwnProperty(key)) {
      // 实现一个递归拷贝
      cloneObj[key] = deepClone(obj[key], hash);
    }
  }
  return cloneObj;
}
```
