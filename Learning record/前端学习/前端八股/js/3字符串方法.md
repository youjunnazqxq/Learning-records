

### 一、 核心考点提炼与升华

根据文档内容，在记忆和回答字符串方法时，你需要抓住以下几个核心：

**1. 绝对的前提：字符串是不可变的（Immutable）**

这是和数组最大的区别！数组的 `push`、`splice` 会改变原数组，但**字符串一旦创建，就不可变**。文档中提到的所有“增”、“删”、“改”方法，本质上都是在内存中**创建并返回了一个新的字符串副本**，绝对不会对原字符串产生任何影响。

**2. 易混淆的“截取三兄弟”**

- `slice()`、`substring()`、`substr()` 都用于截取字符串。
    
- _面试常考区分：_ 现代开发中最推荐使用 `slice()`（支持负数索引）；`substring()` 不支持负数（会将负数视为 0）；`substr()` 的第二个参数是“截取长度”而不是结束索引，且目前在 Web 标准中已被废弃，不推荐使用。
    

**3. 正则表达式的“黄金搭档”**

字符串的 `match()`、`search()`、`replace()` 这三个方法经常结合正则表达式（RegExp）一起使用，是处理复杂文本数据的核心手段。

**4. 桥梁方法：`split()`**

`split()` 是字符串和数组之间互相转换的重要桥梁，它通过指定分隔符将字符串拆分成数组。它和数组的 `join()` 方法刚好是一对反操作。

### 二、 面试标准答句（建议直接背诵）

当面试官问：**“说说 JavaScript 中字符串的常用方法有哪些？”** 时，你可以按照“抛出核心特性 -> 分类罗列 -> 强调高频场景”的逻辑来回答：

**【开场：定下专业基调】**

“JavaScript 提供了非常丰富的字符串处理方法。但在总结这些方法之前，我认为最核心的前提是要明确一点：**JavaScript 中的字符串是不可变的**。这意味着所有的增、删、改操作，实际上都不会改变原字符串，而是返回一个新的字符串副本。”

**【第一部分：基础操作（截取与查找）】**

“我习惯将这些方法按功能进行分类。

首先是**截取方法**，常用的有 `slice()` 和 `substring()`，它们都可以提取字符串的子串。

其次是**查找方法**，如果只找位置，可以用 `indexOf()`；如果需要判断是否包含某个子串，我会优先使用 ES6 引入的更语义化的 `includes()`，或者 `startsWith()` 和 `endsWith()`。”

**【第二部分：格式化与正则匹配】**

“接着是**格式化方法**。比如清除两端空格的 `trim()`，进行大小写转换的 `toLowerCase()` 和 `toUpperCase()`，以及在处理时间或编号时常用来补齐位数的 `padStart()`。

在处理复杂文本时，我会使用**支持正则表达式的匹配方法**。比如用于查找匹配索引的 `search()`，提取匹配内容的 `match()`，以及用于文本替换的 `replace()`。”

**【第三部分：结构转换】**

“最后，还有一个非常重要的数据**转换方法** `split()`。它能够根据指定的分隔符，将字符串拆分成一个数组，这在处理 URL 参数或 CSV 数据时非常常用。”
