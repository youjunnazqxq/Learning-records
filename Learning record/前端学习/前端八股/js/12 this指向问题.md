**面试标准答句（this 指向与绑定规则 极简版）**

在面试中回答 `this` 指向问题时，最核心的是向面试官展示你理解它的“动态绑定”**特性以及**“优先级顺序”。

你可以这样回答：

**1. 核心概念（一句话概括）** “在 JavaScript 中（除了箭头函数），`this` 的指向并不是在函数定义时确定的，而是在**函数执行（被调用）时**决定的。简而言之，就是**谁最后调用了函数，`this` 就指向谁**。”

**2. 四种绑定规则与优先级（得分核心）**

“决定 `this` 指向的规则主要有四种，按照优先级从高到低分别是：

- **new 绑定（最高）：** 当通过 `new` 关键字调用构造函数时，`this` 指向内部新生成的实例对象。(注意：如果构造函数手动 `return` 了一个新对象，`this` 就会指向那个返回的对象)。
    
- **显式绑定：** 通过 `call()`、`apply()` 或 `bind()` 方法主动强制修改 `this` 的指向。
    
- **隐式绑定：** 当函数作为某个对象的方法被调用时（例如 `obj.fn()`），`this` 指向直接调用它的那个上级对象。
    
- **默认绑定（最低）：** 独立函数调用。在非严格模式下指向全局对象（浏览器中是 `window`），在严格模式下 `this` 为 `undefined`。”
    

**3. 箭头函数特例（加分项，必提）** “需要特别说明的是 ES6 的**箭头函数**。箭头函数没有自己的 `this`，它完全不遵守上述的四种运行时绑定规则。它的 `this` 是在编译阶段（词法作用域）就确定的，永远指向它外层作用域的 `this`，并且无法被 `call` 或 `bind` 修改。”
