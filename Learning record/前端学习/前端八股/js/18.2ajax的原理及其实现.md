### 1. AJAX 核心原理

AJAX（异步 JavaScript 和 XML）的核心原理是通过 `XMLHttpRequest` 对象向服务器发送异步请求，获取数据后利用 JavaScript 操作 DOM 进行页面的局部更新，而无需重新加载整个网页。

文档中用了一个很生动的比喻：老板（浏览器）派秘书（XHR 对象）去叫小李（请求数据），老板在此期间可以继续做其他工作（异步执行），等秘书把小李带到（接收到返回数据）再进行后续汇报操作。

### 2. 标准实现步骤 (五步走)

实现一个原生的 AJAX 交互需要以下关键步骤：

- **第一步：创建核心对象**。实例化 `new XMLHttpRequest()`。
    
- **第二步：与服务端建立连接**。调用 `xhr.open(method, url, async)` 方法配置请求的方式（如 GET 或 POST）、目标地址以及是否异步操作。
    
- **第三步：给服务端发送数据**。调用 `xhr.send([body])` 发送请求。需要注意，GET 请求的数据需拼接到 URL 中且 `send` 传 `null`；POST 请求的数据则直接放在 `send` 方法内作为请求体发送。
    
- **第四步：绑定通信状态监听事件**。绑定 `onreadystatechange` 事件，时刻监听 `readyState` 属性（存在 0-4 五个状态）的变化。
    
- **第五步：接收并处理响应**。当 `readyState` 变为 4（代表请求过程完毕）且 HTTP 状态码（`status`）在 200~300 之间时，代表请求成功，此时通过 `responseText` 获取服务端返回的结果并更新到页面中。
    

### 3. AJAX 封装思路

由于每次发送请求都写一遍上述五个步骤非常繁琐，通常会将其封装成一个工具函数。

封装的核心是将配置参数（如请求类型 `type`、地址 `url`、数据载体 `data`）以及处理结果的**回调函数**（`success` 和 `fail`）组合成一个 `options` 对象传入。在函数内部自动判断 GET 或 POST 以决定参数的处理方式，并在 `readyState === 4` 时根据状态码触发对应的成功或失败回调。
