函数缓存（Memoization）是前端性能优化和函数式编程中非常经典的一个技巧。

它的核心思想是：**如果一个函数是纯函数（给定相同的输入，永远返回相同的输出），并且它的计算过程非常耗时，我们就可以把它之前的计算结果“记”下来。下次再遇到相同的参数时，直接从记忆库里拿结果，而不必再算一遍。**

在 JavaScript 中，实现函数缓存主要依赖两个我们前面讲过的核心武器：

1. **闭包（Closure）**：用来在内存中开辟一块私密的空间，长久地保存“记忆库”（缓存字典）。
    
2. **高阶函数（Higher-Order Function）**：接收一个原本的慢函数，给它包装上一层缓存逻辑，然后返回一个变快了的新函数。
    

### 1. 基础实现（单参数）

我们先来看一个最基础的实现逻辑：

JavaScript

```
// 这是一个通用的缓存包装器（高阶函数）
function memoize(fn) {
  // cache 就是我们的记忆库，利用闭包让它一直存在
  const cache = {}; 

  // 返回一个新的带有缓存功能的函数
  return function(arg) {
    // 1. 检查字典里有没有存过这个参数的结果
    if (cache.hasOwnProperty(arg)) {
      console.log('命中缓存，直接返回！');
      return cache[arg];
    }
    
    // 2. 如果没存过，就老老实实调用原函数去算
    console.log('没有缓存，进行复杂计算...');
    const result = fn(arg);
    
    // 3. 把算出来的结果存进字典，方便下次用
    cache[arg] = result;
    
    return result;
  };
}
```

**测试一下：**

JavaScript

```
// 一个假装很耗时的纯函数
function slowSquare(n) {
  for(let i = 0; i < 10000000; i++) {} // 模拟耗时
  return n * n;
}

// 包装它！
const fastSquare = memoize(slowSquare);

fastSquare(5); // 没有缓存，进行复杂计算... (耗时较长)
fastSquare(5); // 命中缓存，直接返回！(瞬间完成)
```

### 2. 进阶实现（多参数）

上面的基础版只支持一个参数。如果我们的函数有多个参数怎么办？对象的 key 只能是字符串，所以我们需要把多个参数组合成一个唯一的“指纹”（Key）。

通常，最暴力的做法是用 `JSON.stringify`，或者把参数用特殊符号拼接起来：

JavaScript

```
function memoizeAdvanced(fn) {
  const cache = {};
  
  // 使用 rest 运算符接收任意数量的参数
  return function(...args) {
    // 将参数数组序列化为字符串作为 Key
    // 注意：如果参数是复杂的对象，JSON.stringify 可能会有性能损耗或循环引用报错
    const key = JSON.stringify(args);
    
    if (cache[key]) {
      return cache[key];
    }
    
    // 使用 apply 或扩展运算符执行原函数
    const result = fn.apply(this, args);
    cache[key] = result;
    return result;
  };
}
```

### 3. 函数缓存的最经典应用：斐波那契数列

如果不加缓存，经典的递归求斐波那契数列（1, 1, 2, 3, 5, 8...）会产生可怕的**冗余计算**。比如算 `fib(5)` 时，`fib(3)` 会被重复计算两次。当数字变大时，计算量会呈指数级爆炸。

加上缓存后，复杂度直接从 $O(2^n)$ 降到了 $O(n)$。

### 面试怎么答？

如果面试官问“如何实现函数缓存？”，你可以这样回答：

“函数缓存本质上是**闭包**和**高阶函数**的结合。我们会编写一个包装函数，在它内部利用闭包维护一个对象或 `Map` 作为缓存字典。返回的新函数在执行时，会先根据传入的参数生成一个唯一的 Key，去字典里查。查到了直接返回，没查到就执行原函数，并把结果存入字典。这种技术特别适合用在纯函数的复杂计算场景中，比如深层递归或大量数据处理，能极大地提升性能。”
