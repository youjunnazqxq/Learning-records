### CSS3 动画核心知识点提取与补充

按照你的需求，我为你梳理了这份 CSS3 动画文档的核心要点，并做出了相应的延伸补充与面试话术总结。

#### 一、 文档核心知识点提取

- **核心概念**：CSS 动画是指允许元素从一种样式逐渐过渡为另一种样式的过程。复杂的动画往往是由多个简单动画组合而成的。
    
- **三大实现技术**：
    
    1. **transition（渐变过渡）**：包含 `property`（需要变化的属性）、`duration`（持续时间）、`timing-function`（速度曲线，如 `ease`, `linear` 等）以及 `delay`（延迟时间）四个部分。需要注意，并非所有 CSS 属性都支持过渡，例如 `display:none` 到 `display:block` 是无法产生渐变效果的。
        
    2. **transform（变形）**：本身只改变元素的“外表”，不涉及时间维度的动画过程，因此通常配合 `transition` 使用。其包含四个常用功能：`translate`（位移）、`scale`（缩放）、`rotate`（旋转）、`skew`（倾斜）。使用时需注意，它不支持 `inline` 元素，需要将其转为 `block` 级别。
        
    3. **animation（自定义动画）**：这是一个复合属性，包含 8 个子属性（例如播放次数 `iteration-count`、方向 `direction`、填充模式 `fill-mode` 等）。通过结合 `@keyframes` 规则，使用 `from...to` 或百分比（如 `0%`, `50%`, `100%`）来定义生命周期中的关键帧，浏览器会自动计算中间的插值并渲染出来。

#### 二、 知识点补充（面试加分项）

除了文档列出的基础知识，面试中抛出以下几点能极大提升你的技术深度：

- **触发机制的区别**：`transition` 通常是被动的，需要一个触发条件（例如鼠标 `:hover`、JS 动态修改 class 等）才能执行；而 `animation` 是主动的，可以设置为页面加载后自动运行，并且可以通过 `animation-play-state` 随时暂停和恢复。
    
- **性能优化（硬件加速）**：在实现动画时，业界最佳实践是优先改变 `transform` 和 `opacity` 属性。因为改变这两个属性不会触发浏览器的重排（Reflow）和重绘（Repaint），并且浏览器会自动为其开启 GPU 硬件加速，使动画极其流畅，避免移动端掉帧卡顿。
    
- **逐帧动画（Sprite 动画）**：`animation` 的 `timing-function` 除了常用的贝塞尔曲线，还支持 `steps()` 函数。它不会平滑过渡，而是像翻书一样一帧一帧地跳跃，非常适合配合雪碧图（Sprite Sheet）制作游戏人物行走、加载中图标等逐帧动画。

#### 三、 面试话语模板（简短版）

**面试官问**：“CSS3 动画有哪些实现方式？它们有什么区别？”

**你的回答**：

> “CSS3 实现动画主要依赖三种技术：**Transition**、**Transform** 和 **Animation**。
> 
> 简单来说，`transform` 是用来改变元素的形态，比如平移、旋转或缩放，它本身是一瞬间完成的；所以我们通常用 `transition` 给它加上时间线，实现平滑的交互过渡，这种方式很适合做按钮悬停等简单的触发式动画。
> 
> 如果需要做复杂的、多阶段的或者一进页面就自动循环播放的动画，我会使用 `animation` 配合 `@keyframes` 关键帧来实现，它可以精细控制动画的每一步和播放状态。
> 
> 另外在开发中我很注重动画性能，所以我会尽量避开改变 `width`、`top` 这类会引起重排的属性，而是优先使用 `transform` 和 `opacity` 来做动画，利用 GPU 硬件加速来保证动画的流畅度。”
