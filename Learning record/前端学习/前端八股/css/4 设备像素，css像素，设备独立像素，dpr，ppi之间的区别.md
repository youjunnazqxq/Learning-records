

### 文档内容总结

文档将这几个概念分为了“像素单位”和“屏幕参数”两个维度来进行解释：

**1. 三种像素概念**

- **设备像素 (物理像素)**：设备硬件上真实的、发光的最小物理单位。屏幕从出厂那一刻起，物理像素的数量和大小就固定不变了。
    
- **设备独立像素 (逻辑像素)**：计算机底层系统抽象出来的一个虚拟单位。它的出现是为了解决不同物理分辨率手机（如 iPhone 3GS 和 iPhone 4）上页面布局大小不一致的问题，确保同一个元素在不同屏幕上看起来物理尺寸相近。
    
- **CSS 像素 (px)**：我们在前端代码中使用的相对长度单位。在页面没有缩放的标准情况下，1个 CSS 像素通常等同于 1个设备独立像素。但它会受页面缩放比、DPR 等因素影响而代表不同的物理像素。
    

**2. 两个关键参数**

- **DPR (设备像素比)**：是**设备像素**与**设备独立像素**的比值（`DPR = 设备像素 / 设备独立像素`）。它决定了用多少个物理发光点来渲染一个逻辑上的像素。例如，当 DPR 为 2 时，1个 CSS 像素实际上是由 4个（2x2）物理像素来显示的。
    
- **PPI (每英寸像素)**：代表屏幕的像素密度。PPI 的数值越高，说明屏幕在单位面积内包含的物理像素点越多，图像显示就越细腻清晰。

### 面试回答话术生成

如果在前端面试中被问到：**“请说说设备像素、CSS像素、设备独立像素、DPR和PPI的区别和联系？”**

**设备像素**就是屏幕真实的物理发光点。为了屏蔽不同设备的硬件差异，系统抽象出了**设备独立像素**（逻辑像素）来帮助我们统一布局。

我们写代码用的 **CSS 像素**，在页面无缩放时，就等于 1 个设备独立像素。

它们之间的转换桥梁是 **DPR（设备像素比）**，也就是物理像素除以逻辑像素的比值。比如在 DPR 为 2 的高清屏上，1个 CSS 像素实际会用 4 个物理像素来渲染，这正是移动端‘1px 边框变粗’的根本原因。

最后，**PPI** 是屏幕的物理像素密度。PPI 越高屏幕越精细，通常厂家为其设定的 DPR 也就越大。”
