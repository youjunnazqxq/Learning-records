这份文档主要总结了前端开发中常见的几种 CSS 长度单位（`px`、`em`、`rem`、`vh`、`vw`）的区别与各自的特点。

### 文档内容总结

文档将这几个单位划分为了**绝对长度单位**和**相对长度单位**两大类：

- **px (像素)**
    
    - **类型**：绝对长度单位。
        
    - **特点**：代表显示器上的小像素点。大小是固定且精确的，不受其他元素属性的影响。
        
- **em**
    
    - **类型**：相对长度单位。
        
    - **特点**：它的基准点是**当前对象或父节点**的字体大小（`font-size`）。
        
    - **缺陷**：它的值并不固定，会随着 DOM 树的嵌套产生级联继承，导致在复杂布局中计算尺寸非常麻烦。
        
- **rem (root em)**
    
    - **类型**：相对长度单位。
        
    - **特点**：它的基准点永远是 **HTML 根元素** 的字体大小。
        
    - **优势**：集成了相对大小和绝对大小的优点。它避免了 `em` 复杂的级联计算，通常开发者会在根节点设置 `font-size: 62.5%`（即 10px，因为浏览器默认 16px），从而实现 `1rem = 10px` 的极简换算，非常利于移动端适配。
        
- **vw / vh (视口单位)**
    
    - **类型**：相对长度单位。
        
    - **特点**：它们是相对于浏览器可视窗口（或移动端布局视口）的尺寸。将视口宽高平分为 100 份，`1vw` 即代表视口宽度的 1%，`1vh` 代表视口高度的 1%。
        
    - **与 `%` 的区别**：`vw/vh` 始终相对于视口，而 `%` 宽泛来说是相对于父元素（或已定位的祖先元素）计算的。

### 面试回答话术生成

如果在面试中被问到：**“请说说 px, em, rem, vh, vw 的区别？”**

你可以这样回答：

> “面试官你好，这几个单位主要可以从**绝对单位**和**相对单位**两个维度来区分。
> 
> 首先，**`px`** 是绝对单位，它代表屏幕上的物理像素点，页面会按照精确的像素进行展示，大小不受外界因素影响。
> 
> 剩下的四个都是相对单位，但它们**相对的基准**各不相同：
> 
> 1. **`em`** 是相对于**父元素**的字体大小。它的缺点是会产生级联继承，嵌套深了之后尺寸计算会变得非常复杂，现在相对少用。
>     
> 2. **`rem`** 是相对于 **HTML 根节点**的字体大小。它规避了 `em` 的继承问题，全局只有一个基准，非常方便统一换算，目前广泛应用于移动端响应式适配。
>     
> 3. **`vw` 和 `vh`** 是相对于**浏览器视口**的宽高。`1vw` 等于视口宽度的 1%。它们在处理全屏布局或者需要严格根据屏幕尺寸缩放的场景下，比百分比（`%`）更加好用，因为百分比通常是受限于父元素尺寸的。
>     
> 
> 总结来说，传统的固定布局多用 `px`，移动端字体或元素缩放适配多用 `rem`，而大屏视口布局则优先考虑 `vw` 和 `vh`。”
