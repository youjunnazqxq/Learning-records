在前端开发中，处理文本溢出（尤其是溢出后显示省略号 `...`）是非常经典的场景，也是高频面试题。根据实际需求，通常分为**单行文本溢出**和**多行文本溢出**两种解决方案。

以下是具体的实现方式和核心知识点：

### 一、 单行文本溢出显示省略号

这是最基础也最常用的场景。要实现单行文本溢出显示省略号，**必须同时满足以下三个 CSS 属性**（缺一不可）：

1. **`white-space: nowrap;`**：强制文本在同一行内显示，不允许换行。
    
2. **`overflow: hidden;`**：将超出容器宽度的文本隐藏起来。
    
3. **`text-overflow: ellipsis;`**：用省略号（`...`）代替被隐藏的溢出文本。
    

**代码示例：**

CSS

```
.single-line-ellipsis {
  width: 200px; /* 必须限制容器宽度 */
  white-space: nowrap; /* 1. 强制不换行 */
  overflow: hidden;    /* 2. 隐藏溢出部分 */
  text-overflow: ellipsis; /* 3. 显示省略号 */
}
```

---

### 二、 多行文本溢出显示省略号

多行文本溢出的处理相对复杂一些。目前最主流且简洁的做法是利用 Webkit 的 CSS 扩展属性。

#### 1. 基于 Webkit 的方案（现代浏览器/移动端首选）

通过 `-webkit-line-clamp` 属性限制文本显示的行数。虽然带有 `-webkit-` 前缀，但目前主流浏览器（包括 Chrome、Safari、Edge、Firefox 等）都已经支持。

同样需要组合使用几个属性：

**代码示例：**

CSS

```
.multi-line-ellipsis {
  width: 200px; /* 必须限制容器宽度 */
  display: -webkit-box; /* 1. 将对象作为弹性伸缩盒子模型显示 */
  -webkit-box-orient: vertical; /* 2. 设置或检索伸缩盒对象的子元素的排列方式为垂直方向 */
  -webkit-line-clamp: 3; /* 3. 限制在一个块元素显示的文本的行数（这里设为3行） */
  overflow: hidden; /* 4. 隐藏超出的内容 */
}
```

#### 2. 兼容老旧浏览器的 CSS 伪元素方案

如果需要兼容极其老旧的浏览器（如早期的 IE），`-webkit-line-clamp` 就无能为力了。此时可以通过设定固定的高度，并利用 `::after` 伪元素在右下角绝对定位一个包含 `...` 的方块来遮挡。

**代码示例：**

CSS

```
.multi-line-fallback {
  position: relative;
  width: 200px;
  line-height: 20px; /* 设置行高 */
  max-height: 60px; /* 最大高度 = 行高 * 行数 (这里是3行) */
  overflow: hidden;
}

.multi-line-fallback::after {
  content: "...";
  position: absolute;
  bottom: 0;
  right: 0;
  padding-left: 20px; /* 预留渐变或背景遮挡的空间 */
  background: linear-gradient(to right, transparent, #fff 50%); /* 渐变遮罩，使过渡更自然 */
}
```

_注意：这种方式的缺点是无论文本是否真的溢出，省略号可能都会显示（除非配合 JS 判断）。_

---

### 三、 进阶：JavaScript 动态截取方案

有些极端场景（比如需要精确到字符数，或者需要在省略号后面紧跟一个“展开/收起”按钮），纯 CSS 很难完美实现，这时候就需要借助 JavaScript。

**核心思路：**

1. 获取容器的实际宽度和文本的完整长度。
    
2. 比较元素的 `scrollHeight` 和 `clientHeight`。
    
3. 如果 `scrollHeight > clientHeight`，说明溢出了，就通过循环不断截掉文本的最后一个字符并加上 `...`，直到它不再溢出为止。
    

### 面试话语模板（简短版）

**面试官问**：“平时开发中你是怎么处理文本溢出显示省略号的？”

**你的回答**：

> “处理文本溢出主要分单行和多行两种情况。
> 
> 如果是**单行文本**，我会组合使用三个 CSS 属性：首先用 `white-space: nowrap` 强制不换行，然后用 `overflow: hidden` 隐藏超出部分，最后用 `text-overflow: ellipsis` 显示省略号。
> 
> 如果是**多行文本**，目前最常用的做法是利用 Webkit 的弹性盒子属性：将 `display` 设置为 `-webkit-box`，`box-orient` 设为 `vertical`，然后通过 `-webkit-line-clamp` 指定需要限制的行数，最后加上 `overflow: hidden` 就可以了。这个方案在移动端和现代浏览器上兼容性已经非常好了。”
