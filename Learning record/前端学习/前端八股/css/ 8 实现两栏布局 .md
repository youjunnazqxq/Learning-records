这份文档列举了多种布局方案，但正如你之前所感觉的，在现代开发中，**Flex 和 Grid 才是这道题的标准答案**。它们不仅代码精简，而且语义清晰。

以下是基于文档中 Flex 和 Grid 方案的原理总结：

### 1. Flex 弹性布局（🌟 万能解法）

Flex 布局的核心逻辑是通过分配“容器的剩余空间”来实现自适应。

- **两栏布局（右侧自适应）：**
    
    - **原理**：父容器设置 `display: flex;`。左侧元素设置固定宽度（如 `width: 200px`），右侧元素设置 `flex: 1;`。
        
    - **效果**：右侧元素会像海绵一样，自动吸收并填满父容器剩下的所有空间。
        
- **三栏布局（中间自适应）：**
    
    - **原理**：父容器设置 `display: flex;`。左、右两侧元素分别设置固定宽度，中间元素设置 `flex: 1;`（或者 `width: 100%` 配合 `margin`）。
        
    - **效果**：左右两边把空间占好后，中间的元素会自动伸展，把两边撑开并填满中间的空隙。
        
    - **细节优势**：Flex 默认带有 `align-items: stretch` 属性，能自动让左右侧和中间的列保持等高。
        

### 2. Grid 网格布局（✨ 降维打击）

Grid 布局的核心逻辑是直接在父容器上“画格子”，子元素按顺序对号入座。

- **三栏/两栏布局：**
    
    - **原理**：父容器设置 `display: grid;`。直接通过 `grid-template-columns` 属性定义每一列的宽度。比如三栏就是 `grid-template-columns: 300px auto 300px;`（或者写成 `300px 1fr 300px`）。
        
    - **效果**：第一列和第三列被严格锁死在 300px，中间那列标记为 `auto`（或 `1fr`），浏览器会自动把中间的格子拉长，填补剩余空间。

### 🎤 面试官模拟答复（精简话术）

在面试中遇到这个问题，建议直接亮出最优解，展现你的现代前端思维：

> “面试官您好。在日常开发中，无论是实现‘右侧自适应的两栏布局’，还是‘中间自适应的三栏布局’，我首选的方案都是 **Flex 布局**或 **Grid 布局**。
> 
> **如果是 Flex 方案：** 我会给父容器开启 `display: flex`。对于需要固定的侧边栏，直接设置固定的 `width`；对于需要自适应的区域（比如两栏的右侧、三栏的中间），直接设置 `flex: 1` 即可让它自动铺满剩余空间。这种写法不仅代码极简，还能顺便解决等高对齐的问题。
> 
> **如果是 Grid 方案则更直观：** 给父容器开启 `display: grid`。通过 `grid-template-columns` 属性，把固定栏写死像素值，自适应栏写成 `auto` 或者 `1fr`，一行代码就能划分好完美的页面骨架。
> 
> 至于像浮动（Float）、BFC 或者绝对定位加负边距等传统方案，虽然能实现，但容易产生副作用或导致 HTML 结构复杂，除了维护老项目，新项目中我已经很少使用了。”
