

## 📝 核心笔记：CSS 选择器、优先级与继承

### 1. CSS 选择器的分类

CSS 选择器通过不同的组合方式来匹配 HTML 元素。

- **基础选择器**：包括 **ID 选择器**（`#id`）、**类选择器**（`.class`）和**标签选择器**（`div`）。
    
- **关系选择器**：
    
    - **后代选择器**（空格）：选择父元素内部所有的后代元素。
        
    - **子选择器**（`>`）：仅选择父元素的直接子元素。
        
    - **相邻同胞选择器**（`+`）：选择紧接在另一元素后的元素。
        
    - **通用兄弟选择器**（`~`）：选择某元素之后的所有同级兄弟元素。
        
    - **群组选择器**（`,`）：同时为多个选择器应用相同样式。
        
- **伪类与伪元素**：
    
    - **伪类**（单冒号）：如 `:hover`（鼠标悬停）、`:focus`（获取焦点）、`:nth-child(n)`（匹配第 n 个子元素）。
        
    - **伪元素**（双冒号/单冒号）：如 `::before` 和 `::after`（在内容前后插入内容）、`::first-line`（匹配首行）。
        
- **属性选择器**：根据元素的属性及其值来选择，如 `[type="text"]` 或 CSS3 新增的 `[attr^="val"]`（以某值开头）。
    

### 2. 优先级计算规则（权重）

当多个 CSS 规则作用于同一个元素时，浏览器通过 **(A, B, C, D)** 权重算法来决定最终样式。

- **A (内联样式)**：如果存在内联样式（style 属性），则 A = 1。
    
- **B (ID 选择器)**：统计 ID 选择器出现的次数。
    
- **C (类、属性、伪类)**：统计这三类选择器出现的总次数。
    
- **D (标签、伪元素)**：统计这二类选择器出现的总次数。
    

**比较规则**：从左往右（A -> B -> C -> D）依次比较，数值大者优先级更高。若全部相等，则遵循**就近原则**，后面的样式覆盖前面的。

> **注意**：`!important` 具有最高优先级，可以覆盖内联样式。

### 3. CSS 属性的继承

继承是指父元素的某些属性会被子元素自动拥有。

- **可继承的属性**：
    
    - **字体系列**：`font-family`、`font-size`、`font-weight` 等。
        
    - **文本系列**：`color`、`line-height`、`text-align`、`letter-spacing` 等。
        
    - **其他**：`visibility`（可见性）、`cursor`（光标形状）、列表属性（`list-style`）。
        
- **不可继承的属性**：
    
    - **盒子模型**：`width`、`height`、`margin`、`padding`、`border`。
        
    - **布局与背景**：`display`、`position`、`float`、`background`。
        
- **特殊情况**：`<a>` 标签的颜色和 `<h1>`-`<h6>` 的字体大小默认不会继承父元素的样式。

## 🎤 面试官：请说说 CSS 选择器有哪些？优先级如何计算？哪些属性可以继承？

**回答示例：**

“CSS 选择器种类非常丰富，最基础的是 **ID、类和标签选择器**。此外，我们在布局中经常用到 **关系选择器**，比如子选择器 `>` 和后代选择器；为了增强交互和样式细节，还会用到 **伪类**（如 `:hover`）和 **伪元素**（如 `::before`）。

关于**优先级**，它有一套严格的权重计算规则，通常记为 **(A, B, C, D)**。

- **A** 代表内联样式；
    
- **B** 代表 ID 选择器；
    
- **C** 代表类、属性选择器和伪类；
    
- **D** 则代表标签和伪元素。
    
    浏览器会从左到右进行比较，一旦在高位胜出，该样式就会生效。如果权重完全相同，则后定义的样式会覆盖先定义的。如果遇到必须强制生效的情况，我们会使用 `!important`。
    

最后是**继承性**。CSS 中大部分与文本相关的属性都是可以继承的，比如 `color`、`font-size` 和 `line-height`。但涉及页面布局的盒子模型属性，比如 `margin`、`padding` 以及 `display` 等，都是不可继承的。需要注意的是，像 `<a>` 标签的颜色和标题标签的字号，由于浏览器有默认样式，通常不会直接继承父级的这些设置。”
