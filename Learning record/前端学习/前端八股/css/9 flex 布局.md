这份关于 Flexbox（弹性盒布局模型）的文档内容非常经典。为了达到**易看、易记**的目的，我将其核心逻辑重新梳理，采用“**总-分-总**”的结构，并利用表格进行对比提炼，帮助你快速建立记忆框架。

---

### 一、 核心心智模型 (Flexbox 是什么？)

记住**两个角色**和**两条轴线**：

- **两个角色**：**容器**（Container，外层父元素）和 **项目**（Item，内层子元素）。
    
- **两条轴线**：**主轴**（默认水平）和 **交叉轴**（默认垂直，与主轴呈90度）。
    

> **💡 记忆口诀**：容器管全局（排版方向、整体对齐），项目管自己（顺序、伸缩、自身对齐）。

---

### 二、 容器属性 (Container) —— 管全局

作用于父元素，控制内部所有子元素的整体布局。共有 6 个属性，可以分为 **3 组**来记忆：

|**分组**|**属性名**|**作用**|**常用属性值 (默认值加粗)**|
|---|---|---|---|
|**1. 排列方向**|`flex-direction`|决定主轴方向|**row** (水平向右), column (垂直向下), row-reverse, column-reverse|
||`flex-wrap`|决定排不下时是否换行|**nowrap** (不换行), wrap (换行往下), wrap-reverse|
||`flex-flow`|上面两者的简写|默认：**row nowrap**|
|**2. 主轴对齐**|`justify-content`|项目在主轴上的对齐方式|**flex-start** (起点), flex-end (终点), center (居中), space-between (两端对齐), space-around (两侧间隔相等)|
|**3. 交叉轴对齐**|`align-items`|单行项目在交叉轴上的对齐|flex-start, flex-end, center, baseline, **stretch** (拉伸占满高度)|
||`align-content`|多行（换行后）在交叉轴的对齐|与 align-items 类似，多用于控制多根轴线间的间距。单行不起作用。|

---

### 三、 项目属性 (Item) —— 管个体

作用于子元素，控制单个元素的特殊表现。也是 6 个属性，同样分为 **3 组**记忆：

| **分组**      | **属性名**       | **作用**                  | **常用/默认值**                                                                                                        |
| ----------- | ------------- | ----------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **1. 排序**   | `order`       | 定义排列顺序                  | 默认 **0**。越小越靠前。                                                                                                   |
| **2. 个体对齐** | `align-self`  | 允许单个项目有不同的交叉轴对齐方式       | 默认 **auto** (继承父级 align-items)。可覆盖父级设置。                                                                           |
| **3. 弹性伸缩** | `flex-grow`   | 有剩余空间时，放大的比例            | 默认 **0** (不放大)。设置为1则等分剩余空间。                                                                                       |
|             | `flex-shrink` | 空间不足时，缩小的比例             | 默认 **1** (空间不足均等缩小)。设为0则不缩小。                                                                                      |
|             | `flex-basis`  | 伸缩前，项目在主轴占据的初始尺寸        | 默认 **auto** (本来大小/由内容决定)。可设具体 px 值。                                                                               |
|             | `flex`        | grow, shrink, basis 的简写 | 默认 **0 1 auto**。<br><br>  <br><br>常用捷径：<br><br>  <br><br>`flex: 1` (等分布局)<br><br>  <br><br>`flex: none` (固定尺寸不伸缩) |

---

### 四、 适用场景总结

Flexbox 几乎是现代 Web 开发的布局标配，尤其适合以下场景：

1. **万能居中**：轻松实现元素的水平 + 垂直方向绝对居中（`justify-content: center` + `align-items: center`）。
    
2. **自适应布局**：两栏/三栏布局，一侧固定，另一侧自适应填满（利用 `flex: 1`）。
    
3. **等分布局**：多个元素自动等分容器宽度或高度。
    
4. **移动端 / 小程序开发**：高度推荐，兼容性极佳，能完美解决各种屏幕尺寸的响应式排版问题。
