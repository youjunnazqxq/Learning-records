

### 1. JavaScript 中的栈实现

在 JavaScript 中，我们不需要像其他语言那样引入特定的栈类，因为 **JS 的数组（Array）天生就具备栈的所有核心功能**。我们主要通过数组自带的方法来模拟栈的操作。

JavaScript

```
// 初始化一个栈
const stack = [];

// 1. 入栈 (Push) - 将元素添加到栈顶
stack.push(10);
stack.push(20);
stack.push(30);
console.log(stack); // 状态: [10, 20, 30] (30是当前的栈顶)

// 2. 出栈 (Pop) - 移除并返回最上面的元素（栈顶元素）
const topElement = stack.pop(); 
console.log("被弹出的元素:", topElement); // 输出: 30
console.log(stack);                      // 状态: [10, 20]

// 3. 查看栈顶元素 (Peek) - 只查看，不移除它
const peekElement = stack[stack.length - 1];
console.log("当前栈顶元素:", peekElement); // 输出: 20

// 4. 判断栈是否为空
const isEmpty = stack.length === 0;
console.log("栈为空吗?", isEmpty);        // 输出: false
```

### 2. 栈的常见题型与应用场景

栈非常适合处理“具有最近匹配关系”**或者需要**“倒退回溯”的问题。以下是面试和日常刷题中最常见的三大类题型：

#### 题型一：符号/括号匹配（经典必考）

这类题目通常要求验证给定的字符串中的括号（如 `()`, `{}`, `[]`）是否完全闭合且顺序正确。

- **核心思路：** 遇到左括号就压入栈中；遇到右括号，就检查栈顶元素是否是对应的左括号。如果是，则说明匹配成功，将左括号出栈；否则匹配失败。
    
- **经典题目：** LeetCode 20. 有效的括号
    

#### 题型二：相邻元素消除问题

这类题目要求你在字符串或数组中，将相邻且满足特定条件的元素进行消除（类似于消消乐）。

- **核心思路：** 遍历元素时，将当前元素与栈顶元素比较。如果满足消除条件，就把栈顶元素弹出，当前元素也不入栈；如果不满足，就将当前元素入栈。
    
- **经典题目：** LeetCode 1047. 删除字符串中的所有相邻重复项
    

#### 题型三：单调栈 (Monotonic Stack) —— 进阶杀手锏

单调栈是指栈内的元素始终保持**单调递增**或**单调递减**的顺序。它专门用于解决“寻找数组中下一个更大（或更小）的元素”这类问题，能够将暴力解法的 $O(N^2)$ 时间复杂度优化到 $O(N)$。

- **核心思路：** 遍历数组，当发现当前元素破坏了栈的单调性时，说明我们找到了栈顶元素的“下一个更大/更小值”。此时将栈顶元素依次弹出并记录答案，然后再将当前元素入栈。
    
- **经典题目：** LeetCode 496. 下一个更大元素 I，LeetCode 739. 每日温度
