

“0-1”的意思非常直白：**每个物品只有一件，你要么拿（1），要么不拿（0），不能重复拿。**

为了让你直接掌握最实用、面试中最常考的写法，我们直接跳过二维数组，使用一维数组（滚动数组）的空间优化版本来进行“DP 五步法”拆解。这里面有一个动态规划中最著名的“遍历顺序陷阱”。

### 0-1 背包的一维 DP 五步法

假设我们有一个容量为 `W` 的背包，还有一系列物品，每个物品有自己的重量 `weight[i]` 和价值 `value[i]`。

**1. 确定 `dp` 数组及下标含义**

`dp[j]` 表示：容量为 $j$ 的背包，所能装下的**最大价值**。

**2. 确定状态转移方程**

对于当前正在考虑的第 $i$ 个物品，背包容量为 $j$ 时，我们有两个选择：

- **不放物品 $i$：** 价值就是之前的 `dp[j]`。
    
- **放物品 $i$：** 我们需要先腾出 `weight[i]` 的空间，此时的价值是 `dp[j - weight[i]]`，再加上当前物品的价值 `value[i]`。
    
    我们要在这两者中取最大值：
    
    $$dp[j] = \max(dp[j], dp[j - weight[i]] + value[i])$$
    
    _(你会发现，这个公式跟完全背包一模一样！区别到底在哪？看第 4 步！)_
    

**3. 确定初始化**

- `dp[0] = 0`：容量为 0 的背包，什么都装不下，最大价值肯定是 0。
    
- 因为我们要求的是最大价值，为了不干扰后面的 `Math.max` 取值，其他的 `dp[j]` 初始默认也全设为 0。
    

**4. 确定遍历顺序（核心灵魂！）**

这是 0-1 背包和完全背包**唯一的、也是最致命的区别**：

- **外层循环：** 遍历物品（从前往后）。
    
- **内层循环：** 遍历背包容量，**必须从大到小倒序遍历！**（从 `W` 递减到 `weight[i]`）。
    

**为什么必须倒序？**

因为 `dp[j]` 是根据它前面的状态 `dp[j - weight[i]]` 推导出来的。

如果你**正序遍历**（从小到大），当你计算 `dp[j]` 时，它依赖的 `dp[j - weight[i]]` 在这一轮中**已经被前面的计算更新过了**。这就意味着，同一个物品被放入了两次甚至多次——这直接变成了“完全背包”！

而**倒序遍历**保证了，当我们计算 `dp[j]` 时，它左边的 `dp[j - weight[i]]` 还是上一轮（上一个物品）留下的“旧状态”。这就完美保证了每个物品只被使用一次。

**5. 举例推导**

假设背包最大容量为 4。

物品 0：重量 1，价值 15。

物品 1：重量 3，价值 20。

物品 2：重量 4，价值 30。

为了让你直观看到**倒序遍历**是如何防止物品被重复放入的，我为你生成了一个 0-1 背包的动态推导组件。你可以点击“下一步”，重点观察内层循环的指针是如何**从右向左**移动的：

### 0-1 背包标准代码模板

这是你在遇到任何 0-1 背包变形题时，都可以直接套用的基础模板：

TypeScript

```
function zeroOneKnapsack(weights: number[], values: number[], capacity: number): number {
    // 1. 定义并初始化 dp 数组
    const dp = new Array(capacity + 1).fill(0);

    // 4. 外层循环遍历物品
    for (let i = 0; i < weights.length; i++) {
        // 内层循环遍历背包容量：必须倒序！
        // 且 j 只需要遍历到刚好能放下当前物品的重量 weights[i] 即可
        for (let j = capacity; j >= weights[i]; j--) {
            // 2. 状态转移方程
            dp[j] = Math.max(dp[j], dp[j - weights[i]] + values[i]);
        }
    }

    // 返回装满容量为 capacity 的背包的最大价值
    return dp[capacity];
}
```

**总结一下背包的套路：**

- **0-1 背包（物品只有一件）：** 外层遍历物品，内层**倒序**遍历容量。
    
- **完全背包（物品有无数件）：** 外层遍历物品（或容量），内层**正序**遍历容量。
    

掌握了这个差异，LeetCode 上大部分涉及到组合求和、子集划分的题目，只要你能抽象出“重量”和“容量”，就能直接秒杀了。
