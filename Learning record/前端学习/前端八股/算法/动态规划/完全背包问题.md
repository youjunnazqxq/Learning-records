

### 完全背包的一维 DP 五步法

假设同样是一个容量为 `W` 的背包，一系列物品的重量为 `weight[i]`，价值为 `value[i]`。**唯一区别是：每种物品都有无限件可用。**

**1. 确定 `dp` 数组及下标含义**

`dp[j]` 表示：容量为 $j$ 的背包，所能装下的**最大价值**。（和 0-1 背包完全一样）

**2. 确定状态转移方程**

$$dp[j] = \max(dp[j], dp[j - weight[i]] + value[i])$$

（**惊人地一致！** 和 0-1 背包的公式一模一样。既然公式一样，那区别到底在哪？）

**3. 确定初始化**

`dp[0] = 0`，其余默认也为 0。（也完全一样）

**4. 确定遍历顺序（魔法发生的地方 ✨）**

完全背包和 0-1 背包的**唯一区别**就在这一步：

- **外层循环：** 遍历物品（从前往后）。
    
- **内层循环：** 遍历背包容量，**必须从小到大正序遍历！**（从 `weight[i]` 递增到 `W`）。
    

**为什么完全背包要正序？**

回想一下，0-1 背包倒序是为了**防止**当前物品被重复放入。

而在完全背包中，我们**恰恰需要**物品能被重复放入！

当你正序计算 `dp[j]` 时，它依赖的 `dp[j - weight[i]]` 是在**这一轮**已经被更新过的值。也就是说，`dp[j - weight[i]]` 里面可能已经装了物品 $i$，现在你再计算 `dp[j]`，相当于又往里塞了一件物品 $i$。这完美契合了“物品有无限件”的题意！

为了直观对比，我为你生成了完全背包的推导组件，使用和刚才 0-1 背包完全一样的数据（重量 `[1,3,4]`，价值 `[15,20,30]`，容量 4）。

**请重点观察：** 当遍历到第一个物品（重量 1，价值 15）时，随着容量指针从左往右（正序）移动，`dp[2]` 会变成 30，`dp[3]` 会变成 45…… 物品被无限次放入了！

### 完全背包标准代码模板

对比一下刚才的 0-1 背包，你只需要把内层循环的 `j--` 变成 `j++`，一切就迎刃而解了：

TypeScript

```
function completeKnapsack(weights: number[], values: number[], capacity: number): number {
    const dp = new Array(capacity + 1).fill(0);

    // 外层遍历物品
    for (let i = 0; i < weights.length; i++) {
        // 内层遍历容量：正序遍历！(从小到大)
        for (let j = weights[i]; j <= capacity; j++) {
            dp[j] = Math.max(dp[j], dp[j - weights[i]] + values[i]);
        }
    }

    return dp[capacity];
}
```

### 💡 进阶考点：先遍历物品，还是先遍历背包？

在完全背包的题目中，有一个非常容易踩坑的高频考点（尤其是求“有多少种组合方式”的题目）。

在刚才的代码中，我们是**先遍历物品，再遍历背包容量**。其实对于纯粹求“最大价值”或“最少硬币数”（比如之前的零钱兑换）来说，**两个 for 循环的顺序是可以颠倒的**（先遍历背包，再遍历物品），结果一样。

**但是，如果题目要求的是“装满背包有几种方法”，顺序就极其重要了！**

1. **先遍历物品，后遍历背包（外层物品，内层容量）：**
    
    - 计算出来的是**组合数**。
        
    - 例如凑出面值 5，它只认 `[2, 3]` 这一种组合，不关心顺序。
        
    - _代表题目：LeetCode 518. 零钱兑换 II_
        
2. **先遍历背包，后遍历物品（外层容量，内层物品）：**
    
    - 计算出来的是**排列数**。
        
    - 例如凑出面值 5，它会把 `[2, 3]` 和 `[3, 2]` 算作两种不同的方式！
        
    - _代表题目：LeetCode 377. 组合总和 Ⅳ_
        

**记忆口诀：**

- 如果要求**组合数**（不强调顺序），就让**物品在外面**（一件物品决定完了，再决定下一件，自然没有顺序交替）。
    
- 如果要求**排列数**（强调顺序），就让**背包在外面**（每个容量状态下，所有物品都要重新竞争一次，所以会产生不同的顺序）。
    

- **0-1 背包（物品只有一次）：** **必须**外层物品，内层容量（且内层**倒序**）。 _(先让物品入场，然后从右往左更新容量，保证每次更新用到的左边数据都是上一轮干净的历史数据，物品就不会被重复使用。)_
    
- **完全背包（物品无限次）：** 内层容量必须**正序**。
    
    - 如果是求**组合**（比如凑硬币，不看顺序），外层物品，内层容量。
        
    - 如果是求**排列**（比如单词拆分，看顺序），外层容量，内层物品。
