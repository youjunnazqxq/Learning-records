基于你上传的笔记文件 `4_function.md` 和相关截图，结合你的 Java 背景，我为你总结了一份 **TypeScript 函数核心指南**。

在 TS 中，函数依然是核心，但它比 Java 的方法更灵活。TS 的主要工作是给 JS 的动态函数穿上“类型铠甲”。

-----

### 1\. 函数定义：给参数和返回值加锁

在 Java 中，方法必须定义在类里。在 TS 中，函数是一等公民，可以独立存在。

  * **基本写法**：
    你需要做的是给 **形参** 和 **返回值** 加上类型注解。
    ```typescript
    // Java: public int add(int x, int y) { ... }

    // TS
    function add(x: number, y: number): number {
        return x + y;
    }
    ```
    *注：TS 有能力根据 `return` 语句自动推导返回值的类型，所以 `: number` 有时可以省略。*

-----

### 2\. 完整的函数类型 (The Function Type)

这是你刚才觉得格式复杂的那个部分（即截图 `image_fc146e.png`）。作为 Java 开发者，你可以把它理解为 **“将接口定义和实现写在了一行”**。

它分为两部分：

1.  **左边（类型声明）**：`(x: number, y: number) => number`
      * 这是告诉编译器：变量 `myAdd2` 只能存放一个“接收两个数字并返回数字”的函数。
2.  **右边（具体实现）**：`function(x: number, y: number): number { return x + y }`
      * 这是实际运行的代码。

<!-- end list -->

```typescript
//               类型定义 (类似 Java 接口)            =             具体实现
let myAdd2: (x: number, y: number) => number = function(x: number, y: number): number { 
  return x + y 
};
```

-----

### 3\. 参数的“花样玩法” (Java 没有的特性)

TS 允许参数更灵活，不像 Java 那样严格要求参数个数必须一一对应。

| 特性 | 写法 | 说明 | Java 类比 |
| :--- | :--- | :--- | :--- |
| **可选参数** | `name?: string` | 参数名后加 `?`，表示可传可不传。如果不传，值就是 `undefined`。 | Java 只能用重载或传 `null`。 |
| **默认参数** | `name: string = 'A'` | 如果不传参数（或传 undefined），自动使用默认值 `'A'`。 | 类似 Kotlin/Python 的默认参数。 |
| **剩余参数** | `...args: string[]` | 将多个参数收集到一个数组中。 | Java 的变长参数 `String... args`。 |

**注意**：可选参数必须放在必须参数的**后面**。

-----

### 4\. 函数重载 (Overloading) —— 最大的陷阱

这是 Java 开发者最容易晕的地方。

  * **Java 重载**：写多个同名方法，**每个方法都有自己的实现代码**。
  * **TS 重载**：写多个同名签名（定义），但**只能有一个实现**。

**为什么？** 因为最终编译成的 JS 是弱类型的，不存在“重载”，TS 只是为了在编译时根据不同参数提示不同的返回值。

**写法套路**：

1.  **写签名**（给编译器看的）：定义所有可能的入参组合。
2.  **写实现**（给引擎跑的）：写一个兼容所有类型的函数，在内部用 `typeof` 或 `if` 判断逻辑。

<!-- end list -->

```typescript
// 1. 重载签名 (Java 开发者看这里，这是对外 API)
function add(x: string, y: string): string;
function add(x: number, y: number): number;

// 2. 唯一实现 (必须兼容上面所有情况，通常用 any 或 联合类型)
function add(x: string | number, y: string | number): string | number {
    // 必须自己在代码里手动判断类型
    if (typeof x === 'string' && typeof y === 'string') {
        return x + y;
    } else if (typeof x === 'number' && typeof y === 'number') {
        return x + y;
    }
}
```

-----

### 5\. 小结

根据你的笔记，学习 TS 函数只需要记住三个变化：

1.  **类型后置**：`function(x: type): returnType`。
2.  **参数灵活**：善用 `?` (可选) 和 `=` (默认值)。
3.  **重载这种假象**：由于 JS 运行时不区分类型，重载只是为了编译时的类型检查，实现逻辑要写在一个函数里。
