

### TypeScript 基础核心笔记

#### 1. 类型注解 (Type Annotation)

TS 的核心机制，用于在编译时进行静态检查。

- **语法格式**：`变量名: 类型`（冒号后置）。
    
- **Java 对比**：
    
    - Java (前置)：`String name = "Yee";`
        
    - TS (后置)：`let name: string = "Yee";`
        
- **特性**：
    
    - **静态检查**：类型不匹配时，代码编辑器会爆红（编译报错），但不会影响运行时（如果强行运行 JS）。
        
    - **类型推导 (Inference)**：如果未显式写类型（如 `let a = 1`），TS 会自动推断为 `number`。
        

#### 2. 基础数据类型 (Basic Types)

|**类型**|**写法 (全小写)**|**Java 对应**|**关键点 / 笔记备注**|
|---|---|---|---|
|**数字**|`number`|`int`/`double`|**不分整型浮点**。所有数字（包括二进制、十进制、浮点数）都是 `number`。|
|**字符串**|`string`|`String`|支持单引号 `'`、双引号 `"` 和反引号 `` ` `` (模板字符串)。|
|**布尔**|`boolean`|`boolean`|只有 `true` / `false`。|
|**空值**|`null` / `undefined`|`null`|在 TS 中是独立的类型，通常作为其他类型的子类型使用。|

#### 3. 集合与特殊类型 (Collections & Special Types)

- **数组 (Array)**
    
    - **写法**：`number[]` 或 `Array<number>`
        
    - **特点**：长度不限，元素类型必须一致（除非用联合类型）。
        
    - _例子_：`let arr: number[] = [1, 2, 3];`
        
- **元组 (Tuple)** (Java 无原生对应)
    
    - **写法**：`[string, number]`
        
    - **特点**：**长度固定**，**类型顺序固定**。适合存储一对结构确定的数据。
        
    - _例子_：`let row: [string, int] = ["id", 1];`
        
- **任意类型 (Any)**
    
    - **写法**：`any`
        
    - **特点**：**放弃类型检查**。相当于写原生 JS。
        
    - _笔记_：**慎用！** 除非你正在迁移老旧代码或完全无法确定类型。
        
- **未知类型 (Unknown)** (推荐代替 any)
    
    - **写法**：`unknown`
        
    - **特点**：类似 Java 的 `Object`。你可以赋任何值给它，但在使用之前**必须先检查类型**（断言）。
        
- **空返回 (Void)**
    
    - **写法**：`void`
        
    - **特点**：通常仅用于**函数返回值**，表示函数不返回任何东西。

### 💡 快速记忆口诀 (Java 开发者版)

1. **位置变了**：类型写在冒号后面。
    
2. **数字统了**：不管 `int` 还是 `double`，统统叫 `number`。
    
3. **小写为主**：`string`, `number`, `boolean` 都要小写。
    
4. **数组泛型**：`number[]` 和 Java 写法逻辑一致。
    
5. **元组定死**：`[string, number]` 是定长、定序的数组。
    
6. **Any 是毒**：尽量用 `unknown` 代替 `any`。
