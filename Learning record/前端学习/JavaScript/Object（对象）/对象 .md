# 方括号

这个[] 可以让我们通过变量来访问对象里面的值了，比如
```
let user = {
	name: "John",
	age: 30,
};
let key = prompt("What do you want to know about the uesr","name");
alert(user[key]);
```

这个方括号其实相当于对里面的值进行解析

解析规则：
1. 如果括号里面的是一个变量，他会解析变量来进行求值（求解到底）
2. 如果是一个字符串，原封不动
3. 表达式，求值计算


# in表达式

相比于其他语言，JavaScript 的对象有一个需要注意的特性：能够被访问任何属性。即使属性不存在也不会报错！

读取不存在的属性只会得到 `undefined`。所以我们可以很容易地判断一个属性是否存在

```
let user ={};
 
alert( user.noSuchProperty === undefined);// true 
```

实际上还有一个操作符 “in”可以来判断 

```
"key" in object;
```
请注意，`in` 的左边必须是 **属性名**。通常是一个带引号的字符串。

如果我们省略引号，就意味着左边是一个变量，它应该包含要判断的实际属性名


## for-in 循环
```
let user = {
  name: "John",
  age: 30,
  isAdmin: true
};

for (let key in user) {
  // 打印键 (keys)
  console.log(key);  // 依次输出 name, age, isAdmin

  // 打印属性的值 (values)
  console.log(user[key]); // 依次输出 John, 30, true
}
```

在循环的过程中 ，key被赋予的是键的名字；
对于for-in循环来说，他会遍历对象的所有属性

# 排序

对象中的顺序规则：
整数属性会被进行排序，其他属性则按照创建的顺序显示。

## 整数属性

>[!note]
这里的“整数属性”指的是一个可以在不做任何更改的情况下与一个整数进行相互转换的字符串。
所以，`"49"` 是一个整数属性名，因为我们把它转换成整数，再转换回来，它还是一样的。但是 “+49” 和 “1.2” 就不行了：
>```javascript
// Number(...) 显式转换为数字
// Math.trunc 是内建的去除小数部分的方法。
alert( String(Math.trunc(Number("49"))) ); // "49"，相同，整数属性
alert( String(Math.trunc(Number("+49"))) ); // "49"，不同于 "+49" ⇒ 不是整数属性
alert( String(Math.trunc(Number("1.2"))) ); // "1"，不同于 "1.2" ⇒ 不是整数属性
>```
>解决方法在整数前面加上“+”号就可以解决了；
