类似于py，js编程语言存在着闭包，最显著的区别就是js的内部函数可以修改外部作用域的变量。

# 词法环境

当｛｝的代码被运行的时候。都有一个被称为词法环境的内部关联对象。
其由两部分组成：
1.环境记录：--存储所有局部变量为其属性的对象。
2.对外部词法环境的引用。

## 变量

1. 当脚本开始运行，词法环境预先填充了所有声明的变量。
    - 最初，它们处于“未初始化（Uninitialized）”状态。这是一种特殊的内部状态，这意味着引擎知道变量，但是在用 `let` 声明前，不能引用它。几乎就像变量不存在一样。
2. 然后 `let phrase` 定义出现了。它尚未被赋值，因此它的值为 `undefined`。从这一刻起，我们就可以使用变量了。
3. `phrase` 被赋予了一个值。
4. `phrase` 的值被修改。



## 函数声明

函数也是一个值，像变量一样。
不同的是，函数声明的初始化会被立即完成。
- 当一个函数被**定义**（也就是你写下 `function foo() { ... }` 的那一刻），它会做一件事：
    
- **创建一个闭包**：这个闭包包含了函数自身的代码，以及一个内部属性 `[[Environment]]`。
    
- `[[Environment]]` **指向它被创建时的词法环境**。这就像是给函数盖了一个“出生地”的戳，记录了它是在哪里被定义的

# `[[Environment]]`

对于这个属性来说，他是在函数被创建的时候来绑定的，他引用的对象是外部的词法环境，这就形成了所谓的闭包，而其真正被调用的时候就形成了自己的词法环境
ps：声明并不是函数被创建，在声明的时候就确定了函数可以访问外部变量的哪些值。

## 内部和外部的词法环境 
在一个函数运行时，在调用刚开始时，会自动创建一个新的词法环境以存储这个调用的局部变量和参数。
**当代码要访问一个变量时 —— 首先会搜索内部词法环境，然后搜索外部环境，然后搜索更外部的环境，以此类推，直到全局词法环境**



## 返回函数

在每次调用函数的时候都会创建一个新的词法环境，所有函数都有名为 `[[Environment]]` 的隐藏属性，该属性保存了对创建该函数的词法环境的引用。

>[!note ]
>[闭包](https://en.wikipedia.org/wiki/Closure_\(computer_programming\)) 是指一个函数可以记住其外部变量并可以访问这些变量。在某些编程语言中，这是不可能的，或者应该以一种特殊的方式编写函数来实现。但如上所述，在 JavaScript 中，所有函数都是天生闭包的（只有一个例外，将在 ["new Function" 语法](https://zh.javascript.info/new-function) 中讲到）。
>
也就是说：JavaScript 中的函数会自动通过隐藏的 `[[Environment]]` 属性记住创建它们的位置，所以它们都可以访问外部变量。
>
在面试时，前端开发者通常会被问到“什么是闭包？”，正确的回答应该是闭包的定义，并解释清楚为什么 JavaScript 中的所有函数都是闭包的，以及可能的关于 `[[Environment]]` 属性和词法环境原理的技术细节。





# 闭包的形成

好的，非常乐意。我们把你已经理解的要点，用更精确和结构化的语言来表述，非常适合做学习笔记。

---

### **核心概念总结：JavaScript 闭包 (Closure)**

#### 1. 定义 (Definition)

闭包 (Closure) 是指**一个函数**以及该函数被定义时所处的**词法环境 (Lexical Environment)** 的组合。本质上，闭包将函数代码与一个“背包”捆绑在一起，这个“背包”里装着函数在“出生地”能访问到的所有变量。

#### 2. 形成时机 (Formation Timing)

闭包在**函数被定义（创建）时**形成，而非调用时。每当JavaScript引擎执行到一段函数定义代码，就会在内存中创建一个函数对象，并在此刻完成闭包的构建。

#### 3. 核心机制 (Core Mechanism)

- 每个函数对象都拥有一个内部私有属性 `[[Environment]]`。
    
- 该属性持有对函数创建时其**外部词法环境 (Outer Lexical Environment)** 的一个持久引用。
    
- 这个 `[[Environment]]` 引用是闭包得以实现的技术关键，它赋予了函数“记忆”其外部环境的能力。
    

#### 4. 结构与查找 (Structure & Lookup)

- 当函数存在嵌套关系时，`[[Environment]]` 的引用会形成一个**链式结构**。
    
- 当在函数内部访问一个变量时，JavaScript引擎的查找规则如下：
    
    1. 首先在**当前函数**的词法环境中查找。
        
    2. 如果未找到，则沿着 `[[Environment]]` 的引用，到**外部词法环境**中查找。
        
    3. 重复此过程，直至查找到顶层的**全局环境**。
        
- 这条由内向外、层层链接的查找路径，被称为**作用域链 (Scope Chain)**。
