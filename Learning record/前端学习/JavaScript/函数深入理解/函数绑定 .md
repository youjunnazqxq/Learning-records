# 丢失this的情况


```
let user = { firstName: "John", 
sayHi() {
 alert(`Hello, ${this.firstName}!`); } };
 setTimeout(user.sayHi, 1000); // Hello, undefined!
```
对于这里的this指针来说他会返回undefined，因为在此，setTimeout获得的是一个函数的名字，这里函数

```
let f = user.sayHi;
setTimeout(f,1000);
```
这里user丢失了上下文，

# 解决方案 

## 包装器
在函数的内部在嵌套一个函数，使得this能够访问其对象

```
setTimeout(function(){
	user.sayHi();
},1000);
```

## bind

```
let boundFunc = func.bind(context);
```
将此函数的this绑定到对象。

和call的区别：call是调用函数，并将函数的this指针绑定到对象，而bind就像是单纯将this指针绑定到对象，没有对象可以绑定的时候就可以写null。
实际上，bind方法就是嵌套的call方法，如下：
```
function bind(func,obj){
	return function(){
		return func.call(obj);
	}
}

```

## 绑定参数

就像函数的在形参设置时候给的值一样，bind还可以绑定参数到固定的值，例如：
```
function mul(a,b){
	return a*b;
}

let double = mul.bind(null,2);//这样a的值就绑定到2，

```
