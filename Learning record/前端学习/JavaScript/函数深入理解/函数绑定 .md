# 丢失this的情况


```
let user = { firstName: "John", 
sayHi() {
 alert(`Hello, ${this.firstName}!`); } };
 setTimeout(user.sayHi, 1000); // Hello, undefined!
```
对于这里的this指针来说他会返回undefined，因为在此，setTimeout获得的是一个函数的名字，这里函数

```
let f = user.sayHi;
setTimeout(f,1000);
```
这里user丢失了上下文，

# 解决方案 

## 包装器
在函数的内部在嵌套一个函数，使得this能够访问其对象

```
setTimeout(function(){
	user.sayHi();
},1000);
```

## bind

```
let boundFunc = func.bind(context);
```

`func.bind(context)` 的结果是一个特殊的类似于函数的“外来对象（exotic object）”，它可以像函数一样被调用，并且透明地（transparently）将调用传递给 `func` 并设定 `this=context`。

换句话说，`boundFunc` 调用就像绑定了 `this` 的 `func`

```
let user = {
firstName: "John",
};
function func(phrase){
	alert(phrase+','+this.name);
}
let funcUser = func.bind(user);
funcUser("Hello");
```
