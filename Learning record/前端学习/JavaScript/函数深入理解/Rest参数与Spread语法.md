# Rest参数 ...

在函数传递的时候，我们将所有的参数都提前设置好是麻烦的，所以出现这样的一个语法 ...+数组名字，这样剩下的变量就会存入到这个数组中，语意就是收集剩余参数到指定数组中，例如：

```
fuction sumAll(num1,num2...restnums);//从接受第3个参数开始，这个参数就被存入到了restnums数组之中
```
注意这里的数组是真正的数组，于arguments数组不同，arguments是类数组无法调用一些参数。


# Spread语法

与rest参数相反的是，他在函数调用的时候使用，他会把`可迭代对象展开`到参数列表之中。
```
let arr = [3,4,5];

let arr2 =[6,7,8]'

alert( Math.max(...arr,...arr2))
```

对于字符串来说，Spread语法会像for of一样依次返回其字符，我们可以用[]来接收他

```
let str = 'hellp';

alert([...str])
```
