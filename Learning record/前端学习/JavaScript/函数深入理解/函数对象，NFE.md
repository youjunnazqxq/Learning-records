
在js中，函数的类型是一个对象，可以将它想象成一种“行为对象”。

# name属性

```
function sayHi(){
	alert("Hi");
}

alert(sayHi.name);
```
值得注意的是如果我们没有为某一个函数进行命名的时候，js引擎会自动根据函数的行为为其进行命名。

# 属性“length”

返回函数形参的个数，注意...rest不计入个数

# 自定义属性

>[!note]
>被赋值给函数的属性，比如 `sayHi.counter = 0`，**不会** 在函数内定义一个局部变量 `counter`。换句话说，属性 `counter` 和变量 `let counter` 是毫不相关的两个东西。
>
我们可以把函数当作对象，在它里面存储属性，但是这对它的执行没有任何影响。变量不是函数属性，反之亦然。它们之间是平行的。

# 命名函数表达式

```
let sayHi = function func(who){
	alert("hello,${who}");
};
```

关于名字 `func` 有两个特殊的地方，这就是添加它的原因：

1. 它允许函数在内部引用自己。
2. 它在函数外是不可见的。

对与这个来说，他可以反正函数外部函数名变化的时候对内层递归的影响
