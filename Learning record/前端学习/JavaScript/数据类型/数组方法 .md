## splice方法 

```javascript
arr.splice(start, deleteCount, elem1, ..., elemN)
```

它从索引 `start` 开始修改 `arr`：删除 `deleteCount` 个元素并在当前位置插入 `elem1, ..., elemN`。在原数组修改之后返回被删除元素组成的新数组。


## slice

slice方法
```
arr.slice([strat],[end]);
```
它会返回一个新数组，将所有从索引 `start` 到 `end`（不包括 `end`）的数组项复制到一个新的数组。`start` 和 `end` 都可以是负数，在这种情况下，从末尾计算索引。
其主主要的应用方式就是复制一个数组。


## concat 

```javascript
arr.concat(arg1, arg2...)
```

它接受任意数量的参数 —— 数组或值都可以。

结果是一个包含来自于 `arr`，然后是 `arg1`，`arg2` 的元素的新数组。

如果参数 `argN` 是一个数组，那么其中的所有元素都会被复制。否则，将复制参数本身。

例如：

```javascript
let arr = [1, 2];

// 从 arr 和 [3,4] 创建一个新数组
alert( arr.concat([3, 4]) ); // 1,2,3,4

// 从 arr、[3,4] 和 [5,6] 创建一个新数组
alert( arr.concat([3, 4], [5, 6]) ); // 1,2,3,4,5,6

// 从 arr、[3,4]、5 和 6 创建一个新数组
alert( arr.concat([3, 4], 5, 6) ); // 1,2,3,4,5,6
```

通常，它只复制数组中的元素。其他对象，即使它们看起来像数组一样，但仍然会被作为一个整体添加：

```javascript
let arr = [1, 2];

let arrayLike = {
  0: "something",
  length: 1
};

alert( arr.concat(arrayLike) ); // 1,2,[object Object]
```

……但是，如果类数组对象具有 `Symbol.isConcatSpreadable` 属性，那么它就会被 `concat` 当作一个数组来处理：此对象中的元素将被添加：
```javascript
let arr = [1, 2];

let arrayLike = {
  0: "something",
  1: "else",
  [Symbol.isConcatSpreadable]: true,
  length: 2
};

alert( arr.concat(arrayLike) ); // 1,2,something,else
```


# forEach

arr.forEach 方法运行为为每一个元素都运行一个方法

基本语法：


```
arr,forEach(function(item,index,array)){
}
```

```
let arr = [1,2,3];

arr.forEach(function(item,index,array)=>{
	alert('${item} is at index ${index} in ${array}')
})
```

对于这个方法来说，这个传入的函数必须按照`item index array`的顺序传入参数，可以不全部传入，但必须要按照顺序。
并且，此方法没有返回值，它是直接对数组进行的修改。


# 数组中的搜索方法

## includes

```
arr.includes(item,from)//item需要找的值，from：从索引开始的位置
```

这个方法当找到目标值返回true，没有返回false。
常用于数组中值的存在判断问题，不过这个的效率太低，外面一般其实回先考虑set这个数据结构来快速判断。

与includes的用法基本一样，但是返回值有所不同，找到返回该值（最主要的区别），没有找到返回-1.

>[!note ]
>includes可以正确找到NaN，并返回true
>indexOf不行，返回-1.

## sort

```
 arr.sort(compareNumber);

function compareNumber(a,b){
	return a-b;
}
//也可以使用箭头函数
arr.sort((a,b)=>a-b);
```

对于sort方法来说，他需要接受一个如何判断大小的函数来支持他来排序。
当sort（）括号内部没有接受到函数的时候他会按照字符串排序的规则来进行排序，
顺便一提：
对于内部的函数来说，他的第一个参数和第二个参数（a，b）来说，
- 如果返回一个负数，a会排在b的前面，
- 返回0，保持a和b的相对位置不变维持稳定性
- 正数
- 其中a，和b是数组中存储的数据

## reduce

```
let value = arr.reduce(function(accumulator,item,index,array),[inital])
```

- accumulator-上一次函数调用的结果，第一次等于initial
1. **`accumulator` (累加器)**：这是 `reduce` 的灵魂。它是上一次 `callback` 函数运行的返回值。在第一次调用时，它的值取决于是否提供了 `initialValue`。你可以把它想象成一个“滚雪球”的那个雪球，在每次迭代中不断变大或改变。
    
2. **`currentValue` (当前值)**：数组中正在被处理的当前元素。
    
3. **`currentIndex` (当前索引)** (可选)：当前元素在数组中的索引。
    
4. **`array` (源数组)** (可选)：调用 `reduce()` 的那个数组本身。
    

> **关键点**：`callback` 函数每次执行后，**必须 `return` 一个值**。这个返回值将作为下一次迭代的 `accumulator`。

## Array.isArray

判断是否为一个数组
- **`value`**：必需。你想要检查的那个值。
    
- **返回值**：
    
    - 如果 `value` 是一个数组，则返回 `true`。
        
    - 如果 `value` 不是一个数组，则返回 `false`。
