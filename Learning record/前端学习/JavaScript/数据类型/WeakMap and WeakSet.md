# 背景 

通常，当对象、数组之类的数据结构在内存中时，它们的子元素，如对象的属性、数组的元素都被认为是可达的。

例如，如果把一个对象放入到数组中，那么只要这个数组存在，那么这个对象也就存在，即使没有其他对该对象的引用。
WeakMap与此不同，他不会阻止垃圾回收机制对作为键的对象的回收

# WeakMap


`WeakMap` 和 `Map` 的第一个不同点就是，`WeakMap` 的键必须是对象，不能是原始值


现在，如果我们在 weakMap 中使用一个对象作为键，并且没有其他对这个对象的引用 —— 该对象将会被从内存（和map）中自动清除。

`eakMap` 不支持迭代以及 `keys()`，`values()` 和 `entries()` 方法。所以没有办法获取 `WeakMap` 的所有键或值


- **强引用 (Strong Reference)**：这是 JavaScript 中最常见的引用。当你把一个对象赋值给一个变量时，你就创建了一个对该对象的强引用。只要至少还有一个强引用指向一个对象，垃圾回收机制（Garbage Collector, GC）就**不会**回收这个对象。
    
    JavaScript
    
    ```
    let obj = { name: 'Gemini' }; // 变量 obj 是对 {name: 'Gemini'} 这个对象的强引用
    // 只要 obj 存在，这个对象就不会被回收
    ```
    
    **`Map` 使用的就是强引用**。如果一个对象被用作 `Map` 的键，那么 `Map` 本身就持有对这个对象的强引用，即使你代码中所有其他的引用都消失了，这个对象也无法被回收。
    
- **弱引用 (Weak Reference)**：这是一种“无足轻重”的引用。它指向一个对象，但**不会**阻止垃圾回收机制回收这个对象。换句话说，如果一个对象只剩下弱引用指向它，那么垃圾回收机制就会忽略这个引用，并随时准备回收该对象的内存。 **`WeakMap` 对它的键（key）使用的就是弱引用**。
