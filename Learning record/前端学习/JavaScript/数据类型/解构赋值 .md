	**解构赋值** 是一种特殊的语法，它使我们可以将数组或对象“拆包”至一系列变量中。有时这样做更方便。

解构操作对那些具有很多参数和默认值等的函数也很奏效。下面有一些例子。


# 数组解构 

```
let arr = ["John","Smith"];
let [firstName,surname] = arr;
````

使用这个可以交换变量

[first,surname] = [surname,first];

这样就会使得这两个值的变量交换，

## 默认值
如果左边变量列表长，那么多出来的我们就可以给予其默认属性

`[]`（数组）是 **按顺序** 匹配。




# 对象的解构赋值

#### 没有解构赋值
```
const user = {
  id: 1,
  name: "张三",
  age: 20
};

const userName = user.name;
const userAge = user.age;

console.log(userName); // "张三"
console.log(userAge);  // 20
```


#### 存在解构赋值

```
const user = {
  id: 1,
  name: "张三",
  age: 20
};

// { } 按名称从对象中提取值
// 变量名 (name) 必须和对象的键名 (key) 完全一致
const { name, age } = user;

console.log(name); // "张三" (注意：不是 userName)
console.log(age);  // 20
```

**核心要点（对象）：**

- **按名称 (Key) 匹配：** 变量名必须和对象里的属性名相同。
    
- **顺序无关：** `const { age, name } = user;` 效果完全一样。
    
- **重命名（Renaming）：** 如果您想使用不同的变量名，可以使用冒号

```
// 意思是：从 user 中取出 'name' 属性，并把它存入 'userName' 变量
const { name: userName, age: userAge } = user;
console.log(userName); // "张三"
```
