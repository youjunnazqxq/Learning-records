	**解构赋值** 是一种特殊的语法，它使我们可以将数组或对象“拆包”至一系列变量中。有时这样做更方便。

解构操作对那些具有很多参数和默认值等的函数也很奏效。下面有一些例子。


# 数组解构 

```
let arr = ["John","Smith"];
let [firstName,surname] = arr;
````

使用这个可以交换变量

[first,surname] = [surname,first];

这样就会使得这两个值的变量交换，

## 默认值
如果左边变量列表长，那么多出来的我们就可以给予其默认属性






# 对象结构

```
let {val1,val2} = {};
```


它会寻找里面对象的值，如果没有就按照默认值来处理，例如
```
let {with:a=60} = {};
```
