
# 🛠️ JavaScript 对象属性的“幕后控制”

我们平时写 obj.name = 'Jack' 时，只是在用默认配置。

Object.defineProperty 允许我们像系统管理员一样，对属性的权限进行精细化控制（比如：设为只读、设为隐藏）。

## 1. 三大权限标志 (The 3 Flags)

你可以把每个属性想象成一个文件，这三个标志就是文件的**属性开关**：

|**标志 (Flag)**|**含义**|**形象比喻**|**默认值***|
|---|---|---|---|
|**`writable`**|**可修改性**<br><br>  <br><br>`true`: 可以修改值<br><br>  <br><br>`false`: **只读** (Read-only)|**文件只读锁**<br><br>  <br><br>开了锁才能改内容。|`false`|
|**`enumerable`**|**可枚举性**<br><br>  <br><br>`true`: 能被 `for...in` 循环遍历出来<br><br>  <br><br>`false`: **隐藏** (Hidden)|**隐藏文件**<br><br>  <br><br>虽然在硬盘里，但搜索时看不见。|`false`|
|**`configurable`**|**可配置性**<br><br>  <br><br>`true`: 可以删除 (`delete`) 或再次修改这几个标志<br><br>  <br><br>`false`: **永久固化**|**系统核心文件**<br><br>  <br><br>不准删，也不准改权限。|`false`|

> **⚠️ 高能预警 (默认值陷阱)**：
> 
> - 当你用 `obj.x = 1` **直接定义**属性时，这三个开关默认都是 **`true`** (最宽松)。
>     
> - 当你用 **`Object.defineProperty`** 定义属性时，没写的开关默认都是 **`false`** (最严格)。
>

## 2. 属性查看 (Audit)

想看看某个属性的权限状态？使用描述符查看器。

- **方法**：`Object.getOwnPropertyDescriptor(对象, '属性名')`
    
- **代码示例**：
    

JavaScript

```
let person = { name: 'Jack' };

// 查看 name 属性的详细配置
let desc = Object.getOwnPropertyDescriptor(person, 'name');

console.log(desc);
/* 输出结果：
{
    value: 'Jack',
    writable: true,      // 默认是可写的
    enumerable: true,    // 默认是可遍历的
    configurable: true   // 默认是可配置的
}
*/
```

## 3. 属性更改/定义 (Control)

这就是 Vue 2 底层用来实现“数据劫持”的核心方法。

- **方法**：`Object.defineProperty(对象, '属性名', 配置对象)`
    
- **场景演示**：创建一个“只读”且“隐藏”的属性。
    

JavaScript

```
let person = { };

Object.defineProperty(person, 'age', {
    value: 18,
    writable: false,     // 【只读】之后再写 person.age = 20 无效
    enumerable: false,   // 【隐藏】for(let k in person) 遍历不到 age
    // configurable: false // (默认就是false) 以后想删也删不掉
});

console.log(person.age); // 18
person.age = 100;        // 修改失败（静默失败或严格模式报错）
console.log(person.age); // 依然是 18
```

## 🧠 关联记忆 (Vue 篇)

你之前学的 **Getter** 和 **Setter**，其实就是 `Object.defineProperty` 配置对象里的另外两个高级属性（访问器属性）。

- **基础版**：用 `value` 和 `writable` 控制值。
    
- **进阶版 (Vue)**：用 `get` 和 `set` 函数来控制值（从而实现响应式）。
    

> **注意**：一旦你写了 `get` 或 `set`，就不能再写 `value` 和 `writable` 了，这两组是互斥的。
