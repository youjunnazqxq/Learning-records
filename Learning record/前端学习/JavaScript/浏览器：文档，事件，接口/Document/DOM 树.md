
# DOM

DOM 是 “**D**ocument **O**bject **M**odel” 的缩写，中文意思是 “**文档对象模型**”。
- **Document (文档):** 指的就是你写的 HTML 页面。
    
- **Object (对象):** 在这个树状结构中，HTML 的每一个标签（如 `<html>`, `<body>`, `<div>`, `<p>`, `<a>` 等）以及标签中的文本，都被转换成了一个一个的“对象”（也叫“节点”）。
    
- **Model (模型):** 整个树状结构就是这个 HTML 文档的模型。
    

**DOM 的核心作用是：** 充当一个**接口** (API)，它让 JavaScript 这样的编程语言能够与网页内容进行交互。
**本质**是JS查看和修改HTML的工具
它**不是** HTML 代码本身，而是浏览器在加载 HTML 文档后，在内存中为这个文档创建的一个**树状结构**。

# DOM例子 
每个树的节点都是一个对象。

标签被称为 **元素节点**（或者仅仅是元素），并形成了树状结构：`<html>` 在根节点，`<head>` 和 `<body>` 是其子项，等。

元素内的文本形成 **文本节点**，被标记为 `＃text`。一个文本节点只包含一个字符串。它没有子项，并且总是树的叶子。

1. 由于历史原因，`<head>` 之前的空格和换行符均被忽略。
2. 如果我们在 `</body>` 之后放置一些东西，那么它会被自动移动到 `body` 内，并处于 `body` 中的最下方，因为 HTML 规范要求所有内容必须位于 `<body>` 内。所以 `</body>` 之后不能有空格。

`文本节点`的截断方式：被元素节点截断。
# 其它节点类型 

**HTML 中的所有内容，甚至注释，都会成为 DOM 的一部分。**

甚至 HTML 开头的 `<!DOCTYPE...>` 指令也是一个 DOM 节点。它在 DOM 树中位于 `<html>` 之前。很少有人知道这一点。我们不会触及那个节点，我们甚至不会在图表中绘制它，但它确实就在那里。

表示整个文档的 `document` 对象，在形式上也是一个 DOM 节点。

一共有 [12 种节点类型](https://dom.spec.whatwg.org/#node)。实际上，我们通常用到的是其中的 4 种：

1. `document` —— DOM 的“入口点”。它是整个网页的代表，可以说是总入口
2. 元素节点 —— HTML 标签，树构建块。
3. 文本节点 —— 包含文本。
4. 注释 —— 有时我们可以将一些信息放入其中，它不会显示，但 JS 可以从 DOM 中读取它。




# 自己看看吧

## 控制台


- **Styles** —— 我们可以看到按规则应用于当前元素的 CSS 规则，包括内建规则（灰色）。几乎所有内容都可以就地编辑，包括下面的方框的 dimension/margin/padding。
- **Computed** —— 按属性查看应用于元素的 CSS：对于每个属性，我们可以都可以看到赋予它的规则（包括 CSS 继承等）。
- **Event Listeners** —— 查看附加到 DOM 元素的事件侦听器

### 选择元素

我们处理 DOM 时，我们可能还希望对其应用 JavaScript。例如：获取一个节点并运行一些代码来修改它，以查看结果。以下是在元素（Elements）选项卡和控制台（Console）之间切换的一些技巧。

首先：

- 在元素（Elements）选项卡中选择第一个 `<li>`。
- 按下 Esc —— 它将在元素（Elements）选项卡下方打开控制台（Console）。

### `$0` 的含义

`$0` 始终指向**你在 “Elements” (元素) 面板中最后一次选中的那个 HTML 元素节点**。
