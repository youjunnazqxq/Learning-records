## 创建一条消息 

分为三个步骤 
```
let div = document.createElement('div');

div.className = 'alert'

div. innerHTML = "<strong>Hi there!</strong> you "

```
#### 步骤 1：创建 (Create) - 使用 `document.createElement()`

首先，您需要使用 `document.createElement()` 方法来“凭空”创建一个元素。这个新元素**只存在于 JavaScript 的内存中**，页面上还看不到它。

JavaScript

```
// 1. 创建一个 <div> 元素
const newDiv = document.createElement('div');
```

#### 步骤 2：配置 (Configure) - (设置属性和内容)

创建完后，它只是一个空的 `<div></div>`。您需要像操作其他 DOM 节点一样，去设置它的**属性 (Properties)**。

JavaScript

```
// 2. 配置这个 <div>
// (a) 设置它的内容
newDiv.textContent = '这是一个新创建的 div！';

// (b) 设置它的 class 或 id
newDiv.className = 'my-new-class';
newDiv.id = 'my-new-div';

// (c) 设置它的样式
newDiv.style.color = 'blue';
```
#### 步骤 3：插入 (Insert) - 使用 `appendChild()`

这是最关键的一步。您必须把这个“漂浮”在内存中的节点，插入到**已经存在**的 DOM 树上。

为此，您需要先**获取一个“父元素”**（即您想把新元素放在_哪里_），然后使用 `.appendChild()` 方法把它作为最后一个子节点加进去。

JavaScript

```
// 3. 插入到 DOM 树
// (a) 首先，找到一个已存在的“父元素”，比如 <body>
const parentElement = document.body; 
// (或者 document.getElementById('container') 等)

// (b) 把新创建的 div 作为子节点“追加”进去
parentElement.appendChild(newDiv);
```

# 插入方法 

## append 
`document.body.append(div)`
在这个例子中，我们对 `document.body` 调用了 `append` 方法。不过我们可以在其他任何元素上调用 `append` 方法，以将另外一个元素放入到里面。例如，通过调用 `div.append(anotherElement)`，我们便可以在 `<div>` 末尾添加一些内容。


- `node.append(...nodes or strings)` —— 在 `node` **末尾** 插入节点或字符串，
- `node.prepend(...nodes or strings)` —— 在 `node` **开头** 插入节点或字符串，
- `node.before(...nodes or strings)` —— 在 `node` **前面** 插入节点或字符串，
- `node.after(...nodes or strings)` —— 在 `node` **后面** 插入节点或字符串，
- `node.replaceWith(...nodes or strings)` —— 将 `node` 替换为给定的节点或字符串。


# insertAdjacentHTML/Text/Element

`elem.insertAdjacentHTML(where, html)`。

该方法的第一个参数是代码字（code word），指定相对于 `elem` 的插入位置。必须为以下之一：

- `"beforebegin"` —— 将 `html` 插入到 `elem` 之前，
- `"afterbegin"` —— 将 `html` 插入到 `elem` 开头，
- `"beforeend"` —— 将 `html` 插入到 `elem` 末尾，
- `"afterend"` —— 将 `html` 插入到 `elem` 之后。

- `elem.insertAdjacentText(where, text)` —— 语法一样，但是将 `text` 字符串“作为文本”插入而不是作为 HTML，
- `elem.insertAdjacentElement(where, elem)` —— 语法一样，但是插入的是一个元素。

# 克隆节点 ：cloneNode


`elem.cloneNode(true)` 来创建元素的一个“深”克隆 —— 具有所有特性（attribute）和子元素。如果我们调用 `elem.cloneNode(false)`，那克隆就不包括子元素。

# DocumentFragment


`DocumentFragment` 是一个特殊的 DOM 节点，用作来传递节点列表的包装器（wrapper）。我们可以向其附加其他节点，但是当我们将其插入某个位置时，则会插入其内容。

```
<ul id="ul"></ul>

<script>
function getListContent() {
  let fragment = new DocumentFragment();

  for(let i=1; i<=3; i++) {
    let li = document.createElement('li');
    li.append(i);
    fragment.append(li);
  }

  return fragment;
}

ul.append(getListContent()); // (*)
</script>

```
