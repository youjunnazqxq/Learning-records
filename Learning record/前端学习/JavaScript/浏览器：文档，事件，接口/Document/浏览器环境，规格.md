
# 文档对象模型（DOM）

`document` 对象是页面的主要“入口点”。我们可以使用它来更改或创建页面上的任何内容。浏览器使用DOM来和HTML语言交流，准确的来说DOM是一个API，它允许js通过其来读取和修改网页的内容。


# 浏览器对象模型（BOM）

BOM 是 Browser Object Model 的缩写，指浏览器（作为主机环境）提供的、用于处理文档（document，属于DOM范畴）之外的所有浏览器相关功能的对象集合。简单来说，DOM 管“网页内容”，BOM 管“浏览器本身的功能”。

- [navigator](https://developer.mozilla.org/zh/docs/Web/API/Window/navigator) 对象提供了有关浏览器和操作系统的背景信息。navigator 有许多属性，但是最广为人知的两个属性是：`navigator.userAgent` —— 关于当前浏览器，`navigator.platform` —— 关于平台（有助于区分 Windows/Linux/Mac 等）。
- [location](https://developer.mozilla.org/zh/docs/Web/API/Window/location) 对象允许我们读取当前 URL，并且可以将浏览器重定向到新的 URL

## windows对象 

`window` 对象是 BOM 的顶层对象，它代表了整个浏览器窗口。

有趣的是，`window` 对象也是 JavaScript 在浏览器环境中的**全局对象**。这意味着您在全局作用域中创建的任何变量或函数，都会成为 `window` 对象的属性或方法。

- `var name = 'Gemini';` 等同于 `window.name = 'Gemini';`
    
- `alert('Hello');` 实际上是 `window.alert('Hello');`
