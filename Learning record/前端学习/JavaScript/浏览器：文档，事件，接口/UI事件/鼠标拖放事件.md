
# 拖放算法 

1. 在 `mousedown` 上 —— 根据需要准备要移动的元素（也许创建一个它的副本，向其中添加一个类或其他任何东西）。
2. 然后在 `mousemove` 上，通过更改 `position:absolute` 情况下的 `left/top` 来移动它。
3. 在 `mouseup` 上 —— 执行与完成的拖放相关的所有行为。

相关实现：
```
ball.onmousedown = function(event){
//准备阶段 

// 确保绝对定位 & 层级置顶
ball.style.position = 'absolute';
ball.style.zIndex = 1000;
// 移动到body下，使定位相对整个文档
document.body.append(ball);
// 定义“让球中心与鼠标对齐”的函数
function moveAt(pageX, pageY) {
  ball.style.left = pageX - ball.offsetWidth / 2 + 'px';
  ball.style.top = pageY - ball.offsetHeight / 2 + 'px';
}
// 初始化球的位置（鼠标按下时的坐标）
moveAt(event.pageX, event.pageY);


鼠标的移动逻辑


function onMouseMove(event) {
  moveAt(event.pageX, event.pageY);
}
// 绑定鼠标移动事件，实现拖拽跟随
document.addEventListener('mousemove', onMouseMove);



鼠标松开后的清理 
ball.onmouseup = function() {
  // 移除鼠标移动的监听器，停止拖拽
  document.removeEventListener('mousemove', onMouseMove);
  // 清理自身事件，避免重复触发
  ball.onmouseup = null;
};

}

```

默认拖放行为的禁用：

```
ball.ondragstart = function(){

	return false;
}
```

# 修正定位 

在上诉例子中，我们用如下代码来定位，使球的中心位于鼠标指针下方
```
ball.style.left = pageX - ball.foosetWidth / 2 + 'px';

```
