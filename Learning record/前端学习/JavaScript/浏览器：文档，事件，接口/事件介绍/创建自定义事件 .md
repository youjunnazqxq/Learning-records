# 事件构造器

`let event = new Event(type[,options]);`

- **type** —— 事件类型，可以是像这样 `"click"` 的字符串，或者我们自己的像这样 `"my-event"` 的参数。
    
- **options** —— 具有两个可选属性的对象：
    
    - `bubbles: true/false` —— 如果为 `true`，那么事件会冒泡。
    - `cancelable: true/false` —— 如果为 `true`，那么“默认行为”就会被阻止。稍后我们会看到对于自定义事件，它意味着什么。


# dispatchEvent

事件对象被创建后，我们应该使用 `elem.dispatchEvent(event)` 调用在元素上“运行”它。

然后，处理程序会对它做出反应，就好像它是一个常规的浏览器事件一样。如果事件是用 `bubbles` 标志创建的，那么它会冒泡。

```
let event = new Event('click');
elem.dispatchEvent(event);
```

`dispatchEvent` 方法的返回值**就是**取决于它分派的那个 `event` 对象在执行过程中**有没有被标记为“取消”**。

而“标记为取消”的**唯一方法**就是调用 `event.preventDefault()`。

我们可以把 `dispatchEvent` 想象成一个函数，它在内部会做这样的判断：

JavaScript

```
function dispatchEvent(event) {
    // 1. 激活所有相关的监听器...
    //    (在监听器内部，event.preventDefault() 可能会被调用)
    
    // 2. 检查事件的状态
    if (event.defaultPrevented) { 
        // event.defaultPrevented 是一个只读属性
        // 如果 event.preventDefault() 被调用过，这个属性就是 true
        return false; 
    } else {
        // 如果 event.preventDefault() 没有被调用过
        return true;
    }
}
```

所以：

- **监听器调用了 `event.preventDefault()`**
    
    - `event.defaultPrevented` 变为 `true`。
        
    - `dispatchEvent` **返回 `false`** (表示“默认行为被取消了”)。
        
- **监听器没有调用 `event.preventDefault()`**
    
    - `event.defaultPrevented` 保持 `false`。
        
    - `dispatchEvent` **返回 `true`** (表示“默认行为未被取消”)。

# 自定义事件 
对于我们自己的全新事件类型，例如 `"hello"`，我们应该使用 `new CustomEvent`。从技术上讲，[CustomEvent](https://dom.spec.whatwg.org/#customevent) 和 `Event` 一样。除了一点不同。

在第二个参数（对象）中，我们可以为我们想要与事件一起传递的任何自定义信息添加一个附加的属性 `detail`。

# event.preventDefault()

通过调用 `event.preventDefault()`，事件处理程序可以发出一个信号，指出这些行为应该被取消。

在这种情况下，`elem.dispatchEvent(event)` 的调用会返回 `false`。那么分派（dispatch）该事件的代码就会知道不应该再继续。
```

<script>
  function hide() {
    let event = new CustomEvent("hide", {
      cancelable: true // 没有这个标志，preventDefault 将不起作用
    });

    if (!rabbit.dispatchEvent(event)) {
      alert('The action was prevented by a handler');
    } else {
      rabbit.hidden = true;
    }
  }

  rabbit.addEventListener('hide', function(event) {
    if (confirm("Call preventDefault?")) {
      event.preventDefault();
    }
  });
</script>
```
