捕获和冒泡允许我们实现最强大的事件处理模式之一，即 **事件委托** 模式。

这个想法是，如果我们有许多以类似方式处理的元素，那么就不必为每个元素分配一个处理程序 —— 而是将单个处理程序放在它们的共同祖先上。

# 实现步骤 
步骤1：确定“共同祖先元素”
 
找到所有需要处理事件的子元素的共同祖先元素（这个元素是它们的父级、祖父级等，能包含所有目标子元素）。
 
步骤2：给祖先元素绑定事件监听器
 
为这个共同祖先元素绑定对应的事件监听器（如 click 、 mouseover 等），事件类型与子元素需要处理的事件一致。
 
步骤3：在事件处理函数中获取 event.target 
 
事件触发时，在处理函数中通过  event.target  获取实际触发事件的子元素（即事件真正发生的那个元素）。
 
步骤4：判断 event.target 是否为目标元素
 
通过元素的特征（如标签名、类名、 id 、自定义属性等），判断 event.target 是否是需要处理的目标子元素。
 
步骤5：执行目标元素的事件处理逻辑
 
若 event.target 是目标元素，就执行对应的业务逻辑（如修改内容、发送请求等）

# 行为模式 

我们还可以使用事件委托将“行为（behavior）”以 **声明方式** 添加到具有特殊特性（attribute）和类的元素中。

行为模式分为两个部分：

1. 我们将自定义特性添加到描述其行为的元素。
2. 用文档范围级的处理程序追踪事件，如果事件发生在具有特定特性的元素上 —— 则执行行为（action）。

```
<div id="menu">
  <button data-action="save">Save</button>
  <button data-action="load">Load</button>
  <button data-action="search">Search</button>
</div>
<script>
  class Menu {
    constructor(elem) {
      this._elem = elem;
      elem.onclick = this.onClick.bind(this); // (*)
    }

    save() {
      alert('saving');
    }

    load() {
      alert('loading');
    }

    search() {
      alert('searching');
    }

    onClick(event) {
      let action = event.target.dataset.action;
      if (action) {
        this[action]();
      }
    }
  }

  new Menu(menu);
</script>

```
