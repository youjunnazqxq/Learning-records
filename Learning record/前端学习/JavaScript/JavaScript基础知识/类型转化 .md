# 字符串转换 

普通的，在其前面加上String（）
例如
```
let value =true;
value=String(value)
```


# Number类型转换

在表达式中进行算数的时候会自动进行运算，例如
```
alert("6"/"3");//3
```

## 常见的转换规则 

| 值              | 变成……                                                                                                            |
| -------------- | --------------------------------------------------------------------------------------------------------------- |
| `undefined`    | `NaN`                                                                                                           |
| `null`         | `0`                                                                                                             |
| `true 和 false` | `1` and `0`                                                                                                     |
| `string`       | 去掉首尾空白字符（空格、换行符 `\n`、制表符 `\t` 等）后的纯数字字符串中含有的数字。如果剩余字符串为空，则转换结果为 `0`。否则，将会从剩余字符串中“读取”数字。当类型转换出现 error 时返回 `NaN`。 |
