#  常量 

关键字：const
作用：一旦确立无法修改 

## 命名格式

在常量中如果一个值是已经确定好的，则是使用大写形式的例如
```
const COLOR_RED='#f00'
```
如果是在执行的时候被确定的则使用驼峰式命名


# let const 及val 的差异 


 
#### 1. 作用域差异
 
- var：仅支持函数作用域（只有函数能限制它的生效范围，if/for等大括号 {} 不形成独立作用域）。
​
- let/const：支持块级作用域（大括号 {} 包裹的区域，比如if代码块、for循环块都是独立作用域）。



#### 2. 变量提升与“暂时性死区”
 
- var：会被提升到作用域顶部，且自动初始化为 undefined （声明前使用不会报错，结果是 undefined ）。
​
- let/const：会被提升，但不初始化——声明前使用会触发“暂时性死区”报错（比如 console.log(a); let a=1; 直接报错）。

##### 变量提升
变量提升（Hoisting）是 JavaScript 引擎在执行代码前的预处理行为：它会把代码中  var  声明的变量、 function  声明的函数，“悄悄”移动到当前作用域的最顶部（但赋值不会跟着移动）。



#### 3. 重复声明限制
 
- var：同一作用域内可以重复声明同一变量（后面的会覆盖前面的，比如 var a=1; var a=2; 有效）。
​
- let/const：同一作用域内不能重复声明同一变量（重复写会直接报错）。




#### 4. 赋值与初始化限制
 
- var/let：声明时可以不初始化（比如 var a; let b; ），且后续可以随时重新赋值。
​
- const：
​
- 声明时必须立即初始化（比如 const c; 会报错，得写 const c=3; ）；
​
- 不能重新赋值（但如果是对象/数组，内部属性/元素可以修改，比如 const obj={x:1}; obj.x=2; 是合法的）。




#### 5. 全局作用域的绑定
 
- var：在全局声明的变量，会成为 window （浏览器环境）的属性（比如 var a=1; window.a 能拿到1）。
​
- let/const：在全局声明的变量，不会绑定到 window （比如 let b=2; window.b 是 undefined ）。
