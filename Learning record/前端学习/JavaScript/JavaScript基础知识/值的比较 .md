# 等于号的比较 == 和===

## == 宽松比较 

对于双等于来说，他在比较的时候会先进行类型的转化，比如

```
"0"==0
```
### 类型相同的时候 
如果 `x` 和 `y` 的类型相同，那么比较规则和 `===` (严格相等) 完全一样。

- **Undefined**: `undefined == undefined` // true
    
- **Null**: `null == null` // true
    
- **Number**:
    
    - `5 == 5` // true
        
    - `NaN == NaN` // **false** (这是特例，NaN 不等于任何东西，包括它自己)
        
    - `+0 == -0` // true
        
- **String**: 比较字符串的内容是否完全相同。
    
    - `"hello" == "hello"` // true
        
- **Boolean**:
    
    - `true == true` // true
        
- **Object**: 比较它们是否指向内存中的同一个对象。
    
    - `let a = { name: 'js' }; let b = a; a == b` // true
        
    - `{ name: 'js' } == { name: 'js' }` // false (两个不同的对象实例)



### 类型不同的时候 
#### null和undefined的比较 
这是 `==` 最常见的一个特例用法。

- `null == undefined` // **true**
    
- `undefined == null` // **true**
    

除此之外，`null` 和 `undefined` 与任何其他值进行 `==` 比较都返回 `false`。

- `null == false` // false
    
- `null == 0` // false
    
- `null == ""` // false
    
- `undefined == 0` // false

> **注意**: 这个特性是 `==` 唯一被推荐使用的场景，即当你希望同时检查一个值是否为 `null` 或 `undefined` 时，可以使用 `variable == null`。




#### 数字和字符串的比较 

#### 数字 (Number) 和 字符串 (String) 比较

当数字和字符串比较时，会将**字符串转换为数字**，然后再进行比较。

- `5 == "5"` // true (字符串 "5" 转换为数字 5)
    
- `1 == " 1 "` // true (字符串 " 1 " 会先去除空格，然后转换为数字 1)
    
- `0 == ""` // true (空字符串 "" 转换为数字 0)
    
- `0 == "0"` // true
    
- `1 == "hello"` // false ("hello" 转换为 `NaN`，而 `1 == NaN` 是 false)
