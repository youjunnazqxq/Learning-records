# 回调

类似与setTimeout方法，方法还没加载完后会先运行之后的代码，这样会产生报错

## 回调的用法 

```
function loadScript(src,callback){
	let script = document.createElement(‘script’);
	script.src = src;
	script.aonload = () => callback(script);

}
```


## 回调嵌套

可以在回调的函数中继续回调
