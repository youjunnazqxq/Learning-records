# 导出

我们可以在被导出的模块中同一到出：
```
export {对象}；
```

# import*

全部导入 
```
inprot * as obj from src;
```
将所有内容导入为一个对象
*经量不要全部导入，这会使得构建变大*

# improt as 

`improt {oring as othername} from src`起别名


# Export default


本质就是一个文件就只有一个导出，然后就可以默认了
语法:
```
//导出
exporat default calsss

//导入
import othername from src

```
