没问题！JS 的模块化（Module）确实容易让人晕，尤其是什么时候加花括号 `{}`，什么时候不加，名字能不能改... 这些都是初学者最容易踩的坑。

我们用一个最生活的例子来比喻：**“发快递”和“收快递”**。

JS 的模块系统主要分为两种模式：**默认导出 (Default Export)** 和 **按需/命名导出 (Named Export)**。

---

### 1. 默认导出 (Default Export) —— “专车独享”

这种模式下，一个文件（模块）**只能有一个**主要的导出对象。这就好比这个文件打包了一个**“神秘大礼包”**发给你。

- **特点**：因为只有一个礼包，你收货的时候，**不需要拆开看（不用花括号），名字也可以随便起**。
    

#### **导出方 (math.js)**

JavaScript

```
// 我定义了一个函数叫 add
const add = (a, b) => a + b;

// 我把它作为默认导出（这个文件的主角就是它）
export default add; 
```

#### **导入方 (index.js)**

JavaScript

```
// 1. 不需要花括号
// 2. 名字随便起！虽然原名叫 add，但我这里叫 plus 也没问题
import plus from './math.js'; 

console.log(plus(1, 2)); // 输出 3
```

> 对应之前的 Axios 例子：
> 
> request.js 里写了 export default service。
> 
> 所以你在 api/user.js 里写 import request from ...。
> 
> 原理：service 是默认导出，所以你可以给它改名叫 request。

---

### 2. 命名导出 (Named Export) —— “自助餐/零食拼盘”

这种模式下，一个文件可以导出**多个**东西。这就好比这个文件给你发了一个透明的**“零件箱”**，里面有螺丝、螺母、扳手。

- **特点**：你收货的时候，**必须打开箱子挑（必须加花括号），而且名字必须对应（要拿螺丝就得叫螺丝）**。
    

#### **导出方 (utils.js)**

JavaScript

```
// 导出第一个：变量
export const pi = 3.14;

// 导出第二个：函数
export function formatTime(date) { ... }

// 导出第三个：类
export class User { ... }
```

#### **导入方 (index.js)**

JavaScript

```
// 1. 必须加花括号 { }
// 2. 名字必须和导出时一模一样！
import { pi, formatTime } from './utils.js';

console.log(pi); // 3.14
```

> 能不能改名？
> 
> 如果非要改名，必须使用 as 关键字：
> 
> import { pi as myPi } from './utils.js';

---

### 3. 最核心的区别：花括号 `{}`

这是 99% 的初学者报错的原因，请务必记住这个口诀：

- **默认导出 (Default)** = **不需要**花括号 = **可以**随便改名
    
- **命名导出 (Named)** = **必须有**花括号 = **必须**原名引用
    

---

### 4. 什么时候用哪个？

在实际项目中（比如 Vue/React 开发）：

|**场景**|**推荐方式**|**例子**|
|---|---|---|
|**工具库 (Utils)**|**命名导出**|一个 `tools.js` 里有 `formatDate`, `checkNumber`, `parseJson` 等十几个小函数。|
|**API 接口管理**|**命名导出**|一个 `user.js` 里有 `login`, `logout`, `getUserInfo` 等多个接口函数。|
|**Vue/React 组件**|**默认导出**|一个文件通常只写一个组件 (`MyComponent.vue`)，所以导出这个组件本身。|
|**Axios 封装**|**默认导出**|一个文件通常只需要导出一个配置好的 Axios 实例 (`request`)。|

---

### 5. 混合使用（进阶）

其实一个文件可以同时拥有“默认导出”和“命名导出”（虽然不建议新手混用，但你要能看懂）。

**file.js:**

JavaScript

```
export const a = 1;       // 命名导出
export const b = 2;       // 命名导出
const defaultThing = 99;
export default defaultThing; // 默认导出
```

**main.js (导入时):**

JavaScript

```
// 默认导出放在外面，命名导出放在花括号里
import defaultThing, { a, b } from './file.js';
```

回到我们之前的 Axios 封装代码，现在你能看懂这几行了吗？

1. **`src/utils/request.js`**:
    
    JavaScript
    
    ```
    const service = axios.create(...)
    export default service; // 默认导出：我是大礼包
    ```
    
2. **`src/api/user.js`**:
    
    JavaScript
    
    ```
    import request from '@/utils/request'; // 没花括号，我随便起名叫 request
    
    // 命名导出：我是自助餐里的第一道菜
    export function login() { ... } 
    // 命名导出：我是自助餐里的第二道菜
    export function getUser() { ... }
    ```
    
3. **`src/views/Login.vue`**:
    
    JavaScript
    
    ```
    // 有花括号，我必须精准点菜，名字必须叫 login
    import { login } from '@/api/user'; 
    ```
