
### 📦 JS 模块导入导出全解 (ES Modules)

#### 1. 按需导出 / 命名导出 (Named Export) 🔥 **常用**

**场景**：写工具库（utils.js）、API 接口文件。一个文件里有多个函数或变量。

- 导出 (Export)
    
    可以写在最后，也可以直接写在定义前（推荐）。
    
    JavaScript
    
    ```
    // 方式 A：定义时直接导出 (最推荐，写起来快) ⭐
    export const name = "Gemini";
    export function sum(a, b) { return a + b; }
    
    // 方式 B：最后统一导出
    const age = 18;
    const gender = "male";
    export { age, gender }; 
    ```
    
- 导入 (Import)
    
    必须加花括号 {}，名字必须和导出时一样。
    
    JavaScript
    
    ```
    import { name, sum } from './utils.js';
    ```
    

---

#### 2. 默认导出 (Default Export) 🔥 **Vue组件必备**

**场景**：Vue 的组件文件（.vue）、主要的主类。一个文件只产出一个核心对象。

- 导出 (Export)
    
    一个模块只能有一个 export default。
    
    JavaScript
    
    ```
    // 方式 A：导出一个对象 (Vue 组件写法) ⭐
    export default {
      name: 'MyComponent',
      data() { ... }
    }
    
    // 方式 B：导出一个类或函数
    export default class User { ... }
    ```
    
- 导入 (Import)
    
    不需要花括号，名字可以随便起（通常起个有意义的名字）。
    
    JavaScript
    
    ```
    // 引入时叫 MyComp 或者 A 都可以
    import MyComp from './MyComponent.vue'; 
    ```
    

---

#### 3. 进阶技巧 (按需取用)

- 重命名 (As)
    
    解决命名冲突，或者想换个短点的名字。
    
    JavaScript
    
    ```
    // 把 sum 导入进来，改名叫 add
    import { sum as add } from './utils.js';
    console.log(add(1, 2)); 
    ```
    
- 整体导入 (Import All)
    
    注意： 正如你笔记所说，尽量少用，会影响打包体积（Tree-shaking 可能会失效）。
    
    JavaScript
    
    ```
    // 把 utils 里导出的所有东西，打包成一个叫 tool 的对象
    import * as tool from './utils.js';
    
    console.log(tool.name);
    console.log(tool.sum(1, 2));
    ```
    
- **混合导入 (同时有默认和命名)**
    
    JavaScript
    
    ```
    // React 中很常见
    import React, { useState, useEffect } from 'react';
    // React 是默认导出，{...} 是命名导出
    ```
    


### ⚡️ 总结：我该用哪个？

- 如果你在写 **`.vue` 文件**：用 **`export default`**。
    
- 如果你在写 **`utils.js`** (存一堆小工具函数)：用 **`export const/function`** (命名导出)。
