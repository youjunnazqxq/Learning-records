# `[[Prototype]]`


这是js中的一个隐藏属性，他是对另一个对象的引用，我们可以通过._proto_方法来设置他，例如
```
let animal = {
	eats: true;
}
let rabbit = {
	jump: true;
}
rabbit._proto_ = animal;
```
这样通过这个方式，这个rabbit的隐藏属性就被设置为了animal，
当rabbit访问到其没有的属性的时候，他会访问这个隐藏属性来看父代有没有这个属性。

## 注意：
- 原型链可以很长，但是不能组成循环
- _proto_是隐藏属性[[Prototype]]的访问器和修改器
- 赋值时，先查自身有没有该属性 → 没有就查原型 → 原型上是访问器属性（setter）就触发它 → setter的this指向当前对象，给当前对象加属性。
- 父代是普通可写属性：子代自身创建属性（不碰父代）；
- 父代是普通不可写属性：赋值失败（既不碰父代，也不创建子代属性）；
- 父代是访问器属性（setter）：触发父代setter，给子代添加属性（不碰父代）。
 
本质：只有“父代普通可写属性”的场景，会直接在子代创建属性；其他场景都不会修改父代的值。
