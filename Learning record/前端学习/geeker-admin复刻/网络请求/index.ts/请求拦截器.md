### 🧱 核心能力总结 (四大支柱)

#### 1. ⚡️ 智能防抖 (Anti-shake)

- **代码**：`axiosCanceler.addPending(config)`
    
- **作用**：**拒绝重复**。
    
- **逻辑**：它会自动检测用户是不是手抖连点了两次按钮。如果是，它会毫不留情地把上一次还没完成的请求“杀掉”（Cancel），只保留最新的这一次。
    
- **默认行为**：默认开启。除非你手动传 `{ cancel: false }`。
    

#### 2. ⏳ 全局动画 (Global Loading)

- **代码**：`showFullScreenLoading()`
    
- **作用**：**拒绝焦虑**。
    
- **逻辑**：只要请求发出，屏幕自动出现 Loading 遮罩；请求结束自动消失。而且它很聪明，如果同时有 3 个请求，它会等 3 个都结束了才关掉动画（计数器原理）。
    
- **默认行为**：默认开启。除非你静默请求时传 `{ loading: false }`。
    

#### 3. 🛡️ 身份植入 (Token Injection)

- **代码**：`config.headers.set("x-access-token", ...)`
    
- **作用**：**自动通行**。
    
- **逻辑**：不用你在每个页面手动去 LocalStorage 或 Pinia 里拿 Token。拦截器会在请求飞出的一瞬间，自动从 Pinia 仓库取出 Token，贴在请求头的 `x-access-token` 字段上。
    
- **安全机制**：使用了 `typeof` 检查，确保 headers 对象和 set 方法存在，防止代码报错。
    

#### 4. 🚨 熔断机制 (Error Handling)

- **代码**：`Promise.reject(error)`
    
- **作用**：**拒绝隐患**。
    
- **逻辑**：如果在“配置阶段”就出错了（比如参数格式不对），拦截器会直接切断流程，把错误抛给业务层，而不是假装成功发送一个空请求。

>     
> 3. 从 Pinia 拿 Token -> 盖章到 Header
>     
>     ⬇️
>     
>     **🚀 飞向服务器**
