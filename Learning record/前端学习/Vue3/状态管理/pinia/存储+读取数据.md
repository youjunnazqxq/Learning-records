
### 📝 Pinia 存储 + 读取数据

#### 1. 核心概念 (Store)

Store 是一个保存状态和业务逻辑的实体，组件可以读取和写入它。它包含三个核心部分，对应 Vue 组件的概念：

- **state**：相当于组件的 `data`，用于存储数据。
    
- **getters**：相当于组件的 `computed`，用于计算数据。
    
- **actions**：相当于组件的 `methods`，用于定义业务逻辑（同步或异步）。
    

#### 2. 定义 Store (存储数据)

通常在 `src/store` 目录下创建文件（如 `count.ts`）。使用 `defineStore` 定义并暴露 Store。

- **语法**：`defineStore('唯一ID', 配置对象)`
    
- **示例代码**：
    
    TypeScript
    
    ```
    // src/store/count.ts
    import { defineStore } from 'pinia'
    
    export const useCountStore = defineStore('count', {
      // 1. 状态 (必须是函数，返回一个对象)
      state() {
        return {
          sum: 6,
          school: 'atguigu'
        }
      },
      // 2. 动作
      actions: {},
      // 3. 计算
      getters: {}
    })
    ```
    

#### 3. 组件中使用 (读取数据)

在组件中引入定义好的 Store Hook（如 `useCountStore`），执行后得到 Store 实例，即可直接读取数据。

- **示例代码**：
    
    代码段
    
    ```
    <template>
      <h2>当前求和为：{{ countStore.sum }}</h2>
      <h2>学校：{{ countStore.school }}</h2>
    </template>
    
    <script setup lang="ts" name="Count">
      // 1. 引入 store
      import { useCountStore } from '@/store/count'
    
      // 2. 获取 store 实例
      const countStore = useCountStore()
    
      // console.log(countStore.sum) // JS中也可以直接读取
    </script>
    ```
    

---

**💡 总结流程：**

1. **定义**：`defineStore('id', { state: ()=>({...}) })`。
    
2. **引入**：`import { useXxxStore } ...`。
    
3. **实例化**：`const store = useXxxStore()`。
    
4. **读取**：`store.属性名`。
