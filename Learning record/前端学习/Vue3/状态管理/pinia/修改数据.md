

### 📝 Vue3 学习笔记：Pinia 修改数据的三种方式

#### 1. 第一种：直接修改 (最简单)

适用于修改单个简单的属性。你可以直接通过 Store 实例读写 state。

- **代码示例**：
    
    TypeScript
    
    ```
    // 假设 countStore 是 useCountStore() 的实例
    countStore.sum = 666
    ```
    

#### 2. 第二种：批量修改 (使用 `$patch`)

适用于需要同时修改多个属性。`$patch` 可以进行性能优化，虽然在 Vue3 中自动批处理已经很好，但在逻辑上将一次变更合并更清晰。

- **代码示例**：
    
    TypeScript
    
    ```
    countStore.$patch({
      sum: 999,
      school: 'atguigu'
    })
    ```
    

#### 3. 第三种：借助 Actions 修改 (推荐 & 最常用)

适用于涉及**业务逻辑**的修改（例如：先判断条件再修改，或者需要复用的逻辑）。这是最符合“状态管理”理念的方式。

- Step 1: 在 Store 中定义 actions
    
    在 src/store/count.ts 中配置 actions 选项：
    
    TypeScript
    
    ```
    actions: {
      // 定义一个动作：加法
      increment(value: number) {
        // 这里的 this 指向当前的 store 实例
        if (this.sum < 10) {
          this.sum += value
        }
      }
    }
    ```
    
- **Step 2: 在组件中调用**
    
    TypeScript
    
    ```
    const countStore = useCountStore()
    
    // 像调用普通函数一样调用 action
    countStore.increment(10)
    ```
    

---

**💡 总结建议：**

- **简单场景**（改个开关、重置个值）：直接修改或 `$patch`。
    
- **复杂场景**（涉及逻辑判断、异步请求）：一定要用 **Actions**，这样便于维护和复用。
