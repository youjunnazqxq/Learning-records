

# 🧮 Vue 3: Computed (计算属性) 核心速查

## 1. 🧠 核心心智模型 (Mental Model)

- **本质**：**派生状态 (Derived State)**。`Output = Function(Input)`。
    
- **CS 类比**：
    
    - 📊 **Excel 公式**：A1 和 B1 变了，C1 自动更新。
        
    - 🗄️ **数据库视图 (View)**：基于基础表生成的虚拟表。
        
- **核心特性**：**依赖追踪 + 缓存 (Caching)**。只有当依赖的响应式数据变化时，才会重新计算；否则直接复用缓存值。

## 2. ⚡ 标准代码模板 (Copy-Paste Ready)

### 2.1 基础只读用法 (Read-Only)

> **场景**：90% 的情况。根据现有数据计算新数据，不修改原数据。

代码段

```
<script setup>
import { ref, computed } from 'vue'

const price = ref(100)
const discount = ref(0.8)

// 1. 定义：返回的是一个 Ref 对象
const finalPrice = computed(() => {
  return price.value * discount.value
})

const check = () => {
  // JS 中读取需要 .value
  console.log(finalPrice.value) 
  
  // ❌ 报错：默认是只读的
  // finalPrice.value = 90 
}
</script>

<template>
  <p>折后价: {{ finalPrice }}</p>
</template>
```

### 2.2 进阶读写用法 (Writable)

> **场景**：双向绑定 (`v-model`)。修改计算结果时，反向更新源数据。

代码段

```
<script setup>
import { ref, computed } from 'vue'

const firstName = ref('John')
const lastName = ref('Doe')

const fullName = computed({
  // 📥 读取 (Getter)
  get() {
    return firstName.value + ' ' + lastName.value
  },
  // 📤 写入 (Setter) - val 是新赋的值
  set(val) {
    const [first, last] = val.split(' ')
    firstName.value = first
    lastName.value = last
  }
})
</script>

<template>
  <input v-model="fullName" />
</template>
```

## 3. ⚔️ 核心对比：Computed vs Methods (Interview)

**面试必问**：为什么不用普通函数代替？因为 **性能**。

|**特性**|**Computed (计算属性) 🏆**|**Methods (普通方法)**|
|---|---|---|
|**缓存机制**|✅ **有缓存**|❌ **无缓存**|
|**执行时机**|仅当**依赖变化**时重新计算|每次组件**重绘**都会执行|
|**调用方式**|像变量一样引用 (无括号)|必须调用函数 (带括号 `()`)|
|**性能影响**|高 (适合复杂计算/大数据遍历)|低 (频繁触发可能卡顿)|

> 🧪 性能实验：
> 
> 假设你需要过滤 10,000 条列表数据。
> 
> - **Computed**: 只有当列表数据变化时，循环才会跑一次。
>     
> - **Methods**: 只要页面上任何无关数据（比如一个无关的 toggle 按钮）变化触发重绘，循环就会**再跑一次**。
>

## 4. 🛑 最佳实践 (Best Practices)

1. **Getter 必须纯粹 (Pure)**：
    
    - ❌ **Don't**: 在 `computed` 里发异步请求、修改 DOM、修改其他 `ref`。
        
    - ✅ **Do**: 它应该只是单纯的计算并返回结果。
        
2. **避免过度嵌套**：虽然 `computed` 可以依赖其他 `computed`，但层级过深会导致“依赖地狱”，难以调试。

## 5. 🔬 底层原理 (Deep Dive)

`computed` 实现了 **惰性求值 (Lazy Evaluation)** 机制：

1. **创建时 (Init)**：
    
    - 不会立刻计算，只是设置一个 `Dirty = true` (脏标记)。
        
2. **依赖变化时 (Dependency Change)**：
    
    - Vue 收到通知，但**不会立刻重算**。
        
    - 只是把标记设回 `Dirty = true`，并触发视图更新。
        
3. **被读取时 (Access)**：
    
    - 如果是 `Dirty`：运行函数 -> 存入缓存 -> 标记 `Dirty = false` -> 返回值。
        
    - 如果是 `Clean` (`Dirty === false`)：直接返回缓存值。
