

# ♻️ Vue 3: Lifecycle Hooks (生命周期) 速查

## 1. 🧠 核心心智模型 (Mental Model)

- **本质**：组件从“出生”到“死亡”的时间轴锚点。
    
- **作用**：允许开发者在特定时刻（如 DOM 渲染后、数据更新前、组件销毁前）插入自定义逻辑。
    
- **变化**：
    
    - **组合式**：在 Vue 3 中，生命周期钩子变成了 **按需导入的函数**（`onXxx`），而不是配置项。
        
    - **合并**：`beforeCreate` 和 `created` 被合并到了 `setup` 中。
        

---

## 2. 🗺️ 映射表：Vue 2 vs Vue 3 (Migration Map)

|**阶段**|**Vue 2 (Options API)**|**Vue 3 (Composition API)**|**📝 备注**|
|---|---|---|---|
|**创建**|`beforeCreate`<br><br>  <br><br>`created`|**`setup()`**|此时无 DOM，仅初始化数据。`setup` 最早执行。|
|**挂载**|`beforeMount`<br><br>  <br><br>`mounted`|`onBeforeMount`<br><br>  <br><br>`onMounted`|`onMounted` 最常用，此时真实 DOM 已存在。|
|**更新**|`beforeUpdate`<br><br>  <br><br>`updated`|`onBeforeUpdate`<br><br>  <br><br>`onUpdated`|数据变更导致视图重新渲染时触发。|
|**销毁**|`beforeDestroy`<br><br>  <br><br>`destroyed`|**`onBeforeUnmount`**<br><br>  <br><br>**`onUnmounted`**|**⚠️ 命名变化**：`Destroy` 改为 `Unmount` (卸载)。|

## 3. ⚡ 标准代码模板 (Copy-Paste Ready)

代码段

```
<script lang="ts" setup>
import { 
  ref, 
  onBeforeMount, 
  onMounted, 
  onBeforeUpdate, 
  onUpdated, 
  onBeforeUnmount, 
  onUnmounted 
} from 'vue'

// 1. Setup 阶段 (相当于 created)
console.log('setup: 组件创建开始')
const sum = ref(0)

// 2. 挂载阶段 (Mounting)
onBeforeMount(() => {
  console.log('onBeforeMount: DOM 渲染之前')
})

onMounted(() => {
  // 🔥 最常用：发请求、操作 DOM、初始化第三方库
  console.log('onMounted: DOM 渲染完毕')
})

// 3. 更新阶段 (Updating)
onBeforeUpdate(() => {
  console.log('onBeforeUpdate: 数据变了，视图更新前')
})

onUpdated(() => {
  console.log('onUpdated: 视图更新完毕')
})

// 4. 卸载阶段 (Unmounting)
onBeforeUnmount(() => {
  // 🔥 常用：清理定时器、解绑全局事件、销毁插件实例
  console.log('onBeforeUnmount: 卸载之前')
})

onUnmounted(() => {
  console.log('onUnmounted: 卸载完毕')
})

// 方法
const changeSum = () => {
  sum.value += 1
}
</script>

<template>
  <div class="person">
    <h2>当前求和：{{ sum }}</h2>
    <button @click="changeSum">点我 sum+1</button>
  </div>
</template>
```

## 4. 💡 最佳实践与注意事项 (Tips)

1. **高频钩子**：
    
    - ✅ **`onMounted`**：初始化操作（API 请求、Canvas 绘图）。
        
    - ✅ **`onBeforeUnmount`**：资源清理（防止内存泄漏）。
        
    - ✅ **`onUpdated`**：需要获取更新后的 DOM 状态时使用。
        
2. **Vue 3 特性**：
    
    - 生命周期钩子函数可以**多次调用**。例如，你可以在一个 `setup` 中写两个 `onMounted`，它们会按照顺序依次执行。这有利于代码逻辑的拆分（如自定义 Hooks）。
        
3. **父子组件顺序**：
    
    - **挂载**：父 `setup` -> 父 `onBeforeMount` -> 子 `setup` -> 子 `onBeforeMount` -> 子 `onMounted` -> 父 `onMounted`。
        
    - (总结：**子组件先挂载完毕，父组件最后挂载完毕**)。
