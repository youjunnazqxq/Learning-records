
### 1. 配置路由文件

通常新建文件 `src/router/index.ts`：

TypeScript

```
import { createRouter, createWebHistory } from 'vue-router'
// 引入组件
import Home from '@/pages/Home.vue'
import About from '@/pages/About.vue'

// 创建路由器
const router = createRouter({
  // 1. 路由模式设置
  // history: createWebHashHistory(), // Hash模式 (带#)
  history: createWebHistory(),        // History模式 (推荐，不带#)

  // 2. 路由规则配置
  routes: [
    {
      path: '/home',
      name: 'home', // 命名路由，可选
      component: Home
    },
    {
      path: '/about',
      name: 'about',
      component: About
    },
    // 重定向：默认跳转到 home
    {
      path: '/',
      redirect: '/home'
    }
  ]
})

// 暴露出去
export default router
```

### 2. 在入口文件中注册

修改 `src/main.ts`：

TypeScript

```
import { createApp } from 'vue'
import App from './App.vue'
import router from './router/index' // 引入路由器

const app = createApp(App)

// 使用路由器插件
app.use(router) //

app.mount('#app')
```

### 3. 在组件中使用

在 `App.vue` 中预留展示位置：

代码段

```
<template>
  <div class="app">
    <div class="nav">
      <RouterLink to="/home" active-class="active">首页</RouterLink>
      <RouterLink to="/about" active-class="active">关于</RouterLink>
    </div>
    
    <div class="content">
      <RouterView></RouterView> 
    </div>
  </div>
</template>
```

### 核心注意点

1. **Vue 3 的变化**：不再使用 `new Router()`，而是使用 `createRouter()` 工厂函数。
    
2. **History 模式**：需要从 `vue-router` 引入 `createWebHistory` (History 模式) 或 `createWebHashHistory` (Hash 模式)。
 3. 路由组件通常存放在`pages` 或 `views`文件夹，一般组件通常存放在`components`文件夹。
 4. 通过点击导航，视觉效果上“消失” 了的路由组件，默认是被**卸载**掉的，需要的时候再去**挂载**。
