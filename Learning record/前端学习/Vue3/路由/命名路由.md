
### 📝 Vue3 学习笔记：命名路由 (Named Routes)

1. 核心作用

给路由规则起一个名字，主要目的是简化路由跳转的写法，同时也便于后续进行路由传参（特别是 params 参数）。

2. 如何配置

在路由配置文件（如 router/index.ts）中，为路由对象添加 name 属性：

JavaScript

```
routes:[
  {
    name: 'zhuye',   // 👈 核心配置：给路由命名
    path: '/home',
    component: Home
  },
  {
    name: 'xinwen',
    path: '/news',
    component: News,
  }
]
```

3. 如何使用

在跳转时，可以使用对象写法配合 name 属性，替代传统的长路径字符串。

- ❌ 简化前（路径写法）：
    
    需手写完整路径，容易出错。
    
    代码段
    
    ```
    <router-link to="/news/detail">跳转</router-link>
    ```
    
- ✅ 简化后（命名写法）：
    
    直接通过名字跳转，清晰且易维护。
    
    代码段
    
    ```
    <router-link :to="{name: 'xinwen'}">跳转</router-link>
    ```
