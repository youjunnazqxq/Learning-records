

### 📝 Vue3 路由传参核心笔记

#### 1. Query 参数 (查询参数)

特点：参数直接拼接在 URL 后面（如 `?a=1&b=2`），**不需要**在路由规则中预先占位。

- **传递参数 (父组件)**
    
    - **字符串写法**：
        
        代码段
        
        ```
        <router-link to="/news/detail?id=1&title=哈哈">跳转</router-link>
        ```
        
    - **对象写法 (推荐)**：
        
        代码段
        
        ```
        <router-link
          :to="{
            path: '/news/detail', // 这里也可以用 name
            query: {
              id: 1,
              title: '哈哈'
            }
          }"
        >跳转</router-link>
        ```
        
- **接收参数 (子组件)**
    
    - 需要引入 `useRoute` 钩子。
        
    - 参数在 `route.query` 中。
        
        TypeScript
        
        ```
        import { useRoute } from 'vue-router'
        const route = useRoute()
        // 打印 query 参数
        console.log(route.query)
        ```
        

---

#### 2. Params 参数 (路径参数)

特点：参数是 URL 路径的一部分（如 `/news/detail/1/哈哈`），**必须**在路由规则中进行占位配置。

- 第一步：路由规则配置 (必须)
    
    在 router/index.ts 中，使用冒号 : 进行占位。
    
    TypeScript
    
    ```
    {
      name: 'xiang',
      path: 'detail/:id/:title/:content', // 占位符
      component: Detail
    }
    ```
    
- **第二步：传递参数 (父组件)**
    
    - **字符串写法**：
        
        代码段
        
        ```
        <router-link to="/news/detail/001/新闻001/内容001">跳转</router-link>
        ```
        
    - 对象写法 (⚠️重点)：
        
        注意： 如果使用对象写法传递 params，必须使用 name，不能使用 path！
        
        代码段
        
        ```
        <router-link
          :to="{
            name: 'xiang', // 必须对应路由配置中的 name
            params: {
              id: '001',
              title: '新闻001',
              content: '内容001'
            }
          }"
        >跳转</router-link>
        ```
        
- **第三步：接收参数 (子组件)**
    
    - 参数在 `route.params` 中。
        
        TypeScript
        
        ```
        import { useRoute } from 'vue-router'
        const route = useRoute()
        // 打印 params 参数
        console.log(route.params)
        ```

#### 3. 路由的 Props 配置 (进阶优化)

作用：将路由参数转换为组件的 `props` 属性，让组件摆脱对 `useRoute` 的依赖，实现解耦。

- 配置方式 (router/index.ts)
    
    支持三种写法：
    
    1. 布尔值写法 (仅限 Params)：
        
        props: true
        
        - **效果**：自动把收到的所有 `params` 参数，以 props 形式传给组件。
            
    2. 函数写法 (最灵活，推荐用于 Query)：
        
        props(route) { return route.query }
        
        - **效果**：函数接收 `route` 对象，返回一个对象，对象中的 key-value 会作为 props 传给组件。常用于把 `query` 参数转换成 props。
            
    3. 对象写法 (传递静态数据)：
        
        props: { a: 1, b: 2 }
        
        - **效果**：原样传递对象中的数据，与路由参数无关。
            
- 组件接收方式 (子组件)
    
    配置好 props 后，组件内直接通过 defineProps 接收，不再需要 useRoute。
    
    TypeScript
    
    ```
    // 假设路由配置了 props: true 或 函数写法返回了 id, title, content
    defineProps(['id', 'title', 'content'])
    ```
