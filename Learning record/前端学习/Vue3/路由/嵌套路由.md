基于文档《Vue3快速上手.md》，为你整理了**嵌套路由**的清晰笔记。

嵌套路由（Nested Routes）主要用于在页面中实现多级展示，比如在“新闻页面”内部点击链接，在当前页面下方显示“新闻详情”。

### 📝 Vue3 学习笔记：嵌套路由

#### 1. 配置规则 (router/index.ts)

使用 `children` 配置项来定义子路由。

- **配置方法**：在父路由规则中添加 `children` 数组。
    
- **⚠️ 关键注意点**：子路由的 `path` **不要写斜杠 `/`**。底层会自动拼接父路径。
    

TypeScript

```
{
  path: '/news',
  component: News,
  children: [ // 👈 开启嵌套
    {
      name: 'xiang',
      path: 'detail', // 👈 正确：detail (❌ 错误：/detail)
      component: Detail
    }
  ]
}
```

#### 2. 组件展示 (父组件)

必须在父组件（例如 News.vue）的 HTML 模板中预留 <RouterView>。

这是子组件（Detail）将来渲染显示的“坑位”。

代码段

```
<template>
  <div class="news">
    <RouterLink to="/news/detail">看详情</RouterLink>
    
    <div class="news-detail">
      <RouterView/>
    </div>
  </div>
</template>
```

#### 3. 路由跳转

跳转时必须写出**完整路径**（父路径 + 子路径）。

- 字符串写法：
    
    <router-link to="/news/detail">
    
- 对象写法：
    
    <router-link :to="{path: '/news/detail'}">
