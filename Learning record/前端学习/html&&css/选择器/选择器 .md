
# 🎨 CSS 选择器全攻略笔记

## 1. 属性选择器 (Attribute Selector)

> **刚才的新知识点**：根据标签的“特征”抓人，Vue 中常用 `[v-cloak]`。

| **写法**          | **含义**        | **举例**                    | **记忆口诀**    |
| --------------- | ------------- | ------------------------- | ----------- |
| `[attr]`        | 有这个属性就行       | `[disabled]` (选被禁用的)      | **不管值，只有名** |
| `[attr="val"]`  | 值必须完全匹配       | `input[type="password"]`  | **名值都要对**   |
| `[attr^="val"]` | 值以 val **开头** | `a[href^="http"]` (选外部链接) | **开头匹配**    |

## 2. 复合选择器 (Compound Selectors)

> 将基础选择器组合起来，实现更精准的定位。

### A. 交集选择器 (并且)

- **语法**：选择器之间**紧挨着，没有空格**。
    
- **含义**：必须**同时满足**这两个条件。
    
- **例子**：
    
    CSS
    
    ```
    /* 既要是 div，又要有名为 box 的 class */
    div.box { color: red; }
    ```
    
- **注意**：如果其中有标签名（如 `div`），标签名必须写在最前面。
    

### B. 并集选择器 (或者)

- **语法**：用**逗号 `,`** 隔开。
    
- **含义**：只要满足其中一个，就生效（大家共用一套样式）。
    
- **例子**：
    
    CSS
    
    ```
    /* h1 和 h2 和 .title 都变红 */
    h1, h2, .title { color: red; }
    ```
    

### C. 后代选择器 (子子孙孙)

- **语法**：用**空格**隔开。
    
- **含义**：选中里面所有的后代（儿子、孙子、重孙子...）。
    
- **例子**：
    
    CSS
    
    ```
    /* 选中 ul 里面所有的 li，不管藏多深 */
    ul li { list-style: none; }
    ```
    

### D. 子代选择器 (亲儿子)

- **语法**：用大于号 **`>`** 隔开。
    
- **含义**：只选**亲儿子**（第一级子元素），不选孙子。
    
- **例子**：
    
    CSS
    
    ```
    /* 只有 ul 的直接子元素 li 变色 */
    ul > li { border: 1px solid black; }
    ```

## 3. 伪类选择器 (Pseudo-classes)

> 用来描述元素的“特殊状态”或“位置结构”。

### A. 动态伪类 (交互状态)

最常用的“爱恨情仇”四件套（注意顺序 **L-V-H-A**）：

1. `:link` - 未访问过的链接
    
2. `:visited` - 访问过的链接
    
3. **:hover** - **鼠标悬停** (最最常用🔥)
    
4. `:active` - 鼠标按下未松开
    

CSS

```
/* 鼠标放上去变色 */
a:hover { color: orange; }
```

### B. 结构伪类 (位置排行)

根据元素在父元素中的位置来选。

- `:first-child`：选第一个子元素。
    
- `:last-child`：选最后一个子元素。
    
- `:nth-child(n)`：选第 n 个。
    
    - `2n` 或 `even`：偶数。
        
    - `2n+1` 或 `odd`：奇数。
        

CSS

```
/* 列表的第一个li变红 */
li:first-child { color: red; }
```

## 4. 伪元素选择器 (Pseudo-elements)

> 用 CSS 在页面里“造”出一个假的元素，通常用于装饰。
> 
> 注意：规范写法是双冒号 ::，虽然单冒号也能用，但建议用双冒号区分。

- `::before`：在元素内容**最前面**加东西。
    
- `::after`：在元素内容**最后面**加东西（常用于清除浮动 `clearfix`）。
    

⚠️ **核心考点**：伪元素必须写 `content` 属性，否则不显示。

CSS

```
/* 在每个 p 标签前面加一个小圆点 */
p::before {
    content: "●"; 
    color: red;
}
```

### ⚡️ 快速对比复习

|**符号**|**名称**|**含义**|**场景**|
|---|---|---|---|
|`[]`|**属性选择器**|看属性抓人|`[v-cloak]`|
|`.`|**类选择器**|穿衣服抓人|`.box`|
|(空格)|**后代**|包含孙子|`div p`|
|`>`|**子代**|只要亲儿子|`div > p`|
|`:`|**伪类**|状态/位置|`:hover`|
|`::`|**伪元素**|假装有个标签|`::after`|
