## padding（内边距）

padding有四个属性：上 右 下 左（顺时针）
如果只写一个属性的话就是 全部应用
2个属性： 上和下，左和右
3个属性 上 ，左和右，下
对于backgroud-color属性来说 他会填充所有边框以内的内容
对于padding属性来说，他对于行内元素的左右是没有影响的
而上下会有影响 它会直接覆盖到上一行文字的下半部分和下一行文字的上半部分，而不会把这两行文字推开

## margin(外边距)

会出现一个常见的现象：外边距折叠
当在垂直方向上两个margin相遇的时候，margin会自动折叠为两个元素中较大的那一个

## 元素区分：行内元素 块级元素 行内块元素

### 块级元素（block）：
可以理解为一个容器 内容独占一行 可以单独设置宽和高
可以用 marge 0 auto来使他水屏居中
默认高度：由其内容撑开
默认宽度：撑满父容器

![[Pasted image 20251007175856.png]]

### 行内元素（inline）
就是一段文字 不能设置宽和高 和其他元素并排
不能使用marge来实现水平居中 依靠父元素处理文字居中来实现来实现
默认宽度：由内容撑开
默认高度：由内容撑开
不可以通过css设置高度
![[Pasted image 20251007175905.png]]
### 行内块元素(inline-block)

不独占一行 但是可以单独设置宽和高 
默认宽度：由内容撑开
默认高度：由内容撑开
可以用css进行改造
![[Pasted image 20251007175914.png]]
