`vertical-align` 主要应用在以下两种场景：

#### 1. 对齐行内级元素（最常用）

这是 `vertical-align` 最核心的用途。当一行中包含不同大小的行内级元素时（例如，文字和图片、图标），`vertical-align` 决定了它们如何相互对齐。

它只对 `display` 值为 `inline`、`inline-block` 或 `inline-table` 的元素生效。

**常用值和效果：**

- `baseline` (默认值): 将元素的基线与父元素的基线对齐。对于图片来说，它的基线就是它的下边缘。这就是为什么图片旁边有文字时，图片底部会和文字 `x` 的底部对齐，看起来有点偏上。
    
- `middle`: 将元素的垂直中点与父元素基线加上 x-height 的一半对齐。这通常是让图标和文字看起来垂直居中的最佳方式。
    
- `top`: 将元素的顶部与它所在行的顶部对齐。
    
- `bottom`: 将元素的底部与它所在行的底部对齐。
    
- `text-top`: 将元素的顶部与父元素内容的顶部对齐（忽略 `padding` 等）。
    
- `text-bottom`: 将元素的底部与父元素内容的底部对齐。
