
您好！您很可能想问的是 CSS 中的 **“包含块” (Containing Block)**，而不是“包含快”。这是一个非常核心且重要的概念，它决定了元素在页面上的尺寸和位置是如何计算的。

简单来说，**包含块就是一个元素用来计算其自身尺寸和位置的“参考矩形”**。

---

### 一个简单的比喻

您可以把它想象成一个元素的“**坐标系**”或“**画板**”。

当您用百分比设置一个元素的宽度（如 `width: 50%`）或者用 `position: absolute;` 定位一个元素时，浏览器都需要知道：

- “这个 `50%` 是相对于**谁**的 `50%`？”
    
- “这个元素是相对于**谁**来定位的？”
    

这个“**谁**”，就是这个元素的**包含块**。

---

### 如何确定一个元素的包含块？

一个元素的包含块**并不总是它的父元素**。确定包含块的关键在于该元素自身的 **`position`** 属性。

以下是决定包含块的最主要规则：

#### 1. 当元素的 `position` 是 `static` (默认值) 或 `relative` 时

- 它的包含块是其**最近的块级祖先元素**的**内容区域 (content area)**。
    
- “块级祖先”就是像 `<div>`, `<p>`, `<li>`, `<body>` 这样的元素。
    

HTML

```
<div style="width: 500px; padding: 20px;">
  <p style="position: relative; width: 50%;"> 
    这个 p 元素的宽度是 250px (500px * 50%)。
  </p>
</div>
```

#### 2. 当元素的 `position` 是 `absolute` 时

- 它的包含块是其**最近的、`position` 值不为 `static` 的祖先元素**的**内边距区域 (padding area)**。
    
- 这个祖先的 `position` 值可以是 `relative`, `absolute`, `fixed` 或 `sticky`。
    
- **如果找不到这样的祖先**，那么它的包含块就是“初始包含块”（通常是 `<html>` 元素，表现得像整个浏览器视口）。
    

这就是为什么我们经常使用“**父相子绝**”（父元素 `position: relative;`，子元素 `position: absolute;`）的布局技巧。给父元素设置 `position: relative;` 就是为了让它成为绝对定位子元素的**包含块**。

HTML

```
<div style="position: relative; width: 500px; height: 200px; border: 1px solid red;">
  <p style="position: absolute; top: 10px; left: 10px;">
    绝对定位的元素
  </p>
</div>
```

#### 3. 当元素的 `position` 是 `fixed` 时

- 它的包含块是**浏览器视口 (Viewport)**。
    
- 这就是为什么固定定位的元素会“固定”在屏幕的某个位置，不会随页面滚动而移动。
