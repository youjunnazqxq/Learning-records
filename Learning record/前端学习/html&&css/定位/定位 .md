# 开启定位 

对元素进行 
```
position:
relation(相对定位)
absolution（绝对定位）
fixer（固定定位）
sticky（粘性定位）
```

## 相对定位 

开启后
```
position:relative
left
right
top
bottom
```
### 参考点：
相对于自己原来的位置

## 绝对定位

### 参考点：
参考他的[[包含块]]，

### 注意点

使用后会脱离文档流，一般来说会将其父亲设置一个相对定位，然后来设置



## 固定定位 


### 参考点：
浏览器窗口

### 注意点

脱离文档流





## 粘性定位 

### 参考点：
离他最近有一个“滚动机制”的祖先元素
