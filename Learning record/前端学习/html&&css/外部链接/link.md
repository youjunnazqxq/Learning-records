主要就是应用于此文件与外部文件的联系

| 属性 (Attribute) | 是否必须  | 作用说明                                                                                                                                                                                            |
| -------------- | ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`href`**     | **是** | **H**ypertext **Ref**erence。指定外部资源的 URL 地址（路径）。这是 `<link>` 最核心的属性之一。                                                                                                                            |
| **`rel`**      | **是** | **Rel**ationship。定义当前文档与被链接资源之间的**关系**。`rel` 的值决定了 `<link>` 的具体用途。 **这是决定 `<link>` 功能的最关键属性。** 常见值有： `stylesheet`, `icon`, `preload`, `canonical`, `alternate`, `preconnect`, `dns-prefetch` 等。 |
| `type`         | 否     | 指定被链接资源的媒体类型 (MIME Type)。例如，CSS文件是 `text/css`，ICO图标是 `image/x-icon`。虽然不是必需的，但建议使用，可以帮助浏览器更快地识别资源。                                                                                               |
| `media`        | 否     | 指定该资源适用于哪种媒体或设备。这在响应式设计中非常有用。例如，可以为一个只在打印时生效的样式表设置 `media="print"`，或者为小屏幕设备设置 `media="screen and (max-width: 600px)"`。                                                                          |
| `sizes`        | 否     | 仅当 `rel="icon"` 时使用。用来指定图标的尺寸（高x宽），可以帮助浏览器选择最合适的图标。例如 `sizes="16x16"` 或 `sizes="16x16 32x32"`。                                                                                                  |
| `crossorigin`  | 否     | 用于处理跨域（CORS）请求。当从另一个域名加载资源时（如字体、脚本），此属性可以控制是否发送用户凭据。常见值为 `anonymous` 和 `use-credentials`。                                                                                                       |
| `as`           | 否     | 仅当 `rel="preload"` 时**必须**使用。它指定了预加载资源的类型，帮助浏览器进行正确的优先级排序和资源处理。常见值为 `style`, `script`, `font`, `image`, `fetch` 等。                                                                              |
| `hreflang`     | 否     | 仅当 `rel="alternate"` 时使用。指定被链接资源的语言。对多语言网站的SEO非常重要。                                                                                                                                             |
| `title`        | 否     | 有多种用途。例如，当链接多个备用样式表时，可以使用 `title` 来为它们命名。                                                                                                                                                       |
| `integrity`    | 否     | 子资源完整性（SRI）校验。提供一个哈希值，浏览器下载资源后会计算其哈希值并与提供的值进行比较，确保资源未被篡改。主要用于从CDN加载的脚本或样式，增强安全性。                                                                                                                |

### 对于rel中的属性的翻译：
- **`stylesheet`**
    
    - **中文翻译**: **样式表**
        
    - **解释**: 这是 `rel` 最常见的属性值。它告诉浏览器，链接的文件是一个 **CSS (Cascading Style Sheets) 样式表**。浏览器会立即下载这个文件，并根据其中的规则来渲染页面的外观（比如颜色、字体、布局等）。
        
- **`icon`**
    
    - **中文翻译**: **图标**
        
    - **解释**: 这个值指定链接的图片为当前页面的 **网站图标 (Favicon)**。这个图标会显示在浏览器的标签页、书签列表、历史记录等位置，作为网站的视觉标识。
        
- **`preload`**
    
    - **中文翻译**: **预加载**
        
    - **解释**: 这是一个用于性能优化的指令。它告诉浏览器，这个链接指向的资源（例如一个关键的脚本、字体或样式文件）是当前页面**稍后一定会用到**的重要资源，请**立即以高优先级在后台开始下载**，但先不要使用它。这样当页面真正需要这个资源时，它已经下载完毕，可以立刻使用，从而缩短了用户的等待时间。
        
- **`canonical`**
    
    - **中文翻译**: **规范链接** 或 **首选链接**
        
    - **解释**: 这是一个主要用于 SEO (搜索引擎优化) 的属性值。如果你的网站上有多个内容相同或非常相似的页面（例如，同一个商品有不同的URL），你可以通过这个标签告诉搜索引擎，哪一个URL才是**“官方”或“首选”**的版本。这可以帮助搜索引擎集中权重，避免因重复内容而受到惩罚。
        
- **`alternate`**
    
    - **中文翻译**: **备用版本** 或 **替代版本**
        
    - **解释**: 这个值表明链接指向的是当前文档的**一个替代版本**。它有多种用途，例如：
        
        - 指向网站的 **RSS 或 Atom 订阅源**。
            
        - 配合 `hreflang` 属性，指向同页面的**其他语言版本**（例如，英文版页面指向中文版）。
            
        - 指向适合打印的版本或移动设备专用的版本。
            
- **`preconnect`**
    
    - **中文翻译**: **预连接**
        
    - **解释**: 这也是一个性能优化指令。它告诉浏览器：“我稍后将要从这个链接的域名（例如 `https://fonts.googleapis.com`）请求资源，请你现在就**提前建立好与那个服务器的连接**（包括DNS解析、TCP握手、TLS协商等）。” 当之后真正需要请求资源时，因为连接已经建立，就可以直接发送请求，从而节省了建立连接所需的时间。
        
- **`dns-prefetch`**
    
    - **中文翻译**: **DNS 预解析** 或 **DNS 预获取**
        
    - **解释**: 这是一个比 `preconnect` 更轻量级的性能优化指令。它只让浏览器**提前对指定的域名进行 DNS 解析**，也就是查询出这个域名对应的 IP 地址。当后续有请求发往该域名时，就省去了 DNS 查询的时间。它的开销比 `preconnect` 小，适用于你认为用户可能会点击的链接域名。
