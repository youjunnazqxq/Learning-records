
### 构建 Vue 项目的基本过程 (笔记)

#### 第 0 步：环境准备 (前提)

- 在开始之前，你需要确保你的电脑上安装了 **Node.js**。
    
- 安装 Node.js 会自动为你安装 **npm** (Node 包管理器)，我们后续的命令都需要依赖它。
    

#### 第 1 步：运行“脚手架” (创建项目)

- **命令：** `npm create vue@latest`
    
- **做什么？** 这是 Vue 官方的“脚手架”工具。它会自动运行一个向导，询问你项目名称、是否需要 TypeScript、是否需要 Vue Router (路由)、是否需要 Pinia (状态管理) 等功能。
    
- **为什么？** 它帮你**自动化**地创建了整个项目的**基础骨架**和所有**配置文件**，让你跳过最繁琐的配置环节，直接开始写代码。
    

#### 第 2 步：进入项目目录

- **命令：** `cd 你的项目名称` (例如：`cd vue-myex`)
    
- **做什么？** “cd” (Change Directory) 是“切换目录”的意思。你必须**“走进”**刚刚创建的项目文件夹里。
    
- **为什么？** 后续所有的安装和运行命令，都必须在这个项目的根目录里执行才有效。
    

#### 第 3 步：安装项目依赖

- **命令：** `npm install`
    
- **做什么？** 读取项目中的 `package.json` 文件（这份“清单”是脚手架自动生成的），然后去下载项目所需要的所有“依赖包”（比如 Vue 框架本身、Vite 工具等）。
    
- **为什么？** 这一步是把项目真正需要的“零件”（代码库）下载到你本地的 `node_modules` 文件夹里。**没有这一步，项目只是一个空壳子，无法运行。**
    

#### 第 4 步：启动“开发服务器”

- **命令：** `npm run dev`
    
- **做什么？** 启动 Vite 提供的“开发服务器”。
    
- **为什么？**
    
    1. **运行：** 它会在你的电脑上（如 `http://localhost:5173`）提供一个网址，让你可以通过浏览器访问你的应用。
        
    2. **“热更新”(HMR)：** 这是最关键的！它会**一直“挂着”**并实时监听你对代码文件的修改。一旦你按下**保存 (Ctrl + S)**，它会立刻自动编译更新，并马上在浏览器里显示出最新效果，你**无需手动刷新**。
        

#### 第 5 步：开始开发与访问

- **访问：** 在终端里按住 `Ctrl` 键并点击 `http://localhost:5173/` 链接（或者手动复制到浏览器），就能看到你的项目欢迎页。
    
- **开发：**
    
    1. 在 VS Code 编辑器中，打开 `src` 文件夹，找到 `App.vue` 文件。
        
    2. 修改文件内容并保存。
        
    3. 切换回浏览器，查看自动更新的效果。
        

#### 第 6 步：停止服务器 (当你休息时)

- **快捷键：** `Ctrl + C`
    
- **做什么？** 当你今天不想学了，想关闭项目时，切回到那个**“挂着”**的终端窗口，按下 `Ctrl + C`，即可停止开发服务器。
    
- **注意：** 服务器一旦停止，`http://localhost:5173/` 网址就访问不了了。下次想继续开发时，从**第 4 步 (`npm run dev`)** 重新开始即可。
