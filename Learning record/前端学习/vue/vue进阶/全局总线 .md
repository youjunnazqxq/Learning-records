### 📌 核心定义

**全局事件总线 (Global Event Bus)** 是 Vue 2 中一种**任意组件间通信**的模式。它利用一个公共的 Vue 实例作为“中介”，实现了跨层级（父子、兄弟、祖孙）的消息传递。

---

### 🧠 一、 原理总结 (How it works)

它的底层逻辑建立在 JavaScript 的 **原型继承** 和 Vue 实例的 **事件机制** 之上：

1. **物理基础（单例引用）：**
    
    - 在 `main.js` 中，我们将根实例（`this`）赋值给了 `Vue.prototype.$bus`。
        
    - 所有组件通过原型链（`__proto__`）都能访问到这个 `$bus`。
        
    - **本质：** 全应用的所有组件，操作的都是**同一个**根实例对象。
        
2. **逻辑基础（发布-订阅模式）：**
    
    - `$bus` 内部维护了一个事件记录表（`_events`）。
        
    - **订阅 ($on)**：接收方告诉 `$bus\`，“把我的函数存进列表里”。
        
    - **发布 ($emit)**：发送方告诉 `$bus\`，“去列表里找到那个函数并执行它，顺便把我的数据当参数传进去”。
        

---

### 🛠️ 二、 标准使用步骤 (4步法)

#### 1. 安装总线 (main.js)

利用 `beforeCreate` 钩子，在数据初始化前，将根实例挂载到原型上。

JavaScript

```
new Vue({
  // ...
  beforeCreate() {
    Vue.prototype.$bus = this // 安装全局事件总线
  }
}).$mount('#app')
```

#### 2. 接收数据 (Receiver.vue)

在组件挂载完成 (`mounted`) 时订阅事件。

- **为什么是 mounted？** 确保页面 DOM 已渲染，操作界面更安全。
    

JavaScript

```
mounted() {
  // 绑定事件，定义回调函数 (data 就是传过来的参数)
  this.$bus.$on('hello', (data) => {
    console.log('收到数据：', data)
  })
}
```

#### 3. 发送数据 (Sender.vue)

在需要的时候（如点击按钮）触发事件。

- **如何传递？** 数据通过函数参数传递。
    

JavaScript

```
methods: {
  sendData() {
    // 触发事件，携带数据
    this.$bus.$emit('hello', '我是消息内容') 
  }
}
```

#### 4. 解绑事件 (Receiver.vue) — **重要！**

在组件销毁前 (`beforeDestroy`) 关闭监听。

- **为什么要解绑？** 防止组件反复创建时重复绑定事件，导致内存泄漏或逻辑执行多次。
    

JavaScript

```
beforeDestroy() {
  // 关闭当前组件用到的 'hello' 事件
  this.$bus.$off('hello')
}
```

### 💡 三、 关键细节回顾

|**疑问点**|**核心解答**|
|---|---|
|**`this` 指向谁？**|指向 **`new Vue()` 创建的根实例**。它是整个应用的“老祖宗”。|
|**为什么能通信？**|因为所有组件拿到的 `$bus` 都是**同一个对象**（共享引用）。|
|**数据怎么过去的？**|就像**函数传参**。`$emit` 负责调用 `$on` 里存好的函数，并把数据填入参数位置。|
