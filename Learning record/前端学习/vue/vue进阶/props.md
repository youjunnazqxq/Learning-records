## Vue 配置项：props 学习笔记

### 1. 核心功能

**props** 是组件间通信最基础的方式，用于**让组件接收外部传过来的数据**。

- **方向：** 父组件 ==> 子组件（单向传递）。
    

### 2. 使用步骤

#### 第一步：父组件传递数据

在组件标签上通过属性的方式写上要传的数据。

HTML

```
<Demo name="张三" :age="18" />
```

> _注意：如果要传数字、布尔值或变量，记得前面加冒号 `:` (v-bind)，否则会被当成普通字符串。_

#### 第二步：子组件接收数据（三种方式）

方式一：简单接收（只接收，不检查）

最简单，但在项目中较少用，因为不严谨。

JavaScript

```
props: ['name', 'age']
```

方式二：限制类型（接收 + 类型检查）

如果传入类型不对，控制台会报警告。

JavaScript

```
props: {
  name: String,
  age: Number
}
```

方式三：完整配置（类型 + 必要性 + 默认值）

最推荐的写法，规范且健壮。

JavaScript

```
props: {
  name: {
    type: String,   // 类型：字符串
    required: true  // 必要性：必须要传，不传报错
  },
  age: {
    type: Number,
    default: 99     // 默认值：如果不传，就默认是99
  }
}
```

### 3. ⚠️ 重要原则：Props 是只读的！

Vue 遵循**单向数据流**原则。

- **现象：** 子组件**不应该**直接修改 props 里的数据。如果你试图修改（例如 `this.name = '李四'`），Vue 底层会监测到，并在控制台发出警告。
    
- **原因：** props 的数据归父组件所有，如果子组件随意修改，会导致数据流混乱。
    

### 4. 常见问题：如果我确实需要改怎么办？

**解决方案：** 把 props 的数据“复制”一份到组件自己的 `data` 中，然后去修改 data 里的那个变量。

**代码示例：**

JavaScript

```
props: ['name'], // 1. 接收父组件传来的 name
data() {
  return {
    // 2. 把 props 的 name 值赋给 data 里的 myName
    myName: this.name 
  }
},
methods: {
  changeName() {
    // 3. 修改 data 里的 myName，而不是修改 props 里的 name
    this.myName = '李四' 
  }
}
```
