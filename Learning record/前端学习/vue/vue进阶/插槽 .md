

# 💻 Vue 插槽实战案例补充

### 1. 默认插槽 (Default Slot)

场景： 封装一个通用的按钮组件或弹窗组件。

特点： 父组件只传一段内容，子组件只挖一个坑。

- **子组件 (`MyButton.vue`)**
    

HTML

```
<template>
  <button class="my-btn">
    <slot>默认按钮</slot>
  </button>
</template>
```

- **父组件使用：**
    

HTML

```
<MyButton />

<MyButton>提交</MyButton>

<MyButton>
  <span class="icon">🔍</span> 搜索
</MyButton>
```

### 2. 具名插槽 (Named Slot)

场景： 封装一个标准的卡片组件 (Card)，包含标题、内容区、底部操作区。

特点： 需要把内容“对号入座”放到指定位置。

- **子组件 (`BaseCard.vue`)**
    

HTML

```
<template>
  <div class="card">
    <div class="card-header">
      <slot name="header"></slot>
    </div>

    <div class="card-body">
      <slot></slot>
    </div>

    <div class="card-footer">
      <slot name="footer"></slot>
    </div>
  </div>
</template>
```

- 父组件使用：
    
    (注：v-slot:header 可以简写为 #header，这是现在最推荐的写法)
    

HTML

```
<BaseCard>
  <template #header>
    <h3>今日新闻</h3>
  </template>

  <p>今天天气不错，适合学 Vue。</p>

  <template #footer>
    <a href="#">阅读更多</a>
  </template>
</BaseCard>
```

### 3. 作用域插槽 (Scoped Slot) —— **最重要**

场景： 封装一个通用列表组件，逻辑（如循环、分页）在子组件，但每一行长什么样由父组件定。

特点： 子组件交出数据，父组件接管渲染。

- **子组件 (`UserList.vue`)** —— 负责提供数据
    

HTML

```
<template>
  <ul>
    <li v-for="(user, index) in userList" :key="user.id">
      <slot :info="user" :idx="index"></slot>
    </li>
  </ul>
</template>

<script>
export default {
  data() {
    return {
      userList: [
        { id: 1, name: '张三', role: 'admin' },
        { id: 2, name: '李四', role: 'user' }
      ]
    }
  }
}
</script>
```

- **父组件使用** —— 负责决定长相
    

HTML

```
<UserList>
  <template v-slot="slotProps">
    
    <span>
      {{ slotProps.idx + 1 }} - {{ slotProps.info.name }}
      
      <strong v-if="slotProps.info.role === 'admin'" style="color:red">
        (管理员)
      </strong>
    </span>

  </template>
</UserList>
```

### 💡 笔记小贴士 (Syntax Sugar)

在现代 Vue 开发中（Vue 2.6+ 和 Vue 3），你会经常看到**解构赋值**的写法，这会让代码更简洁。

**普通写法：**

HTML

```
<template v-slot="slotProps">
  {{ slotProps.info.name }}
</template>
```

**高手写法 (解构)：** 直接把里面的属性拿出来

HTML

```
<template v-slot="{ info }">
  {{ info.name }}
</template>
```
