

## Vue 配置项：plugin (插件) 学习笔记

### 1. 核心功能

**Plugin** 用于**增强 Vue**。

- **本质：** 它就是一个包含 `install` 方法的对象。
    
- **作用：** 能做很多全局性的工作，比如安装全局组件、添加全局指令、挂载原型方法等。通常第三方库（如 Vue Router, Vuex, ElementUI）都是以插件的形式存在的。
    

### 2. 定义插件 (制作工具)

你需要创建一个对象（或函数），并必须包含一个 `install` 方法。

JavaScript

```
// myPlugin.js
export default {
  // install 方法是必须的
  // 参数1：Vue 构造函数 (让你能直接操作 Vue)
  // 参数2：options (使用者传递的配置参数)
  install(Vue, options) {
    console.log('插件被调用了', options)

    // 1. 添加全局过滤器
    Vue.filter('myFilter', function(value) {
      return value.slice(0, 4)
    })

    // 2. 添加全局指令
    Vue.directive('fbind', {
      bind(el, binding) {
        el.value = binding.value
      }
    })

    // 3. 配置全局混入 (Mixin)
    Vue.mixin({
      data() { return { x: 100 } }
    })

    // 4. 添加实例方法 (最常用！)
    // 给 Vue 原型上添加方法，所有组件实例(vc)都能用 this.hello() 访问
    Vue.prototype.hello = () => { alert('你好啊') }
  }
}
```

### 3. 使用插件 (使用工具)

在 `main.js` 中引入并使用。

JavaScript

```
import Vue from 'vue'
import App from './App.vue'
import MyPlugin from './plugins/myPlugin' // 引入

// 使用插件
// 此时，插件里的 install 方法会被自动调用
// 且 Vue 会作为第一个参数自动传进去
Vue.use(MyPlugin)

// 也可以传入配置参数，这会作为 install 的第二个参数 options
// Vue.use(MyPlugin, { size: 'small' })

new Vue({
  el: '#app',
  render: h => h(App)
})
```

### 💡 重点补充：Mixin 和 Plugin 的区别

既然你刚学完这两个，很容易混淆。这里做一个简短对比：

|**特性**|**Mixin (混入)**|**Plugin (插件)**|
|---|---|---|
|**主要目的**|**复用业务逻辑**（比如多个组件都要用某个计算属性）。|**增强 Vue 功能**（比如引入一个 UI 库、添加 `$http` 方法）。|
|**作用范围**|通常是局部的（谁引入谁用），也可以全局。|**一定是全局的**，一旦 `Vue.use`，整个项目都能受到影响。|
|**典型例子**|比如两个页面都有“分页逻辑”，提取成 Mixin。|Vue Router, Vuex, ElementUI, Axios封装。|
