
## Vue Render 函数核心笔记

### 1. 定义与本质

- **定义**：`render` 函数是 Vue 组件中用于生成 **虚拟 DOM (Virtual DOM)** 的函数。
    
- **地位**：它是 Vue 渲染机制的底层核心。我们平时写的 `<template>` 最终都会被 Vue 编译器转换为 `render` 函数。
    
- **作用**：相比模板语法，它提供了完全的 JavaScript 编程能力，适用于需要极高灵活性的复杂场景（如动态生成标签）。
    

### 2. 核心工具：`h` 函数

`render` 函数通常接收一个参数 `createElement`，社区约定缩写为 **`h`**（Hyperscript）。

- **全称**：`createElement`
    
- **返回值**：**VNode**（虚拟节点）
    
- **基本语法**：
    
    JavaScript
    
    ```
    h(tag, data, children)
    ```
    
    1. **tag**：标签名（字符串）或 组件对象。
        
    2. **data**（可选）：属性对象（如 class, style, props, on）。
        
    3. **children**（可选）：子节点数组或文本。
        

### 3. 参数的“智能识别”（多态性）

`h` 函数根据第一个参数的类型，决定创建什么节点：

- **传字符串**：`h('div')` $\rightarrow$ 创建原生 HTML 标签节点。
    
- **传对象**：`h(App)` $\rightarrow$ 创建 Vue 组件节点（Vue 会根据组件内的逻辑进一步渲染）。
    

### 4. 经典场景：main.js 入口

JavaScript

```
new Vue({
  render: h => h(App)
})
```

- **翻译**：调用 `h` 函数，传入 `App` 组件对象，直接将该组件渲染为根节点的虚拟 DOM。
    
- **原因**：这是为了配合 **Runtime-only（仅运行时）** 版本的 Vue。
    
    - 该版本不带模板编译器，体积小（轻约 30%），运行快。
        
    - 因为没有编译器，不能解析 `template` 选项，必须显式提供 `render` 函数。
        

### 5. 模板 (Template) vs. Render 函数

| **特性**   | **Template (模板)**        | **Render 函数**     |
| -------- | ------------------------ | ----------------- |
| **写法**   | HTML 语法，声明式              | JavaScript 语法，编程式 |
| **可读性**  | 高，直观                     | 低，嵌套复杂            |
| **灵活性**  | 受限于 Vue 指令 (v-if, v-for) | 极高，完全使用 JS 逻辑控制   |
| **编译**   | 运行时需要编译 (或预编译)           | 不需要编译，直接运行        |
| **适用场景** | 95% 的业务开发                | 开发复杂的通用组件、动态标签    |
