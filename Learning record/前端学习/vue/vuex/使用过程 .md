

### 第一步：安装 (注意版本)

Vue 2 必须配合 **Vuex 3** 使用（Vuex 4 是给 Vue 3 用的）。

Bash

```
npm install vuex@3 --save
```

---

### 第二步：创建仓库 (Create Store)

通常在 src/store/index.js 中编写。

注意： 在 Vue 2 中，我们需要先显式地调用 Vue.use(Vuex)。

JavaScript

```
// src/store/index.js
import Vue from 'vue'
import Vuex from 'vuex'

// 1. 必须先安装插件
Vue.use(Vuex)

// 2. 创建并导出 Store 实例 (注意这里是 new Vuex.Store)
export default new Vuex.Store({
  // State: 存放数据
  state: {
    count: 0
  },
  
  // Mutations: 同步修改数据
  mutations: {
    INCREMENT(state) {
      state.count++
    },
    ADD_NUMBER(state, payload) {
      state.count += payload
    }
  },
  
  // Actions: 异步操作
  actions: {
    incrementAsync({ commit }) {
      setTimeout(() => {
        commit('INCREMENT')
      }, 1000)
    }
  },
  
  // Getters: 计算属性
  getters: {
    doubleCount: state => state.count * 2
  }
})
```

### 第三步：在入口文件中注册 (Register)

这里就是你记忆中“要注册”的地方。在 `src/main.js` 中，你需要把 `store` 作为一个选项传给 Vue 实例。

JavaScript

```
// src/main.js
import Vue from 'vue'
import App from './App.vue'
import store from './store' // 引入 store

Vue.config.productionTip = false

new Vue({
  // 关键步骤：在这里注册 store
  // 这样所有的子组件才能通过 this.$store 访问到它
  store, 
  
  render: h => h(App)
}).$mount('#app')
```

---

### 第四步：在组件中使用 (Usage)

在 Vue 2 的组件（Options API）中，我们通过 `this` 来访问。

#### 1. 读取数据

HTML

```
<template>
  <div>
    <p>当前计数: {{ $store.state.count }}</p>
    <p>两倍计数: {{ $store.getters.doubleCount }}</p>
  </div>
</template>
```

#### 2. 修改数据

JavaScript

```
<script>
export default {
  methods: {
    // 同步修改 (调用 Mutations)
    addOne() {
      this.$store.commit('INCREMENT')
    },
    
    // 异步修改 (调用 Actions)
    addAsync() {
      this.$store.dispatch('incrementAsync')
    }
  }
}
</script>
```

### 进阶：使用辅助函数 (Map Helpers)

这是 Vue 2 中非常常用的写法，可以让代码更整洁。

JavaScript

```
<script>
import { mapState, mapMutations, mapActions } from 'vuex'

export default {
  computed: {
    // 将 this.count 映射为 this.$store.state.count
    ...mapState(['count']) 
  },
  methods: {
    // 将 this.INCREMENT() 映射为 this.$store.commit('INCREMENT')
    ...mapMutations(['INCREMENT']),
    
    // 将 this.incrementAsync() 映射为 this.$store.dispatch('incrementAsync')
    ...mapActions(['incrementAsync'])
  }
}
</script>
```

### 总结 Vue 2 写法的核心特征：

1. **版本**：用 `vuex@3`。
    
2. **插件**：必须写 `Vue.use(Vuex)`。
    
3. **实例化**：用 `new Vuex.Store({...})`。
    
4. **挂载**：在 `new Vue({ store, ... })` 里手动传入。
    

这套流程是不是看着眼熟多了？如果你的项目是老项目，按照这个写绝对没错。
