

## 📝 知识点笔记：命名路由 (Named Routes)

### 1. 核心概念

**命名路由**就是给路由规则起一个“名字”。

- **本质**：给 URL 路径（Path）起一个“短昵称”。
    
- **作用**：用“名字”代替“路径”进行跳转。
    

### 2. 如何配置 (router/index.js)

在定义路由规则时，多加一个 `name` 属性。

JavaScript

```
{
  path: '/demo/test/welcome', // 路径很长
  name: 'hello',              // 起个短名字
  component: Welcome
}
```

### 3. 如何使用 (跳转)

#### A. 模板中 (`<router-link>`)

**注意**：必须使用对象写法 (`:to="{ ... }"`)。

HTML

```
<router-link to="/demo/test/welcome">跳转</router-link>

<router-link :to="{ name: 'hello' }">跳转</router-link>

<router-link :to="{ name: 'hello', query: { id: 666 } }">带参跳转</router-link>
```

#### B. 代码中 (`this.$router.push`)

JavaScript

```
this.$router.push({
  name: 'hello',
  query: { id: 666 }
})
```

### 4. 为什么要用？(优点)

1. **简化代码**：避免在代码里写又长又复杂的 URL 字符串。
    
2. **便于维护（解耦）**：
    
    - 如果未来 `path` 变了（例如从 `/welcome` 改成 `/home`），只需要修改路由配置文件。
        
    - 页面里的 `:to="{ name: 'hello' }"` **不需要修改**，因为它只认名字。
        

### 5. ⚠️ 关键注意事项 (必考题)

- **对象写法**：使用 `name` 跳转时，`to` 属性必须写成对象形式。
    
- **Params 搭配**：如果你想使用 **Params 参数**（路径参数），**必须**使用 `name`，不能使用 `path`。
    
    - ✅ `name: 'hello', params: { id: 1 }` (生效)
        
    - ❌ `path: '/welcome', params: { id: 1 }` (Params 会被忽略，不生效)
