

## 📝 知识点笔记：路由守卫 (Route Guards)

### 1. 核心概念

- **定义**：在路由跳转的过程中，进行**拦截**、**检查**和**放行**的机制。
    
- **比喻**：就像大厦门口的**保安**或火车站的**检票员**。
    
- **作用**：权限控制（没登录不让进）、页面标题修改、数据预加载等。
    

### 2. 三个核心参数 (必考)

在守卫函数 `(to, from, next) => {}` 中：

|**参数名**|**含义**|**作用**|
|---|---|---|
|**`to`**|**去哪里**|目标路由对象（包含 path, query, params, meta 等信息）|
|**`from`**|**从哪来**|来源路由对象（你刚才所在的页面信息）|
|**`next`**|**开关**|**必须调用！** 否则路由会卡死|

**关于 `next` 的用法：**

- `next()`：**放行**。一切正常，去吧。
    
- `next(false)`：**中断**。不准去，留在原地。
    
- `next('/login')`：**改道**。强制跳转到指定路径。
    

### 3. 守卫的分类

#### A. 全局守卫 (router/index.js 中配置)

影响所有的路由跳转。

- **全局前置守卫 `beforeEach`** (最常用)
    
    - _触发时机_：初始化时、每次路由切换**前**。
        
    - _用途_：**登录拦截**、权限校验。
        
- **全局后置守卫 `afterEach`**
    
    - _触发时机_：初始化时、每次路由切换**后**。
        
    - _注意_：**没有 `next` 参数**（因为已经跳过来了，拦不住了）。
        
    - _用途_：修改网页标题 (`document.title`)。
        

#### B. 独享守卫 (路由配置数组中配置)

只影响这一个具体的路由。

- **`beforeEnter`**
    
    - _位置_：写在 `routes` 配置项的具体对象里。
        
    - _用途_：针对某个特定页面进行单独保护（如“VIP专属页”）。
        

#### C. 组件内守卫 (写在 .vue 文件里)

_(你的截图中未详细列出，但了解即可)_

- `beforeRouteEnter`: 进组件前。
    
- `beforeRouteLeave`: 离开组件前（比如问用户“表单未保存，确定离开吗？”）。
    

### 4. 路由元信息 (`meta`)

- **作用**：给路由添加自定义的数据（如：是否需要鉴权、页面标题）。
    
- **配置**：
    
    JavaScript
    
    ```
    {
      path: '/home',
      component: Home,
      meta: { isAuth: true, title: '首页' } // 自定义口袋
    }
    ```
    
- **使用**：在守卫中通过 `to.meta.isAuth` 获取。
    

### 5. 标准代码模板 (登录拦截)

JavaScript

```
router.beforeEach((to, from, next) => {
  // 1. 判断该页面是否需要权限 (从 meta 里拿)
  if (to.meta.isAuth) {
      // 2. 判断是否已登录 (检查 token 或 localStorage)
      if (localStorage.getItem('token')) {
          next() // 有权限，放行
      } else {
          alert('请先登录！')
          next('/login') // 没权限，踢回登录页
      }
  } else {
      // 3. 不需要权限的页面 (如首页、注册页)，直接放行
      next()
  }
})
```

---

⚠️ 避坑指南：

千万不要在 if 里写了 next(...)，却忘记在 else 里写 next()。如果代码执行完没有任何一个 next 被调用，页面就会一片空白，像死机了一样。
