**“多级路由”**，在 Vue Router 官方文档里通常叫做**“嵌套路由” (Nested Routes)**。

这也是 Vue 开发中最常用的功能之一。

### 1. 为什么要用多级路由？

想象一下你正在使用一个后台管理系统，或者像“网易云音乐”这样的网站：

1. **一级路由**：你点击顶部的“发现音乐”，整个页面变了。
    
2. **二级路由**：在“发现音乐”页面里，又有“推荐”、“排行榜”、“歌单”几个子菜单。
    
    - 当你点击“排行榜”时，顶部的“发现音乐”导航栏**不动**。
        
    - 底部的播放器**不动**。
        
    - 只有**中间的一块区域**变成了排行榜的内容。
        

这就是多级路由的意义：**在父组件（大盒子）里，再挖一个坑，用来展示子组件（小盒子）。**

---

### 2. 代码配置详解 (基于你的截图)

你截图中的代码非常标准，我为你拆解一下其中的关键点：

#### A. 核心配置：`children`

我们在父路由（`/home`）的配置对象里，增加了一个 `children` 数组。

JavaScript

```
{
  path: '/home',
  component: Home,
  children: [ // 这里开始配置子路由
    {
      // 【重点】这里的 path 不要写斜杠 /
      // 写 'news'，Vue 会自动帮你拼接成 /home/news
      path: 'news', 
      component: News
    },
    {
      path: 'message',
      component: Message
    }
  ]
}
```

#### B. 路径写法规则 (新手必看)

- **一级路由**：必须加 `/`，例如 `/home`。
    
- **子路由**：**千万不要加 `/`**，例如直接写 `news`。
    
    - 如果你写了 `path: '/news'`，Vue 会把它当作根路径，URL 会变成 `localhost:8080/news`，而不是你想要的 `localhost:8080/home/news`。
        

#### C. 跳转写法

在 `<router-link>` 中跳转时，必须写出**完整的长路径**：

HTML

```
<router-link to="/home/news">看新闻</router-link>

<router-link to="news">看新闻</router-link>
```

---

### 3. 极其重要的一步：父组件里的 `<router-view>`

这是很多初学者配置完路由表后，页面却死活显示不出子组件的原因：**你忘了在父组件里挖坑！**

**结构图解（套娃模式）：**

1. **`App.vue` (爷爷)**
    
    - 它里面有一个 `<router-view>`。
        
    - 这个坑显示的是 `Home` 组件。
        
2. **`Home.vue` (爸爸)**
    
    - **关键点：** `Home.vue` 的 HTML 代码里，**必须也要写一个 `<router-view>`**。
        
    - 这个内部的坑，才是用来显示 `News` 或 `Message` (孙子) 的地方。
        

HTML

```
<template>
  <div>
    <h1>我是 Home 页面的标题（这一块是不变的）</h1>
    
    <router-link to="/home/news">新闻</router-link>
    <router-link to="/home/message">消息</router-link>
    
    <router-view></router-view>
  </div>
</template>
```

### 总结

多级路由其实就是**“大路由套小路由，大组件套小组件”**。

1. **配置上：** 使用 `children` 属性。
    
2. **路径上：** 子路由 `path` 不写 `/`，跳转 `to` 写全路径。
    
3. **显示上：** 别忘了在父组件 (`Home.vue`) 里加一个 `<router-view>`。
