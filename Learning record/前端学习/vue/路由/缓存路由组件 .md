
## 📝 知识点笔记：缓存路由组件 `<keep-alive>`

### 1. 核心作用

- **默认行为**：路由切换时，旧组件会被**销毁**（数据丢失），新组件会被**挂载**。
    
- **缓存作用**：让不展示的路由组件**保持挂载（活着）**，不被销毁。
    
- **效果**：切换回来时，**数据还在，滚动条位置还在**，且不需要重新渲染和发请求。
    

### 2. 基本代码写法

在父组件（通常是 `App.vue` 或某个布局组件）中，用 `<keep-alive>` 包裹住 `<router-view>`。

HTML

```
<keep-alive include="News">
    <router-view></router-view>
</keep-alive>
```

### 3. 三个重要属性

|**属性名**|**作用**|**写法示例**|
|---|---|---|
|**`include`**|**白名单**：只有匹配的组件会被缓存|`include="News,Message"`|
|**`exclude`**|**黑名单**：匹配的组件**不**被缓存|`exclude="User"`|
|**`max`**|**最大缓存数**：超过数量时，最久没用的组件会被销毁|`max="10"`|

### 4. ⚠️ 必坑点：组件名匹配

`include` 和 `exclude` 匹配的字符串，**必须**是组件文件内部 `name` 选项的值！

JavaScript

```
// News.vue 文件内部
export default {
  name: 'News', // 【关键】这个名字必须和 include="News" 对应！
  data() { ... }
}
```

> 如果组件里没写 `name`，缓存规则将无法生效。

### 5. 生命周期的变化 (考点)

当组件被缓存后，它不会被销毁和重新挂载，因此 mounted 和 destroyed 钩子失效。

Vue 提供了两个专属钩子：

- **`activated()`**：组件**被激活**时触发（即：你看到它的时候）。
    
    - _用法：_ 每次进来都想做点什么（比如刷新时间），写在这里。
        
- **`deactivated()`**：组件**失活**时触发（即：你切走的时候）。
    
    - _用法：_ 离开时想暂停定时器、保存滚动位置，写在这里。
        

---

### 💡 场景举例

- **列表页 -> 详情页**：
    
    - 希望从详情页退回列表页时，列表的筛选条件保留、滚动条位置保留 -> **使用 `<keep-alive>`**。
        
- **详情页 -> 列表页**：
    
    - 希望从列表页再次点进详情页时，详情页是全新的（ID变了）-> **不要缓存详情页**。
