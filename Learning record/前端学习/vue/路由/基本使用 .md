

### 第一步：安装 (Installation)

如果你不是通过 Vue CLI 自动安装的，需要在终端运行以下命令（注意 `@3` 指定版本）：

Bash

```
npm install vue-router@3
```

---

### 第二步：配置路由表 (Configuration)

通常在项目中新建一个 `router/index.js` 文件，在这里定义你的“映射关系”。

假设你有两个组件：`Home.vue` (首页) 和 `About.vue` (关于页)。

JavaScript

```
// 文件位置：src/router/index.js

import Vue from 'vue'
import VueRouter from 'vue-router'

// 1. 引入你的组件
import Home from '../components/Home.vue'
import About from '../components/About.vue'

// 2. 安装插件
Vue.use(VueRouter)

// 3. 定义路由映射表 (Routes)
// 这里就是你说的：路径 -> 组件
const routes = [
  {
    path: '/home',     // 浏览器地址栏显示的路径
    name: 'Home',      // 给路由起个名字（可选，但在跳转时很有用）
    component: Home    // 对应的组件
  },
  {
    path: '/about',
    name: 'About',
    component: About
  },
  // 重定向：默认进入 /home
  {
    path: '/',
    redirect: '/home'
  }
]

// 4. 创建 router 实例
const router = new VueRouter({
  routes // 简写，等同于 routes: routes
})

// 5. 导出 router 实例，供 main.js 使用
export default router
```

---

### 第三步：在入口文件注册 (Registration)

你需要告诉 Vue 实例：“请使用我刚才配置好的那个路由器”。

JavaScript

```
// 文件位置：src/main.js

import Vue from 'vue'
import App from './App.vue'
import router from './router' // 引入刚才写的 router/index.js

Vue.config.productionTip = false

new Vue({
  router, // 【关键点】把 router 挂载到 Vue 实例上
  render: h => h(App)
}).$mount('#app')
```

---

### 第四步：在页面中使用 (Usage)

在你的根组件 `App.vue` 中，需要两个核心标签：

1. **`<router-link>`**：相当于 `<a>` 标签，用于点击跳转。
    
2. **`<router-view>`**：相当于“占位符”或“显示屏”，匹配到的组件会显示在这里。
    

HTML

```
<template>
  <div id="app">
    <h1>Vue2 路由演示</h1>
    
    <nav>
      <router-link to="/home">去首页</router-link> | 
      <router-link to="/about">去关于页</router-link>
    </nav>

    <hr>

    <router-view></router-view>

  </div>
</template>
```

---

### 补充：如何在 JS 代码中跳转？

除了点击 `<router-link>`，你经常需要在 JavaScript 代码逻辑里（比如登录成功后）自动跳转。

这时就要用到你之前问 Query 参数时的知识点：

JavaScript

```
// 在任何组件的方法(methods)中：

methods: {
  goToAbout() {
    // 方式一：字符串路径
    this.$router.push('/about')
    
    // 方式二：对象形式 (推荐)
    this.$router.push({ 
      path: '/about',
      query: { name: 'user1' } // 带参数跳转
    })
  }
}
```

### 总结

Vue 2 的路由使用核心就这三块：

1. **`router/index.js`**：定义“去哪儿 -> 显什么”的**规则**。
    
2. **`main.js`**：**启用**这个规则。
    
3. **`App.vue`**：用 `<router-view>` 给规则匹配到的组件**留位置**。
