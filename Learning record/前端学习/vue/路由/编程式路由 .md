

## 📝 知识点笔记：编程式路由导航

### 1. 核心概念

- **定义**：不使用 HTML 中的 `<router-link>` 标签，而是通过写 **JavaScript 代码** 来控制路由跳转。
    
- **核心对象**：**`this.$router`** (路由器/操作者)。
    
- **适用场景**：需要**先执行逻辑**（如：登录验证、提交表单、处理数据）然后再跳转的时候。
    

### 2. 五个核心 API (都在 `this.$router` 下)

| **方法名**             | **作用**         | **浏览器历史记录**       | **等同于**                          |
| ------------------- | -------------- | ----------------- | -------------------------------- |
| **`push(path)`**    | **普通跳转** (最常用) | **追加** (能后退回来)    | `<router-link to="...">`         |
| **`replace(path)`** | **无痕跳转**       | **替换** (不能后退回来)   | `<router-link replace to="...">` |
| **`back()`**        | **后退一步**       | -                 | 浏览器左上角 "←"                       |
| **`forward()`**     | **前进一步**       | -                 | 浏览器左上角 "→"                       |
| **`go(n)`**         | **穿越 N 步**     | `n>0` 前进，`n<0` 后退 | `go(-1)` 等于 `back()`             |

### 3. 具体代码写法

不管是 `push` 还是 `replace`，写法规则和 `<router-link>` 的 `to` 属性完全一致。

#### A. 字符串写法 (简单)

JavaScript

```
// 直接跳转到路径
this.$router.push('/home/news')
```

#### B. 对象写法 (推荐，传递参数必用)

JavaScript

```
this.$router.push({
  name: 'xiangqing', // 使用路由的名字
  params: {
    id: 666,
    title: '你好'
  }
  // 或者使用 query
  // path: '/detail',
  // query: { id: 666 }
})
```

### 4. 常见面试/实战点

1. **区别 `$router` 和 `$route`**：
    
    - 想**跳转**，找 `$router` (动词)。
        
    - 想**看参数**，找 `$route` (名词)。
        
2. **重复跳转报错**：
    
    - 在 Vue Router 3 (Vue 2版本) 中，如果你编程式跳转到**当前已经在的路径**，控制台可能会报 `NavigationDuplicated` 错误。虽然不影响使用，但需要注意捕获异常。
