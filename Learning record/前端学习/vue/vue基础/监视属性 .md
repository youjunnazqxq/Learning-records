
# 📝 Vue 监视属性 (Watch) 核心笔记

### 1. 基本概念

- **作用**：当被监视的属性（`data` 或 `computed` 中的属性）发生变化时，回调函数自动调用，执行相关操作。
    
- **前提**：被监视的属性**必须存在**，才能进行监视。
    
- **两种写法**：
    
    1. **配置项写法**：在 `new Vue` 时传入 `watch: { ... }` 配置。
        
    2. **API 写法**：通过 `vm.$watch('属性名', { ... })` 动态监视。
        

---

### 2. 深度监视 (Deep Watch) ⚠️重点

Vue 的 `watch` 默认行为与深度监视的区别：

- **Vue 默认行为**：
    
    - `watch` 默认**不监测**对象内部值的改变（只看对象引用的地址变没变）。
        
    - 即：默认是“浅层监视”。
        
- **开启深度监视**：
    
    - 配置 **`deep: true`**。
        
    - 开启后，可以监测对象内部属性（多层）的改变。
        
- **底层原理备注**：
    
    - Vue **自身**其实是可以监测到对象内部数据的改变的（所以页面会更新）。
        
    - 但 Vue 提供的 **`watch`** 为了省性能，默认关闭了深度监测。需根据数据结构手动开启。
        

---

### 3. 语法写法对比

#### A. 完整写法 (对象式)

当你需要配置 `deep` (深度) 或 `immediate` (立即) 时，必须用这种写法。

JavaScript

```
watch: {
    isHot: {
        // ✅ 常用配置
        immediate: true, // 初始化时，让 handler 立即先执行一次
        deep: true,      // 开启深度监视（监视对象内部变化）
        
        // ✅ 回调函数
        handler(newValue, oldValue) {
            console.log('isHot 被修改了', newValue, oldValue);
        }
    }
}
```

#### B. 简写方式 (函数式)

当你**不需要** `deep` 和 `immediate`，只需要 `handler` 逻辑时，可以简写。

JavaScript

```
watch: {
    // 直接写成函数，它就是 handler
    isHot(newValue, oldValue) {
        console.log('isHot 被修改了', newValue, oldValue, this);
    }
}
```

### 4. Computed 与 Watch 的区别 (面试必考)

|**维度**|**Computed (计算属性)**|**Watch (监视属性)**|
|---|---|---|
|**功能范围**|能做的事，Watch 都能做|**能做异步操作** (Computed 做不到)|
|**侧重点**|侧重 **结果** (return 值)|侧重 **过程** (执行逻辑)|
|**缓存**|**有缓存** (效率高)|**无缓存**|
|**适用场景**|一个值依赖多个属性 (多对一)|一个值变化影响多个逻辑 (一对多)|

### 5. 两个重要的 `this` 原则 (黄金法则) 🌟

这是很多新手容易报错的地方，请务必背诵：

#### 原则一：Vue 管理的函数 $\rightarrow$ 普通函数

- **哪些是？** `methods` 里的方法、`watch` 的回调、`computed` 的函数。
    
- **怎么写？** 最好写成 **普通函数**。
    
- **为什么？** 这样 `this` 的指向才是 **vm (Vue 实例)** 或 组件实例对象。
    

#### 原则二：不被 Vue 管理的函数 $\rightarrow$ 箭头函数

- **哪些是？** **定时器**的回调 (`setTimeout`)、**Ajax** 的回调、**Promise** 的回调。
    
- **怎么写？** 最好写成 **箭头函数**。
    
- **为什么？** 箭头函数没有 `this`，它会往外找。这样 `this` 才能找到外层的 **vm**。
    

---

### 🧠 场景速记

> 想要异步（setTimeout/Ajax）？只能用 Watch。
> 
> 想要深度监视对象？记得加 deep: true。
> 
> 定时器里想用 this？一定要写箭头函数 ()=>。
