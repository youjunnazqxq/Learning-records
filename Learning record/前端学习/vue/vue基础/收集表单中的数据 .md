

# 📝 Vue 表单收集与修饰符笔记

### 1. 不同表单元素的收集规则

`v-model` 会根据 `<input>` 的 `type` 类型不同，自动切换收集逻辑：

| **Input 类型**       | **收集的内容**                                                         | **关键配置要求**             |
| ------------------ | ----------------------------------------------------------------- | ---------------------- |
| **text** (文本框)     | 用户输入的**字符串**                                                      | 无                      |
| **radio** (单选框)    | 选中项的 **`value`** 值                                                | 必须给标签配置 **`value`** 属性 |
| **checkbox** (复选框) | **情况 A：布尔值** (true/false)<br><br>  <br><br>**情况 B：数组** (value 集合) | **看下方详解 👇**           |

---

### 2. 复选框 (Checkbox) 的两大陷阱 ⚠️

复选框是单选还是多选，**完全取决于你在 `data` 中定义的初始值类型**。

#### A. 勾选模式 (Switch/开关)

- **场景**：用户协议勾选、记住密码。
    
- **Data 定义**：非数组 (通常是 `false`)。
    
- **收集结果**：**`checked` 状态** (true 或 false)。
    
    - _注：此时标签上的 value 属性无效。_
        

#### B. 多选模式 (Multi-select)

- **场景**：兴趣爱好 (抽烟、喝酒)。
    
- **Data 定义**：**必须是数组 `[]`**。
    
- **标签配置**：**必须配置 `value` 属性**。
    
- **收集结果**：Vue 会把勾选的 value **自动 push 进数组**。
    

---

### 3. v-model 的三个修饰符

|**修饰符**|**作用**|**适用场景**|
|---|---|---|
|**`.lazy`**|**懒加载**。<br><br>  <br><br>失去焦点 (blur) 或回车时才更新数据，而不是实时更新。|输入大段文本、搜索框防抖。|
|**`.number`**|**转数字**。<br><br>  <br><br>将输入的字符串尝试转为 Number 类型。|年龄、价格、计算器。|
|**`.trim`**|**去空格**。<br><br>  <br><br>自动过滤输入内容的首尾空格。|用户名、密码输入。|

---

### 🧠 避坑口诀

> 文本输入看 value，单选一定要配值。
> 
> 复选若想做多选，初始必须是数组。
> 
> 数字转换 number，首尾去空 trim。
> 
> 失去焦点再收集，lazy 懒人最省力。
