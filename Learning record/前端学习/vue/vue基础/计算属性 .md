
# 📝 Vue 计算属性 (Computed) 核心笔记

### 1. 核心定义

**计算属性**是指：**原本不存在**的属性，需要通过**已有属性**（通常是 `data` 里的数据）经过计算/加工后得来的。

- **原料**：`data` 中的数据。
    
- **产品**：`computed` 中的属性。
    

### 2. 书写与使用 (最大的反差)

- **写的时候**：它是一个 **函数**（必须要有 `return` 返回值）。
    
- **用的时候**：它是一个 **属性**（直接写变量名，**千万别加括号** `()`）。
    
    - _原理_：Vue 内部会自动调用这个函数，并把返回值拿出来给你用。
        

JavaScript

```
// 1. 定义
computed: {
    fullName() {
        return this.firstName + '-' + this.lastName;
    }
}
```

HTML

```
<div>{{ fullName }}</div>
```

### 3. 核心优势：缓存机制 (Caching) ⭐️

这是计算属性和 `methods` 最本质的区别。

| **对比项**  | **computed (计算属性)**                                      | **methods (方法)**       |
| -------- | -------------------------------------------------------- | ---------------------- |
| **机制**   | **有缓存**                                                  | **无缓存**                |
| **执行时机** | 1. 初次读取时执行一次。<br><br>  <br><br>2. **只有当依赖的数据变了**，才会重新执行。 | 只要页面重新渲染，**永远都会重新执行**。 |
| **效率**   | **高** (懒加载，不做无用功)                                        | **低** (太勤快，容易浪费性能)     |
| **形象比喻** | **懒惰的聪明人** (算过了就记在本子上，下次直接读本子)                           | **勤劳的打工仔** (每次都要重新算一遍) |

### 4. 底层原理

底层依然是借助了 **`Object.defineProperty`**。

- 你写的函数，其实就是这个属性的 **Getter (`get`)**。
    
- 当你读取这个计算属性时，Vue 调用 `get` 函数，并进行依赖收集（记下来它用了哪些 data）。
    

### 5. 完整写法 (get 与 set)

默认情况下，计算属性是只读的（只能通过 get 读取）。

如果你想直接修改计算属性的值（例如 vm.fullName = '李-四'），并让它反过来影响 firstName 和 lastName，就必须写成对象形式，配置 set。

JavaScript

```
computed: {
    fullName: {
        // 读：把名和姓拼起来给别人看
        get() {
            return this.firstName + '-' + this.lastName;
        },
        // 写：别人给你一个全名，你负责拆开塞回 data
        set(value) {
            const arr = value.split('-');
            this.firstName = arr[0];
            this.lastName = arr[1];
        }
    }
}
```
