
# 🛠️ Vue 自定义指令核心笔记

### 1. 核心作用

当 Vue 内置指令（`v-if`, `v-model`）满足不了需求，需要对 **底层 DOM 元素** 进行直接操作（如获取焦点、滚动定位、绑定特殊事件）时使用。

### 2. 两种定义方式

|**类型**|**语法位置**|**作用范围**|
|---|---|---|
|**局部指令**|组件内 `directives: { ... }`|只在当前组件有效|
|**全局指令**|`Vue.directive('名', ...)`|整个项目都能用|

---

### 3. 两种写法逻辑 (重点)

#### A. 函数式简写 (90% 场景)

当 **bind (绑定时)** 和 **update (更新时)** 的逻辑一样，且不需要处理 `inserted` 时使用。

JavaScript

```
directives: {
    // 指令名: color，使用: v-color="x"
    color(el, binding) {
        el.style.color = binding.value;
    }
}
```

#### B. 对象式完整写法 (处理细节)

当你需要在元素 **真正插入页面后** 才能执行某些操作（如获取焦点）时使用。

JavaScript

```
directives: {
    fbind: {
        // 1. 指令与元素绑定时 (初始化样式)
        bind(el, binding) { ... },
        
        // 2. 元素插入页面时 (✨ 操作 DOM 行为，如 focus)
        inserted(el, binding) { 
            el.focus(); 
        },
        
        // 3. 模板重新解析时 (同步数据)
        update(el, binding) { ... }
    }
}
```

---

### 4. 核心参数详解

回调函数通常接收两个参数：`fn(el, binding)`

- **`el`**：指令所绑定的**真实 DOM 元素** (可以直接 `el.style...`)。
    
- **`binding`**：一个对象，包含指令的详细信息。
    
    - **`binding.value`**：**最常用**。指令绑定的值 (例如 `v-big="1+1"`，值就是 `2`)。
        

---

### 5. 避坑指南 (必背) ⚠️

1. **`this` 指向问题**：
    
    - 自定义指令函数里的 `this` 指向 **`Window`**，**不是** `vm` 实例。
        
2. **`focus()` 失效问题**：
    
    - `el.focus()` **不能**写在 `bind` 钩子中（因为此时元素还在内存，没上页面）。
        
    - **必须**写在 **`inserted`** 钩子中。
        
3. **命名规范**：
    
    - 建议使用 **kebab-case** (短横线)。
        
    - 如定义 `bigNumber`，使用时要写 `<span v-big-number="...">`。
