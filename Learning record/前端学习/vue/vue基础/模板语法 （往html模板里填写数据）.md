
# 📝 Vue 模板语法核心总结

### 1. 两大语法分类

Vue 的模板语法主要分为两类，根据**位置**决定使用哪一种：

#### A. 插值语法 (Mustache Syntax)

- **符号**：`{{ }}` (双大括号)
    
- **位置**：**标签体内容** (即 `>` 和 `<` 中间)。
    
- **作用**：像填空一样，把数据显示在网页文本中。
    
- **示例**：
    
    HTML
    
    ```
    <h1>Hello, {{ name }}</h1>
    ```
    

#### B. 指令语法 (Directives)

- **符号**：`v-bind:` (可简写为 **`:`**)
    
- **位置**：**标签属性** (即 `<div ... >` 标签头内部)。
    
- **作用**：动态控制标签的属性（如链接、图片路径、样式等）。
    
- **示例**：
    
    HTML
    
    ```
    <a v-bind:href="url">链接</a>
    
    <a :href="url">链接</a>
    ```
    

---

### 2. 核心原理：v-bind 的“魔法”

你刚才总结得非常到位，这是理解 Vue 的关键：

- **普通写法** (`name="val"`): 浏览器把引号里的内容看作**普通字符串**。
    
- **Vue 绑定** (`:name="val"`): 冒号告诉 Vue，**“把引号打开，把里面的内容当成 JS 表达式去执行”**。
    

**对比表：**

|**代码写法**|**引号内容的身份**|**最终结果 (假设 data 中 x='hello')**|
|---|---|---|
|`<div title="x">`|**纯文本字符串**|title 属性值为 "x"|
|`<div :title="x">`|**JS 变量**|title 属性值为 "hello" (去 data 找)|
|`<div :title="'x'">`|**JS 字符串字面量**|title 属性值为 "x" (JS 里带引号的是字符串)|
|`<div :title="1+1">`|**JS 运算**|title 属性值为 "2"|

---

### 3. 什么是 "JS 表达式"?

在 `{{ }}` 和 `:属性=""` 中，你都可以写 **JS 表达式**。

- **✅ 可以写：** (产生一个值的式子)
    
    - 变量名：`name`
        
    - 算术运算：`1 + 1`
        
    - 字符串拼接：`'No.' + id`
        
    - 三元运算：`age > 18 ? '成年' : '未成年'`
        
    - 方法调用：`name.toUpperCase()`
        
- **❌ 不能写：** (语句/控制流)
    
    - `if (a) { ... }`
        
    - `var a = 1` (这是声明语句，不是表达式)
