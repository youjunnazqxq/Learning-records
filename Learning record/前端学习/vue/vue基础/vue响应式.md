### 📝 Vue 核心概念笔记：响应式 (Reactivity)

#### 1. 核心定义

**响应式**是指：当 JavaScript 中的**数据 (Data)** 发生变化时，Vue 会自动检测到，并立即更新对应的**视图 (DOM/页面)**，无需人工干预。

> **公式：** `数据变动` $\Rightarrow$ `Vue 自动感应` $\Rightarrow$ `页面刷新`

#### 2. 两种模式对比

| **维度**   | **传统模式 (原生 JS/jQuery)** | **Vue 响应式模式**         |
| -------- | ----------------------- | --------------------- |
| **编程范式** | **命令式 (Imperative)**    | **声明式 (Declarative)** |
| **操作对象** | 直接操作 **DOM** 节点         | 仅操作 **数据 (Data)**     |
| **更新方式** | 手动监听变化，手动修改 `innerHTML` | 数据变了，视图**自动**同步       |
| **关注点**  | "怎么一步步去改界面"             | "界面应该显示什么状态"          |
