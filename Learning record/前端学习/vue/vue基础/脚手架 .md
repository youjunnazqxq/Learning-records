

## 🏗️ 编程术语：脚手架 (Scaffold)

### 1. 核心定义

**脚手架**是一个**项目初始化工具**。它能通过简单的命令，自动帮你生成一个项目的**基础结构**和**预设配置**。

### 2. 为什么叫“脚手架”？（形象记忆）

- **来源**：借用建筑术语。
    
- **含义**：就像盖楼前必须先搭架子让工人站上去一样，代码脚手架提供了**开发的“施工平台”**。
    
- **关系**：它不是最终的产品（房子），而是为了让你能高效开发（盖房子）而必须存在的**基础设施**。
    

### 3. 脚手架的三大作用

它帮你省去了“从零开始”的痛苦，直接完成以下工作：

- 📂 搭建骨架（目录结构）
    
    自动生成标准的文件夹结构（如 src, components, assets, main.js），大家不用纠结文件放哪。
    
- ⚙️ 配置环境（底层设施）
    
    自动配好 Vite/Webpack（打包）、Babel（转译）、本地服务器。让浏览器能直接运行 Vue 代码。
    
- 📦 安装依赖（全家桶）
    
    一键装好 Vue、Router、Pinia 等核心库，不用一个个去 npm install。
    

### 4. 总结一句话

**脚手架就是给你一套通了水电、砌好墙的“毛坯房”，你不需要关心怎么打地基，只需要专注于“搞装修”（写业务代码）。**

### 5. 常见例子

- **Vue 官方**：`create-vue` (基于 Vite，目前主流)
    
- **React 官方**：`create-react-app`
