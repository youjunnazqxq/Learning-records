
# 📝 Vue 2 数据代理核心总结

### 1. 什么是数据代理？

**定义**：通过一个对象（代理者）来代理对另一个对象（被代理者）中属性的操作（读/写）。

- **在 Vue 中**：通过 Vue 实例对象 (`vm`)，来直接代理 `data` 对象中属性的操作。
    
- **简单来说**：本来数据藏在 `_data` 里，Vue 帮你把它搬到了 `vm` 的第一层，让你能直接用。
    

### 2. 为什么要代理？

**目的**：为了**简化代码**，提升开发体验。

- **没有代理时**：你必须写 `this._data.name` 才能访问数据。
    
- **有代理时**：你可以直接写 `this.name`。
    

### 3. 基本原理 (底层机制)

Vue 在初始化时，利用 **`Object.defineProperty()`** 方法完成了这项工作。

**核心流程四步走**：

1. **加工**：Vue 将你配置的 `data` 对象进行响应式处理，并保存到 `vm._data` 中（此时 `_data` 才是数据的真身）。
    
2. **遍历**：Vue 遍历 `_data` 中的所有属性名（如 `name`, `age`）。
    
3. **定义**：使用 `Object.defineProperty` 把这些属性名一个个添加到 `vm` 身上。
    
4. **关联**：
    
    - 配置 **`get()`**：当你读取 `vm.name` 时，它去 `vm._data.name` 里读给你。
        
    - 配置 **`set()`**：当你修改 `vm.name` 时，它把值写入 `vm._data.name`。
        

### 4. 结构关系图 (脑海模型)

代码段

```
graph LR
    User[用户代码]
    VM[Vue实例 (vm)]
    Data[真实数据 (vm._data)]

    User -- 1. 访问 vm.name --> VM
    VM -- 2. getter (代理转发) --> Data
    
    User -- 3. 修改 vm.name = '新值' --> VM
    VM -- 4. setter (代理转发) --> Data
```

### 5. 关键代码对比

|**操作**|**代码写法**|**实际访问的位置**|**备注**|
|---|---|---|---|
|**定义数据**|`data: { name: 'Jack' }`|`vm._data.name`|`data` 被转存为 `_data`|
|**访问数据**|`console.log(vm.name)`|`vm._data.name`|通过 getter 转发|
|**修改数据**|`vm.name = 'Tom'`|`vm._data.name`|通过 setter 转发|

---

### 💡 一句话总结

> **Vue 数据代理就是利用 `Object.defineProperty` 给 `vm` 装了一组“遥控器”（Getter/Setter），让你操作 `vm.属性` 时，实际上是在操作 `vm._data.属性`。**
