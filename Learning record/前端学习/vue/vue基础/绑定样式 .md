# 🎨 Vue 样式绑定核心笔记

### 1. 核心作用

利用 **`v-bind`** (简写 **`:`**) 将 HTML 元素的样式与 Vue 的 `data` 数据绑定。

- **公式**：**数据改变 $\Rightarrow$ 样式自动刷新**。
    

---

### 2. 绑定 Class 样式 (`:class`) 🌟重点

|**写法**|**语法示例**|**适用场景**|**核心逻辑**|
|---|---|---|---|
|**字符串写法**|`:class="mood"`|**类名不确定**|"今天穿哪件衣服，看心情（数据）"|
|**对象写法**|**`:class="{ active: isSelect }"`**|**类名确定，但要控制开关**|**(最常用)**<br><br>  <br><br>"这件衣服穿不穿，看开关（布尔值）"|
|**数组写法**|`:class="[styleA, styleB]"`|**同时用好几个样式**|"我要穿这件，也要穿那件（批量）"|

> 🔥 最佳实践：
> 
> 90% 的场景都会用对象写法。例如点击高亮、错误提示红框等，都是通过 { '类名': boolean } 来控制的。

---

### 3. 绑定 Style 样式 (`:style`)

用于精确控制某个 CSS 属性的值（如动态计算宽度、颜色）。

- **语法**：对象形式 `{ key: value }`
    
- **注意**：CSS 属性名要转为 **小驼峰命名 (camelCase)**。
    
    - `font-size` $\rightarrow$ `fontSize`
        
    - `background-color` $\rightarrow$ `backgroundColor`
        

**代码示例：**

HTML

```
<div :style="{ fontSize: size + 'px', color: 'red' }"></div>
```

---

### 🧠 极简记忆口诀

> 样式要想动，冒号来帮弄。
> 
> 类名不确定，字符串最硬。
> 
> 批量加载多，数组来组合。
> 
> 开关控有无，对象最舒服 (最常用)。
> 
> 内联用 Style，驼峰要记住。
