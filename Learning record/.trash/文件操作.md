
### 核心用法总结：

1. **表示文件和目录**:
    
    - 在Java中，无论是文件还是目录，都使用 `File` 对象来表示。
        
    - **示例**: `File f = new File("文件名.txt");` 或 `File d = new File("目录名");`
        
2. **创建引用 vs. 实际创建**:
    
    - 执行 `new File(...)` 仅仅是在内存中创建了一个指向特定路径的 `File` 对象（一个引用），并**不会**在硬盘上真正创建出文件或目录。
        
3. **实际创建文件和目录**:
    
    - **创建文件**: 需要在 `File` 对象上调用 `.createNewFile()` 方法。
        
        - `f.createNewFile();`
            
    - **创建目录**: 需要在 `File` 对象上调用 `.mkdir()` 方法。
        
        - `d.mkdir();`
            
4. **简化文件写入 (核心建议)**:
    
    - 标准的Java文件内容写入操作比较繁琐。
        
    - 为了简化，文档提供了一个 **`Utils.java`** 辅助类。
        
    - **强烈建议**在当前项目（如 "Gitlet" 实验）中使用这个类来操作文件。
        
    - **示例**: 使用 `Utils.writeContents()` 方法可以轻松地将字符串写入文件。
        
        - `Utils.writeContents(f, "Hello World");`
            

### 总而言之：

您应该首先用 `new File("...")` 来定义一个文件或目录的路径，然后根据需要调用 `.createNewFile()` 或 `.mkdir()` 来在硬盘上创建它。对于读写文件内容等更复杂的操作，则应该直接使用提供的 `Utils.java` 类中的便捷方法。
