好的，我们来把整个流程和语法总结一下。创建一个文件夹总共分三步：

### **第一步：确定起点 —— 当前工作目录 (CWD)**

所有相对路径都从这里开始。Java程序在运行时自动知道这个位置。

- **语法 (可选, 用于获取路径字符串):**
    
    Java
    
    ```
    String cwdPath = System.getProperty("user.dir");
    ```
    

### **第二步：规划路径 —— 创建`File`对象**

使用`new File()`或`Utils.join()`来创建一个代表你想要文件夹路径的`File`对象。这只是在内存里创建了一个“地址”，还没有实际创建文件夹。

- **语法:**
    
    Java
    
    ```
    // 创建一个代表 .capers 目录的File对象
    File capersDir = new File(".capers");
    
    // 使用Utils.join来创建一个代表 .capers/dogs 目录的File对象
    File dogsDir = Utils.join(capersDir, "dogs");
    ```
    

### **第三步：开始施工 —— 调用`mkdirs()`**

对第二步创建的`File`对象调用`.mkdirs()`方法，Java就会根据这个“地址”在硬盘上真正地创建出文件夹。

- **语法:**
    

// 在CWD下创建 .capers 文件夹

capersDir.mkdirs();
