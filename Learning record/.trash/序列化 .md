
### 实例操作流程

#### 步骤 1: 让 `Dog` 对象可以被序列化

这是首要前提。为了让Java虚拟机知道

`Dog` 类的对象可以被转换成字节流，`Dog.java` 文件中的类必须声明实现 `Serializable` 接口 3333。

**具体代码 (`Dog.java`):**

Java

```
import java.io.Serializable;

// 通过 "implements Serializable" 标记该类的对象是可序列化的 [cite: 493, 679]
public class Dog implements Serializable {
    private String name;
    private String breed;
    private int age;

    // ... 构造函数和其他方法 ...
}
```

#### 步骤 2: 保存（序列化）一个 `Dog` 对象

这对应于

`dog [name] [breed] [age]` 命令的实现 4。当用户输入此命令时，程序会创建一个新的

`Dog` 对象，并将其序列化后存入文件。

操作场景:

用户在命令行执行：java capers.Main dog Fido Poodle 5

**背后发生的具体代码操作**:

1. **创建 `Dog` 对象**：程序内部根据命令行的参数创建一个 `Dog` 实例。
    
2. **确定保存路径**：程序会为这只名叫 "Fido" 的狗创建一个专门的文件。根据文档建议，这个文件应该存放在 `.capers/dogs/` 目录下 5555。可以使用
    
    `Utils.join` 来安全地构建文件路径 6。
    
3. **调用辅助函数进行序列化**：程序调用 `Utils.writeObject` 方法，将 `Dog` 对象写入指定的文件 7。这个辅助函数处理了所有复杂的字节流转换和文件I/O操作 8。
    

**具体代码 (`Dog.java` 中的 `saveDog` 方法):**

Java

```
import java.io.File;

public class Dog implements Serializable {
    // ... 字段和构造函数 ...

    /**
     * 将当前的 Dog 对象序列化并保存到文件。
     */
    public void saveDog() {
        // DOG_FOLDER 是一个指向 ".capers/dogs/" 目录的File对象 [cite: 663]
        File dogFile = Utils.join(DOG_FOLDER, this.name); // 使用狗的名字作为文件名 
        
        // 调用辅助函数，将 'this' (当前的Dog对象) 写入到 dogFile 文件中 [cite: 1049]
        Utils.writeObject(dogFile, this); [cite: 654]
    }
}
```

当

`makeDog` 方法被调用时，它会创建 `Dog` 对象并调用 `saveDog()` 9。

#### 步骤 3: 读取（反序列化）一个 `Dog` 对象

这对应于

`birthday [name]` 命令的实现 10。为了给一只狗增加年龄，程序必须首先从文件中将这只狗的信息读取（反序列化）出来，变回一个

`Dog` 对象。

操作场景:

用户在命令行执行：java capers.Main birthday Fido

**背后发生的具体代码操作**:

1. **确定文件路径**：程序根据狗的名字 "Fido" 定位到之前保存它的文件，即 `.capers/dogs/Fido`。
    
2. **调用辅助函数进行反序列化**：程序调用 `Utils.readObject` 方法，从文件中读取字节，并将其转换回一个 `Dog` 对象 11。你需要告诉这个方法期望恢复的对象类型是
    
    `Dog.class` 12。
    
3. **修改对象状态**：对象恢复后，程序就可以像操作普通Java对象一样修改它的年龄。
    
4. **重新保存（序列化）**：为了让年龄的增长被持久化，修改后的 `Dog` 对象必须再次被序列化并覆盖写回原文件 13。
    

**具体代码 (`Dog.java` 中的 `fromFile` 和 `CapersRepository.java` 中的 `celebrateBirthday`):**

Java

```
// 在 Dog.java 中
public static Dog fromFile(String name) {
    File dogFile = Utils.join(DOG_FOLDER, name);

    // 从 dogFile 文件中读取数据，并将其反序列化为一个 Dog.class 类型的对象 [cite: 655, 1051]
    return Utils.readObject(dogFile, Dog.class);
}

// 在 CapersRepository.java 中
public static void celebrateBirthday(String name) {
    // 1. 反序列化：从文件中读取并恢复 Dog 对象
    Dog dogToCelebrate = Dog.fromFile(name); [cite: 681]

    // 2. 修改对象状态
    dogToCelebrate.haveBirthday(); // 假设这个方法会让 age++

    // 3. 重新序列化：将更新后的对象保存回文件，实现持久化 
    dogToCelebrate.saveDog();

    System.out.println("Happy birthday! Woof! Woof!"); [cite: 601]
}
```

通过以上步骤，`Dog` 对象的状态（名字、品种、年龄）得以在程序的多次运行之间保持不变，这就是序列化的实际应用。
