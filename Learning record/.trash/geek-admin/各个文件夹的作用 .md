
### 1. 核心开发区 (你每天都要打交道的地方)

这是你写业务代码最频繁接触的 4 个文件夹：

- **`src/views` (页面视图)**
    
    - **作用**：存放所有的**页面文件**。比如“用户管理”、“菜单管理”的具体 `.vue` 文件都在这里。
        
    - **注意**：通常一个文件夹代表一个功能模块（例如 `system/user/index.vue`）。
        
- **`src/api` (接口请求)**
    
    - **作用**：统一管理后端接口。
        
    - **为什么重要**：不要在 `.vue` 文件里直接写 `axios.get(...)`。这里的做法通常是定义一个函数，比如 `export const getUserList = (params) => http.post(...)`，然后在页面中调用这个函数。
        
- **`src/routers` (路由配置)**
    
    - **作用**：配置页面跳转路径。
        
    - **重点**：这里面通常包含“静态路由”（如登录页、404页）和“动态路由”（从后端获取菜单权限后生成的路由）。
        
- **`src/stores` (状态管理)**
    
    - **作用**：基于 **Pinia** 的状态管理。
        
    - **内容**：存放全局共享的数据，比如 `user.ts` (用户信息)、`auth.ts` (权限/Token)、`global.ts` (全局主题配置)。
        

---

### 2. 公共资源与UI区 (决定项目长什么样)

- **`src/components` (全局组件)**
    
    - **作用**：存放通用的、可在多个页面复用的组件。
        
    - **核心**：这里面肯定有 `ProTable` (超级表格)、`SvgIcon` (图标组件) 等。
        
- **`src/layouts` (布局容器)**
    
    - **作用**：管理系统的“外壳”。
        
    - **内容**：包括侧边栏 (Menu)、头部 (Header)、标签栏 (Tabs) 以及主要内容区域 (Main) 的布局结构。
        
- **`src/assets` (静态资源)**
    
    - **作用**：存放图片、字体、CSS 中引用的本地资源。
        
- **`src/styles` (全局样式)**
    
    - **作用**：存放全局的 `.scss` 或 `.css` 文件，比如重置浏览器默认样式 (`reset.scss`) 或定义全局变量。
        

---

### 3. 配置与工具区 (提升效率与规范)

- **`src/utils` (工具函数)**
    
    - **作用**：存放通用的 JS/TS 函数。
        
    - **重点**：**`http` (Axios 封装)** 就在这里，还有日期格式化、数据校验等工具函数。
        
- **`src/hooks` (组合式函数)**
    
    - **作用**：Vue3 的核心特性。存放提取出来的复用逻辑（Composables），比如 `useHandleData` (通用的增删改查逻辑)。
        
- **`src/types` 或 `src/typings` (类型定义)**
    
    - **作用**：**TypeScript** 的声明文件。定义全局通用的接口（Interface）和类型（Type），比如“接口返回数据的通用格式”。
        
- **`src/directives` (自定义指令)**
    
    - **作用**：存放 Vue 自定义指令。比如 `v-auth="['add']"` (控制按钮权限) 的逻辑就在这里实现。
        
- **`src/enums` (枚举)**
    
    - **作用**：定义常量字典。比如 HTTP 状态码（200, 401, 500）通常会定义在这里，避免代码里出现“魔术数字”。
        
- **`src/config` (全局配置)**
    
    - **作用**：项目的全局配置项，比如网站标题、默认语言、API 的超时时间等。
        

---

### 4. 根目录其他文件

- **`.husky`**：Git 提交规范工具（确保你 commit 的时候代码格式是正确的）。
    
- **`build`**：Vite 的打包构建配置或插件配置。
    
- **`public`**：不需要构建工具处理的纯静态资源（如 `favicon.ico`）。
