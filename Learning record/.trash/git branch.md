好的，我们来聊聊 `git branch` 这个命令。

`git branch` 是一个用于**管理分支**的命令。分支是 Git 中一个极其重要的概念，而 `git branch` 就是你用来查看、创建和删除这些分支的工具。

您可以把分支想象成书里的**书签**。主分支 `main` 是你正在读的主线故事，而 `git branch` 可以让你在书的任何一页（任何一次提交）上夹一个新的书签，然后从那里开始阅读或写下新的旁注，而不影响主线故事。

---

`git branch` 命令有几种核心用法，取决于你是否给它提供了参数：

### 1. 查看分支 (Listing Branches)

当你**不带任何参数**，只输入 `git branch` 时，它的作用是**列出你本地仓库中所有的分支**。

Bash

```
git branch
```

执行后，你会看到一个列表，并且当前你所在的分支前面会有一个 `*` 号标记。

**输出示例：**

```
  feature/login
* main
  hotfix/bug-123
```

这个结果告诉你：

- 你的项目有三个本地分支。
    
- 你当前正处于 `main` 分支上。
    

---

### 2. 创建分支 (Creating a Branch)

当你提供一个**分支名**作为参数时，`git branch` 会**在当前所在的提交位置创建一个新的分支**。

Bash

```
git branch new-feature
```

**重要提示**：这个命令**只创建**了一个新的分支（就像在书里夹了个新书签），但它**并不会**自动把你切换到那个新分支上。你仍然停留在当前的分支。创建之后，你还需要使用 `git checkout new-feature` 或 `git switch new-feature` 来切换过去。

---

### 3. 删除分支 (Deleting a Branch)

当你使用 `-d` (delete) 或 `-D` 参数时，`git branch` 可以用来**删除一个不再需要的分支**。

- **安全删除 (`-d`)**：
    
    Bash
    
    ````
    git branch -d hotfix/bug-123
    ```-d` 是一个“安全”的删除选项。如果 `hotfix/bug-123` 分支上的修改**还没有被合并**到其他分支，Git 会阻止你删除它，以防你丢失工作成果。
    
    ````
    
- **强制删除 (`-D`)**：
    
    Bash
    
    ````
    git branch -D old-feature
    ```-D` 是一个“强制”的删除选项。无论这个分支有没有被合并，它都会被**强制删除**。这在你确定某个分支上的所有工作都不再需要时使用。
    
    ````
    

---

### 其他常用选项

- **`git branch -a`**：列出**所有**的分支，包括本地分支和远程跟踪分支（那些以 `remotes/origin/` 开头的分支）。
    
- **`git branch -m <新名字>`**：重命名当前分支。
    

### 总结

|命令|作用|
|---|---|
|`git branch`|列出本地所有分支，并标记出当前分支|
|`git branch <分支名>`|创建一个新分支|
|`git branch -d <分支名>`|安全地删除一个已合并的分支|
|`git branch -D <分支名>`|强制删除一个分支|
|`git checkout -b <分支名>`|**创建并立即切换**到新分支（常用快捷方式）|
