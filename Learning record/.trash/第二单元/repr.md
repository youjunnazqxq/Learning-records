在 Python 中，方法名（或属性名）前后各加两个下划线 `__`（例如 `__init__`、`__repr__`、`__str__`）表示这是一个特殊的方法或属性。这些通常被称为**魔术方法 (magic methods)** 或 **双下划线方法 (dunder methods)**（dunder 是 "double underscore" 的缩写）。

它们之所以特殊，主要有以下几个原因：

1. 由 Python 解释器在特定情况下自动调用：
    
    你通常不会直接显式地调用这些方法。相反，Python 解释器会在特定的语法结构或内置函数被使用时自动调用它们。
    
    - 例如，当你写 `obj = MyClass()` 来创建一个对象时，Python 会自动调用 `MyClass` 类中定义的 `__init__(self, ...)` 方法来初始化这个新创建的对象 `obj`。
    - 当你使用 `print(obj)` 或 `str(obj)` 时，Python 会自动调用 `obj` 对象的 `__str__()` 方法。如果 `__str__()` 未定义，则会尝试调用 `__repr__()`。
    - 当你使用 `repr(obj)` 或在交互式解释器中直接输入对象名并回车时，Python 会调用 `obj` 对象的 `__repr__()` 方法。
2. 实现 Python 的内置行为和协议：
    
    这些方法允许你的自定义类与 Python 的内置操作符、函数和语法结构进行交互，就像内置类型（如列表、字典、字符串）一样。通过实现这些魔术方法，你可以：
    
    - 控制对象的创建和初始化 (`__new__`, `__init__`)
    - 控制对象的字符串表示 (`__str__`, `__repr__`)
    - 使对象可以像函数一样被调用 (`__call__`)
    - 使对象支持迭代 (`__iter__`, `__next__`)
    - 使对象支持索引和切片 (`__getitem__`, `__setitem__`, `__delitem__`)
    - 使对象支持算术运算 (`__add__`, `__sub__`, `__mul__`, 等)
    - 控制属性访问 (`__getattr__`, `__setattr__`, `__delattr__`)
    - 等等。
3. 命名约定，避免与用户自定义方法冲突：
    
    使用双下划线作为前缀和后缀是一种命名约定，用来表示这些方法具有特殊的含义，并且是由 Python 语言本身定义的。这有助于避免用户在自己的类中定义的方法名与这些特殊用途的方法名发生冲突。
    

在图片中的 `Link` 类中：

- `__init__(self, first, rest=empty)`: 是构造函数，在创建 `Link` 对象时自动调用，用于初始化对象的 `first` 和 `rest` 属性。
- `__repr__(self)`: 定义了当调用 `repr(link_obj)` 时对象的“官方”字符串表示形式，通常用于调试。
- `__str__(self)`: 定义了当调用 `str(link_obj)` 或 `print(link_obj)` 时对象的“非正式”或用户友好的字符串表示形式。

简而言之，前后加双下划线 `__` 是 Python 用来标识这些方法具有特殊意义并会被解释器在特定情境下自动调用的方式，使得自定义对象能够更好地融入 Python 语言的生态。
