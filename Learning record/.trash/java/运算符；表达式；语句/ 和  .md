| **运算符**   | **名字**    | **规则 (最关键的区别)**                         | **数学意义**                             | **记忆口诀**    |
| --------- | --------- | --------------------------------------- | ------------------------------------ | ----------- |
| **`<<`**  | **左移**    | 右边补 0                                   | **乘以 2 的 n 次方**                      | 变大          |
| **`>>`**  | **带符号右移** | **看人下菜碟**：<br><br>  <br><br>正数补 0，负数补 1 | **除以 2 的 n 次方**                      | 变小 (保持正负)   |
| **`>>>`** | **无符号右移** | **六亲不认**：<br><br>  <br><br>统统补 0        | (通常用于逻辑处理，<br><br>  <br><br>不用于数学计算) | 变正 (负数变大正数) |
