在 Java 中，创建（初始化）数组主要有 **3 种** 常见方法。我们将它们分为“动态初始化”和“静态初始化”。

### 1. 动态初始化（指定长度）

只指定数组的**长度**，由系统为数组分配初始值（默认值）。

- **语法：** `数据类型[] 数组名 = new 数据类型[长度];`
    
- **特点：** 也就是你刚才题目中 `new int[8]` 的方式。数组里全是默认值（int是0，boolean是false，对象是null）。
    
- **示例：**
    
    Java
    
    ```
    // 创建一个能存 5 个整数的数组
    int[] arr = new int[5]; 
    
    // 此时 arr[0] 到 arr[4] 的值都是 0
    ```
    

### 2. 静态初始化（标准格式）

在创建数组时，直接指定数组中每个元素的**具体值**，由系统自动计算长度。

- **语法：** `数据类型[] 数组名 = new 数据类型[]{值1, 值2, ...};`
    
- **特点：** 注意 `[]` 中**不能**写长度，Java 会根据后面的元素个数自动推算。
    
- **示例：**
    
    Java
    
    ```
    // 创建一个包含 1, 2, 3 的数组
    int[] arr = new int[]{1, 2, 3};
    
    // 长度自动为 3
    ```
    

### 3. 静态初始化（简化格式 / 语法糖）

这是最常用的写法，它是标准格式的简写。

- **语法：** `数据类型[] 数组名 = {值1, 值2, ...};`
    
- **特点：** 省略了 `new 数据类型[]`，写起来最快。也就是你刚才题目中 `{1, 2, ...}` 的方式。
    
- **示例：**
    
    Java
    
    ```
    int[] arr = {1, 2, 3};
    ```
    

---

### ⚠️ 重点注意事项（考试常考陷阱）

虽然第 2 种和第 3 种看起来一样，但它们有一个巨大的区别：**能否拆分写**。

1. **动态初始化** 和 **标准静态初始化** 可以先声明，后赋值（拆成两行）：
    
    Java
    
    ```
    int[] a;
    a = new int[5];      // ✅ 正确
    
    int[] b;
    b = new int[]{1,2};  // ✅ 正确
    ```
    
2. **简化静态初始化** **必须写在同一行**，不能拆分：
    
    Java
    
    ```
    int[] c;
    c = {1, 2, 3};       // ❌ 报错！Java 不知道 {} 是什么类型
    ```
    

总结：

如果你一开始就知道数组里要存什么数，用 方法 3（简化静态）。

如果你只知道数组要多大，但还不知道具体存什么，用 方法 1（动态）。
