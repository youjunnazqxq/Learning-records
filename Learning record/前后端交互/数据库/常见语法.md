学习 SQL 最快的方法是把它理解为一种指令式的语言。数据库的核心逻辑就是对数据进行 **CRUD**（增删改查）。

这是一份为你整理的最常见 SQL 关键字清单，你可以直接保存为 Markdown 笔记：

### 1. 数据查询 (Read) —— 使用频率最高

- **`SELECT`** (挑选): 决定你要拿取哪些**列**（字段）的数据。
    
    - _JS 类比_: `array.map()`，只提取你想要的属性。
        
    - _示例_: `SELECT recipient_name, recipient_phone ...` （也可以用 `SELECT *` 代表选取所有列）。
        
- **`FROM`** (来自): 指定你要去哪张**表**里找数据。
    
    - _示例_: `... FROM package`
        
- **`WHERE`** (条件): 对数据进行过滤，只留下满足条件的**行**。
    
    - _JS 类比_: `array.filter()`。
        
    - _示例_: `... WHERE status = 0`
        
- **`ORDER BY`** (排序): 根据某个字段对结果进行升序 (`ASC`，默认) 或降序 (`DESC`) 排列。
    
    - _JS 类比_: `array.sort()`。
        
    - _示例_: `... ORDER BY in_time DESC` （按入库时间从新到旧排）。
        
- **`LIMIT`** (限制): 限制返回的数据条数，通常用于前端页面的**分页**。
    
    - _JS 类比_: `array.slice()`。
        
    - _示例_: `... LIMIT 10` （只取前10条）。
        

### 2. 数据操作 (Create, Update, Delete) —— 改变表里的业务数据

- **`INSERT INTO ... VALUES`** (新增): 向表中插入一行全新的数据。
    
    - _JS 类比_: `array.push()`。
        
    - _示例_: `INSERT INTO package (tracking_number, recipient_name) VALUES ('YT123456', '张三');`
        
- **`UPDATE ... SET ... WHERE`** (修改): 更新表里已有的数据。**极其重要：绝大多数情况下必须加 WHERE 条件，否则会把整张表的数据全改了！**
    
    - _示例_: `UPDATE package SET status = 1 WHERE tracking_number = 'YT123456';` （把单号为 YT123456 的包裹状态改为 1）。
        
- **`DELETE FROM ... WHERE`** (删除): 删除整行数据。**同样必须加 WHERE！**
    
    - _示例_: `DELETE FROM package WHERE status = 2;` （把所有异常滞留的包裹记录删掉）。
        

### 3. 数据定义 (DDL) —— 改变数据库本身的设计

（这些是你刚才在实验里用过的）

- **`CREATE`** (创建): 用于创建数据库对象，比如表 (`TABLE`)、视图 (`VIEW`)、索引 (`INDEX`)。
    
- **`DROP`** (销毁): 直接把表或视图整个抹除，数据也会跟着消失（危险操作）。
    
- **`ALTER`** (修改结构): 修改表的设计结构，比如临时决定给 `package` 表增加一个“快递重量”的字段，就需要用它。
    

结合你的快递后台系统来看：前端点“添加包裹”对应 `INSERT`；点“确认取件”对应 `UPDATE`；点开“待取件列表”对应 `SELECT ... WHERE status = 0`。
