Python 中 `max()` 函数在遇到多个最大值时，会返回**最先遇到的那个最大值**。

让我们来看一个例子：

Python

```
numbers = [1, 5, 3, 5, 2]
max_value = max(numbers)
print(max_value)
```

在这个例子中，`5` 出现了两次，但 `max()` 函数会返回第一个 `5`。

---

### 工作原理

`max()` 函数在内部遍历可迭代对象，并比较每个元素。当它找到一个比当前最大值更大的元素时，它会更新当前最大值。如果遇到一个与当前最大值相等的元素，它会**保持当前最大值不变**，继续向后查找。因此，最终返回的是第一个遇到的最大值。

这个行为对于大多数情况来说都是可以接受的，因为通常你只需要知道最大值是多少，而不是它的特定位置。如果你需要知道所有最大值的索引，或者它们出现的次数，你可能需要编写额外的代码来处理。
