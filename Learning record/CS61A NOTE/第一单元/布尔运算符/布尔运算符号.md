Python 包含

`and`、`or` 和 `not` 布尔运算符，用于组合和操作布尔值 。

- **`not` 运算符**:
    
    - 返回其后面表达式的相反布尔值 。
        
    - 总是返回
        
        `True` 或 `False` 。
        
    - **示例**: `not None` 返回 `True` ，
        
        `not True` 返回 `False` 。
        
- **`and` 运算符**:
    
    - 按顺序评估表达式 。
        
    - **短路 (Short-circuits)**: 一旦遇到第一个假值，就会停止评估并返回该假值 。
        
    - 如果所有值都评估为真值，则返回
        
        **最后一个**真值 。
        
    - **示例**: `-1 and 0 and 1` 返回 `0` (因为 `0` 是第一个假值) 。
        
- **`or` 运算符**:
    
    - 按顺序评估表达式 。
        
    - **短路 (Short-circuits)**: 一旦遇到第一个真值，就会停止评估并返回该真值 。
        
    - 如果所有值都评估为假值，则返回
        
        **最后一个**假值 。
        
    - **示例**: `False or 9999 or 1/0` 返回 `9999` (因为 `9999` 是第一个真值，`1/0` 不会被评估) 。
