## `iter()` 函数

### 作用 (Purpose)

`iter()` 函数的主要作用是**从一个可迭代对象（Iterable）中获取一个迭代器（Iterator）**。

在 Python 中，很多数据类型（如列表、元组、字符串、字典、集合等）都是可迭代的，这意味着你可以用 `for` 循环遍历它们。但这些对象本身并不是迭代器，它们不能直接被 `next()` 函数调用。`iter()` 函数就是连接可迭代对象和迭代器之间的桥梁。

### 语法 (Syntax)

`iter(object, sentinel=None)`

- `object`: 必需参数，任何可迭代对象（例如列表、字符串、文件对象等），或者一个实现了 `__call__` 方法的“可调用”对象（Callables）。
    
- `sentinel`: 可选参数，一个特殊的标记值。这个参数只在 `object` 是一个“可调用”对象时才有意义。
    

### 行为与原理

1. **当 `object` 是一个可迭代对象时（最常见用法）：**
    
    - `iter(object)` 会调用 `object` 的 `__iter__()` 方法（如果存在）。
        
    - 如果 `__iter__()` 方法不存在，它会尝试调用 `object` 的 `__getitem__()` 方法，并传入从 0 开始递增的索引，直到引发 `IndexError`。
        
    - 它返回一个**迭代器对象**。这个迭代器对象实现了 `__next__()` 方法，可以用于逐个获取 `object` 中的元素。
        
2. **当 `object` 是一个可调用对象（Callable）且提供了 `sentinel` 参数时：**
    
    - `iter(callable, sentinel)` 会创建一个迭代器，这个迭代器会反复调用 `callable`，每次调用都返回 `callable` 的结果。
        
    - 当 `callable` 返回的值等于 `sentinel` 时，迭代器会停止，并引发 `StopIteration` 异常。
        
    - 这种用法常用于读取文件或处理流数据，直到遇到某个特定标记。
        

### 示例

**常见用法（从可迭代对象获取迭代器）：**

Python

```
my_list = [10, 20, 30]
list_iterator = iter(my_list)

print(type(my_list))        # <class 'list'>
print(type(list_iterator))  # <class 'list_iterator'>

my_string = "hello"
string_iterator = iter(my_string)
print(type(string_iterator)) # <class 'str_iterator'>

# 文件对象本身就是迭代器
with open("my_file.txt", "w") as f:
    f.write("Line 1\nLine 2\nLine 3\n")
with open("my_file.txt", "r") as f:
    file_iterator = iter(f)
    print(type(file_iterator)) # <class '_io.TextIOWrapper'> (文件对象本身就是迭代器)
```

**特殊用法（可调用对象与 sentinel）：**

假设我们有一个函数，每次调用它都会返回一个随机数，直到返回 0。

Python

```
import random

def get_random_number():
    """返回 1-5 的随机数，有 20% 几率返回 0."""
    num = random.randint(0, 5)
    return num

# 创建一个迭代器，它会不断调用 get_random_number() 直到返回 0
random_iterator = iter(get_random_number, 0)

print("Random sequence until 0:")
for num in random_iterator:
    print(num)
# 可能的输出（每次运行不同）:
# Random sequence until 0:
# 3
# 1
# 5
# 0 (这个 0 是 sentinel，不会被打印，但会导致迭代停止)
```

## `next()` 函数

### 作用 (Purpose)

`next()` 函数的主要作用是**从一个迭代器（Iterator）中获取下一个元素**。

### 语法 (Syntax)

`next(iterator, default=None)`

- `iterator`: 必需参数，一个迭代器对象（必须实现了 `__next__()` 方法）。
    
- `default`: 可选参数。如果迭代器已经耗尽（没有更多元素），`next()` 就会返回这个 `default` 值，而不是引发 `StopIteration` 异常。
    

### 行为与原理

1. `next(iterator)` 会调用 `iterator` 对象的 `__next__()` 方法。
    
2. `__next__()` 方法会返回序列中的下一个元素。
    
3. 如果迭代器中没有更多元素可供返回，`__next__()` 方法会引发 `StopIteration` 异常。`next()` 函数会捕获这个异常并抛出，除非你提供了 `default` 参数。
    
4. 如果提供了 `default` 参数，当 `StopIteration` 发生时，`next()` 不会抛出异常，而是返回 `default` 值。
    

### 示例

Python

```
my_list = [100, 200, 300]
list_iterator = iter(my_list) # 先获取一个迭代器

print(next(list_iterator)) # 输出: 100
print(next(list_iterator)) # 输出: 200
print(next(list_iterator)) # 输出: 300

# 迭代器已经耗尽，再次调用 next() 会引发 StopIteration
try:
    print(next(list_iterator))
except StopIteration:
    print("Oops! Iterator is exhausted.") # 输出: Oops! Iterator is exhausted.

print("-" * 20)

# 使用 default 参数避免 StopIteration
another_iterator = iter([1, 2])
print(next(another_iterator, 99)) # 输出: 1
print(next(another_iterator, 99)) # 输出: 2
print(next(another_iterator, 99)) # 输出: 99 (迭代器已耗尽，返回默认值)
print(next(another_iterator, 99)) # 输出: 99 (再次返回默认值)
```

## `iter()` 和 `next()` 的关系

`iter()` 和 `next()` 函数是 Python 迭代机制的基石：

- 你首先使用 `iter()` 函数从一个**可迭代对象**那里**获取**一个迭代器。
    
- 然后，你反复使用 `next()` 函数来**请求**这个迭代器中的下一个元素。
    
- 当迭代器没有更多元素时，`next()` 函数（或底层的 `__next__()` 方法）会发出 `StopIteration` 信号，表示迭代结束。
    

Python 的 `for` 循环在后台正是利用了这两个函数来遍历可迭代对象的：

Python

```
my_numbers = [1, 2, 3]

# 等价于以下手动操作：
_iterator = iter(my_numbers) # 内部调用 iter()
while True:
    try:
        item = next(_iterator) # 内部反复调用 next()
        print(item)
    except StopIteration:      # 内部捕获 StopIteration
        break
```

理解这两个函数对于深入掌握 Python 的迭代、生成器以及编写高效代码至关重要。
