
### 字典 (Dictionaries) 的基本语法

字典是 Python 中一种无序（在 Python 3.7+ 中保持插入顺序，但概念上仍是键值映射而非序列）且可变的数据结构，用于存储键值对（key-value pairs）的集合。

#### 1. 创建字典

字典主要通过花括号 `{}` 来定义。每个键值对由一个键（key）和一个值（value）组成，键和值之间用冒号 `:` 分隔，不同的键值对之间用逗号 `,` 分隔。

**基本创建语法**:

Python

```
my_dict = {key1: value1, key2: value2, key3: value3, ...}
```

**示例**:

- **创建空字典**:
    
    Python
    
    ```
    empty_dict = {}
    print(empty_dict) # 输出: {}
    ```
    
- **创建包含数据的字典**:
    
    Python
    
    ```
    # 示例: 键是字符串，值是整数
    pokemon = {'pikachu': 25, 'dragonair': 148, 'mew': 151} [cite: 474]
    print(pokemon) # 输出: {'pikachu': 25, 'dragonair': 148, 'mew': 151}
    ```
    
- 使用 dict() 构造函数:
    
    也可以使用内置的 dict() 构造函数来创建字典，例如从键值对的元组列表中创建。
    
    Python
    
    ```
    another_dict = dict([('apple', 1), ('banana', 2)])
    print(another_dict) # 输出: {'apple': 1, 'banana': 2}
    ```
    

#### 2. 键 (Keys) 的特性

- **唯一性**: 字典的键必须是唯一的。如果为同一个键分配新值，旧值将被覆盖 1。
    
    Python
    
    ```
    my_dict = {'a': 1, 'b': 2}
    my_dict['a'] = 10 # 键 'a' 的值从 1 变为 10
    print(my_dict) # 输出: {'a': 10, 'b': 2}
    ```
    
- **不可变性 (Immutable)**: 字典的键必须是不可变的值（即可哈希的 Hashable）2222。
    
    - 常见的不可变键类型包括：数字 (integers, floats)、字符串 (strings)、元组 (tuples)。
        
    - **重要提示**: 列表 (lists) 或其他字典等**可变**类型不能作为字典的键，因为它们是不可哈希的 3。
        
        Python
        
        ```
        # 错误示例：列表作为键会引发 TypeError
        # my_dict = {['firetype', 'flying']: 146} # 导致 Error: unhashable type 
        ```
        

#### 3. 值 (Values) 的特性

- **任意类型**: 字典的值可以是任何数据类型，包括数字、字符串、列表、元组、甚至其他字典 4444。
    
- **可重复**: 字典的值可以重复。
    
    Python
    
    ```
    pokemon = {'pikachu': 25, 'dragonair': 148, 'mew': 151}
    pokemon['ditto'] = 25 # 'pikachu' 和 'ditto' 的值都是 25
    print(pokemon) # 输出: {'pikachu': 25, 'dragonair': 148, 'mew': 151, 'ditto': 25}
    ```
    

#### 4. 访问字典元素

- 使用方括号
    
    `[]` 和键来访问对应的值 5。
    
    Python
    
    ```
    pokemon = {'pikachu': 25, 'dragonair': 148, 'mew': 151} [cite: 474]
    print(pokemon['pikachu']) # 输出: 25 [cite: 475, 476]
    ```
    
- 如果访问不存在的键，会引发 `KeyError`。
    

#### 5. 添加和修改元素

- 通过赋值操作添加新的键值对，或修改现有键的值。
    
    Python
    
    ```
    pokemon = {'pikachu': 25, 'dragonair': 148} [cite: 495, 496]
    pokemon['jolteon'] = 135 # 添加新键值对 [cite: 477]
    print(pokemon) # 输出: {'jolteon': 135, 'pikachu': 25, 'dragonair': 148, 'mew': 151} (实际输出取决于Python版本和操作顺序) [cite: 478, 479]
    
    pokemon['pikachu'] = 30 # 修改现有键的值
    print(pokemon) # 示例输出: {'pikachu': 30, 'dragonair': 148, 'jolteon': 135}
    ```
    
    字典是可变的；创建后可以添加、删除和更改条目 6。
    

#### 6. 删除元素

- 使用 `del` 关键字删除键值对。
    
    Python
    
    ```
    my_dict = {'a': 1, 'b': 2, 'c': 3}
    del my_dict['b']
    print(my_dict) # 输出: {'a': 1, 'c': 3}
    ```
    

#### 7. 长度

- 使用 `len()` 函数获取字典中键值对的数量。
    
    Python
    
    ```
    pokemon = {'pikachu': 25, 'dragonair': 148} [cite: 495]
    print(len(pokemon)) # 输出: 2 [cite: 499, 500]
    ```
    

#### 8. 成员检查

- 使用 `in` 运算符检查**键**是否存在于字典中。
    
    Python
    
    ```
    pokemon = {'pikachu': 25, 'dragonair': 148} [cite: 495]
    print('mewtwo' in pokemon) # 输出: False [cite: 497, 498]
    print('pikachu' in pokemon) # 输出: True
    ```
