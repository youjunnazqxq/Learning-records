f-string (格式化字符串字面量) 是 Python 3.6 引入的一种字符串格式化方法，它提供了一种简洁且易读的方式来嵌入表达式到字符串中。

### f-string 的基本语法

f-string 的基本语法是在字符串前加上前缀字母 `f` (或 `F`)。在 f-string 内部，你可以使用花括号 `{}` 来包含表达式，这些表达式会在运行时被求值，并将其结果插入到字符串中。

Python

```
f"这是 {expression} 嵌入到字符串中的例子。"
```

- `f` 或 `F`: 放在字符串字面量前，表示这是一个 f-string。
    
- `{expression}`: 花括号内可以放置任何有效的 Python 表达式，包括变量、函数调用、算术运算等。这些表达式的值会被转换为字符串并替换掉花括号及其中的内容。
    

### f-string 的特性和应用

1. 简洁易读:
    
    f-string 的主要优点是其简洁性和可读性。你可以在字符串字面量中直接看到要插入的内容和如何格式化。
    
    Python
    
    ```
    name = "爱丽丝"
    age = 30
    print(f"你好，我的名字是 {name}，我今年 {age} 岁。")
    # 输出: 你好，我的名字是 爱丽丝，我今年 30 岁。
    ```
    
2. 嵌入任意 Python 表达式:
    
    花括号内可以是任何有效的 Python 表达式，不仅仅是变量。
    
    Python
    
    ```
    x = 10
    y = 5
    print(f"10 加 5 等于 {x + y}")
    # 输出: 10 加 5 等于 15
    
    def get_greeting():
        return "欢迎！"
    print(f"{get_greeting()} 这是 f-string 的示例。")
    # 输出: 欢迎！ 这是 f-string 的示例。
    ```
    
3. 支持格式化迷你语言:
    
    你可以在表达式后面加上一个冒号 : 来使用格式化迷你语言，控制输出的格式（例如，浮点数的精度、整数的进制、对齐方式等）。
    
    Python
    
    ```
    pi = 3.1415926
    print(f"PI 的值保留两位小数: {pi:.2f}")
    # 输出: PI 的值保留两位小数: 3.14
    
    num = 255
    print(f"255 的十六进制是: {num:x}")
    # 输出: 255 的十六进制是: ff
    
    price = 12345.678
    print(f"价格（逗号分隔）: {price:,.2f}")
    # 输出: 价格（逗号分隔）: 12,345.68
    ```
    
4. 调试辅助 (= 符号):
    
    在 Python 3.8 及更高版本中，你可以在表达式后面使用 = 号，f-string 会打印出表达式的文本、等号和表达式的求值结果。这对于调试非常方便。
    
    Python
    
    ```
    value = 42
    print(f"{value=}")
    # 输出: value=42
    
    x = 10
    y = 20
    print(f"{x + y = }")
    # 输出: x + y = 30
    ```
    
5. 不进行隐式字符串转换:
    
    f-string 不会像 str.format() 那样对非字符串类型进行隐式转换。它直接使用表达式的 __str__ 或 __repr__ 方法。
    
6. 禁止在表达式中使用反斜杠:
    
    在 f-string 的表达式部分 ({expression}) 中不能使用反斜杠 \。这是为了避免语法歧义。
    

f-string 因其强大的功能和简洁的语法，已成为 Python 中推荐的字符串格式化方式。
