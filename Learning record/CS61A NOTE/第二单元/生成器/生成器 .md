## `yield` 语法

### 作用 (Purpose)

`yield` 关键字是 Python 中用来定义**生成器函数（Generator Function）**的核心。当一个函数中包含 `yield` 语句时，它就不再是一个普通的函数，而变成了一个生成器函数。

生成器函数被调用时，不会立即执行函数体，而是返回一个**生成器迭代器（Generator Iterator）对象**。每次从这个迭代器请求下一个值时（例如通过 `next()` 函数或 `for` 循环），函数体才会执行到下一个 `yield` 语句，返回一个值，然后**暂停执行**，并**保存当前的状态**。下次请求值时，函数会从上次暂停的地方继续执行。

### `yield` 与 `return` 的区别

- **`return`**:
    
    - 当函数执行到 `return` 语句时，函数会立即**终止**执行。
        
    - 它返回一个值给调用者，并且该函数的所有局部变量都会被销毁。
        
    - 函数一旦 `return`，就不能再被调用以继续之前的执行状态。
        
- **`yield`**:
    
    - 当函数执行到 `yield` 语句时，函数会**暂停**执行，并返回 `yield` 后面的值给调用者。
        
    - 函数的所有局部变量的状态会被**保存**下来。
        
    - 当再次请求值时，函数会从上次 `yield` 暂停的地方**继续执行**。
        
    - 一个生成器函数可以有多个 `yield` 语句，并且可以在 `yield` 之后继续执行其他代码。
        
    - 当生成器函数执行完毕，或者遇到 `return` 语句（不带返回值），或者没有更多 `yield` 语句可执行时，它会隐式地引发 `StopIteration` 异常，表示生成器已耗尽。
        

### 示例

**基本用法：**

Python

```
def my_generator():
    n = 1
    print("This is printed first")
    yield n

    n += 1
    print("This is printed second")
    yield n

    n += 1
    print("This is printed third")
    yield n

# 调用生成器函数，得到一个生成器迭代器对象
gen = my_generator()
print(gen) # 输出: <generator object my_generator at 0x...>

# 第一次调用 next()
value1 = next(gen)
print(f"Received from generator: {value1}")
# 输出:
# This is printed first
# Received from generator: 1

# 第二次调用 next()
value2 = next(gen)
print(f"Received from generator: {value2}")
# 输出:
# This is printed second
# Received from generator: 2

# 第三次调用 next()
value3 = next(gen)
print(f"Received from generator: {value3}")
# 输出:
# This is printed third
# Received from generator: 3

# 第四次调用 next()，生成器已耗尽，会引发 StopIteration
try:
    next(gen)
except StopIteration:
    print("Generator exhausted!")
```

**`yield` 表达式（发送值给生成器）：**

`yield` 语句本身也可以作为一个表达式，这意味着你可以将值**发送**回生成器。这使得生成器可以作为协程（coroutine）使用，实现更复杂的交互。

Python

```
def interactive_generator():
    print("Generator started.")
    received = yield "First message"
    print(f"Generator received: {received}")
    received = yield "Second message"
    print(f"Generator received: {received}")
    yield "Done"

gen_interactive = interactive_generator()

# 启动生成器，运行到第一个 yield
print(next(gen_interactive)) # 输出: Generator started. \n First message

# 发送值 'Hello' 给生成器，并获取下一个 yield 的值
print(gen_interactive.send("Hello")) # 输出: Generator received: Hello \n Second message

# 发送值 'World' 给生成器
try:
    print(gen_interactive.send("World")) # 输出: Generator received: World \n Done
except StopIteration:
    print("Generator finished.")
```

## `yield from` 语法 (PEP 380)

### 作用 (Purpose)

`yield from` 语法（在 Python 3.3 中引入）用于**委托给子生成器（subgenerator）或任何可迭代对象**。它提供了一种更简洁、更高效的方式来将当前生成器（委托生成器）的一部分操作委托给另一个生成器或迭代器。

`yield from` 语句会**自动处理**子生成器（或可迭代对象）的迭代，以及将值从子生成器传递给委托生成器，将值从委托生成器发送回子生成器，以及处理子生成器抛出的异常和返回的值。

### `yield from` 的行为与原理

当 `yield from iterable` 语句被执行时：

1. **自动迭代：** `yield from` 会自动从 `iterable`（子生成器或可迭代对象）中获取每个值，并将其直接 `yield` 给委托生成器的调用者。
    
2. **值传递：** 任何通过 `send()` 方法发送给委托生成器的值，都会直接传递给子生成器。
    
3. **异常传递：** 子生成器中发生的任何异常，也会直接传递给委托生成器的调用者。
    
4. **返回捕获：** 子生成器通过 `return value` 语句返回的值，会被 `yield from` 表达式**捕获**。这个捕获的值可以赋给委托生成器中的一个变量。
    
5. **结束处理：** 当子生成器耗尽或完成时（即抛出 `StopIteration`），`yield from` 会恢复委托生成器的执行。
    

本质上，`yield from` 可以看作是以下 `for` 循环的**语法糖**（但它处理了更复杂的 `send()`、`throw()` 和 `return` 逻辑）：

Python

```
# 伪代码：yield from sub_generator() 大致等价于：
_i = iter(sub_generator())
try:
    _y = next(_i)
except StopIteration as _e:
    _result = _e.value # 捕获子生成器的返回值
else:
    while True:
        try:
            _send_val = yield _y
        except GeneratorExit:
            _i.close()
            raise
        except BaseException as _e:
            _y = _i.throw(_e)
        else:
            try:
                _y = _i.send(_send_val)
            except StopIteration as _e:
                _result = _e.value
                break
_result # 委托生成器可以接收子生成器的返回值
```

### 示例

**委托给另一个生成器：**

Python

```
def sub_generator():
    yield "Sub A"
    yield "Sub B"
    print("Sub generator finished")
    return "Sub Done" # 子生成器返回一个值

def main_generator():
    print("Main generator started")
    # 委托给 sub_generator
    result = yield from sub_generator()
    print(f"Main generator received from sub: {result}")
    yield "Main C"

gen_main = main_generator()

print(next(gen_main)) # 输出: Main generator started \n Sub A
print(next(gen_main)) # 输出: Sub B
print(next(gen_main))
# 输出:
# Sub generator finished
# Main generator received from sub: Sub Done
# Main C

try:
    next(gen_main)
except StopIteration:
    print("Main generator finished.")
```

**委托给普通可迭代对象：**

Python

```
def process_numbers():
    print("Processing numbers...")
    yield from [10, 20, 30] # 委托给列表
    print("Numbers processed.")
    yield from (x for x in range(1, 4)) # 委托给生成器表达式
    print("Range processed.")

num_processor = process_numbers()

for val in num_processor:
    print(f"Received: {val}")
# 输出:
# Processing numbers...
# Received: 10
# Received: 20
# Received: 30
# Numbers processed.
# Received: 1
# Received: 2
# Received: 3
# Range processed.
```

yield from 将后面那个看出一个迭代器就能在函数中理解许多东西
