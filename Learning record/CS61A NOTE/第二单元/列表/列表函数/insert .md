
## `insert()` 方法的介绍

`insert()` 是 Python 中列表（List）的一个内置方法，用于在列表的**指定位置**插入一个元素。与 `append()` 方法不同，`append()` 只能在列表末尾添加，而 `insert()` 允许你精确控制新元素的位置。

### 基本语法

Python

```
list.insert(index, item)
```

- `list`: 你想要插入元素的列表对象。
    
- `index`: 一个整数，表示你想要插入元素的位置的**索引**。
    
    - 如果 `index` 是 `0`，元素会插入到列表的开头。
        
    - 如果 `index` 大于或等于列表的当前长度，元素会被插入到列表的末尾（类似于 `append()` 的行为）。
        
    - 如果 `index` 是负数，它会从列表的末尾开始计数（例如 `-1` 表示倒数第一个位置，但元素会插入到倒数第一个元素**之前**）。如果计算后的索引小于 0，元素会插入到列表的开头。
        
- `item`: 任何你想要插入到列表中的元素。这个元素可以是任何数据类型（数字、字符串、布尔值、甚至是另一个列表、元组、字典等）。
    

`insert()` 方法**没有返回值**（或者说返回 `None`），它会**直接修改**原始列表。

**示例：**

Python

```
my_list = ['a', 'b', 'c']

# 在索引 1 处插入 'x'
my_list.insert(1, 'x')
print(my_list) # 输出: ['a', 'x', 'b', 'c']

# 在开头插入 '0' (索引 0)
my_list.insert(0, '0')
print(my_list) # 输出: ['0', 'a', 'x', 'b', 'c']

# 在末尾插入 'z' (索引超出范围时，插入到末尾)
my_list.insert(100, 'z')
print(my_list) # 输出: ['0', 'a', 'x', 'b', 'c', 'z']

# 使用负数索引：在倒数第二个元素 'c' 之前插入 'y'
my_list.insert(-2, 'y')
print(my_list) # 输出: ['0', 'a', 'x', 'b', 'y', 'c', 'z']
```

## `insert()` 方法的原理

`insert()` 方法的原理相比 `append()` 会稍微复杂一些，主要是因为涉及到中间位置的插入：

1. **内存重新分配与元素移动：** 当你在列表的中间位置使用 `insert()` 插入一个元素时，Python 需要为新元素腾出空间。这意味着从插入位置开始，所有后续元素都需要向后移动一个位置。
    
    - 如果列表的当前内存空间足够，这些元素的移动会在现有内存区域内完成。
        
    - 如果当前内存空间不足以容纳新元素和移动后的所有元素，Python 会像 `append()` 可能做的那样，重新分配一块更大的内存空间，将所有元素（包括新元素）复制到新位置。
        
2. **效率考量：** 由于可能涉及大量元素的移动，`insert()` 操作的效率通常低于 `append()`。
    
    - 在列表的**开头**或**中间**插入元素时，其时间复杂度为 **O(n)** (线性时间)，其中 `n` 是列表中需要移动的元素数量。列表越长，需要移动的元素越多，效率就越低。
        
    - 在列表的**末尾**插入元素（即 `index` 大于或等于列表长度时），其行为类似于 `append()`，平均时间复杂度为 **O(1)** (常数时间)。

## 注意事项

在使用 `insert()` 方法时，需要注意以下几点：

1. **修改原始列表：** `insert()` 方法会**直接修改**你调用的列表，而不是返回一个新的列表。如果你需要保留原始列表不变，可以先创建一个副本（例如使用 `list.copy()` 或切片 `[:]`），然后对副本进行操作。
    
    Python
    
    ```
    original = [1, 2, 3]
    new_list = original.copy() # 创建副本
    new_list.insert(1, 99)
    print(original) # 输出: [1, 2, 3] (原始列表未变)
    print(new_list)  # 输出: [1, 99, 2, 3]
    ```
    
2. **效率问题：** 鉴于其 O(n) 的时间复杂度，如果在性能敏感的代码中需要频繁地在列表的开头或中间插入大量元素，`insert()` 可能不是最佳选择。在这些情况下，考虑使用 `collections.deque`（双端队列），它在两端添加和删除元素的效率更高（O(1)）。
    
    Python
    
    ```
    from collections import deque
    
    my_deque = deque([1, 2, 3])
    my_deque.appendleft(0) # 在左侧（开头）添加
    my_deque.insert(2, 99) # deque 也支持 insert，但同样是 O(n)
    
    print(my_deque) # 输出: deque([0, 1, 99, 2, 3])
    ```
    
3. **返回值为 `None`：** 由于 `insert()` 会修改原始列表，它的返回值是 `None`。因此，不要尝试将 `insert()` 的结果赋值给变量，除非你明确想要赋值 `None`。
    
    Python
    
    ```
    my_list = [1, 2]
    result = my_list.insert(1, 3)
    print(result) # 输出: None
    print(my_list) # 输出: [1, 3, 2]
    ```
