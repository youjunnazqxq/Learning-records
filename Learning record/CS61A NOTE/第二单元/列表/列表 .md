


- **有序 (Ordered)**：列表中的元素是按照它们被添加的顺序进行排列的 。这意味着你可以通过索引（位置）来访问列表中的元素，并且元素的顺序是固定的，不会随意改变。例如，
    
    `[1, 2, 3]` 和 `[3, 2, 1]` 是两个不同的列表。
    
- **可变 (Mutable)**：列表是可变的数据类型 。这意味着列表创建后，你可以修改、添加或删除其中的元素，而无需创建新的列表对象。
    
    - **修改元素**: `my_list = [1, 2, 3]; my_list[0] = 10` 后变为 `[10, 2, 3]`。
        
    - **添加元素**: `my_list.append(4)` 或 `my_list.insert(1, 5)`。
        
    - **删除元素**: `del my_list[0]` 或 `my_list.remove(2)`。
        
- **可包含不同类型的元素 (Can Contain Mixed Data Types)**：一个列表中可以包含任意数据类型的元素，甚至可以包含其他列表、元组、字典、函数等。例如：`[1, "hello", True, 3.14, [4, 5]]` 是一个完全有效的列表。
    
- **可迭代 (Iterable)**：列表是可迭代的 。这意味着你可以使用
    
    `for` 循环遍历列表中的每一个元素。
    
- **动态大小 (Dynamic Sizing)**：列表的大小是动态变化的，可以根据需要自动增长或缩小。你不需要在创建时预先指定它的大小。
    
- **允许重复元素 (Allows Duplicate Elements)**：列表中可以包含相同的值的元素。例如：`[1, 2, 2, 3]` 是一个合法的列表。
    
- **基于索引 (Index-based)**：列表中的每个元素都有一个对应的索引，从 0 开始。你可以使用索引来访问、修改或删除特定位置的元素。支持正向索引 (从左到右，从 0 开始) 和负向索引 (从右到左，从 -1 开始)
