列表推导式（List Comprehensions）是 Python 中一种非常简洁和强大的创建列表的方式。它提供了一种紧凑的语法，可以在一行代码中完成循环、条件判断和列表构建。

### 基本语法

列表推导式的基本语法结构如下：

Python

```
[expression for item in iterable if condition]
```

- `expression`：这是一个表达式，用于对 `item` 进行操作，其结果将成为新列表中的一个元素。
    
- `for item in iterable`：这是一个 `for` 循环，用于遍历可迭代对象（如列表、元组、字符串、range 对象等）中的每个元素。`item` 是在循环中临时绑定的变量。
    
- `if condition` (可选)：这是一个可选的条件语句。如果提供了，只有当 `condition` 为 `True` 时，`expression` 的结果才会被包含在新列表中。
    

### 语法解析与示例

#### 1. 最简单的形式：仅循环

当只需要对一个可迭代对象进行遍历并构建新列表时，可以省略 `if condition` 部分。

Python

```
# 示例：创建一个包含 1 到 5 平方的新列表
squares = [x**2 for x in range(1, 6)]
print(squares)  # 输出: [1, 4, 9, 16, 25]
```

这等价于传统的 `for` 循环：

Python

```
squares = []
for x in range(1, 6):
    squares.append(x**2)
```

#### 2. 包含条件判断

当需要根据某些条件过滤元素时，可以使用 `if condition` 子句。

Python

```
# 示例：创建一个包含 1 到 10 之间所有偶数平方的新列表
even_squares = [x**2 for x in range(1, 11) if x % 2 == 0]
print(even_squares)  # 输出: [4, 16, 36, 64, 100]
```

这等价于传统的 `for` 循环和 `if` 语句：

Python

```
even_squares = []
for x in range(1, 11):
    if x % 2 == 0:
        even_squares.append(x**2)
```

#### 3. 嵌套循环

列表推导式也支持嵌套循环，这在处理多维数据或需要组合多个可迭代对象时非常有用。

Python

```
# 示例：生成所有颜色和尺寸的组合
colors = ['red', 'green']
sizes = ['S', 'M', 'L']

combinations = [(color, size) for color in colors for size in sizes]
print(combinations)
# 输出: [('red', 'S'), ('red', 'M'), ('red', 'L'),
#          ('green', 'S'), ('green', 'M'), ('green', 'L')]
```

这等价于传统的嵌套 `for` 循环：

Python

```
combinations = []
for color in colors:
    for size in sizes:
        combinations.append((color, size))
```

#### 4. 包含 `if/else` 表达式 (条件表达式)

如果需要在 `expression` 部分根据条件返回不同的值，可以使用条件表达式（`if ... else ...`）。

Python

```
# 示例：将列表中大于 5 的数字加倍，否则保持不变
numbers = [1, 6, 3, 8, 2, 7]
transformed_numbers = [x * 2 if x > 5 else x for x in numbers]
print(transformed_numbers) # 输出: [1, 12, 3, 16, 2, 14]
```

这等价于：

Python

```
transformed_numbers = []
for x in numbers:
    if x > 5:
        transformed_numbers.append(x * 2)
    else:
        transformed_numbers.append(x)
```

### 列表推导式的优势

- **简洁性**：用更少的代码实现相同的功能。
    
- **可读性**：对于简单的循环和过滤操作，列表推导式通常比传统的 `for` 循环更易读。
    
- **效率**：在许多情况下，列表推导式的执行效率比等效的 `for` 循环更高，因为它在内部进行了优化。
    
- **符合 Pythonic 风格**：是 Python 语言中推荐的编写简洁高效代码的方式之一。
    

然而，对于过于复杂或多层嵌套的逻辑，过度使用列表推导式可能会降低代码的可读性，此时传统的 `for` 循环可能是更好的选择。
