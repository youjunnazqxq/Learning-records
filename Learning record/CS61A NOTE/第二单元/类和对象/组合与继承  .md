好的，我们来详细解释 Python 中**继承 (Inheritance)** 和**组合 (Composition)** 这两种重要的面向对象设计模式的语法和概念。

---

## 1. 继承 (Inheritance)

**概念：** 继承代表一种“**is-a**”（是一种）的关系。它允许你创建一个新类（**子类 / Derived Class / Child Class**），从一个已存在的类（**父类 / Base Class / Parent Class**）中获取（继承）属性和方法。子类可以扩展、修改或覆盖从父类继承来的功能。

**作用：**

- **代码复用：** 子类可以直接使用父类的代码，无需重复编写。
    
- **多态性：** 允许不同类的对象对同一个方法调用做出不同的响应。
    
- **建立层次结构：** 更好地组织和管理代码。
    

### 基本语法

在定义子类时，将父类的名称放在子类名称后面的括号中。

Python

```
# 定义父类
class ParentClass:
    def __init__(self, name):
        self.name = name
        print(f"ParentClass __init__ called for {self.name}")

    def parent_method(self):
        print(f"{self.name} is calling parent_method.")

# 定义子类，继承自 ParentClass
class ChildClass(ParentClass):
    def __init__(self, name, age):
        # 语法1: 使用 super() 调用父类的构造方法 (推荐且常用)
        # super() 会返回父类的代理对象，然后可以调用父类的方法
        super().__init__(name)
        self.age = age
        print(f"ChildClass __init__ called for {self.name}, age {self.age}")

    # 方法覆盖 (Method Overriding): 子类重新定义父类的方法
    def parent_method(self):
        print(f"{self.name} is calling OVERRIDDEN parent_method from ChildClass.")
        # 可以在覆盖的方法中调用父类的方法
        # super().parent_method() # 如果需要调用父类的同名方法

    def child_method(self):
        print(f"{self.name} is calling child_method.")

# --- 示例用法 ---
print("--- Creating Parent Object ---")
parent_obj = ParentClass("BaseGuy")
parent_obj.parent_method()

print("\n--- Creating Child Object ---")
child_obj = ChildClass("Youngster", 10)
child_obj.parent_method() # 调用的是子类覆盖后的方法
child_obj.child_method()  # 调用子类自己的方法
print(f"Child name: {child_obj.name}, age: {child_obj.age}")

# 子类也继承了父类的属性
# print(child_obj.name) # 已经通过 super().__init__(name) 初始化了

```

**`super()` 函数的使用：**

`super()` 函数是一个非常重要的内置函数，在多重继承和方法覆盖时尤其关键。

- `super().__init__(...)`：在子类的 `__init__` 方法中调用父类的 `__init__` 方法，确保父类的属性得到正确初始化。这是最常见的用法。
    
- `super().method_name(...)`：在子类中覆盖某个方法后，如果你还想调用父类中被覆盖的同名方法，可以使用 `super()`。

## 2. 组合 (Composition)

**概念：** 组合代表一种“**has-a**”（拥有一个）的关系。它通过在一个类中包含另一个或多个类的对象作为其属性，来构建更复杂的对象。

**作用：**

- **提高灵活性：** 对象的各个部分可以独立替换。
    
- **避免继承的局限性：** 解决了单继承语言中多重继承的复杂性，以及深层继承层次结构可能导致的问题。
    
- **代码解耦：** 各个组件类相对独立，修改其中一个组件不大会影响到包含它的类。
    

### 基本语法

在类的 `__init__` 方法中创建另一个类的实例，并将其赋值给当前实例的一个属性。

Python

```
# 定义组件类：引擎
class Engine:
    def __init__(self, horsepower):
        self.horsepower = horsepower
        print(f"Engine with {self.horsepower} HP created.")

    def start(self):
        print(f"Engine ({self.horsepower} HP) started.")

    def stop(self):
        print(f"Engine stopped.")

# 定义组件类：轮胎
class Wheel:
    def __init__(self, size):
        self.size = size
        print(f"Wheel of size {self.size} created.")

    def rotate(self):
        print(f"Wheel (size {self.size}) is rotating.")

# 定义容器类：汽车，它“拥有”一个引擎和多个轮胎
class Car:
    def __init__(self, brand, model, hp):
        self.brand = brand
        self.model = model
        # 组合：在 Car 的构造方法中创建 Engine 和 Wheel 的实例
        self.engine = Engine(hp) # Car 拥有一个 Engine 对象
        self.wheels = [Wheel(18) for _ in range(4)] # Car 拥有四个 Wheel 对象
        print(f"Car {self.brand} {self.model} created.")

    def drive(self):
        print(f"Driving the {self.brand} {self.model}...")
        self.engine.start() # 通过组合的对象调用其方法
        for wheel in self.wheels:
            wheel.rotate()
        print("Car is moving.")

    def park(self):
        print(f"Parking the {self.brand} {self.model}...")
        self.engine.stop()
        print("Car is parked.")

# --- 示例用法 ---
print("--- Creating Car Object ---")
my_car = Car("Toyota", "Camry", 180)

print("\n--- Driving Car ---")
my_car.drive()

print("\n--- Parking Car ---")
my_car.park()

# 可以直接访问组合的组件
print(f"\nCar's engine horsepower: {my_car.engine.horsepower}")
print(f"Car has {len(my_car.wheels)} wheels, first wheel size: {my_car.wheels[0].size}")
```

## 继承 vs. 组合：何时选择？

- **选择继承：**
    
    - 当两者之间存在明显的“**is-a**”关系时（例如，`Dog` **is a** `Animal`）。
        
    - 当你想要共享公共行为并在子类中进行特化时。
        
    - 当你想要利用多态性，将子类对象视为父类类型时。
        
- **选择组合：**
    
    - 当两者之间存在“**has-a**”关系时（例如，`Car` **has an** `Engine`）。
        
    - 当你希望在不改变现有类的情况下，动态地添加或改变对象的行为时（因为你可以替换组合的组件）。
        
    - 当你想要避免深层次的继承结构，或者你希望一个类能够利用多个不相关的类的功能时（避免多重继承的复杂性）。
        
    - 通常，**组合比继承提供更大的灵活性**，因为它允许运行时改变对象的行为，而且它避免了继承层次结构可能变得僵化的问题。在面向对象设计中，**“优先使用组合而不是继承”（Prefer composition over inheritance）**是一个常见的指导原则。
