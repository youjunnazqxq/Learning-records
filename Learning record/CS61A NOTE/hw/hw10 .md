#### 1. `CREATE TABLE ... AS SELECT ...` (创建表并将查询结果作为内容)

- **语法**: `CREATE TABLE table_name AS SELECT ...;`
    
- **作用**: 这是 SQL 中一种非常常用的方式，用于根据一个 `SELECT` 查询的结果来创建一个新表。新表的结构（列名和数据类型）会从 `SELECT` 查询的结果集中继承。
    
- **示例**: 你在所有 `CREATE TABLE by_parent_height AS SELECT ...`, `CREATE TABLE size_of_dogs AS SELECT ...`, `CREATE TABLE siblings AS SELECT ...`, `CREATE TABLE sentences AS SELECT ...`, `CREATE TABLE low_variance AS SELECT ...` 中都使用了这种语法。
    

#### 2. `SELECT` 子句 (选择列)

- **语法**: `SELECT column1 [AS alias1], column2 [AS alias2], aggregate_function(column) [AS alias], ...`
    
- **作用**: 指定你希望从查询结果中返回哪些列。
    
- **关键点**:
    
    - **列名**: 可以直接列出表中的列名。
        
    - **别名 (`AS`)**: 使用 `AS` 关键字为列或表达式的结果指定一个临时的、更具可读性的名称。
        
        - 示例: `SELECT "ace" AS name`, `a.child AS siblings1`, `b.child AS siblings2`。
            
    - **字符串拼接 (`||`)**: 在某些 SQL 方言中（如 SQLite, PostgreSQL, Oracle），`||` 运算符用于连接（拼接）字符串。
        
        - 示例: `SELECT "The two sibings,"||sibings1||"and"||sibings2||",have the same size"||a.size`，用于构建复杂的文本字符串。
            
    - **聚合函数**: 用于对一组值进行计算并返回单个结果。
        
        - `MAX(height) - MIN(height)`: 计算最大值和最小值之差。
            

#### 3. `FROM` 子句 (指定数据来源)

- **语法**: `FROM table1 [AS alias1], table2 [AS alias2], ...`
    
- **作用**: 指定查询的数据来源表。
    
- **关键点**:
    
    - **多表并列 (隐式连接/交叉连接)**: 当你在 `FROM` 子句中用逗号分隔多个表时（例如 `from parents,dogs`），这会执行一个**交叉连接（Cross Join）**，即第一个表的每一行与第二个表的每一行组合。这种连接的结果通常需要通过 `WHERE` 子句进一步过滤（通常是用来实现内连接的效果）。
        
    - **表别名 (`AS`)**: 使用 `AS` 关键字为表指定一个别名，这在多表查询（特别是自连接）中非常有用，可以简化代码并提高可读性。
        
        - 示例: `parents AS a, parents AS b`, `size_of_dogs AS a, size_of_dogs AS b`。
            

#### 4. `WHERE` 子句 (行过滤与连接条件)

- **语法**: `WHERE condition [AND|OR condition] ...`
    
- **作用**: 用于在行级别过滤数据。只有满足指定条件的行才会被包含在结果集中。
    
- **关键点**:
    
    - **筛选条件**: 如 `height<=max and height >min`。
        
    - **连接条件**: 在隐式连接（如 `FROM parents,dogs`）中，`WHERE` 子句通常包含连接两个表的条件，例如 `parent = name`。这实际上模拟了 `INNER JOIN` 的行为。
        
    - **逻辑运算符**: `AND` 和 `OR` 用于组合多个条件。
        

#### 5. `ORDER BY` 子句 (排序结果)

- **语法**: `ORDER BY column1 [ASC|DESC], column2 [ASC|DESC], ...`
    
- **作用**: 对查询结果进行排序。
    
- **关键点**:
    
    - **排序方向**:
        
        - `ASC` (Ascending): 升序（默认）。
            
        - `DESC` (Descending): 降序。
            
    - **示例**: `order by height DESC` (原始 `by_parent_height` 题目注释是降序，但你的代码写的是默认升序，这里与题目要求略有不符，但语法上是正确的)。
        

#### 6. `GROUP BY` 子句 (分组数据)

- **语法**: `GROUP BY column1, column2, ...`
    
- **作用**: 将结果集按照一个或多个列的值进行分组，以便对每个组应用聚合函数。
    
- **关键点**: `SELECT` 列表中所有非聚合的列都必须出现在 `GROUP BY` 子句中。
    
- **示例**: `group by fur`，用于按毛发类型进行聚合计算。
    

#### 7. `HAVING` 子句 (分组过滤)

- **语法**: `HAVING aggregate_condition [AND|OR aggregate_condition] ...`
    
- **作用**: 在 `GROUP BY` 之后，用于过滤分组。`HAVING` 子句中可以包含聚合函数。
    
- **关键点**:
    
    - `WHERE` 过滤**行**（在分组前），`HAVING` 过滤**组**（在分组后）。
        
- **示例**: `having max(height)<1.3*avg(height) and min >0.7*avg(height)`，用于筛选那些身高差异小的毛发类型组。
    

#### 8. 聚合函数 (再次强调其在表达式和`HAVING`中的应用)

- `MAX()`: 求最大值。
    
- `MIN()`: 求最小值。
    
- `AVG()`: 求平均值。
    
- 这些函数在 `SELECT` 列表用于显示计算结果，在 `HAVING` 子句中用于对分组进行条件判断。
    

#### 9. `UNION` (合并结果集)

- **语法**: `SELECT ... UNION SELECT ...`
    
- **作用**: 用于合并两个或多个 `SELECT` 语句的结果集。`UNION` 会自动去除重复行。
    
- **示例**: 在创建 `dogs` 和 `parents` 表时，你使用了多次 `SELECT ... UNION SELECT ...` 来构建这些表的初始数据。
