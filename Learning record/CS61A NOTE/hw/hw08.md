## Q2
```
(define (my-filter pred s)
  (cond ((null? s)               ; 基本情况：如果列表 s 为空...
         '())                    ; ...就返回一个空列表，递归结束。
        
        ((pred (car s))          ; 递归情况1：如果 s 的第一个元素通过了 pred 测试...
         (cons (car s)           ; ...就保留它，并将其与过滤后的剩余列表合并
               (my-filter pred (cdr s))))
        
        (else                    ; 递归情况2：如果 s 的第一个元素没有通过测试...
         (my-filter pred (cdr s))); ...就直接丢弃它，只返回过滤后的剩余列表
  )
)
```




这道题我不会递归终止的条件，以及新的函数是上轮函数的延续这个该概念
