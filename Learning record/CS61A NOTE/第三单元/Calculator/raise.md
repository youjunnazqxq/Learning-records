### **Python `raise` 语句核心笔记**

#### **1. 核心作用**

- 主动、人为地在代码中**引发（抛出）一个异常**。

#### **2. 主要用途**

- **输入验证**：当函数参数不符合要求时，阻止程序运行。
- **信号错误**：表明程序进入了不合法的状态。
- **异常处理**：在 `except` 块中执行完清理或日志记录后，将异常再次抛出。
- **强制实现**：在父类中用 `raise NotImplementedError` 强制子类重写方法。

#### **3. 语法与用法**

|   |   |   |
|---|---|---|
|**形式**|**语法 (Syntax)**|**用途说明**|
|**引发新异常**|`raise ExceptionType('错误信息')`|**最常用**。创建一个指定类型的新异常并抛出。 &lt;br> _示例: `raise ValueError('输入值无效')`_|
|**重新抛出**|`raise` &lt;br> (不带任何参数)|**只能在 `except` 块中使用**。将当前捕获到的异常原封不动地再次抛出，以便上层代码继续处理。|
|**异常链**|`raise NewException from OldException`|将一个底层异常 (`OldException`) 包装成一个新的、更具体的异常 (`NewException`)，同时保留原始异常信息作为“根本原因”，便于调试。|
