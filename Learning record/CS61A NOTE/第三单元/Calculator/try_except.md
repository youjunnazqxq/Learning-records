### **Python `try` 语句核心笔记**

#### **1. 核心作用**

- **异常处理**：提供一个“安全网”，用于捕获和处理代码在运行时可能发生的错误，防止程序因此崩溃。

#### **2. 语法结构**

Python

```
try:
    # 监控区：存放可能出错的代码
    pass
except ExceptionType as e:
    # 补救区：当 try 中发生匹配的异常时执行
    pass
else:
    # 成功区：当 try 中没有发生任何异常时执行
    pass
finally:
    # 清理区：无论是否发生异常，最后总会执行
    pass
```

- **注意**：`try` 必须与 `except` 或 `finally` 至少一个配合使用。`else` 和 `finally` 是可选的。

---

#### **3. 各模块说明**

|   |   |   |
|---|---|---|
|**代码块 (Block)**|**执行时机 (When it Executes)**|**核心作用 (Core Purpose)**|
|**`try`**|总是首先执行|包裹并监控可能引发异常的代码。|
|**`except`**|**发生匹配的异常时**|处理错误，执行补救措施。|
|**`else`**|**未发生任何异常时**|执行成功后的代码（与 `try` 块解耦）。|
|**`finally`**|**永远执行**|**资源清理** (如关闭文件/网络连接)。|

---

#### **4. `except` 的常见用法**

- `except ValueError:`：捕获特定类型的异常。
- `except (ValueError, TypeError):`：捕获元组中列出的多种异常。
- `except ValueError as e:`：捕获异常并将其赋值给变量 `e`，以便查看错误信息。
- `except:`：捕获所有异常（**强烈不推荐**，会隐藏未知错误）。

#### **5. 记忆技巧**

- `try` → **尝试**执行危险操作。
- `except` → 如果失败了，就**补救**。
- `else` → 如果成功了，就**庆祝**一下。
- `finally` → 无论成败，都要**打扫战场**。
