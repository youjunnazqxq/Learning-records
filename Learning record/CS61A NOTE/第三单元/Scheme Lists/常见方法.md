这四个函数是函数式编程中处理列表的“瑞士军刀”，它们都属于**高阶函数 (Higher-Order Functions)**，即可以接受其他函数作为参数的函数。

---

### **翻译**

- `(append s t)`: 列出 `s` 和 `t` 的所有元素；`append` 可以接受超过2个列表作为参数。
- `(map f s)`: 对列表 `s` 的每个元素调用过程 `f`，并将结果组成一个列表。
- `(filter f s)`: 对列表 `s` 的每个元素调用过程 `f`，并将所有使得 `f` 返回真值的元素组成一个列表。
- `(apply f s)`: 以列表 `s` 中的元素作为参数来调用过程 `f`。

---

### **解释与示例**

#### 1. `append` (拼接列表)

- **作用**: 将一个或多个列表“平铺”拼接成一个全新的列表。
- **示例**:
    
    Scheme
    
    ```
    (append '(1 2) '(a b))
    ;=> '(1 2 a b)
    
    (append '(1) '(2 3) '(4 5 6))
    ;=> '(1 2 3 4 5 6)
    ```
    
- **注意**: 它创建的是一个新列表，不会修改原始列表。

#### 2. `map` (映射/转换)

- **作用**: 对一个列表中的**每一个元素**执行相同的操作（由函数 `f` 定义），然后将每次操作的**结果**收集起来，组成一个与原列表等长的新列表。
- **类比**: 就像工厂流水线，`map` 将每个原材料（列表元素）通过同一个模具（函数 `f`）加工成新产品（新列表的元素）。
- **示例**: 将列表中的每个数字都平方。
    
    Scheme
    
    ```
    (define (square x) (* x x))
    
    (map square '(1 2 3 4))
    ;=> '(1 4 9 16)
    
    ; 使用 lambda 匿名函数更常见
    (map (lambda (x) (* x x)) '(1 2 3 4))
    ;=> '(1 4 9 16)
    ```
    

#### 3. `filter` (过滤/筛选)

- **作用**: 使用一个返回真或假的“断言函数” `f` 来**检查**列表中的每一个元素，只保留那些使 `f` 返回真 (任何非 `#f` 的值) 的元素，并将它们组成一个新列表。
- **类比**: 就像用一个筛子（函数 `f`）过滤沙子，只有符合尺寸（条件为真）的石子才能留下来。
- **示例**: 从一个列表中筛选出所有的奇数。
    
    Scheme
    
    ```
    ; odd? 是一个内置函数，判断一个数是否为奇数
    (filter odd? '(1 2 3 4 5 6))
    ;=> '(1 3 5)
    
    ; 筛选出所有正数
    (filter (lambda (x) (> x 0)) '(-1 5 -10 2 0))
    ;=> '(5 2)
    ```

#### 4. `apply` (应用/散开)

- **作用**: 将一个函数 `f` 应用于一个**参数列表** `s`。它的核心功能是把一个列表“解开”或“散开”，将其中的元素作为独立的参数传递给函数 `f`。
- **类比**: `apply` 就像一个自动分发装置。你给它一个指令（函数 `f`）和一整包零件（列表 `s`），它会自动把零件一个个摆好，然后执行指令。
- **示例**:
    
    Scheme
    
    ```
    ; 这两个表达式是等价的：
    (+ 1 2 3 4)
    (apply + '(1 2 3 4))
    ; 两者都返回 => 10
    
    ; 另一个例子：
    (apply max '(10 50 20 40))
    ; 等价于 (max 10 50 20 40)，返回 => 50
    ```
    
- **`apply` vs `map` 的关键区别**:
    - `(map + '(1 2) '(3 4))` 会执行 `(+ 1 3)` 和 `(+ 2 4)`，返回 `'(4 6)`。`map` 是**逐个元素**操作。
    - `(apply + '(1 2 3 4))` 会执行 `(+ 1 2 3 4)`，返回 `10`。`apply` 是将**整个列表**作为参数集，对函数**调用一次**。
