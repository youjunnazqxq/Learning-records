### **核心作用：阻止求值 (Preventing Evaluation)**

单引号（`'`）最核心、最直接的作用就是告诉 Lisp 解释器：**“请不要对紧随其后的这个表达式进行求值（计算），而是把它本身当作一个字面数据（literal data）返回。”**

它本质上是一个“代码”与“数据”之间的切换开关。

### **基本语法**

语法非常简单，就是在任何合法的 Lisp 表达式前面加上一个单引号。

`'表达式`

#### **1. 应用于符号 (Symbol)**

当单引号用于单个符号时，它会返回该符号本身，而不是该符号所绑定的值。

- **语法**: `'符号名`
- **示例**:
    
    Lisp
    
    ```
    (define my-variable 100)
    
    my-variable   ; => 100 (求值，返回变量绑定的值)
    'my-variable  ; => my-variable (不求值，返回符号本身)
    ```
    

#### **2. 应用于列表 (List)**

当单引号用于一个列表时，它会阻止解释器将该列表视为一个函数调用，而是将其作为一个包含多个元素的列表数据返回。这是在 Lisp 中创建静态列表最常见的方法。

- **语法**: `'(元素1 元素2 ...)`
- **示例**:
    
    Lisp
    
    ```
    (+ 1 2)         ; => 3 (求值，执行加法函数调用)
    '(+ 1 2)       ; => (+ 1 2) (不求值，返回一个包含三个元素的列表)
    ```
    
    在这个例子里，返回的列表包含三个元素：符号 `+`、数字 `1` 和数字 `2`。

### **详细解释与常见用例**

1. **创建数据列表**: 这是单引号最广泛的用途。当你需要一个包含符号、数字或其他数据的静态列表时，使用单引号是最直接的方式。
    
    Lisp
    
    ```
    (define my-shopping-list '(apple milk bread))
    ```
    
2. **将符号作为函数参数**: 有时，函数需要的不是一个值，而是一个符号本身（例如，用作字典的键或设置属性）。
    
    Lisp
    
    ```
    ; 假设有一个函数 (set-property object key value)
    ; 我们想给 'user' 这个对象的 'status' 属性设置为 'active'
    (set-property 'user 'status 'active)
    ; 这里传递的是符号本身，而不是试图查找 user, status, active 这些变量的值
    ```
    
3. **代码即数据 (Code as Data)**: 单引号是 Lisp “代码即数据”哲学的基石。它允许你将一段本应被执行的代码，变成一个可以被检查、操作和转换的列表数据结构。这是宏 (Macro) 和元编程 (Metaprogramming) 的基础。
    

### **与 `quote` 的关系**

单引号 `'` 实际上是一个名为 `quote` 的特殊操作符的**语法糖 (Syntactic Sugar)**。以下两种形式是完全等价的，解释器在读取代码时会自动将前者转换为后者。

`'expression` 等价于 `(quote expression)`

示例:

'(a b c) 在内部被视为 (quote (a b c))。

### **总结**

|   |   |
|---|---|
|**方面**|**描述**|
|**核心功能**|**暂停求值**，将代码转为数据。|
|**语法形式**|在任何表达式前加 `'`。|
|**对符号的作用**|返回符号本身，而非其绑定的值。|
|**对列表的作用**|返回列表结构本身，而非将其作为函数调用执行。|
|**本质**|`(quote ...)` 的简写形式。|
|**关键用途**|创建静态数据列表、传递符号作为参数、实现元编程。|
