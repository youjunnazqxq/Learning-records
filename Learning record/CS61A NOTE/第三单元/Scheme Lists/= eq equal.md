### **=, eq?, equal?**

- `(= <a> <b>)` - 如果 `a` 等于 `b` 则返回真 (`true`)。两者必须都是数字。
    
- `(eq? <a> <b>)` - 如果 `a` 和 `b` 是等价的原始值，则返回真。对于两个对象，如果它们都指向内存中的**同一个对象**，`eq?` 返回真。这类似于在 Python 中使用 `is` 来检查两个对象的同一性。
    
- `(equal? <a> <b>)` - 如果 `a` 和 `b` 是具有相同内容的**序对 (pairs)**（即它们的 `car` 部分和 `cdr` 部分都 `equal?`），则返回真。这类似于在 Python 中使用 `==` 来检查两个列表的相等性。如果 `a` 和 `b` 不是序对，`equal?` 的行为与 `eq?` 相同。
    

Scheme

```
scm> (define a '(1 2 3))
a
scm> (= a a)
Error ; 错误，因为 = 只适用于数字，而 a 是一个列表
scm> (equal? a '(1 2 3))
#t    ; #t (真)，因为 a 和 '(1 2 3) 的内容相同
scm> (eq? a '(1 2 3))
#f    ; #f (假)，因为 a 和 '(1 2 3) 是在内存中独立创建的两个不同对象
```
