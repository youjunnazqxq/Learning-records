### **`cons`, `nil`, `car`, `cdr` 作用与基本语法总结**

这四个工具是函数式编程（特别是Lisp家族语言）中操作链表的基础。您可以将它们想象成操作一列火车的工具。

---

#### **1. `cons` (构造 | "连接车厢")**

- **作用**: 创建一个新的列表节点，将一个新元素添加到现有列表的最前端。它的核心功能是**构建和扩展**列表。
- **基本语法**: `(cons element list)`
    - `element`: 任何你想添加的元素。
    - `list`: 一个已存在的列表（可以是 `nil`）。
- **示例**:
    
    Lisp
    
    ```
    ; 将数字 1 添加到列表 '(2 3) 的前面
    (cons 1 '(2 3))   ; => '(1 2 3)
    ```
    

#### **2. `nil` (终点 | "火车终点站")**

- **作用**: 代表一个**空列表**，是所有合法列表的**终结标记**。
- **基本语法**: `nil` 或 `'()`
    - 这两个是等价的，都表示空列表。`nil` 是一个常量。
- **示例**:
    
    Lisp
    
    ```
    ; 创建一个只包含数字 1 的列表
    (cons 1 nil)      ; => '(1)
    ```
    

#### **3. `car` (头部 | "查看第一节车厢的货物")**

- **作用**: 获取（返回）列表的**第一个元素**。它的核心功能是**读取**列表的“头”部内容。
- **基本语法**: `(car list)`
    - `list`: 一个非空的列表。
- **示例**:
    
    Lisp
    
    ```
    ; 获取列表 '(A B C) 的第一个元素
    (car '(A B C))    ; => 'A
    ```
    

#### **4. `cdr` (尾部 | "断开第一节车厢，得到后面的整列火车")**

- **作用**: 获取（返回）列表中**除了第一个元素之外的剩余部分**。它的核心功能是**向下遍历**列表。返回的结果永远是一个列表。
- **基本语法**: `(cdr list)`
    - `list`: 一个非空的列表。
- **示例**:
    
    Lisp
    
    ```
    ; 获取列表 '(A B C) 第一个元素之后的部分
    (cdr '(A B C))    ; => '(B C)
    
    ; 获取只含一个元素的列表的cdr，结果是空列表
    (cdr '(A))        ; => nil
    ```
    

---

### **核心关系**

对于任何由 `cons` 创建的非空列表 `L`，以下等式永远成立：

`L` 等价于 `(cons (car L) (cdr L))`

示例:

如果 L 是 '(A B C):

- `(car L)` 是 `A`
- `(cdr L)` 是 `'(B C)`
- `(cons 'A '(B C))` 就重新构建了原始列表 `'(A B C)`。

这个关系清晰地展示了 `cons` 如何将 `car`（元素）和 `cdr`（剩余列表）组合在一起，构成了整个数据结构的基础。


## list（包含cons）与quote的区别



`list`（以及 `cons`）和 `quote` 之间一个重要的区别是：`list` 和 `cons` 会在将操作数放入列表之前对**每一个操作数进行求值**，而 `quote` 则会**原样返回**你所输入的列表，不会对其中任何独立的元素进行求值。

Scheme

```
scm> (define a 1)
a
scm> (define b 2)
b
scm> (list a b 3)
(1 2 3)
scm> '(a b 3)
(a b 3)
```

请注意，如果我们想使用 `list` 过程来创建列表 `(a b 3)`，我们可以引用 (quote) 符号 `a` 和 `b`，这样它们在生成列表时就不会被求值了：

Scheme

```
scm> (list 'a 'b 3)
(a b 3)
```
