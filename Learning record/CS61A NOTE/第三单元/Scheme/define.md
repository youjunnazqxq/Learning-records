### **`define` 的核心作用**

`define` 是 Scheme 中用于在当前环境中**创建绑定**的基础工具。它的核心作用就是**给一个“值”起一个永久性的“名字”**。这个“值”既可以是普通数据（如数字、列表），也可以是一个可执行的过程（即函数）。

---

### **`define` 的两种核心用法**

`define` 的所有功能都可以归结为以下两种基本模式：

#### 1. **定义变量 (给数据命名)**

这是 `define` 最直接的用法，用于创建一个指向特定数据值的全局变量。

- **用途**: 为一个数据（数字、字符串、列表等）创建一个可以被反复引用的名字。
- **语法**: `(define <变量名> <值>)`
- **示例**:
    
    Scheme
    
    ```
    ; 将名字 pi 绑定到数值 3.14159
    (define pi 3.14159)
    
    ; 将名字 my-list 绑定到一个列表
    (define my-list '(a b c))
    ```
    

#### 2. **定义函数 (给过程命名)**

这是 `define` 最常见的用法，它将一个名字绑定到一个可执行的过程（procedure）上。它有两种等价的写法。

##### a) 简写形式 (推荐用法)

这种形式清晰地表达了定义一个函数的意图，是首选的写法。

- **用途**: 创建一个带名字的、可被调用的函数。
- **语法**: `(define (<函数名> <参数...>) <函数体...>)`
- **示例**:
    
    Scheme
    
    ```
    ; 定义一个名为 square 的函数，它接受一个参数 x
    (define (square x)
      (* x x))
    ```
    

##### b) `lambda` 标准形式 (揭示本质)

这种形式虽然代码稍长，但它清晰地揭示了**函数定义的本质：创建一个匿名的 `lambda` 过程，然后用 `define` 将一个名字绑定到这个过程上**。

- **用途**: 理解函数即是值的概念。
- **语法**: `(define <函数名> (lambda (<参数...>) <函数体...>))`
- **示例**:
    
    Scheme
    
    ```
    ; 和上面的简写形式完全等价
    (define square
      (lambda (x)
        (* x x)))
    ```
    

### **总结**

|   |   |   |
|---|---|---|
|**用法**|**语法模式**|**核心思想**|
|**定义变量**|`(define 变量 值)`|将一个**名字**绑定到一个**数据值**。|
|**定义函数**|`(define (函数名 参数...) 函数体)`|将一个**名字**绑定到一个**过程值 (procedure)**。|

总而言之，`define` 的工作只有一个：**建立“名字”和“值”之间的关联**。函数在 Scheme 中也是一种值，因此定义函数只是定义变量的一个特例，只不过 Scheme 为此提供了更方便的“语法糖”。
