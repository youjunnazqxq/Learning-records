在 Scheme 中，`let` 的核心功能是创建**局部变量**，这些变量只在一段特定的代码区域内有效。

### 基本用法 `let`

它的作用是在一个临时的“盒子”里定义变量，在盒子内部使用它们，然后当代码离开盒子时，这些变量就消失了。

**语法结构：**

Scheme

```
(let ((变量1 值1)
      (变量2 值2))
  ; ... 主体代码 ...
  ; 在这里可以使用 变量1 和 变量2
  )
```

**最关键的规则：**

`let` 在绑定变量时有一个特点：所有右侧的 `值` 会**首先**在 `let` **外部**的环境中被一次性计算好，然后才将这些结果绑定给左侧的新变量。

这意味着，在绑定列表中，一个变量的定义**不能**使用同一个 `let` 中正在定义的其他变量。

**示例：**

Scheme

```
(define x 5)

(let ((x 10)         ; 准备将 x 绑定为 10
      (y (+ x 1)))  ; 计算 y 的值时，使用的是外部的 x (值为5)，而不是上面那个 10
  y)               ; -> 因此 y 的值是 5 + 1 = 6
```
注意，let表达式只有最后一个会被返回，其他不会

### `let` 的变体：`let*` 和 `letrec`

为了应对 `let` 的限制，Scheme 提供了两个有用的变体：

#### 1. `let*` (顺序绑定)

`let*` 允许你**按顺序**定义变量，后面的变量**可以**使用前面刚刚定义好的变量。

**示例：**

Scheme

```
(define x 5)

(let* ((x 10)        ; 首先，将 x 绑定为 10
       (y (+ x 1))) ; 然后，计算 y 的值时，使用的是这个 let* 内部刚刚定义的 x (值为10)
  y)                ; -> 因此 y 的值是 10 + 1 = 11
```

#### 2. `letrec` (递归绑定)

`letrec` 主要用于在局部定义一个或多个**可以相互调用（递归）的函数**。

**用途：** 当你想创建一个只在局部使用的辅助递归函数时，`letrec` 是最佳选择。

### 总结对比

|   |   |   |
|---|---|---|
|**特殊形式**|**主要用途**|**变量绑定规则**|
|**`let`**|创建基本的局部变量|所有变量的值**同时**在外部环境中计算，然后绑定。|
|**`let*`**|创建相互依赖的局部变量|变量**按顺序**依次绑定，后者可以依赖前者。|
|**`letrec`**|创建局部的、可相互递归的函数|用于函数之间的循环引用。|
