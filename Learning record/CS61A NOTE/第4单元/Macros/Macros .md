### Scheme 宏语法笔记

#### 1. 宏的核心概念

- **功能**：在程序**编译阶段**（或称**宏展开阶段**）对代码进行转换。
    
- **输入**：一段代码（S-表达式模板）。
    
- **输出**：另一段新的代码（S-表达式）。
    
- **目的**：创建自定义语法、自动化代码生成、提高代码复用性。
    
- **与函数区别**：函数在**运行时**执行，处理**数据**；宏在**编译时**展开，处理**代码**。
    

#### 2. 宏定义 (`define-syntax`)

这是定义宏最基本的方式。

**基本语法：**

Scheme

```
(define-syntax 宏名称
  (syntax-rules ()
    [(宏名称 参数1 参数2 ...)
     宏的展开模板]))
```

- **`define-syntax`**：定义一个语法规则（宏）。
    
- **`宏名称`**：你给宏起的名字。
    
- **`syntax-rules`**：这是定义宏规则的特殊形式。它后面跟着一个“关键字列表”和多个“规则”。
    
- **`()`**：这个空括号表示“关键字列表”。在最简单的宏中，这个列表是空的。
    
- **`[(宏名称 参数1 参数2 ...)`**：这是宏的**匹配模式**。它描述了你调用宏时代码应该是什么样子。
    
    - `宏名称` 必须与 `define-syntax` 后面的名称一致。
        
    - `参数1`, `参数2` 等是**模式变量**，用来匹配传入宏的参数。
        
- **`宏的展开模板`**：这是宏展开后生成的代码。
    

#### 3. 宏展开模板的核心工具

宏展开模板中会用到Lisp家族特有的**准引用（Quasiquotation）**系统。

|符号|名称|作用|示例|
|---|---|---|---|
|**`'`**|**引用 (Quote)**|**阻止求值**。将后面的S-表达式视为字面数据。|`'(+ 1 2)` 结果是列表 `(+ 1 2)`，不是3。|
|**`` ` ``**|**准引用 (Quasiquote)**|**模板化**。将S-表达式视为模板。大部分内容保持不变，但允许部分代码被求值或插入。|(a b c) `展开为` (a b c) `|
|**`,@`**|**拼接反引用 (Unquote-splicing)**|**在准引用内部求值并拼接**。将后面的表达式**求值**后，把结果列表中的元素**拆开并插入**到模板中。|`(define xs '(1 2))` <br> (a b ,@xs c) `<br> **展开为**` (a b 1 2 c) `|

#### 4. 示例：用 `syntax-rules` 定义一个简单的宏

示例1：when 宏

该宏实现了一个简单的条件分支，当条件为真时执行一段代码。

Scheme

```
(define-syntax when
  (syntax-rules ()
    [(when test body ...)    ; 匹配模式：when 后面跟着一个 test 和一些 body
     (if test               ; 展开模板：使用 if
       (begin body ...)     ; 如果 test 为真，执行 body 序列
       #f)]))               ; 否则，返回 #f
```

**使用方式：**

Scheme

```
(define x 10)
(when (> x 5)
  (display "x is greater than 5")
  (newline))
; -> 输出 "x is greater than 5"
```

**展开过程：** `(when (> x 5) ...)` 在编译时被展开成 `(if (> x 5) (begin (display "x is greater than 5") (newline)) #f)`。

示例2：square-expr 宏

这是你提供的例子。

Scheme

```
(define-syntax square-expr
  (syntax-rules ()
    [(square-expr term)    ; 匹配模式：square-expr 后面跟着一个 term
     `(* ,term ,term)]))   ; 展开模板：使用准引用生成代码
```

**使用方式：**

Scheme

```
`(+ ,(square-expr 'a) ,(square-expr 'b))
; 在宏展开阶段，会变成 `(+ (* 'a 'a) (* 'b 'b))`
```

#### 5. 模式变量 `...`

- `...` 称为**省略号**，用于匹配0个或多个表达式。
    
- 它在匹配模式中出现，表示前面的模式变量可以重复。
    
- 在展开模板中，它表示匹配到的所有重复部分都会被插入。
    

示例：sum-up 宏

该宏可以对任意数量的参数求和。

Scheme

```
(define-syntax sum-up
  (syntax-rules ()
    [(sum-up arg ...)       ; 匹配模式：匹配一个或多个 arg
     `(+ arg ...)]))        ; 展开模板：将所有 arg 放入一个 + 表达式中
```

**使用方式：**

Scheme

```
(sum-up 1 2 3 4)
; -> 展开为 (+ 1 2 3 4)
; -> 求值为 10
```

这就是Scheme宏语法的核心部分。理解**匹配模式**和**展开模板**，以及**准引用**、**反引用**和**拼接反引用**这三个符号，是掌握Scheme宏的关键。
