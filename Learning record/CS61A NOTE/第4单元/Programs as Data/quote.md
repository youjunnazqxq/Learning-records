### **引用 (Quote)**

- **语法**: `'(... an expression ...)` 或 `(quote ... an expression ...)`
- **作用**: **完全阻止**其后表达式的求值（Evaluation）。它将代码原封不动地当作**字面数据**（通常是列表）返回。
- **核心思想**: “你看到的就是你得到的”。它告诉解释器：“不要执行这里面的任何东西，把它本身给我。”

---

### **准引用 (Quasiquote) 与反引用 (Unquote)**

这是构建代码模板的强大工具，常用于宏和代码生成。

- **准引用 (Quasiquote)**
    
    - **语法**: `` `(... an expression ...) `` 或 `(quasiquote ... an expression ...)`
    - **作用**: 像 `quote` 一样，它也阻止其后表达式的求值，将其视为一个**数据模板**。
- **反引用 (Unquote)**
    
    - **语法**: `,(... an expression ...)` 或 `(unquote ... an expression ...)`
    - **作用**: 只能在**准引用 (`` ` ``) 的模板内部**使用。它的作用是“打一个洞”，让其后的表达式**被求值**，然后将结果**填充**回模板中。
- **反引用-拼接 (Unquote-Splicing)**
    
    - **语法**: `,@(... an expression ...)` 或 `(unquote-splicing ... an expression ...)`
    - **作用**: 与 `,` 类似，也只能在准引用内部使用。但它要求其后的表达式求值结果必须是一个**列表**。然后，它会把这个列表“剥开”，将其中的所有元素直接**拼接**到外层模板中，而不是作为单个列表项插入。

### **核心区别总结**

|            |         |                                                      |
| ---------- | ------- | ---------------------------------------------------- |
| **命令**     | **语法**  | **功能**                                               |
| **引用**     | `'`     | **完全冻结**：所有内容都变成字面数据，不做任何计算。                         |
| **准引用**    | `` ` `` | **建立模板**：大部分内容是字面数据，但为反引用留出空间。                       |
| **反引用**    | `,`     | **求值并插入**：在 `` ` `` 模板中，计算表达式并将结果作为**单个元素**插入。       |
| **反引用-拼接** | `,@`    | **求值并展开插入**：在 `` ` `` 模板中，计算一个列表，并将其**所有元素**平铺展开后插入。 |
