### SQL 语法核心笔记

#### 1. `SELECT` (选择)

- **作用**：从数据库中**查询**数据。
    
- **基础语法**：`SELECT [列名/表达式] FROM [表名];`
    
- **核心点**：
    
    - **临时结果**：`SELECT` 查询的结果是**临时**的，只显示给用户，不保存。
        
    - **别名（`AS`）**：`SELECT 表达式 AS 列名`，给查询结果的列起一个别名，让结果更易读。
        
    - **字面量选择**：`SELECT "值"`，可以直接选择字面量，生成一个**单行**结果。
        

#### 2. `UNION` (合并)

- **作用**：将多个 `SELECT` 查询的结果**合并**成一个结果集。
    
- **语法**：`[SELECT 语句1] UNION [SELECT 语句2] ...`
    
- **核心点**：
    
    - **行合并**：把第二个查询的行追加到第一个查询的行后面。
        
    - **自动去重**：`UNION` 默认会**移除所有重复的行**。
        
    - **列数匹配**：所有参与 `UNION` 的 `SELECT` 语句必须有**相同数量的列**。
        
    - **数据类型兼容**：对应位置的列的数据类型必须兼容。
        

#### 3. `UNION ALL` (全部合并)

- **作用**：和 `UNION` 类似，但**保留所有重复行**。
    
- **语法**：`[SELECT 语句1] UNION ALL [SELECT 语句2] ...`
    
- **核心点**：
    
    - **不去重**：即使行完全相同，也会全部保留。
        
    - **性能更快**：因为它省去了去重这一步。
        

#### 4. `CREATE TABLE ... AS ...` (创建并保存)

- **作用**：将一个 `SELECT` 查询的**临时结果**永久地**保存**为一个新的表。
    
- **语法**：`CREATE TABLE [新表名] AS [SELECT 语句];`
    
- **核心点**：
    
    - **持久化**：将临时查询结果转为**永久表**，可以被后续查询引用。
        
    - **列名继承**：新表的列名和数据类型由 `SELECT` 语句决定。
        
    - **常见用途**：
        
        - 从现有数据中创建新表。
            
        - 手动构建表格（如图片所示，用 `SELECT` 和 `UNION` 组合字面量）。
