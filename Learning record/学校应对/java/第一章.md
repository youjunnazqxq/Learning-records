### Java 第一章：Java 基础与入门笔记

#### 1. Java 开发环境与基础概念

_(来源：PPT 提取关键词)_

- **Java 版本体系**：Java 经历了从 1.1 到 1.7 等版本的迭代，核心平台称为 **Java SE** (Standard Edition) 1。
    
- **环境配置 (关键环境变量)**：
    
    - **Path**：指定操作系统查找可执行文件（如编译器 `javac` 和解释器 `java`）的路径 2。
        
    - **ClassPath**：指定 Java 虚拟机 (JVM) 查找类文件 (`.class`) 的路径 3。
        
- **JDK (Java Development Kit)**：Java 开发工具包，包含开发 Java 程序所需的工具和库（PPT中提到了 JDK1.6）4。
    

#### 2. Java 源文件 (.java) 的命名规则 **(重点)**

(来源：图片 image_0cf6e9.png)

编写 Java 源代码时，文件名必须严格遵循以下规则：

- **扩展名**：必须是 `.java`。
    
- **含有 public 类时**：
    
    - 如果源文件中包含一个 `public` 类（例如 `public class Hello`），那么**源文件名必须与该 public 类的名字完全相同**（包括大小写）。
        
    - **限制**：一个源文件中**只能有一个** `public` 类。
        
- **没有 public 类时**：
    
    - 如果源文件中没有 `public` 类，**源文件名只要和文件中的任意一个类的名字相同即可**。
        

#### 3. Java 程序的代码结构

_(来源：例1_1.txt, 例.txt)_

- **类的定义**：
    
    - Java 程序的基本单位是**类 (class)**。
        
    - 一个源文件可以包含多个类。例如 `例1_1.txt` 中同时包含了 `class A`、`class B` 和 `public class Hello` 5。
        
- **程序入口 (main 方法)**：
    
    - Java 应用程序从 `main` 方法开始执行。
        
    - **标准格式**（必须背诵）：
        
        Java
        
        ```
        public static void main(String args[])
        ```
        
        或者
        
        Java
        
        ```
        public static void main(String[] args)
        ```
        
        _(注：args 是参数名，可以改变，但通常习惯用 args)_ 666。
        

#### 4. 面向对象编程初步

_(来源：例.txt - Tom 类与 Example 类)_

- **定义类成员**：
    
    - **成员变量（属性）**：描述对象的特征。
        
        - 例如：`int leg;` (腿的数量), `String head;` (头的描述) 7。
            
    - **成员方法（行为）**：描述对象能做什么。
        
        - 例如：`void cry(String s) { ... }` 8。
            
- **使用对象**：
    
    1. **声明对象**：`Tom cat;` (声明一个 Tom 类型的变量 cat) 9。
        
    2. **创建对象 (实例化)**：`cat = new Tom();` (使用 `new` 关键字为对象分配内存) 10。
        
        - 也可以合并写为：`Tom cat = new Tom();`。
            
    3. **访问成员**：使用点运算符 `.`。
        
        - 访问属性：`cat.leg = 4;` 11。
            
        - 调用方法：`cat.cry("我今天要和Jerry拼了");` 12。
            

#### 5. 基本输入输出

- **输出语句**：
    
    - `System.out.println("内容");`：在控制台输出内容并换行。
        
    - 支持字符串拼接，例如：`System.out.println("腿:" + cat.leg + "条");` 13。

Java 程序的执行分为两步：**编译 (Compile)** 和 **运行 (Run)**。

- **Step 1：编写源文件**
    
    - 文件后缀：`.java`
        
    - 内容：符合语法的 Java 源代码。
        
- **Step 2：编译 (Compilation)**
    
    - **工具/命令**：`javac` (Java Compiler)
        
    - **操作对象**：**源文件名** (需要带后缀 `.java`)
        
    - **作用**：检查语法错误，将源代码翻译成**字节码 (Bytecode)**。
        
    - **生成文件**：`.class` 文件 (与源文件中的类名对应)。
        
    - **命令示例**：`javac Hello.java`
        
- **Step 3：运行 (Execution)**
    
    - **工具/命令**：`java` (Java Interpreter / Launcher)
        
    - **操作对象**：**类名** (千万**不能**带后缀 `.class`，也不能带 `.java`)
        
    - **作用**：启动 Java 虚拟机 (JVM)，加载字节码文件，解释并执行。
        
    - **命令示例**：`java Hello`

### ✅ 答案与解析

**1. 答案：B**

- **解析**：根据源文件命名规则，如果文件中包含 `public` 类，文件名**必须**与该 `public` 类的名字**完全相同**（包括大小写）。
    

**2. 答案：C**

- **解析**：`new` 关键字用于实例化对象并分配内存，如 `cat = new Tom();` 5。
    

**3. 答案：D**

- **解析**：标准格式必须包含 `public`（公开）、`static`（静态）、`void`（无返回值）以及字符串数组参数 `String args[]` 6。
    

**4. 答案：B**

- **解析**：`Path` 用于查找可执行命令（如 javac.exe），而 `ClassPath` 用于查找类文件（.class）7。
    

**5. 答案：错**

- **解析**：必须是**相同**，而不是**相似**。Java 严格区分大小写，如果类名是 `Cat`，文件名必须是 `Cat.java`，不能是 `cat.java`。
    

**6. 答案：对**

- **解析**：Java 的跨平台特性依赖于 JVM 对字节码的解释执行。
    

7. 答案：

(1) javac, javac

(2) Hello.class

(3) java, java

- **解析**：编译用 `javac` 带后缀，生成 `.class`；运行用 `java` 不带后缀。
    

**8. 答案：错误**

- **解析**：`Tom cat;` 只是声明了一个引用变量，并没有分配内存空间。必须先使用 `cat = new Tom();` 进行实例化后，才能访问其成员变量 `cat.leg`，否则会报错（空指针异常或未初始化错误）8。
