

#### 1. Java 的 8 种基本数据类型

Java 是一门强类型语言，共有 8 种原始数据类型，通常分为四类：

- **逻辑类型**：`boolean` (值只有 `true` 或 `false`)。
    
- **整数类型**：
    
    - `byte` (1字节, -128 到 127)
        
    - `short` (2字节)
        
    - `int` (4字节，**整数默认为 int 类型**)
        
    - `long` (8字节，定义时若超过 int 范围需在数字后加 `L` 或 `l`，如 `long a = 12345678900L;`)
        
- **字符类型**：`char` (2字节，使用 Unicode 编码，用单引号 `'a'` 表示)。
    
- **浮点类型**：
    
    - `float` (4字节，单精度，**定义时必须加 `F` 或 `f`**，如 `float f = 3.14f;`，否则会被默认为 double 报错)
        
    - `double` (8字节，双精度，**浮点数默认为 double 类型**)
        

#### 2. 基本数据类型的转换

- **自动类型转换（低精度 -> 高精度）**：
    
    - 顺序：`byte`, `short`, `char` -> `int` -> `long` -> `float` -> `double`。
        
    - 例如：`int i = 10; double d = i;` (自动变为 10.0)。
        
- **强制类型转换（高精度 -> 低精度）**：
    
    - 格式：`(类型名) 要转换的值`。
        
    - 风险：可能会导致精度损失或数据溢出。
        
    - 例如：`float f = 3.14f; int i = (int)f;` (i 的结果为 3)。
        

#### 3. 数据的输入与输出 (课件特别提及)

根据课件末尾出现的关键词 `Scanner` 和 `System.out.printf` ，这是本章的重点操作技能：

- **输入 (Scanner 类)**：
    
    - 需要导入：`import java.util.Scanner;`
        
    - 创建对象：`Scanner reader = new Scanner(System.in);`
        
    - 读取方法：`reader.nextInt()`, `reader.nextDouble()`, `reader.next()` 等。
        
- **格式化输出 (printf)**：
    
    - 使用 `System.out.printf` 进行类似于 C 语言的格式化输出。
        
    - 常用格式符：`%d` (整数), `%f` (浮点数), `%c` (字符), `%s` (字符串), `%b` (布尔)。

### 什么是 Unicode？

- **背景**：在计算机早期，不同国家使用不同的编码标准（如美国的 ASCII、中国的 GBK）。这导致同一个文件在不同语言的系统上打开时会出现乱码。
    
- **定义**：Unicode 是为了解决乱码问题而诞生的**国际标准编码**。它为世界上几乎所有的字符（包括中文、英文、日文、Emoji 表情等）都分配了一个唯一的数字编号。
    
- **作用**：实现了“一种编码，走遍天下”。
    

### 2. Unicode 与 Java 的关系

在您刚才学习的《第2章 基本数据类型》中，这个知识点通常体现在 `char` 类型上：

- **Java 的 char 本质**：Java 中的 `char` 类型占用 **2个字节**（16位）。
    
- **取值范围**：`0` ~ `65535`（即 `\u0000` ~ `\uFFFF`）。
    
- **特点**：因为使用了 Unicode，**Java 的 `char` 可以直接存储一个中文字符**。
    
    - 例如：`char c = '中';` 是合法的，因为在 Unicode 中，“中”字占用的空间（通常视为2字节逻辑单位）可以被容纳。
        
    - 相比之下，在 C 语言等使用 ASCII 的传统环境中，一个 `char` 只有1字节，存不下汉字。
