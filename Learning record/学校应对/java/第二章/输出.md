### 核心知识点：Java 的三种输出方式

#### 1. `System.out.println()` (换行输出)

这是最常用的输出方式。

- **特点**：输出内容后，**自动换行**（光标移动到下一行开头）。
    
- **用法**：
    
    Java
    
    ```
    System.out.println("Hello");
    System.out.println("World");
    // 输出结果：
    // Hello
    // World
    ```
    
- **考点**：即使括号内没有任何内容 `System.out.println();`，它也会输出一个换行符。
    

#### 2. `System.out.print()` (不换行输出)

- **特点**：输出内容后，光标**停留在同一行**的末尾，不会自动换行。
    
- **用法**：
    
    Java
    
    ```
    System.out.print("Hello");
    System.out.print("World");
    // 输出结果：HelloWorld
    ```
    
- **注意**：括号内必须有内容，不能像 `println` 那样留空（除非编译器特定优化，一般要求有参数）。
    

#### 3. `System.out.printf()` (格式化输出)

这是课件中特别提及的知识点 2，用法与 C 语言的 `printf` 非常相似。

- **特点**：用于控制输出格式，不会自动换行。
    
- **场景**：保留小数点后两位、对齐文本、输出特定格式的日期等。
    
- **格式**：`System.out.printf("格式字符串", 变量1, 变量2...);`
    
- **常用占位符**：
    
    - `%d`: 整数 (int, long 等)
        
    - `%f`: 浮点数 (float, double) —— **常考点**：`%.2f` 表示保留两位小数。
        
    - `%s`: 字符串
        
    - `%c`: 字符
        
    - `%b`: 布尔值
        
- **示例**：
    
    Java
    
    ```
    double pi = 3.1415926;
    System.out.printf("圆周率保留两位小数：%.2f", pi);
    // 输出结果：圆周率保留两位小数：3.14
    ```
