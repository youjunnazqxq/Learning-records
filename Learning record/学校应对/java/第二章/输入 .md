根据您的课件《第2章 基本数据类型和数组.ppt》中的关键词 `Scanner` 1，**`Scanner` 类**是 Java 中用于获取控制台输入最核心的工具。

以下是关于 Java 输入（Input）的详细知识点总结：

### 核心知识点：使用 Scanner 类

#### 1. 基本步骤 (三部曲)

要在 Java 中读取输入，必须遵循以下三个步骤：

- 第一步：导包 (Import)
    
    Scanner 类不在 java.lang 包中（只有 java.lang 是自动导入的），它位于 java.util 包中，所以必须显式导入。
    
    Java
    
    ```
    import java.util.Scanner; // 必须写在代码文件的最开头
    ```
    
- 第二步：创建对象
    
    你需要创建一个 Scanner 对象来监听键盘（System.in 代表标准输入流，即键盘）。
    
    Java
    
    ```
    Scanner reader = new Scanner(System.in);
    ```
    
- 第三步：接收数据
    
    根据你想读取的数据类型，调用不同的方法。
    

#### 2. 常用读取方法

|**目标数据类型**|**方法名**|**说明**|
|---|---|---|
|**整数 (int)**|`reader.nextInt()`|读取下一个整数，**忽略**前面的空白（空格、换行）。|
|**浮点数 (double)**|`reader.nextDouble()`|读取下一个浮点数。|
|**字符串 (单词)**|`reader.next()`|读取字符串，**遇到空格或换行符停止**（读不到带空格的句子）。|
|**字符串 (整行)**|`reader.nextLine()`|读取**整行**文本，包括空格，直到按下回车键。|

#### 3. 代码示例

Java

```
import java.util.Scanner;

public class InputDemo {
    public static void main(String[] args) {
        Scanner scan = new Scanner(System.in);

        System.out.println("请输入你的年龄：");
        int age = scan.nextInt(); // 输入 18 并回车

        System.out.println("请输入你的名字：");
        String name = scan.next(); // 输入 "ZhangSan"

        System.out.println("收到：" + name + "，" + age + "岁");
        
        // scan.close(); // 好习惯：用完关闭，但在简单的控制台程序中常被省略
    }
}
```

### 🚨 必考难点：`nextLine()` 的“吞车符”问题

这是一个 90% 的初学者都会遇到的坑。

- **场景**：当你先调用了 `nextInt()`，紧接着调用 `nextLine()`。
    
- **现象**：程序似乎**跳过了** `nextLine()` 的输入，直接结束了。
    
- **原因**：
    
    1. 你输入数字 `18` 并按下**回车**。
        
    2. `nextInt()` 只拿走了数字 `18`，但**回车符（`\n`）还留在缓冲区里**。
        
    3. 随后的 `nextLine()` 一执行，立刻读到了这个留下的回车符，它认为“哦，你已经输入了一行空行”，于是直接结束读取。
        
- 解决方法：
    
    在 nextInt() 和 nextLine() 之间，多加一句 scan.nextLine(); 专门用来吃掉那个回车符。
