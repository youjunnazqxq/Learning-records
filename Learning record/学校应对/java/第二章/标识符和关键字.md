#### 标识符 (Identifiers)

标识符是用来给类、方法、变量等命名的字符序列。

- **命名规则（强制）：**
    
    - 由**字母**（a-z, A-Z）、**数字**（0-9）、**下划线**（_）或**美元符号**（$）组成。
        
    - **不能以数字开头**。
        
    - **不能是 Java 的关键字**（如 `class`, `int`）或保留字（如 `true`, `false`, `null`）。
        
    - **区分大小写**（例如 `myVar` 和 `MyVar` 是两个不同的标识符）。
        
- **命名规范（约定）：**
    
    - **类名**：使用大驼峰命名法（PascalCase），首字母大写，如 `HelloWorld`。
        
    - **方法名/变量名**：使用小驼峰命名法（camelCase），首字母小写，后续单词首字母大写，如 `studentName`, `getAge`。
        
    - **常量**：全部大写，单词间用下划线分隔，如 `MAX_VALUE`。
        

#### 2. 关键字 (Keywords)

关键字是 Java 语言赋予了特殊含义的单词，**必须全部小写**。

- **常见关键字分类：**
    
    - **数据类型**：`int`, `double`, `boolean`, `char`, `void` 等。
        
    - **流程控制**：`if`, `else`, `for`, `while`, `switch`, `case`, `break`, `return` 等。
        
    - **访问修饰符**：`public`, `private`, `protected`。
        
    - **类与对象**：`class`, `interface`, `extends`, `implements`, `new`, `this`, `super`, `static` 等。
        
- **注意**：`goto` 和 `const` 是保留字，但在 Java 中目前未使用；`true`, `false`, `null` 是字面量，虽然有特殊含义，但在技术定义上不算关键字，不过同样不能用作标识符。

在 Java（以及大多数编程语言）中，**标识符绝对不能以数字开头**。

这是为了让编译器能够区分**数字字面量**（如 `123`）和**标识符**。如果允许标识符以数字开头，编译器在解析像 `123L` 这样的代码时，就会混淆它是代表长整型数字 `123`，还是一个名为 `123L` 的变量。
