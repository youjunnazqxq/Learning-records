这在 Java 中被称为 **字符串连接（String Concatenation）**。

### 1. 核心规则

- 只要 `+` 号的**任意一侧**是字符串（String），系统就会自动将另一侧的数据也转换为字符串，然后将它们拼接到一起。
    
- **语法**：`"文本内容" + 变量名`
    

### 2. 代码示例

#### 基础用法

Java

```
String name = "张三";
int age = 18;

// 拼接字符串和变量
System.out.println("姓名：" + name);          // 输出：姓名：张三
System.out.println("年龄：" + age + " 岁");   // 输出：年龄：18 岁
```

#### 常见陷阱（必考点！）

这是新手最容易混淆的地方：**`+` 号既表示“拼接”，也表示数学运算的“加法”。** 它的执行顺序是从左到右。

- **情况 A：字符串在前面**
    
    Java
    
    ```
    // 系统先看到字符串，所以后面的数字都被当成字符拼接
    System.out.println("结果：" + 1 + 2); 
    // 输出：结果：12  (不是3！)
    ```
    
- **情况 B：数字在前面**
    
    Java
    
    ```
    // 系统先看到两个数字，先做加法，然后再拼接字符串
    System.out.println(1 + 2 + "结果"); 
    // 输出：3结果
    ```
    
- **如何解决情况 A？** (使用括号改变优先级)
    
    Java
    
    ```
    System.out.println("结果：" + (1 + 2)); 
    // 输出：结果：3
    ```
    

---

### 3. 三种输出方式对比总结

为了帮您理清思路，看看它们在连接变量时的区别：

|**输出方式**|**连接符号**|**示例**|**特点**|
|---|---|---|---|
|**print / println**|**`+` (加号)**|`println("年龄:" + age)`|简单直观，但变量多时拼接比较乱。|
|**printf**|**`,` (逗号)**|`printf("年龄:%d", age)`|像填空题，使用占位符，格式整齐。|
