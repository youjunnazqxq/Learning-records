### 核心知识点梳理：数组 (Arrays)

#### 1. 数组的定义与声明

- **概念**：数组是一种**引用数据类型**（Reference Type），它是相同类型数据的有序集合。
    
- **声明格式**：
    
    - 格式 1（推荐）：`数据类型[] 数组名;` （例如：`int[] scores;`）
        
    - 格式 2（C 语言风格）：`数据类型 数组名[];` （例如：`int scores[];`）
        

#### 2. 数组的创建与初始化

- **动态初始化**（指定长度）：
    
    - `int[] arr = new int[5];`
        
    - **注意**：创建后，数组元素会有**默认值**（int 为 0，double 为 0.0，boolean 为 false，对象为 null）。
        
- **静态初始化**（指定内容）：
    
    - `int[] arr = {1, 2, 3, 4, 5};`
        
    - 或者 `int[] arr = new int[]{1, 2, 3};`
        

#### 3. 数组的访问与长度 (重点)

- **下标 (Index)**：数组的索引从 **0** 开始，到 `数组长度 - 1` 结束。
    
- **长度属性**：使用 `数组名.length` 获取数组的长度。
    
    - **易错点**：数组的 `length` 是**属性**，不是方法（没有括号）；而 String 的 `length()` 是方法。
        
- **常见异常**：
    
    - `ArrayIndexOutOfBoundsException`：数组下标越界异常（访问了不存在的索引）。
        
    - `NullPointerException`：空指针异常（数组未初始化就使用）。
        

#### 4. 数组在内存中的存储

- **栈 (Stack)**：存储数组的**引用**（即变量名，指向堆中的地址）。
    
- **堆 (Heap)**：存储数组**对象**（即实际的数据元素）。
    
- **引用模型**：两个数组变量可以指向同一个堆内存地址。
    
    - 例如：`int[] a = {1, 2}; int[] b = a;` 修改 `b[0]` 也会影响 `a[0]`。

### 核心知识点：二维数组的创建

#### 1. 动态初始化（规则形状）

这是最常见的创建方式，用于创建一个“矩形”或“表格”形状的数组。

- **语法**：`数据类型[][] 数组名 = new 数据类型[行数][列数];`
    
- **示例**：
    
    Java
    
    ```
    // 创建一个 3 行 4 列的整型数组
    int[][] matrix = new int[3][4];
    ```
    
- **内存状态**：所有元素被初始化为默认值（如 `int` 为 0）。
    
- **理解**：可以把它想象成一个 3x4 的 Excel 表格。
    

#### 2. 静态初始化（已知内容）

如果你已经知道数组中具体要存什么数据，可以直接列出来。

- **语法**：`数据类型[][] 数组名 = {{值1, 值2}, {值3, 值4}, ...};`
    
- **示例**：
    
    Java
    
    ```
    int[][] scores = {
        {90, 85, 88},  // 第0行
        {76, 80, 82}   // 第1行
    };
    ```
    
- **注意**：大括号的层级必须匹配。
    

#### 3. 动态初始化（不规则形状/锯齿数组）

这是 Java 的一个特色考点。因为二维数组是“数组的数组”，所以**每一行的列数可以不同**。

- **语法**：
    
    1. 先指定行数（列数留空）：`new 数据类型[行数][];`
        
    2. 再单独为每一行创建数组。
        
- **示例**：
    
    Java
    
    ```
    // 1. 先声明有 3 行，但不知道每一行有多长
    int[][] jagged = new int[3][]; 
    
    // 2. 分别初始化每一行
    jagged[0] = new int[2]; // 第0行有2个元素
    jagged[1] = new int[5]; // 第1行有5个元素
    jagged[2] = new int[3]; // 第2行有3个元素
    ```
    
- **关键考点**：**声明时，第一维（行）的长度必须指定，但第二维（列）的长度可以留空。** 写成 `new int[][4]` 是**非法**的。
