### **基于 PPT 的核心讲解：类的构造方法**

构造方法是类中一种特殊的方法，主要用于**创建对象**时进行**初始化**操作（给成员变量赋初值）。

#### **1. 核心注意点 (Key Points)**

- **名称规定**：构造方法的名字**必须与类名完全相同**。
    
- **无返回值**：构造方法**没有返回值类型**，甚至连 `void` 都不能写。
    
    - ✅ `class A { A() {...} }`
        
    - ❌ `class A { void A() {...} }` （写了 `void` 就变成普通方法了，不再是构造方法）
        
- **调用方式**：构造方法不能像普通方法那样被对象直接调用（`obj.method()`），它只能在**使用 `new` 关键字**创建对象时被系统自动调用。
    
    - 例如：`A a = new A();` 这里 `A()` 就是在调用构造方法。
        
- **默认构造方法**：
    
    - 如果您在类中**没有定义任何构造方法**，Java 系统会默认赠送一个**无参数的构造方法**（方法体为空）。
        
    - **重要**：一旦您定义了**任何一个**构造方法（哪怕是有参数的），系统就**不再赠送**那个默认的无参构造方法了。如果此时还需要无参构造，必须自己显式写出来。
        
- **构造方法的重载 (Overloading)**：
    
    - 一个类可以有多个构造方法，只要它们的**参数列表不同**（参数个数、类型或顺序不同）。这允许我们用不同的方式来初始化对象。
