
### 1. `static` 的核心逻辑：独乐乐 vs 众乐乐

为了理解 `static`，我们用**“班级”**来做比喻：

- **实例变量 (无 static)**：比如 **“名字”**。
    
    - 每个学生都有自己的名字，你的名字叫“小明”，他的名字叫“小红”。**互不干扰**。
        
    - 必须 `new` 出一个学生对象，才能有名字。
        
- **静态变量 (有 static)**：比如 **“教室里的饮水机”**。
    
    - 它是**属于整个班级**的，大家共用这一台。
        
    - 如果小明把饮水机的水喝干了，小红去接水时，水也是干的（**一处修改，处处受影响**）。
        
    - **不需要** `new` 学生，饮水机就在那里了。
        

### 2. `static` 的三大用法

#### ① 修饰变量：全类共享

- **学名**：类变量（Class Variable）。
    
- **特点**：无论创建多少个对象，内存中只有一份。
    
- **调用**：建议使用 `类名.变量名`（虽然用对象也能调，但不推荐，容易误导）。
    

Java

```
class Student {
    String name;          // 实例变量：每人一份
    static String school; // 静态变量：大家共用同一个学校
}

Student.school = "清华大学"; // 直接用类名赋值
```

#### ② 修饰方法：工具人

- **学名**：类方法（Class Method）。
    
- **特点**：**不需要创建对象就能直接调用**。通常用于编写“工具方法”。
    
- **典型例子**：`Math.sqrt()`，你从来不需要 `new Math()` 就能算开根号，因为它是 static 的。
    
- **入口**：Java 的 `main` 方法必须是 `static` 的，因为程序启动时还没有对象，虚拟机必须能直接调用它。
    

#### ③ 修饰代码块：初始化

- **形式**：`static { ... }`
    
- **特点**：类被加载时**只执行一次**。通常用于加载驱动、初始化复杂的静态数据。

### 3. ⚠️【死穴】考试最爱考的规则

这是 `static` 知识点里**最重要**的一条规则，请默念三遍：

> 静态方法中，只能访问静态成员！
> 
> （Static methods can ONLY access static members!）

- **原理**：
    
    - **静态**加载得很早（类加载时就有了）。
        
    - **非静态（实例）**加载得很晚（`new` 对象时才有的）。
        
    - 你不能在“老前辈”（静态方法）里去调用一个“还没出生”（非静态变量）的东西。
        

**代码错误示范**：

Java

```
class Test {
    int x = 10;        // 非静态变量
    static int y = 20; // 静态变量

    static void show() {
        System.out.println(y); // ✅ 静态调静态，没问题
        
        // System.out.println(x); 
        // ❌ 报错！静态方法里不能用非静态变量 x。
        // 因为调用 show() 时，可能连对象都没 new 出来，x 根本不存在。
        
        // System.out.println(this.x); 
        // ❌ 报错！静态方法里绝对不能出现 'this' 关键字。
    }
}
```
