既然您理解了构造方法，那么**方法重载（Method Overloading）**就非常好懂了。

构造方法可以有多个（带参的、无参的），这其实就是**构造方法的重载**。普通的成员方法（如 `void f()`）同样也可以“重载”。

简单来说，方法重载就是：**“同一个班级里，有好几个叫‘张三’的人，但他们的特征（参数）各不相同，所以老师（编译器）能分得清。”**

---

### 方法重载的核心注意点 (3个“必须” + 1个“无关”)

#### 1. 必须在同一个类中

重载是发生在一个类内部的事情。（或者是父子类继承关系中，子类增加了新的同名不同参方法）。

#### 2. 方法名必须相同

如果名字不同，那就叫两个完全不同的方法，不叫重载。

* `void eat()` 和 `void drink()` ——这叫两个方法。
* `void eat()` 和 `void eat(String food)` ——这叫重载。

#### 3. 参数列表必须不同（关键！）

这是区分它们的唯一标准。编译器只看参数来决定调用哪一个。
不同指以下三种情况之一：

* **个数不同**：`add(int a)` vs `add(int a, int b)`
* **类型不同**：`add(int a)` vs `add(double a)`
* **顺序不同**：`save(int a, String b)` vs `save(String b, int a)`

#### 4. ⚠️【死穴】与返回值类型无关

这是考试最大的**陷阱**！
**只改变返回值类型，不改变参数，不算重载，编译会报错。**

* ❌ **错误示范**：
```java
int getNum() { return 1; }
double getNum() { return 1.0; } 
// 报错！当你调用 getNum() 时，编译器不知道该用哪个。

```
