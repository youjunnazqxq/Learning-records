**方法重载 (Overloading)** 是 Java 中最基础但也容易忽视细节的特性。它的核心目的是**“方便调用者”**——用同一个方法名，处理不同类型的数据（比如 `System.out.println()` 既能打印 int 也能打印 String）。

虽然看似简单，但有 **3 个死规定** 和 **1 个核心本质** 必须注意，否则编译直接报错。

---

### 1. 核心铁律：参数列表必须不同

这是重载的**唯一**判断标准。只要方法名相同，参数列表必须由以下至少一项区别：

- **参数个数不同**：`add(int a)` vs `add(int a, int b)`
    
- **参数类型不同**：`add(int a)` vs `add(double a)`
    
- **参数顺序不同**：`add(int a, double b)` vs `add(double a, int b)`
    

**注意**：参数的**名字**不同（比如 `add(int a)` 和 `add(int b)`）是不算重载的！编译器只看类型，不看变量名。

---

### 2. 最大的坑：不能只改变返回值类型

这是面试中最常问的陷阱。

- **错误示例**：
    
    Java
    
    ```
    public int getNum() { return 1; }
    public double getNum() { return 1.0; } // ❌ 编译报错！
    ```
    
- 为什么不行？
    
    因为 Java 允许你调用方法时不接收返回值（例如直接写 getNum();）。
    
    这时候编译器会傻眼：“你只叫了 getNum，也没说要 int 还是 double，两个参数都为空，我该调哪一个？”
    
    为了避免这种歧义，Java 禁止仅通过返回值来区分重载。
    

---

### 3. 修饰符（public/private）无关紧要

- **规则**：仅仅改变访问权限（public/private/protected）或抛出的异常，**不构成**重载。
    
- **原因**：和返回值一样，编译器在调用时无法区分。
    
    Java
    
    ```
    private void test() {}
    public void test() {} // ❌ 报错：在类中已定义了方法 test()
    ```
    
    _当然，如果参数列表变了，那你返回值、修饰符随便怎么变都可以。_
    

---

### 4. 核心本质：它是“静态绑定”

结合你刚才学的知识，这点非常重要。

- **重写 (Override)**：是**运行时**决定的（看实际对象是谁）。
    
- **重载 (Overload)**：是**编译时**决定的（看引用类型和参数类型）。
    

编译器在编译代码的那一瞬间，就会根据你传入的参数（是 int 还是 String），直接把要调用的那个方法**“写死”**在字节码里。它不需要等到运行时候再去判断。

---

### ⚡️ 高级坑：基本类型自动提升

当传入的参数没有“完全匹配”的方法时，Java 会尝试“自动类型提升”来寻找最匹配的方法。

Java

```
public void method(int a) { System.out.println("int"); }
public void method(long a) { System.out.println("long"); }

// 调用：
method(5); // 匹配 int
// 假如我删掉了 method(int a)，只剩下 method(long a)
method(5); // ✅ 依然可以运行！5 会自动提升为 long，匹配 method(long)
```

**注意**：如果自动提升有多种路径导致歧义（Ambiguity），编译器会报错。

---

### 总结一张表：重写 vs 重载 (必背)

|**维度**|**重载 (Overload)**|**重写 (Override)**|
|---|---|---|
|**位置**|同一个类中 (或者父子类中)|必须在父子类之间|
|**方法名**|必须相同|必须相同|
|**参数列表**|**必须不同**|**必须相同**|
|**返回值**|无所谓|必须相同 (或由子类返回父类返回值的子类型)|
|**修饰符**|无所谓|子类不能比父类更严格 (父public，子不能private)|
|**绑定时期**|**编译期 (静态)**|**运行期 (动态)**|

一句话口诀：

重载看参数，重写看对象。
