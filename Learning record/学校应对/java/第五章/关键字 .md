### **一、 核心关键字详解**

#### **1. `super` (父类引用)**

- **含义**：代表当前对象中**父类特征**的那部分引用。
    
- **用途**：
    
    1. **访问父类成员**：当子类和父类有同名属性或方法时，用 `super.变量` 或 `super.方法()` 来区分。
        
    2. **调用父类构造器**：`super(参数)`，用于初始化父类成员。
        

#### **2. `this` (当前对象)**

- **含义**：代表**当前对象**的引用（谁调用这个方法，this 就是谁）。
    
- **用途**：
    
    1. **解决重名**：当局部变量（如参数）和成员变量同名时，用 `this.name = name` 来指定成员变量。
        
    2. **调用本类构造器**：`this(参数)`，用于构造方法之间的相互调用（代码复用）。
        

#### **3. `final` (最终的)**

- **含义**：不可改变的。
    
- **用途**：
    
    1. **修饰类**：不能被继承（断子绝孙），如 `String`、`System`。
        
    2. **修饰方法**：不能被重写（Override），但可以被继承使用。
        
    3. **修饰变量**：变成**常量**，只能赋值一次。
        

#### **4. `static` (静态的)**

- **含义**：属于**类**的，不属于对象。
    
- **用途**：实现资源共享（如 `static` 变量）或工具方法（如 `Math.random()`）。
    

---

### **二、 关键字使用的“高危”注意点**

1. **构造器里的“一山不容二虎”**
    
    - `super()` 和 `this()` 都强制要求必须放在构造方法的**第一行**。
        
    - **后果**：因此，在一个构造方法中，**不能同时出现** `super()` 和 `this()`。你只能二选一：要么调用父类构造，要么调用本类其他构造。
        
2. **`static` 方法里没有“我”和“父”**
    
    - 静态方法是属于类的，加载时还没有对象产生。
        
    - **后果**：在 `static` 方法（如 `main`）中，**绝对不能使用** `this` 或 `super` 关键字。编译器会直接报错：“Cannot use this in a static context”。
        
3. **`final` 修饰引用类型的陷阱**
    
    - `final Person p = new Person();`
        
    - **注意**：这表示 `p` 这个**引用地址**不能变（不能 `p = new Person()`），但是 `p` 指向的**对象内部的数据**是可以变的（可以 `p.age = 20`）。
        
    - **口诀**：`final` 管得了“人”，管不了“心”。
        
4. **`super` 不引用对象**
    
    - 虽然我们常说 `super` 代表父类，但它**不是一个对象的引用**（不像 `this` 可以打印出来）。你不能把 `super` 赋值给一个变量，也不能打印 `System.out.println(super)`。
