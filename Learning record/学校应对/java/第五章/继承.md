### **一、 继承 (Inheritance) 核心知识点**

从文件目录结构（5.1~5.10）及关键词推测，本章关于继承的内容主要包含以下几点：

1. **继承的概念与语法**
    
    - **定义**：继承是面向对象编程的三大特征之一，允许创建一个新类（子类/派生类）来继承现有类（父类/基类/超类）的属性和方法。
        
    - **关键字**：使用 `extends` 关键字。例如：`class Student extends Person { ... }`。
        
    - **作用**：实现代码复用，建立类之间的层次结构。
        
2. **`super` 关键字 (文件中提及 "5.5 Super")**
    
    - **调用父类构造方法**：在子类构造方法的首行，使用 `super()` 或 `super(参数)` 来调用父类的构造器。
        
    - **访问父类成员**：当子类和父类有同名成员变量或方法时，使用 `super.变量名` 或 `super.方法名()` 显式访问父类成员。
        
3. **方法重写 (Overriding)**
    
    - 子类可以对从父类继承来的方法进行重新实现，以体现子类的特有行为。
        
    - **规则**：方法名、参数列表、返回类型必须与父类一致（或返回类型为父类返回类型的子类）。
        
4. **`final` 关键字 (文件中提及 "5.6 final")**
    
    - **修饰类**：表示该类**不能被继承**（断子绝孙类，如 `String` 类）。
        
    - **修饰方法**：表示该方法**不能被子类重写**。
        
    - **修饰变量**：表示该变量是常量，一旦赋值**不能被修改**。
        
5. **访问修饰符 `protected` (文件中提及 "protected")**
    
    - `protected` 修饰的成员可以被**同一个包**中的类访问，也可以被**不同包中的子类**访问。它是专门为继承设计的权限修饰符。

### **二、 继承的注意点 (Attention Points)**

1. **单继承限制**：Java 中的类只支持**单继承**（即一个类只能有一个直接父类），但支持多层继承（A继承B，B继承C）。
    
2. **构造方法不被继承**：子类不能继承父类的构造方法，但必须在构造过程中调用父类的构造方法（若未显示调用，编译器默认插入 `super()`）。
    
3. **重写权限问题**：子类重写父类方法时，**访问权限不能比父类更严格**（例如：父类是 `public`，子类不能改成 `protected` 或 `private`）。
    
4. **`Object` 类**：所有的类都隐式地继承自 `java.lang.Object` 类，它是所有类的根父类。
