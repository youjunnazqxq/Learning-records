

### **一、 多态 (Polymorphism) 核心知识点**

1. **定义**
    
    - 多态是指同一个行为具有多个不同表现形式或形态的能力。
        
    - 在代码中的体现：**父类的引用指向子类的对象**。
        
    - **格式**：`父类类型 变量名 = new 子类类型();`
        
        - 例如：`Animal a = new Cat();`
            
2. **多态存在的三大前提**
    
    - **要有继承（或实现）关系**：如 `Cat extends Animal`。
        
    - **要有方法重写**：子类重写父类的方法（如 `eat()`）。
        
    - **要有父类引用指向子类对象**（向上转型）。
        
3. **多态的成员访问规则（口诀：重点！）**
    
    - **成员变量**：编译看左边（父类），运行看左边（父类）。
        
        - _解释：多态无法访问子类特有的成员变量。_
            
    - **成员方法**：编译看左边（父类），运行看右边（子类）。
        
        - _解释：这是多态的核心，执行的是子类重写后的逻辑（动态绑定）。_
            
    - **静态方法**：编译看左边（父类），运行看左边（父类）。
        
        - _解释：静态与类相关，不涉及对象的多态性。_
            
4. **转型技术**
    
    - **向上转型 (Upcasting)**：自动类型转换。`Animal a = new Cat();` 安全，但不能调用子类特有方法。
        
    - **向下转型 (Downcasting)**：强制类型转换。`Cat c = (Cat) a;` 用于调用子类特有方法。
        

---

### **二、 多态的注意点 (Attention Points)**

1. **“变量无多态”**：
    
    - 这是考试中最大的坑。如果父类和子类都有同名的成员变量 `name`，通过多态引用 `a.name` 取到的是**父类**的值，而不是子类的。
        
2. **类型转换异常 (`ClassCastException`)**：
    
    - 在进行向下转型时，如果把“狗”转成了“猫”，编译不报错，但运行会崩溃。
        
    - **解决方案**：使用 `instanceof` 关键字进行判断。
        
        Java
        
        ```
        if (a instanceof Cat) {
            Cat c = (Cat) a;
            c.catchMouse();
        }
        ```
        
3. **私有方法不能多态**：
    
    - `private` 方法不能被重写，因此通过父类引用调用时，根本无法访问子类的私有逻辑（实际上父类引用也无法直接访问私有方法，需通过公共接口）。
