### 一、 核心知识点 (Knowledge Points)

泛型的本质是 **“参数化类型” (Parameterized Type)**。即把数据类型像参数一样传递给类或方法。

#### 1. 为什么要用泛型？

- **类型安全 (Type Safety)**：编译器在**编译阶段**就能检查出类型错误。
    
- **消除强制转换 (No Casting)**：取数据时不需要 `(String)` 强转，代码更简洁。
    
    - _无泛型_：`List list = new ArrayList(); list.add("abc"); String s = (String)list.get(0);`
        
    - _有泛型_：`List<String> list = new ArrayList<>(); list.add("abc"); String s = list.get(0);`
        

#### 2. 三种使用形式

- **泛型类 (Generic Class)**：
    
    Java
    
    ```
    // T 是类型参数，实例化时指定，如 Box<String>
    class Box<T> {
        private T t;
        public void set(T t) { this.t = t; }
        public T get() { return t; }
    }
    ```
    
- **泛型接口 (Generic Interface)**：
    
    Java
    
    ```
    interface Generator<T> {
        public T next();
    }
    ```
    
- **泛型方法 (Generic Method)**：
    
    - **关键标识**：`<T>` 必须放在返回值类型（`void` 或具体类型）的**前面**。
        
    
    Java
    
    ```
    // 这是一个泛型方法，它可以存在于普通类中
    public <T> void show(T t) {
        System.out.println(t.toString());
    }
    ```

### 二、 必须死记的注意点 (Caveats)

这是考试中的“陷阱区”，请务必注意：

#### 1. 泛型不接受基本数据类型

泛型参数 `<T>` 必须是**类类型（对象）**。

- ❌ **错误**：`List<int> list = new ArrayList<>();`
    
- ✅ **正确**：`List<Integer> list = new ArrayList<>();` (使用包装类)
    

#### 2. 静态方法与泛型类的“代沟”

- **规则**：静态（`static`）方法或静态变量**不能**引用类定义的泛型参数 `<T>`。
    
- **原因**：泛型类是在 `new` 对象时才确定 `T` 是什么，而静态成员在类加载时就存在了，那时候还不知道 `T` 是谁。
    
    Java
    
    ```
    class Demo<T> {
        // ❌ 编译报错：静态变量不能用 T
        static T info; 
    
        // ❌ 编译报错：静态方法不能直接用 T
        public static void show(T t) { }
    
        // ✅ 正确：静态方法必须自己定义泛型参数 <E>
        public static <E> void print(E e) { }
    }
    ```
    

#### 3. 泛型没有“多态” (赋值不兼容)

- 虽然 `String` 是 `Object` 的子类，但 `List<String>` **不是** `List<Object>` 的子类。
    
- ❌ **错误**：`List<Object> list = new ArrayList<String>();`
    
- **原因**：如果允许这样，你就可以往 `list` 里存 `Integer`，但实际它是 `String` 列表，这会破坏类型安全。
    

#### 4. 类型擦除 (Type Erasure)

- Java 的泛型是**伪泛型**。在编译后的 `.class` 文件中，所有的 `<T>` 都会被擦除，替换为 `Object`（或者上限类型）。JVM 运行时是不知道泛型的存在的。
