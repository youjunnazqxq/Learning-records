基于你提供的复习重点图片，`ResultSet` 是 JDBC 中用来**“封装查询结果”**的接口。

如果说 `Statement` 是去数据库拉货的车，那么 **`ResultSet` 就是车拉回来的那一箱货**（也就是你查出来的表格数据）。

以下是关于它的 **3 个核心机制** 和 **1 个必须死记的坑**：

### 1. 它的本质：游标 (Cursor)

很多初学者以为 ResultSet 是一个把所有数据都读进内存的大数组，其实不是。

它更像是一个**“指针”**（或者叫游标）。

- **初始状态**：这个指针指向**第一行数据的前面**（Before First Row）。
    
- **操作方式**：你必须指挥它“往下走一步”，它才会指向某一行有效数据，然后你才能读取那一行。
    

### 2. 核心开关：`next()` 方法

这是遍历结果集必须用的方法。

- **`boolean next()`**
    
    - **作用**：将指针向下移动一行。
        
    - **返回值**：
        
        - **`true`**：说明移到了有效的一行（还有数据），可以读取。
            
        - **`false`**：说明后面没数据了（读完了），循环结束。
            

### 3. 取数据：`getXxx()` 方法

指针移到某一行后，你需要用 get 方法把列里的值取出来。

你需要根据数据库里的字段类型，选择对应的方法：

- **`getString("列名")`**：获取字符串类型（varchar, char）。
    
- **`getInt("列名")`**：获取整数类型（int）。
    
- **`getDouble("列名")`**：获取浮点数类型。
    
- **`getDate("列名")`**：获取日期类型。
    

### 4. 标准代码模版 (必背)

考试让你写 JDBC 代码时，这段逻辑是固定的：

Java

```
String sql = "SELECT id, name, age FROM student";
ResultSet rs = stmt.executeQuery(sql); // 1. 执行查询拿到结果集

// 2. 使用 while 循环遍历
while (rs.next()) { // 只要还能往下走，就一直循环
    // 3. 取出当前行的数据
    int id = rs.getInt("id");       // 写列名
    String name = rs.getString(2);  // 也可以写列的索引（第2列）
    int age = rs.getInt("age");
    
    System.out.println(id + " - " + name + " - " + age);
}

// 4. 用完一定要关闭（它是非常占资源的！）
rs.close();
```

---

### ⚠️ 必须要防的“坑”：索引从 1 开始！

在 Java 里的数组、List 都是从 0 开始计数的，但是！

JDBC 的列索引（Column Index）是从 1 开始的！

- `rs.getString(0)` $\rightarrow$ **❌ 报错**（SQLSQLException）。
    
- `rs.getString(1)` $\rightarrow$ **✅ 获取第 1 列数据**。
    

### 总结一张图 (JDBC 流程闭环)

1. **`Connection`**：建立连接。
    
2. **`Statement`**：发送 SQL。
    
3. **`ResultSet`**：`executeQuery()` 的返回值，用 `next()` 遍历，用 `getXxx()` 取值。
