**移位运算符**（Bitwise Shift Operators）是程序设计中（如 Java, C, C++）直接对整数在内存中的**二进制位**进行操作的运算符。

在计算机底层，数据都是以二进制（0和1）存储的。移位运算就是将这些二进制位整体向左或向右移动。

在 Java 等语言中，主要有以下三种移位运算符：

### 1. 左移运算符 (`<<`)

- **规则**：将数字的二进制位全部向左移动指定的位数。
    
    - 高位（左侧）溢出的位被丢弃。
        
    - 低位（右侧）空出的位置补 **0**。
        
- **数学意义**：在数字没有溢出的前提下，左移 $n$ 位相当于乘以 $2^n$。
    
- **示例**：
    
    Java
    
    ```
    int a = 5; // 二进制: 0000...0101
    int b = a << 2; 
    // 移动后: 0000...010100 (末尾补了两个0)
    // 结果 b = 20 (即 5 * 2^2)
    ```
    

### 2. 有符号右移运算符 (`>>`)

- **规则**：将数字的二进制位全部向右移动指定的位数。
    
    - 低位（右侧）移出的位被丢弃。
        
    - 高位（左侧）补什么？**看符号位**（正数补0，负数补1）。这也叫“算术右移”。
        
- **数学意义**：相当于除以 $2^n$（向下取整）。
    
- **示例**：
    
    Java
    
    ```
    int a = 20; // 二进制: ...00010100
    int b = a >> 2; 
    // 移动后: ...00000101 
    // 结果 b = 5 (即 20 / 4)
    
    int c = -20;
    int d = c >> 2;
    // 结果 d = -5 (负数保留符号)
    ```
    

### 3. 无符号右移运算符 (`>>>`)

- **注意**：这是 Java 特有的运算符（C/C++ 中通常取决于数据类型）。
    
- **规则**：将数字的二进制位全部向右移动，低位丢弃。
    
- **重点**：无论原数是正还是负，高位（左侧）**一律补 0**。
    
- **用途**：通常用于处理非数值的二进制逻辑（如位掩码、哈希算法），或者当你确定该数不需要保留负号时。

### 练一练

为了确认你掌握了移位运算，试着回答这几个问题：

1. **基础题**：表达式 `2 << 3` 的结果是多少？
    
2. **进阶题**（Java）：`byte b = 127;`，执行 `b << 1` 后如果不强制转换，结果类型是什么？（提示：Java 的 byte/short 计算时会自动提升类型）
    
3. **负数题**：`-2 >>> 1` 的结果是正数还是负数？
    

<details>

<summary>点击查看答案</summary>

1. **16**。解析：$2 \times 2^3 = 2 \times 8 = 16$。
    
2. **int**。解析：在 Java 中，`byte`、`short`、`char` 在进行运算（包括移位）时，会自动提升为 `int` 类型。
    
3. **正数**（且是一个非常大的正数）。解析：`-2` 的二进制是补码形式（111...1110），`>>>` 会在最左边补 0，导致符号位变为 0，因此结果变为正整数。
