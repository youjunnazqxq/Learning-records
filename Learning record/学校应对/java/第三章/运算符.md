### 第3章：核心知识点梳理

#### 1. 自增与自减运算符 (`++` 和 `--`)

这是编程初学者最容易混淆的难点。

- **基本概念**：`++` 表示变量值加 1，`--` 表示变量值减 1。
    
- **区别**：
    
    - **前缀 (`++a`)**：**“先变后用”**。先将变量 a 的值加 1，然后用加 1 后的新值参与表达式运算。
        
    - **后缀 (`a++`)**：**“先用后变”**。先用变量 a 原来的值参与表达式运算，运算结束后，a 的值再加 1。
        

> **代码示例：**
> 
> Java
> 
> ```
> int a = 5;
> int b = a++; // b的值为5（先用），之后 a变为6
> ```

> int x = 5;
> 
> int y = ++x; // x先变为6，然后y的值为6（先变）

#### 2. 运算符优先级 (Precedence)

在一个复杂的表达式中，不同的运算符执行顺序不同。

**常见优先级顺序（由高到低）：**

1. **括号** `()`：优先级最高，永远最先算。
    
2. **一元运算符**：`++`, `--`, `!` (逻辑非)。
    
3. **算术运算符**：`*`, `/`, `%` **高于** `+`, `-`。
    
4. **关系运算符**：`>`, `<`, `>=` **高于** `==`, `!=`。
    
5. **逻辑运算符**：`&&` (逻辑与) **高于** `||` (逻辑或)。
    
6. **赋值运算符**：`=`, `+=`, `-=` 等（优先级最低）。
    

#### 3. 其他重要运算符（课件中提及）

- **instanceof** 2：二元运算符，用于判断对象是否是特定类的实例（例如 `str instanceof String`）。
    
- **逻辑短路**：
    
    - `&&`：如果左边为 `false`，右边不再执行。
        
    - `||`：如果左边为 `true`，右边不再执行。

### 章节练习题

您可以利用下面的题目自测，答案附在最后。

#### 题目一：自增自减逻辑

**代码：**

Java

```
int m = 10;
int n = m++ + ++m;
System.out.println("m=" + m);
System.out.println("n=" + n);
```

**问题**：输出的 `m` 和 `n` 分别是多少？

#### 题目二：运算符优先级

**表达式：**

Java

```
int result = 10 + 10 / 2 * 5;
```

问题：result 的结果是多少？

A. 50

B. 35

C. 11

D. 2

#### 题目三：逻辑运算陷阱

**代码：**

Java

```
int a = 10;
boolean b = (a > 20) && (a++ > 10);
System.out.println("a=" + a);
```

问题：执行后，a 的值是多少？

A. 10

B. 11

C. 12

D. 报错

#### 题目四：instanceof 判断

问题：表达式 "Hello" instanceof String 的结果是？

A. true

B. false

C. null

D. 报错

### 练习题答案与解析

1. **题目一答案：m=12, n=22**
    
    - **解析**：
        
        1. `m++`：先取值 **10** 参与加法，`m` 随即自增变为 11。
            
        2. `+`：中间的加号。
            
        3. `++m`：`m` 此时已经是 11，先自增变为 **12**，取值 12 参与加法。
            
        4. 运算：`n = 10 + 12 = 22`。
            
        5. 最终 `m` 为 12。
            
2. **题目二答案：B (35)**
    
    - **解析**：乘除法优先级相同，从左到右计算，且都高于加法。
        
        1. 先算除法：`10 / 2 = 5`。
            
        2. 再算乘法：`5 * 5 = 25`。
            
        3. 最后算加法：`10 + 25 = 35`。
            
3. **题目三答案：A (10)**
    
    - **解析**：考查 **逻辑短路**。
        
        1. 左边 `(a > 20)` 即 `10 > 20` 为 `false`。
            
        2. 对于 `&&` 运算，只要左边为假，结果必为假，**右边的 `a++` 不会被执行**。
            
        3. 所以 `a` 保持原值 10。
            
4. **题目四答案：A (true)**
    
    - **解析**：`"Hello"` 是字符串字面量，属于 `String` 类的实例。
