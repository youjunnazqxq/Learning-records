根据你提供的课件内容 ，Java 中创建线程最常见的两种代码实现方式如下：

### 方式一：继承 `Thread` 类

这是最直接的方式。你需要创建一个类继承 `Thread`，重写 `run()` 方法，然后直接 `new` 出该对象并调用 `start()`。

```java
// 1. 定义一个类继承 Thread
class MyThread extends Thread {
    @Override
    public void run() {
        // 在这里写线程要执行的代码
        System.out.println("方式一：继承 Thread 类创建的线程正在运行...");
    }
}

public class Main {
    public static void main(String[] args) {
        // 2. 创建线程对象
        MyThread t1 = new MyThread();
        
        // 3. 启动线程 (千万不要直接调 run()，那样就不是多线程了)
        t1.start(); 
    }
}

```

---

### 方式二：实现 `Runnable` 接口 (推荐)

这是更灵活的方式，因为 Java 是单继承的，实现接口可以避免占用父类名额。你需要创建一个类实现 `Runnable`，然后把它作为参数传给 `Thread` 对象。

```java
// 1. 定义一个类实现 Runnable 接口
class MyRunnable implements Runnable {
    @Override
    public void run() {
        // 在这里写线程要执行的代码
        System.out.println("方式二：实现 Runnable 接口创建的线程正在运行...");
    }
}

public class Main {
    public static void main(String[] args) {
        // 2. 创建任务对象 (它还不是线程)
        MyRunnable task = new MyRunnable();
        
        // 3. 创建线程对象，并将任务作为参数传递给它
        Thread t2 = new Thread(task);
        
        // 4. 启动线程
        t2.start();
    }
}

```

### 核心区别总结：

* 
**写法不同**：一个用 `extends Thread`，一个用 `implements Runnable` 。


* **启动方式不同**：方式一直接 `new MyThread().start()`；方式二需要包装一层 `new Thread(task).start()`。
