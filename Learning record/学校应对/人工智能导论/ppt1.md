这份文档是Damien Brun教授的《8IAR101：人工智能导论》课程的引言部分 。以下是其中涵盖的核心知识点提取：

### 1. 什么是人工智能 (What is Artificial Intelligence?)

历史上对人工智能有四种不同的定义维度，主要取决于目标是“模拟人类”还是“追求理性”，以及侧重于“思维”还是“行为” 。

- **像人一样行动 (Acting humanly)**：基于图灵测试（1950年）。为了通过测试，机器需要自然语言处理、知识表示、自动推理和机器学习能力 。如果是“完全图灵测试”，还需要计算机视觉和机器人技术来感知并操作物理世界 。 * **像人一样思考 (Thinking humanly)**：认知建模方法。通过内省、心理学实验和脑成像技术来研究人类思维，试图让计算机以与人脑相同的方式进行思考 。
    
- **理性地思考 (Thinking rationally)**：“思维法则”方法。起源于亚里士多德的逻辑学，但在将现实世界中存在不确定性的知识转化为逻辑方程时面临困难 。
    
- **理性地行动 (Acting rationally)**：理性智能体（Rational Agent）方法。这是现代人工智能的标准模型，也是本课程的核心。它致力于设计在现有计算资源和信息下，能够做出最佳行动以最大化实现既定目标的程序 。
    

### 2. 人工智能的跨学科基础 (Foundations of AI)

人工智能的发展汲取了多个学科的思想和工具：

- **哲学**：探索关于知识、推理、智能本质和伦理的基本问题 。
    
- **数学**：为严格的推理和处理不确定性提供形式化工具（逻辑、代数、概率论、优化算法） 。
    
- **经济学**：贡献了决策理论和博弈论，帮助智能体在竞争环境中做出理性决策 。
    
- **神经科学与心理学**：启发了模仿人类认知、学习机制和人工神经网络的模型架构 。
    
- **计算机工程**：提供实现大规模数据运算所需的硬件与软件基础架构（如GPU） 。
    
- **控制理论**：用于设计能在动态环境中维持稳定、具有反馈回路的自主系统 。
    
- **语言学**：句法和语义学的研究奠定了自然语言处理 (NLP) 的基础 。
    

### 3. 人工智能发展史 (History of AI)

- **起源期 (1940s-1950s)**：1943年提出人工神经元，1950年提出图灵测试，1956年的达特茅斯会议正式确立了“人工智能”这一术语 。
    
- **符号AI与早期热情 (1950s-1970s)**：开发了基于逻辑的程序和通用问题求解器，证明机器可以进行推理 。
    
- **第一次AI寒冬 (1970s-1980s)**：由于预期过高、算力有限以及数据不足，导致资金减少 。
    
- **专家系统 (1980s)**：基于规则的知识系统（如医疗诊断软件 MYCIN）被广泛应用于特定商业领域 。
    
- **第二次AI寒冬 (1980s末-1990s)**：专家系统成本高昂且难以扩展，研究再次受挫 。
    
- **机器学习时代 (1990s-2000s)**：从手工制定规则转向数据驱动的统计方法，让算法通过数据进行学习 。
    
- **现代AI与深度学习 (2010s至今)**：在大规模数据集上训练深度神经网络，在图像识别、语音处理和复杂博弈（如 AlphaGo）中达到或超越人类水平 。
    

### 4. 现代人工智能的应用 (Applications)

- **自动驾驶**：具备从辅助驾驶到全自动驾驶（Level 0 到 Level 5）的不同自动化层级 。 * **机器人技术**：波士顿动力的四足机器人 Spot 及双足人形机器人 。
    
- **语言与语音**：手机端的实时机器翻译及语音分析 。
    
- **博弈玩耍**：AI 在国际象棋（Deep Blue）、围棋（AlphaZero）和星际争霸等游戏中展现出超越人类的策略能力 。
    
- **医疗健康**：医学影像自动分析（如计算骨龄）、辅助诊断以及通过达芬奇系统进行外科手术辅助 。
    

### 5. 哲学、伦理与安全 (Philosophy, Ethics, and Safety)

- **弱AI与强AI**：目前的大多数系统是“弱AI”（作为工具解决特定任务，模拟智能），而“强AI”则指真正拥有与人类相当的理解和推理能力的机器 。
    
- **哲学反驳**：
    
    - _非正式性论点_：认为人类行为过于复杂，无法被编码为规则。反驳观点指出，现代AI可以通过概率推理应对开放世界 。
        
    - _中文房间实验 (Searle, 1990)_：哲学家通过此实验论证机器仅仅是在遵循规则而没有产生真正的“理解”。反驳观点（系统论）认为，即使人不理解，整个房间系统作为一个整体是在理解的 。 * **伦理挑战**：
        
    - _偏见与公平性_：模型可能会延续数据中存在的社会偏见，需要建立基于个体、群体或结果平等的公平性标准 。
        
    - _就业与信任_：关注技术性失业及收入不平等问题；同时要求算法具备透明度（可解释的人工智能 XAI），让消费者理解黑箱系统的运作 。
        
- **安全与有益的机器 (Value Alignment)**：
    
    - 必须防范设定错误目标导致的意外副作用（“迈达斯国王”问题） 。
        
    - 未来的AI设计必须确保机器的目标与人类的真实偏好保持一致，机器在执行任务时应表现出谨慎并服从人类控制 。
