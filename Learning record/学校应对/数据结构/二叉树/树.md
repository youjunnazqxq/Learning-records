

# 数据结构复习笔记：第六章 树与二叉树

## 一、 核心性质与公式 (必背)

### 1. 二叉树通用性质

- **节点关系**：
    
    $$n_0 = n_2 + 1$$
    
    - **含义**：叶子节点数 = 度为2的节点数 + 1。
        
- **空指针数量**：在有 $n$ 个节点的二叉链表中，空链域（NULL指针）个数为
    
    $$n + 1$$
    
    。
    
- **形态数量**：$n=3$ 的二叉树有 **5种** 形态；$n=3$ 的普通树有 **2种** 形态。
    

### 2. 完全二叉树 (Complete Binary Tree)

- **深度与节点数**：深度为 $k$ 的完全二叉树：
    
    - 至少有 $2^{k-1}$ 个节点。
        
    - 至多有 $2^k - 1$ 个节点。
        
- **数组下标性质** (根从1开始)：
    
    - 节点 $i$ 的左孩子：$2i$
        
    - 节点 $i$ 的右孩子：$2i + 1$
        
    - 节点 $i$ 的父节点：$\lfloor i/2 \rfloor$。
        
- **判定技巧**：若某节点无左孩子，则它一定无右孩子（必为叶子）。
    

### 3. 满二叉树 (Full Binary Tree)

- **定义**：每一层都满，不存在度为1的节点 ($n_1 = 0$)。
    
- **公式推导**：
    
    - 分支节点数（度为2）：$n_2 = (n-1)/2$
        
    - 叶子节点数：$n_0 = (n+1)/2$。

## 二、 二叉树的遍历与还原 (重点大题)

### 1. 三种遍历 (递归逻辑)

- **前序 (Pre-order)**：**根** $\rightarrow$ 左 $\rightarrow$ 右
    
- **中序 (In-order)**：左 $\rightarrow$ **根** $\rightarrow$ 右
    
- **后序 (Post-order)**：左 $\rightarrow$ 右 $\rightarrow$ **根**
    
- **结论**：叶子节点在三种遍历中的相对次序**永远不变**。
    

### 2. 还原二叉树 ("破案法")

- **必要条件**：必须包含**中序**序列才能唯一确定一棵二叉树。
    
- **方法**：
    
    1. 用 **前序/后序** 确定 **根节点**。
        
    2. 用 **中序** 区分 **左右子树**。
        
    3. 递归重复上述步骤。

## 三、 哈夫曼树 (Huffman Tree)

### 1. 构造与计算

- **构造口诀**：选两小，合成新，扔回堆。
    
- **节点总数**：$n$ 个叶子的哈夫曼树，总节点数
    
    $$N = 2n - 1$$
    
    。
    
- **度数特点**：只有度为0和度为2的节点，**没有度为1的节点**。
    
- **WPL速算法**：所有**新生成的非叶子节点值**之和。
    

### 2. 哈夫曼编码

- **性质**：前缀编码（任一编码不是另一编码的前缀），是不等长编码。
    
- **规则**：通常左分支标 `0`，右分支标 `1`。
    

---

## 四、 线索二叉树与树的转换

### 1. 线索二叉树 (Threaded Binary Tree)

- **结构**：利用空指针域存放前驱/后继。
    
- **标志位**：
    
    - `ltag/rtag == 0`：指向孩子。
        
    - `ltag/rtag == 1`：指向线索（前驱/后继）。
        
- **判空条件**：无右孩子的条件是 `p->rtag == 1`。
    
- **找前驱**：中序线索树中，某节点（有左孩子）的前驱是其**左子树中最右边的节点**。
    

### 2. 树/森林转二叉树

- **口诀**：**左孩子右兄弟** (Left Child, Right Sibling)。
    
- **遍历对应关系**：
    
    - 树的**后序**遍历 = 对应二叉树的**中序**遍历。

## 五、 C语言代码模板 (笔试必背)

### 1. 二叉链表结构体

C

```
typedef struct BiTNode {
    int data;                // 数据域
    struct BiTNode *lchild;  // 左指针
    struct BiTNode *rchild;  // 右指针
} BiTNode, *BiTree;
```

### 2. 核心递归模板 (求深度/叶子数/遍历)

C

```
// 例：求二叉树深度
int Depth(BiTree T) {
    if (T == NULL) return 0;  // 递归出口
    
    int m = Depth(T->lchild); // 递归左
    int n = Depth(T->rchild); // 递归右
    
    return (m > n ? m : n) + 1; // 处理根
}

// 例：求叶子节点数
int CountLeaf(BiTree T) {
    if (!T) return 0;
    if (!T->lchild && !T->rchild) return 1; // 是叶子
    return CountLeaf(T->lchild) + CountLeaf(T->rchild);
}
```

### 3. 指针操作注意事项

- 访问成员必用 `->` (如 `p->data`)。
    
- 判断相等必用 `==`。
    
- 空指针写作 `NULL`。
    
- 创建节点：`malloc(sizeof(BiTNode))`。
