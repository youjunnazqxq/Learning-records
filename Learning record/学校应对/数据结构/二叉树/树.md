# 数据结构复习笔记：第六章 树与二叉树 (Trees and Binary Trees)

## 一、 核心性质与公式 (Core Properties & Formulas)

### 1. 二叉树通用性质 (General Properties of Binary Trees)

- 节点关系 (Node Relationship)：
    
    $$n_0 = n_2 + 1$$
    
    - **含义**：**叶子节点 (Leaf Node)** 数 = **度为2的节点 (Nodes of Degree 2)** 数 + 1。
        
- 空指针数量 (Number of Null Pointers)：在有 $n$ 个节点的 二叉链表 (Binary Linked List) 中，空链域（NULL指针）个数为
    
    $$n + 1$$
    
- **形态数量 (Number of Morphologies/Shapes)**：$n=3$ 的二叉树有 **5种** 形态；$n=3$ 的普通树 (General Tree) 有 **2种** 形态。
    

### 2. 完全二叉树 (Complete Binary Tree)

- **深度与节点数 (Depth & Node Count)**：深度为 $k$ 的完全二叉树：
    
    - 至少有 (at least) $2^{k-1}$ 个节点。
        
    - 至多有 (at most) $2^k - 1$ 个节点。
        
- **数组下标性质 (Array Index Properties)** (根从1开始 / Root starts at 1)：
    
    - 节点 $i$ 的 **左孩子 (Left Child)**：$2i$
        
    - 节点 $i$ 的 **右孩子 (Right Child)**：$2i + 1$
        
    - 节点 $i$ 的 **父节点 (Parent Node)**：$\lfloor i/2 \rfloor$。
        
- **判定技巧**：若某节点无左孩子，则它一定无右孩子（必为叶子）。
    

### 3. 满二叉树 (Full Binary Tree)

- **定义**：每一层都满，不存在度为1的节点 ($n_1 = 0$)。
    
- **公式推导**：
    
    - **分支节点数 (Branch/Internal Nodes)**：$n_2 = (n-1)/2$
        
    - **叶子节点数 (Leaf Nodes)**：$n_0 = (n+1)/2$。

## 二、 二叉树的遍历与还原 (Traversal & Reconstruction)

### 1. 三种遍历 (Three Traversals - Recursive Logic)

- **前序遍历 (Pre-order Traversal)**：**根 (Root)** $\rightarrow$ 左 (Left) $\rightarrow$ 右 (Right)
    
- **中序遍历 (In-order Traversal)**：左 (Left) $\rightarrow$ **根 (Root)** $\rightarrow$ 右 (Right)
    
- **后序遍历 (Post-order Traversal)**：左 (Left) $\rightarrow$ 右 (Right) $\rightarrow$ **根 (Root)**
    
- **结论**：叶子节点在三种遍历中的相对次序 **永远不变 (Invariant)**。
    

### 2. 还原二叉树 (Reconstruction / Constructing a Tree)

- **必要条件**：必须包含 **中序 (In-order)** 序列才能唯一确定一棵二叉树。
    
- **方法 ("破案法")**：
    
    1. 用 **前序/后序 (Pre-order/Post-order)** 确定 **根节点 (Root)**。
        
    2. 用 **中序 (In-order)** 区分 **左右子树 (Left/Right Subtrees)**。
        
    3. **递归 (Recursion)** 重复上述步骤。

## 三、 哈夫曼树 (Huffman Tree / Optimal Binary Tree)

### 1. 构造与计算 (Construction & Calculation)

- **构造口诀**：选两小，合成新，扔回堆 (Select two smallest, combine, put back)。
    
- 节点总数 (Total Nodes)：$n$ 个叶子的哈夫曼树，总节点数
    
    $$N = 2n - 1$$
    
- **度数特点**：只有度为0和度为2的节点，**没有度为1的节点**。
    
- **WPL速算法 (Weighted Path Length)**：所有 **新生成的非叶子节点值** 之和。
    

### 2. 哈夫曼编码 (Huffman Coding)

- **性质**：**前缀编码 (Prefix Code)**（任一编码不是另一编码的前缀），是 **不等长编码 (Variable-length Coding)**。
    
- **规则**：通常左分支标 `0`，右分支标 `1`。

## 四、 线索二叉树与树的转换 (Threaded Binary Tree & Conversion)

### 1. 线索二叉树 (Threaded Binary Tree)

- **结构**：利用空指针域存放 **前驱 (Predecessor)** / **后继 (Successor)**。
    
- **标志位 (Flags/Tags)**：
    
    - `ltag/rtag == 0`：指向孩子 (Child)。
        
    - `ltag/rtag == 1`：指向线索 (Thread)。
        
- **判空条件**：无右孩子的条件是 `p->rtag == 1`。
    
- **找前驱**：中序线索树中，某节点（有左孩子）的前驱是其 **左子树中最右边的节点 (Rightmost node of the left subtree)**。
    

### 2. 树/森林转二叉树 (Forest/Tree to Binary Tree Conversion)

- **口诀**：**左孩子右兄弟 (Left Child, Right Sibling Representation)**。
    
- **遍历对应关系**：
    
    - 树的 **后序 (Post-order)** 遍历 = 对应二叉树的 **中序 (In-order)** 遍历。

## 五、 C语言代码模板 (C Code Templates)

### 1. 二叉链表结构体 (Binary Linked List Struct)

C

```
typedef struct BiTNode {
    int data;                    // Data Field
    struct BiTNode *lchild;      // Left Pointer
    struct BiTNode *rchild;      // Right Pointer
} BiTNode, *BiTree;
```

### 2. 核心递归模板 (Recursion Templates)

C

```
// 例：求二叉树深度 (Calculate Depth/Height)
int Depth(BiTree T) {
    if (T == NULL) return 0;  // 递归出口 (Base Case)
    
    int m = Depth(T->lchild); // 递归左 (Recurse Left)
    int n = Depth(T->rchild); // 递归右 (Recurse Right)
    
    return (m > n ? m : n) + 1; // 处理根 (Handle Root)
}

// 例：求叶子节点数 (Count Leaf Nodes)
int CountLeaf(BiTree T) {
    if (!T) return 0;
    if (!T->lchild && !T->rchild) return 1; // 是叶子 (Is Leaf)
    return CountLeaf(T->lchild) + CountLeaf(T->rchild);
}
```

### 3. 指针操作注意事项 (Pointer Operations)

- 访问成员必用 `->` (Access member)，如 `p->data`。
    
- 判断相等必用 `==` (Equality check)。
    
- 空指针写作 `NULL`。
    
- 创建节点 (Allocate Memory)：`malloc(sizeof(BiTNode))`。
