### 1. 栈 (Stack)

- **定义与特性**：
    
    - 栈是**限定在表的一端**进行插入和删除操作的线性表 1。
        
    - **操作原则**：**后进先出 (LIFO, Last In First Out)**。即最后进入的元素最先被删除。
        
    - **术语**：允许操作的一端称为**栈顶 (Top)**，固定的一端称为**栈底 (Bottom)** 2。
        
- **出栈序列规律**：
    
    - 若入栈序列为 $1, 2, 3, \dots, n$，则出栈序列必须符合 LIFO 原则。例如入栈 1,2,3,4，不可能得到 4,3,1,2 的出栈序列（因为 1 被 2 压住，必须 2 先出 1 才能出）3。
        
    - $n$ 个元素依次进栈，出栈序列的种数由卡特兰数 (Catalan Number) 公式给出：$C_n = \frac{1}{n+1} C_{2n}^{n}$ 4。
        
- **存储结构**：
    
    - **顺序栈 (Sequential Stack)**：使用数组实现。`top` 指针指示栈顶位置。`top < 0` 为空栈，`top == MAXSIZE - 1` 为满栈。存在**上溢 (Overflow)** 和 **下溢 (Underflow)** 现象 5。
        
    - **链栈 (Link Stack/Chain Stack)**：使用链表实现。通常在链表头部进行插入和删除，不存在空间溢出问题（除非内存耗尽）6。
        
    - **双向栈/共享栈 (Shared Stack)**：两个栈共享同一个一维数组空间，栈底分别在数组两端。**栈满条件**是两个栈顶指针相邻，即 `|top[1] - top[0]| == 1` (或 `top[0] + 1 == top[1]`) 777。
        

### 2. 队列 (Queue)

- **定义与特性**：
    
    - 队列是限定只能在**表的一端插入**，在**另一端删除**的线性表 8。
        
    - **操作原则**：**先进先出 (FIFO, First In First Out)**。
        
    - **术语**：允许插入的一端叫**队尾 (Rear)**，允许删除的一端叫**队头 (Front)** 9。
        
- **存储结构与问题**：
    
    - **顺序队列**：随着入队出队，整个队列向后移动，可能出现**假溢出 (False Overflow)**，即尾部空间满了但头部还有空闲空间 1010。
        
    - **循环队列 (Circular Queue)**：
        
        - **目的**：解决顺序队列的“假溢出”问题 11111111。
            
        - **实现**：利用模运算 `%`，将存储空间看作环状。
            
        - **判空与判满**：由于队空和队满时都可能出现 `front == rear`，通常采用**牺牲一个存储单元**的方法来区分：
            
            - **队空条件**：`front == rear` 12。
                
            - **队满条件**：`(rear + 1) % MaxSize == front` 13131313。
                
            - **队列长度**：`(rear - front + m) % m` 14。
                
    - **链队列 (Link Queue)**：使用带头指针和尾指针的单链表。入队在表尾，出队在表头 15。
        ### 入队公式 (Enqueue)

入队操作是往队尾加元素，所以要移动 **`rear` (队尾指针)**。

- **操作逻辑**：先把元素放到 `rear` 指向的位置，然后 `rear` 向后移一位（如果到了数组末尾，就回到数组开头）。
    
- 指针移动公式：
    
    $$rear = (rear + 1) \% \text{MaxSize}$$
    

> 注意：在执行这个公式之前，通常需要先判断队列是否已满。
> 
> 根据你的图片，判满条件是：(rear + 1) % MaxSize == front。

### 2. 出队公式 (Dequeue)

出队操作是从队头取元素，所以要移动 **`front` (队头指针)**。

- **操作逻辑**：先把 `front` 指向的元素取出来，然后 `front` 向后移一位（同样利用取模回到开头）。
    
- 指针移动公式：
    
    $$front = (front + 1) \% \text{MaxSize}$$
    

> 注意：在执行这个公式之前，通常需要先判断队列是否为空。
> 
> 根据你的图片，判空条件是：front == rear。

### 3. 栈与队列的应用

- **函数调用与递归**：递归程序 (Recursion) 的执行依赖于**栈**来保存每一层的局部变量和返回地址 16161616。
    
- **表达式求值**：利用栈将中缀表达式转换为**后缀表达式 (Postfix Expression)** 并求值 17171717。
    
- **回文判断**：利用栈（逆序）和队列（顺序）比较字符序列是否相同来判断回文 18。
    
- **用栈模拟队列**：使用两个栈 ($S1, S2$) 可以模拟一个队列。$S1$ 负责入队，$S2$ 负责出队。当 $S2$ 为空需出队时，将 $S1$ 所有元素弹出并压入 $S2$ 19。
    
- **浏览器历史记录**：使用两个栈（前进栈、后退栈）来实现浏览器的“前进”和“后退”功能 20。
    

### 4. 重点代码逻辑

- **循环队列入队**：`rear = (rear + 1) % m` 21。
    
- **共享栈判满**：`abs(s->top[0] - s->top[1]) == 1` 22。
    
- **递归函数**：必须包含**终止条件**和**递归部分** 23。
