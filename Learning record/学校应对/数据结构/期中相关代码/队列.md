### **一、 队列的基本概念**

1. **定义**：
    
    - 队列 (Queue) 是限定只能在**表的一端进行插入**和在**另一端进行删除**操作的线性表 1。
        
    - **原则**：先进先出 (First In First Out, **FIFO**) 2。
        
2. **术语**：
    
    - **队尾 (rear)**：允许插入的一端 3。
        
    - **队头 (front)**：允许删除的一端 4。
        

---

### **二、 顺序循环队列 (Circular Queue) —— 重点考点**

为了解决顺序队列中出现的**“假溢出”**（即系统存储区未满但队列却发生了溢出）问题，采用循环队列 5。

#### **2. 核心逻辑与公式 (必背)**

文档明确指出，为了区分队空和队满，常用方法是**“少用一个元素空间”** 77。

- **队空条件**：`front == rear` 888。
    
- **队满条件**：`(rear + 1) % MaxSize == front` 9。
    
    - 注意：文档例3.3中提到 (rear + 1) % n = front 10。
        
- **入队指针变化**：`rear = (rear + 1) % m` (或 `% MaxSize`) 11。
    
- **出队指针变化**：`front = (front + 1) % n` 12。
    
- **队列长度计算**：`(rear - front + m) % m` 13。

### **三、 链队列 (Linked Queue)**

链队列是一个仅在**表头删除**和**表尾插入**的单链表 14。为了操作方便，将头尾指针封装在一起。

#### **1. 结构体定义 (代码)**

这是文档给出的标准写法，考试请按这个写：

C

```

    datatype data;              // 数据域
    struct Queuenode *next;     // 指针域
} Linknode;

// 2. 定义链队 (封装头尾指针)
typedef struct {
    Linknode *front, *rear;     // 队头、队尾指针
```

### 一、 顺序循环队列 (Circular Queue)

考点：解决“假溢出”问题，必须掌握取模运算 %。

**资料参考**：1

#### 1. 结构体与初始化

C

```
#define MAXLENGTH 10  // [cite: 203]
typedef char datatype; // [cite: 204]

typedef struct {
    datatype Queue_Temp[MAXLENGTH]; // [cite: 206]
    int Front, Rear; // 队头、队尾指针 [cite: 208]
} SeqQueue;

// 初始化
void InitQueue(SeqQueue *Q) {
    Q->Front = Q->Front = 0;
}
```

#### 2. 入队代码 (EnQueue)

**逻辑**：先判满，再入队，最后移动尾指针（循环移动）。

C

```
int EnQueue(SeqQueue *Q, datatype x) {
    // 1. 判满：(队尾+1) % 总长 == 队头 [cite: 295]
    if ((Q->Rear + 1) % MAXLENGTH == Q->Front) {
        return 0; // 队满，入队失败
    }
    
    // 2. 存入数据
    Q->Queue_Temp[Q->Rear] = x;
    
    // 3. 移动队尾指针 (核心公式)
    Q->Rear = (Q->Rear + 1) % MAXLENGTH;
    
    return 1; // 成功
}
```

#### 3. 出队代码 (DeQueue)

**逻辑**：先判空，再取值，最后移动头指针。

C

```
int DeQueue(SeqQueue *Q, datatype *x) {
    // 1. 判空：队头 == 队尾 [cite: 210]
    if (Q->Front == Q->Rear) {
        return 0; // 队空，出队失败
    }
    
    // 2. 取出数据
    *x = Q->Queue_Temp[Q->Front];
    
    // 3. 移动队头指针
    Q->Front = (Q->Front + 1) % MAXLENGTH;
    
    return 1; // 成功
}
```

### 二、 链队列 (Linked Queue)

考点：链表尾插法（入队）和头部删除（出队），注意处理头结点。

**资料参考**：2

#### 1. 结构体定义

C

```
// 结点定义 [cite: 213-216]
typedef struct Queuenode {
    datatype data;
    struct Queuenode *next;
} Linknode;

// 队列定义 [cite: 217-221]
typedef struct {
    Linknode *front; // 队头指针
    Linknode *rear;  // 队尾指针
} LINKQUEUE;

// 初始化 (构造一个空的头结点)
void InitQueue(LINKQUEUE *Q) {
    Q->front = Q->rear = (Linknode*)malloc(sizeof(Linknode));
    Q->front->next = NULL;
}
```

#### 2. 入队代码 (EnQueue)

**逻辑**：在链表**尾部**插入新结点。

C

```
void EnQueue(LINKQUEUE *Q, datatype x) {
    // 1. 申请新结点
    Linknode *s = (Linknode *)malloc(sizeof(Linknode));
    s->data = x;
    s->next = NULL;
    
    // 2. 挂在队尾 (当前rear的next指向s)
    Q->rear->next = s;
    
    // 3. 更新尾指针 (rear指向新的队尾s)
    Q->rear = s;
}
```

#### 3. 出队代码 (DeQueue)

**逻辑**：删除**头结点的下一个结点**。**注意**：如果队列只剩一个元素，删完后要修复 `rear` 指针。

C

```
int DeQueue(LINKQUEUE *Q, datatype *x) {
    // 1. 判空 (头尾指针重合表示空)
    if (Q->front == Q->rear) {
        return 0;
    }
    
    // 2. 找到要删除的结点 p (头结点的下一个)
    Linknode *p = Q->front->next;
    
    // 3. 保存数据
    *x = p->data;
    
    // 4. 修改指针 (头结点的next跳过p)
    Q->front->next = p->next;
    
    // ★关键点：如果删的是最后一个结点，rear会变成野指针
    // 必须让 rear 重新指向头结点 front
    if (Q->rear == p) {
        Q->rear = Q->front;
    }
    
    // 5. 释放内存
    free(p);
    return 1;
}
```
