### 1. 链表节点的定义 (Structure Definition)

考试第一步通常是写结构体。

> 笔记重点：包含数据域（Data）和指针域（Next）。
> 
> 资料参考：资料中多次出现类似定义，如 typedef struct 1和链队结点定义 2。

C

```
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// 定义节点结构体
typedef struct Node {
    int id;             // 数据域：学号
    char name[20];      // 数据域：姓名
    struct Node *next;  // 指针域：指向下一个节点
} Node, *LinkList;
```

---

### 2. 建立链表（尾插法）

虽然重点是搜索和输出，但通常需要先建立链表。**尾插法**（Tail Insert）建立的链表顺序与输入顺序一致，考试最推荐。

> **笔记重点**：需要一个 `r` (rear) 指针始终指向链表尾巴，每次由 `r->next = s; r = s;` 连接新节点。

C

```
// n 为要输入的节点数量
void CreateListTail(LinkList L, int n) {
    Node *p, *r;
    r = L; // r 始终指向当前链表的尾结点

    printf("请输入 %d 个学生的信息(学号 姓名):\n", n);
    for(int i = 0; i < n; i++) {
        p = (Node *)malloc(sizeof(Node)); // 1. 申请新节点
        scanf("%d %s", &p->id, p->name);  // 2. 存入数据
        
        r->next = p; // 3. 尾结点指向新节点
        r = p;       // 4. 更新尾结点指针，让它指向新的最后一位
    }
    r->next = NULL; // ★别忘了：最后一个节点的 next 要置空
}
```

### 3. 链表的搜索 (Search Node)

**考点核心**。题目通常要求“查找学号为X的学生”。

> 笔记重点：
> 
> 1. 指针 p 初始化指向首元结点 (L->next) 3。
> 
> 2. 循环条件是 p != NULL 且 p->data != target 4444。

C

```
// 在链表 L 中查找学号为 targetId 的节点
Node* SearchNode(LinkList L, int targetId) {
    Node *p = L->next; // 从第一个有效节点开始查
    
    // 遍历链表
    // 逻辑参考资料中的查找逻辑：只要 p 不为空，且当前 id 不等于目标 id，就继续找
    while (p != NULL && p->id != targetId) {
        p = p->next; // 指针后移
    }
    
    // 如果跳出循环时 p 不为空，说明找到了；如果 p 为 NULL，说明没找到
    return p; 
}
```

### 4. 链表的输出 (Output/Display)

**考点核心**。题目通常要求“打印链表所有元素”。

> **笔记重点**：标准的 `while(p)` 循环遍历。资料中多次体现了这种遍历逻辑 `while(p && p->next)` 5。

C

```
void PrintList(LinkList L) {
    Node *p = L->next; // 跳过头结点，指向第一个真实数据
    
    printf("链表内容如下:\n");
    while (p != NULL) {
        printf("学号: %d, 姓名: %s\n", p->id, p->name);
        p = p->next; // ★千万别忘了这句：指针后移
    }
    printf("\n");
}
```

### 5. 主函数调用示例 (main)

考试如果要求写完整程序，通常需要写 main 函数来测试。

C

```
int main() {
    // 1. 初始化头结点
    LinkList L = (Node *)malloc(sizeof(Node));
    L->next = NULL;

    // 2. 建立链表 (假设输入3个学生)
    CreateListTail(L, 3);

    // 3. 输出链表
    PrintList(L);

    // 4. 搜索测试
    int searchId;
    printf("请输入要查找的学号: ");
    scanf("%d", &searchId);
    
    Node *result = SearchNode(L, searchId);
    if (result != NULL) {
        printf("查找成功！姓名是: %s\n", result->name);
    } else {
        printf("查找失败，链表中无此人。\n");
    }

    return 0;
}
```

### 备考小贴士 (Exam Tips)

1. **指针判空**：在操作 `p->next` 或 `p->data` 之前，心里一定要确认 `p` 是不是 `NULL`。
    
2. **带头结点**：为了代码通用性，考试默认链表都是**带头结点**的（即 `L` 指向一个不存数据的头，`L->next` 才是第一个数据）。以上代码均按此编写。
    
3. **循环终止条件**：
    
    - **遍历完**：`while (p != NULL)`
        
    - **查找到**：`if (p->id == target) break;`
