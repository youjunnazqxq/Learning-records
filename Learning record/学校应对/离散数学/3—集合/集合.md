## 运算

1. 并运算： A∪B = {x|x∈A∨x∈B}
    
2. 交运算： A∩B = {x|x∈A∧x∈B}
    
3. 差运算： A－B = {x|x∈A∧x∉B}
    
4. 对称差： A⊕B = (A－B)∪(B－A) = (A∪B)－(A∩B)
    
5. A的绝对补集： ~A = E－A = {x|x∈E∧x∉A}
