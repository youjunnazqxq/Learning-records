# 为什么需要一个新的科研时间管理系统？

![[../Attachment/Pasted image 20260101011332.png|500]]
科研之所以难以坚持，往往不是因为不自律，而是因为**反馈机制本身失效**。

- **目标太远**：论文、毕业、博后，看不到尽头  
- **反馈太慢**：写三天代码 ≈ 什么都没发生  
- **情绪内耗**：摸鱼 → 自责 → 更不想开始  

在这样的系统里，努力很难被“看见”。

👉 这个系统想做的事只有一件：  
**把科研，从一个只给终局奖励的系统，改造成一个“每天都会掉经验值的长期养成游戏”。**

---

# 核心理念：把科研当成「长期养成类游戏」

| 传统科研系统          | 科研养成计划      |
| --------------- | ----------- |
| 只有最终成就（论文 / 毕业） | 每天都有任务与反馈   |
| 中途几乎没有正反馈       | 完成即获得“经验值”  |
| 很容易怀疑自己         | 进度、等级、记录都可见 |

> **时间管理不是为了压榨自己，  
> 而是为了制造持续的成就感。**

# 总体框架：从「年 → 日」的任务分解系统

![[../Attachment/Pasted image 20260101011412.png|500]]

## 年度计划｜世界观层 🌍

- [[年度反思模版]]

- 时间点：每年年初 / 跨年
- 不追求具体执行
- 只回答三个问题：
  - 今年科研的主线是什么？
  - 我希望自己变成什么样的研究者？
  - 有哪些「如果能完成就很酷」的事？

> 年度计划是世界观，不是待办清单。


---

## 季度计划｜关键推进层

- [[季度计划模版]]

- 时间点：每个季度开始
- 聚焦 **3–5 件最重要的事**
- 例如：
  - 改完一篇文章
  - 跑完一套关键模拟
  - 系统性补齐一个方向的知识

---

## 月度计划｜模块层

- [[月度反思模版]]

- 把季度目标拆成“模块级行动”
- 问一句：
  > 这个月，哪几步是**必须走的**？

---

## 周计划｜科研的黄金粒度 ⭐

- [[周记模版]]

- 把月目标拆成**本周可完成的最小单元**
- 原则：
  - 今天不做，明天还能接着做
  - 做完后你清楚地知道：**我完成了什么**

---

## 日计划｜打怪用的任务列表 🐾

- [[日记模版]]

- 极具体、极小
- 示例：
  - 改 Section 2 的第一段
  - 跑 3 组参数测试
  - 读 1 篇文章并写 3 条笔记

> 日计划不是用来“完美完成”的，  
> 是用来**触发行动**的。

# 反馈机制：给每一天打分（经验值系统）
![[../Attachment/Pasted image 20260101011439.png|500]]
## 为什么要给一天打分？
不是为了评判好坏，而是为了记录：

> **我今天有没有前进。**

## 打分示意：
| 经验值区间 | 含义 |
|-----------|------|
| **1–20** 😅 | 几乎没有推进科研任务；主要在休息、调整状态或被现实事务占满 |
| **20–30** | 有轻量行动（如打开代码、翻看资料），但尚未形成有效推进 |
| **30–40** | 做了一些实事，但推进较慢或被卡住 |
| **40–50** | 稳定推进了一部分计划任务 |
| **50–70** | 明显推进了当日的核心科研任务 |
| **70+** 🥳 | 高效的一天：核心任务有实质性进展，思路清晰、状态在线 |
![[Pasted image 20260101011500.png|475]]
👉 **低分不是失败，是数据。**

这些数据会帮助你：
- 看清自己的真实节奏
- 区分「累了」和「系统出了问题」

## 常用记录模块（科研外挂系统）

### 💡 灵感记录
- 随手记下：
  - 突然想到的 idea
  - 看文献时的疑问
  - 和别人讨论时的火花
- 不要求完整，只求捕捉

标签: #Note/life/Memos

---

### 🌤️ 心情记录
- 记录科研之外的状态
- 标签: 
	- 核心记忆: #Note/life/mood/Core 
	- 开心: #Note/life/mood/Joy 
	- 难过: #Note/life/mood/Sad 
	- 害怕: #Note/life/mood/Fear
	- 生气: #Note/life/mood/Angry
	- 厌恶: #Note/life/mood/Disgust 
	- 焦虑: #Note/life/mood/Anxiety 
	- 羡慕: #Note/life/mood/Envy 
	- 尴尬: #Note/life/mood/Embarrassed 
	- 丧:  #mood/life/mood/Ennui 
	- 怀旧: #Note/life/mood/Nostalgia 
	- 感谢: #Note/life/mood/Thanks 
---

### 🎁 收获记录
- 哪怕很小：
  - 想明白一个公式
  - Debug 成功
  - 写清了一段话
- 用来对抗「我今天什么都没干」的错觉

- 标签: #Note/life/yeah 

---

### 🔍 反思与改进
- 不追求深度复盘
- 只回答两个问题：
  - 今天最卡的是哪一步？
  - 下次我可以怎么让它更顺一点？

- 标签: #Note/life/hard

# 最终目标

这个系统不追求：
- 每天满分
- 永远自律
- 持续高强度

它只希望你做到一件事：

> **在科研这条长期曲线上，不掉线。**

慢慢养号，  
经验值会自己涨起来 🐱✨
