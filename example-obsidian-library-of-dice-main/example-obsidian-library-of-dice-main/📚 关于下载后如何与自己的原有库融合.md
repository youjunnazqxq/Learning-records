

从 Gitee 下载本库后，建议按以下顺序操作，以便沿用现成的配置与模板。

# 从零开始：直接 Git 克隆

## 直接下载.zip

![[../Attachment/Screenshot 2026-01-02 at 18.34.51.png]]

## 使用git 克隆

- 环境准备：确保已安装 Git，并选择本地存放路径。
- 克隆命令：在目标路径执行  
  ```bash
  git clone https://gitee.com/你的账号/你的仓库.git
  ```  
  （按需替换为你自己的仓库地址；如果只想使用本库，直接用本库地址即可。）
- 打开库：克隆完成后，用 Obsidian 打开克隆下来的文件夹作为新的库即可。
- 后续同步：通常只需要在库目录执行 `git pull` 获取我这边的更新即可，本地自用的修改不必推送到远端；若你维护自己的远端仓库，再用 `git add . && git commit -m "备注" && git push` 推送即可。

# 嵌入自己的 obsidian 库

## 1. 使用本库的 `.obsidian` 插件设置
>[!tip] (骰子修改了一些bug, 使用原版有部分问题)
>修改的插件: Dust Calendar; Tag summery

- 打开本库的 `.obsidian` 目录，复制其中的 `plugins`（路径：`.obsidian/plugins`）到你自己的库中，替换原有的插件目录。
- 替换前可先备份自己原有的 `.obsidian`，以便需要时恢复。

## 2. 引入隐藏嵌入标题的样式
- 将 `.obsidian/snippets/hide-embed-title.css` 复制到你自己的库的同名路径下。
- 该样式用于隐藏 `![[页面]]` 的嵌入标题，视觉更简洁；根据个人习惯在外观设置中开启或关闭。

## 3. 保持日记路径不变
- 建议保留本库的日记路径结构（`01. Daily`），避免在模板里大量修改引用路径。
- 如确需调整，请同步更新Dust calendar插件中的路径以及模板中的路径引用，以免失效。(有可多地方要替换, 可以使用一键替换01. Daily)

## 4. 复制模板
- 将本库的 `Template` 目录整体复制到你自己的库，保持现有的模板结构，便于直接使用。
